# 性能调优视角

> 一句话：MFU 不达标先算后网——通信占比 → busbw 基线 → 规模二分 → 单跳打流 → 协议/路由，五步定位；每个参数改动都用前后基线对账。

## 核心问题清单

1. MFU 掉点是算得慢还是网得慢？怎么在 30 分钟内切分责任？
2. 全网 busbw 与基线差多少才进网络排障流程？
3. NCCL 的 ALGO/PROTO/CHANNEL 参数按什么规则定？
4. RoCE 侧 ECN/PFC/缓冲/AR 的调优 checklist 是什么？
5. 「整体掉 ~10%」最常见的原因怎么排序？
6. 每项调优怎么验收，防止改动互相打架？

## 评估框架

### 排障路径图（文字版：MFU 不达标分层定位）

1. 先算后网：核对 MFU 口径（是否含 embedding/lm_head）、GPU 时钟与功耗墙、单卡算力基线。算侧掉点不进网络流程。
2. 通信占比测量：profiler 把步长拆成 计算 + 暴露通信 + 流水线空泡 + 其它；暴露通信占比 >15–20%（工程经验口径）才值得动网。
3. busbw 对基线：全规模 nccl-tests all_reduce 与历史基线比；差 >5% 进第 4 步，不差则回算侧查 overlap/调度。
4. 规模二分：8 卡 → 64 卡 → 512 卡 → 全量逐级跑，掉点首次出现的规模即故障层级（NVLink 域 / leaf 域 / spine 域 / core 域）。
5. 单跳打流：对疑似层级逐 rail/逐口 iperf3 或 RDMA 打流找慢口（细化动作见网络运维篇慢链路定位法）。
6. 协议/路由：ECN 标记率是否过高反压、PFC 是否头堵、自适应路由是否启用生效、ECMP 哈希是否极化（大流挤单链路）。

### NCCL 调优参数表

| 参数 | 作用 | 取值规则 | 依据 |
|---|---|---|---|
| NCCL_ALGO | Ring/Tree/Collnet | 大消息 Ring/Tree 混合；小消息 Tree；IB+SHARP 用 Collnet | 消息大小与拓扑 |
| NCCL_PROTO | Simple/LL/LL128 | 小消息 LL128、大消息 Simple | 时延与带宽取舍 |
| NCCL_MAX_NCHANNELS / MIN_NCHANNELS | 通道并发 | 上限对齐 rail 数（8 rail → 8/16） | 网卡与 rail 映射 |
| NCCL_IB_HCA | 网卡过滤 | 严格等于 rail 绑定表，禁止默认全选 | 轨道优化 |
| NCCL_IB_TIMEOUT / GID_INDEX | 超时与寻址 | 大规模适当放宽 timeout | 万卡稳定性 |
| NCCL_COLLNET_ENABLE | 在网计算 | IB SHARP 可用即开 | SHARP在网计算 |
| NCCL_DEBUG | 排障日志 | INFO/TRACE 仅排障时开 | 定位通道映射 |

参数定版后写入集群配置基线，不随任务手调。

### RoCE 调优 checklist

1. PFC：仅 RoCE 优先级使能，无失配风暴；三网分离时只在计算网生效。
2. ECN 阈值：按缓冲与 burst 标定 Kmin/Kmax/概率，目标标记率个位数百分比（工程经验口径），过高反噬吞吐。
3. 缓冲与 headroom：交换机 per-port headroom 与网卡 responder buffer 匹配，防 underrun 与超时重传。
4. 自适应路由：对称拓扑开启并验证包序重排正确性；非对称拓扑慎开。
5. CNP 处理：网卡 CNP 生成/解析开启，reaction rate 实测过。
6. ECMP：哈希字段避免极化；链路捆绑粒度与 rail 对齐。

### 典型性能问题案例表（整体掉 ~10% 的常见五因）

| 因 | 现象 | 一句话定位 |
|---|---|---|
| 个别慢链路 | busbw 掉 3–8%，无 down 告警 | FEC 重传/CRC 排序 top 口 |
| ECN 阈值过紧 | 吞吐被 CNP 反压，标记率偏高 | 逐跳 ECN 标记率 |
| 哈希极化/路由不对称 | 少数 spine 链路打满、其余空闲 | 链路利用率分布 |
| NCCL 通道数不齐 | busbw 按比例低于网卡线速 | NCCL_DEBUG 看通道映射 |
| 固件/驱动版本漂移 | 全网小幅劣化、无单点异常 | 版本审计 diff |

### 调优验收

1. 单变量原则：一次只改一项；同规模同消息前后各跑 ≥3 次取中位。
2. 验收口径：目标项（busbw/MFU）改善量化，非目标项（时延、CPU 占用、稳定性）不劣化。
3. 归档：改动、前后数据、结论入配置库；不达标即回滚。

## 关键指标与基线

| 指标 | 基线 | 口径 |
|---|---|---|
| 跨机 all_reduce busbw | ≥网卡线速 90%（400G → 45+ GB/s/卡） | nccl-tests 大消息 |
| 暴露通信占比 | <15% | DP 训练 profiler timeline（工程经验口径） |
| ECN 标记率 | 个位数百分比 | 交换机计数器 |
| 调优后 MFU 增量 | 逐项可归因、可复现 | 前后基线对账 |

## 常见误区

1. 先动网后查算：功耗墙降频、时钟不稳都伪装成网络问题。
2. 多参数同改：无法归因，回滚都不知道回哪个。
3. 拿别家集群参数抄作业：拓扑、固件、库版本不同，参数不可迁移。
4. 只看均值不看尾部：慢链路只伤 P99，均值掩盖问题。
