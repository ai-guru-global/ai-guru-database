## ISS-101: wikilink 断链积压

| 属性 | 值 |
|-----|-----|
| **状态** | 🟡 Investigating |
| **优先级** | P0 |
| **发现** | 2026-07-27 严口径评估（679 次） |
| **峰值** | 2026-09-04 实测 2,201 次 / 8.9% |
| **当前** | **1,598 次 / 6.4%**（门禁基线 2026-09-04） |

**根因**:
1. 2026 年 5-7 月批量目录重组与改名未同步入链（stale_path 类 1,873 次）；
2. 批量扩写时大量引用「规划中但从未创建」的页面（580 个缺失目标）。

**已处置（2026-09-04）**:
- `工具/fix_wikilinks_precise.py` 重映射修复 358 处（41 项人工核实映射）；
- 补建 4 个高频缺失枢纽页（解析 50 处引用）；
- P2-6 门禁落地：`工具/link_gate.py` + 基线 + pre-commit + GitHub Actions，断链只许降不许升；
- `工具/move_page.py` 改名安全工具上线，根治「改名型断链」。

**剩余处置**: 580 个缺失目标三分类清零（高引用补建 / 同类改指 / 长尾清理引用），计划见 [[治理/_meta/development-plan-2026-09|发展计划 2026-09]] §2.1。

## ISS-102: 度量口径分裂

| 属性 | 值 |

| **状态** | 🟡 Investigating |
| **优先级** | P0 |
| **发现** | 2026-09-04 评估 |

**已处置（2026-09-04）**:

**剩余处置**: 其余治理文档（[[治理/Quality_Metrics|质量度量]]、历史审计报告）中的旧口径数字随月度巡检逐步标注口径或刷新。
