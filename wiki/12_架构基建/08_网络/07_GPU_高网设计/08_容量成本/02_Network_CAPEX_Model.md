# 网络 CAPEX 模型

> 中文简称：网络 CAPEX 模型

> **一句话理解**: 网络要花多少钱、钱主要花在光模块上、以及怎么在三年口径下把它省下来。

---

## 一、成本构成拆解

网络 CAPEX 不是一张交换机采购清单，而是七类器件与服务的合计；占比为量级参考，随代际与采购折扣浮动：

| **成本项** | **占网络成本量级** | **说明** |
|---|---|---|
| **交换机** | 次大头 | leaf + spine + super-spine 台数由拓扑推演决定，三层方案台数与光模块一起跳涨 |
| **光模块** | 近半，数量最大头 | 数量 ≈ 2 × 链路数，随卡数线性增长，最易被低估 |
| **线缆 / DAC** | 个位数百分比 | 机柜内用 DAC 替代光模块，是结构内降本项 |
| **网卡** | 常随服务器采购 | 是否计入网络预算取决于采购口径，方案对比时要拉齐 |
| **布线施工与机柜** | 个位数百分比 | 预端接主干、理线、机柜、轨尾与上架工时 |
| **软件许可** | IB 需 per-switch license | SONiC 路线免 license，但成本转移为人力 |
| **备件** | 1-3% | 光模块按 1-2% 备件率、交换机按 N+1 备机 |

「近半」的直觉来源：一条 400G 链路两端各 1 个模块，模块数量是链路数的两倍，而单价比线缆高一个量级。

对比口径清单：是否含网卡、是否含施工、是否含备件与 license——三问没对齐之前，任何报价对比都无效。

## 二、量级参考与 1024 卡两方案对比

三条量级锚点：

- 网络约占 AI 集群整体 CAPEX 的 10-20%，万卡规模下是亿元级支出
- IB 相对 RoCE 以太方案存在溢价：专网溢价（专用芯片与生态）叠加 per-switch license
- 光模块常占网络成本近半，是第一降本杠杆

两方案对比骨架（1024 卡、8 卡/机、每卡 1 张 400G 网卡，均为单向线速口径）：

- 方案 A：IB NDR 400G 1:1，leaf 为 64×400G 盒子（32 下 + 32 上）
- 方案 B：以太 RoCE 400G 2:1，leaf 为 51.2T 盒子 128×400G（64 下 + 32 上）

| **器件 / 项目** | **方案 A：IB 400G 1:1** | **方案 B：以太 RoCE 400G 2:1** | **差异说明** |
|---|---|---|---|
| **网卡** | 1024 张 400G（IB 版） | 1024 张 400G（RoCE 版） | 数量相同，IB 版含专网溢价 |
| **leaf 交换机** | 1024 ÷ 32 = 32 台 | 1024 ÷ 64 = 16 台 | B 盒口数多一倍且 2:1，台数减半 |
| **spine 交换机** | (32 × 32) ÷ 64 = 16 台 | (16 × 32) ÷ 128 = 4 台 | B 上行口总量少一半 |
| **光模块** | 2 × (1024 + 1024) ≈ 4096 个 | 2 × (1024 + 512) ≈ 3072 个 | B 省 1/4 以上，机柜内换 DAC 再省 |
| **软件许可** | per-switch IB license | 无 license（SONiC 免费路径） | B 的许可成本转为调优人力 |
| **定性成本差** | 器件溢价 + 许可，总价更高 | 交换机与模块更省，需 PFC/ECN 调优投入 | 溢价幅度随代际与折扣浮动 |

两方案网卡数相同，差异全在交换机与光模块侧。方案 A 的 1:1 换来跨机 AllReduce 峰值带宽不打折；方案 B 的 2:1 适合可容忍通信降速的负载，两者不是纯价格对比。

再叠加功耗差异：方案 A 交换机台数多一倍，电费与机柜位也随之上涨（见下节）。

## 三、OPEX：电费、备件与人力

OPEX 三件套：电费、备件、人力，都是逐年复利的成本。

```text
网络年电费 ≈ 网络总功耗（kW）× 8760h × PUE × 电价（元/kWh）
算例（1024 卡、方案 A 口径）：交换机 48 台 × 1-3kW + 光模块约 4096 个 × 8-12W + 网卡 1024 × 约 20W
取网络总功耗 150kW、PUE 1.3、电价 0.7 元/kWh：150 × 8760 × 1.3 × 0.7 ≈ 120 万元/年
```

- 功耗大头是交换机本体与光模块：放宽收敛比与 DAC 化能直接压低这项
- 备件周转：光模块 RMA 周期长，现场备件池（1-2% 备件率）是 SLA 的一部分
- 专人力：IB 需要熟悉 ibstat 工具链与 SHARP 配置的网工；RoCE 需要能调 PFC / ECN / DCQCN 的工程师，两者都要 7×24 值守或购买原厂服务
- 人力成本量化：一名资深网工的全成本按年计通常为数十万元级，直接进 TCO 公式
- 机柜位成本：交换机台数多的方案还多占机柜位与上架工时，IDC 按柜收费时直接进成本
- 峰值电价与需量电费：按需量计费的机房里，网络功耗同样计入需量口径

## 四、TCO 视角：3 年折旧与租用 vs 自建

```text
3 年 TCO = 网络 CAPEX + 3 ×（电费 + 备件周转 + 专人力成本）− 期末残值
年折旧 = CAPEX ÷ 3（网络设备常用 3-5 年折旧，本页取 3 年口径）
```

| **维度** | **租用（云上 / 托管）** | **自建** |
|---|---|---|
| **支出形态** | CAPEX 转 OPEX，按时计费 | 一次性投入，网络占集群 10-20% |
| **代际锁定** | 跟随云厂商升级节奏 | 自主选型，可走白盒路线 |
| **电力与运维** | 含在账单内 | 自担电费、备件与专岗人力 |
| **折旧与残值** | 无 | 3 年折旧，代际迭代快、残值低 |

残值按二手行情估，网络设备残值通常低于服务器，代际越新折价越快。租用的隐性成本是长期单价与规格锁定，自建的隐性成本是折旧期内技术过时与运维队伍投入；峰值型业务偏租用，长稳型业务偏自建。

## 五、降本四杠杆与风险

| **杠杆** | **直接节省** | **风险与代价** |
|---|---|---|
| **放宽收敛比（1:1 → 2:1 / 3:1）** | spine 台数与上行光模块近乎减半 | 牺牲跨机集合通信峰值带宽 |
| **LPO / AEC** | 光模块功耗与单价下降 | 供应链新，互通性与排障风险 |
| **白盒交换机 + SONiC** | 硬件成本下降、免 license | 自研 / 集成人力门槛，故障责任自担 |
| **混部分时复用** | 训练 / 推理错峰共用链路与平面 | 调度复杂化，租户隔离与故障域扩大 |

四个杠杆可叠加，但每一项都把成本转成另一种形式（峰值带宽、供应链、人力、调度复杂度），降本决策要与风险预算一起过审。

优先级排序的常识：先动收敛比（零供应链风险），再 DAC 化（零互通风险），最后才碰白盒与混部。
