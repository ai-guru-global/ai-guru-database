# 先进封装

> CoWoS/SoIC/混合键合把 GPU 与 HBM 装到一起，是当前算力供给最硬的产能瓶颈。

## 拆解卡

- **价值来源**：单卡性能提升放缓后封装成为系统级性能的新前沿，AI 卡出货的直接卡点。
- **护城河**：与前道制程联动的工艺积累、大客户绑定产能。
- **瓶颈**：CoWoS 产能与混合键合良率；洁净室与人力扩张速度。
- **领先指标**：CoWoS 月产能；封装在加速卡 BOM 成本中的占比

## 六层速览

先进封装把多颗芯片装进一个「系统」：CoWoS 把 GPU 与 HBM 并排贴在中介层上，SoIC 直接上下堆叠——当前算力供给最硬的产能瓶颈就在这一步。

**打个比方**：像从「独栋别墅」改成「高层精装合体楼」：地皮（硅片面积）不变，住进去的功能翻几倍；但楼盖得越高，良率与散热越难。

**拆开看**：四段链条：中介层制备（硅中介层/重布线）→ 2.5D 并排贴装（CoWoS 类）→ 3D 直接堆叠（SoIC/混合键合）→ 测试与良片筛选；良率是乘法，任何一层偏低都会拖垮整体。

**怎么运转**：台积电按封装产能配给加速卡出货，英伟达、AMD、博通提前一年锁定；长电、通富、日月光承接溢出订单；封装在 AI 卡 BOM 成本中的占比逐年上升。

**格局与博弈**：台积电主导 CoWoS/SoIC，英特尔以 Foveros 转型追赶，日月光与安靠做委外封测，长电/通富/华天承接国产需求；混合键合是 3D 时代的分水岭技术。

**边界与走向**：CoWoS 产能连年翻倍仍供不应求，价值向面板级与扇出型封装转移；芯粒（UCIe 标准）会让封装从「制造环节」变成「设计选择」，定制 base die 与光电共封装是下一个战场。

## 关键判断

算力供给的真瓶颈：未来两年产能为王，芯粒与混合键合决定长期格局（置信度 高，展望 12–24 个月）——评估看「产能 × 良率 × 客户绑定」三件套；台海集中度是估值最大折扣项。

规模口径：全球先进封装约 $450–550 亿（2025e），AI 相关（2.5D/3D）约 $80–120 亿

## 二级细分

- **2.5D（CoWoS 类）** — GPU 与 HBM 并排封装到中介层，AI 加速卡当前主流形态。
- **3D 与混合键合** — SoIC/Foveros 直接堆叠，带宽与密度再上一档。
- **芯粒与标准接口** — UCIe 标准下的模块化设计，把大芯片拆成小芯粒分别流片。
