# Hello-Agents (Datawhale)：从零开始构建智能体

这是 Datawhale 社区开源教程 **《从零开始构建智能体》** 的外部源引用索引。项目聚焦 AI Native Agent（而非 Dify/Coze/n8n 等流程驱动型低代码 Agent），强调从第一性原理出发，亲手实现并构建多智能体应用。

- **GitHub 仓库**: [datawhalechina/hello-agents](https://github.com/datawhalechina/hello-agents)
- **本地克隆路径**: `_raw/github-sources/hello-agents`
- **在线阅读**: [国外访问](https://datawhalechina.github.io/hello-agents/) | [国内加速](https://hello-agents.datawhale.cc)
- **自研框架**: [HelloAgents (jjyaoao/helloagents)](https://github.com/jjyaoao/helloagents)
- **开源许可证**: [CC BY-NC-SA 4.0](http://creativecommons.org/licenses/by-nc-sa/4.0/)（署名-非商业性使用-相同方式共享 4.0 国际）
- **PDF 下载**: [GitHub Releases](https://github.com/datawhalechina/hello-agents/releases/latest/) | [国内镜像](https://www.datawhale.cn/learn/summary/239)

## 课程概览

| 属性 | 说明 |
|------|------|
| **正课章节** | 16 章（五大部分） |
| **额外章节** | 13 个 Extra-Chapter（面试题、Dify 实操、GUI/Web Agent、自进化等） |
| **主力框架** | 自研 HelloAgents 框架（基于 OpenAI 兼容 API） |
| **涉及框架/平台** | AutoGen、AgentScope、CAMEL、LangGraph、Coze、Dify、FastGPT、n8n |
| **编程语言** | Python 3.10+ |
| **核心主题** | Agent 定义与历史、LLM 基础、ReAct / Plan-and-Solve / Reflection、低代码平台、主流框架、自研框架、记忆/RAG、上下文工程、通信协议（MCP/A2A/ANP）、Agentic RL、性能评估、旅行助手、深度研究、赛博小镇 |

## 推荐前置条件

- 基础 Python 编程能力
- 了解如何通过 API 调用大语言模型
- 无需深厚算法/模型训练背景

## 你将收获

- 理解智能体概念、历史与经典范式
- 亲手实现 ReAct、Plan-and-Solve、Reflection
- 掌握 Coze、Dify、n8n 等低代码平台使用
- 使用 AutoGen、LangGraph 等主流框架
- 基于 HelloAgents 自研框架扩展记忆、RAG、协议、评估等能力
- 完成智能旅行助手、自动化深度研究、赛博小镇等综合项目
- 了解 Agent 岗位面试问题
