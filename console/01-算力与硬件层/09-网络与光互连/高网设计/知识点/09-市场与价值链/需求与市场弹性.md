# 需求与市场弹性

> 一句话定位：本域不对应单一环节，而是整条价值链的收入总闸门——光芯片约 15% / 光模块约 25% / 交换芯片约 25% / 交换系统与白盒约 10% / 网卡与 DPU 约 8% / 线缆连接器约 9% / CPO 光引擎约 3% / 网络软件约 5%（利润池口径），一切弹性测算从这里出发。

## 规模与驱动

需求的第一性不在「网络」，在并行策略：张量并行（TP）要求最高带宽/最低时延，放进机内 NVLink 域；数据并行（DP）的梯度 AllReduce 放机间；MoE 的专家 All-to-All 是机间最凶的流量，直接决定收敛比与光模块配比。因果链一以贯之：通信模式 → 拓扑 → 器件采购量。

TAM 必须分层计价（scale-up 与 scale-out 混算会同时高估与低估）：

| 分层 | 口径 | 规模锚点 | 增速 |
| --- | --- | --- | --- |
| 数据中心网络整体 | 前端+后端 | 约 $300–400 亿（2025e，估算口径） | — |
| 其中 AI 集群网络 | 交换+光模块+线缆+网卡 | 约 $150–250 亿（2025e，估算口径），AI 后端占大头 | 40%+ |
| 机柜内 scale-up 互连 | NVSwitch/铜背板等 | 若计入再扩大数十亿美元级（2026e 估算） | 高于后端 |

双驱动结构：

1. 代际切换：光模块 400G（2020）→800G（2023）→1.6T（2025H2 导入、2026 上量）；交换芯片 51.2T（2022）→102.4T（TH6，2025）；NVLink 900GB/s（H100）→1.8TB/s（NVL72）→3.6TB/s（Rubin，2026-01 CES）。每代切换都抬高单卡网络价值量。
2. 超节点扩张：NVL72（单柜 5000+ 铜缆）→NVL144（计划 2026H2）→NVL576（Kyber，已公布规划）；国内摩尔线程夸娥 kUAE 超节点（2025）、阿里 HPN 15k GPU（SIGCOMM 2024）、字节 MegaScale 12,288 GPU（NSDI 2024）。scale-up 域变大抬高机柜内铜/背板用量，同时把 scale-out 压力后移到更大域间。

## 竞争格局

需求侧是寡头买家市场，代际节奏由头部买家与 NVIDIA 参考设计共同定义；供给侧各环节集中度差异极大（交换芯片 CR1 70%+ vs 系统白盒毛利 10–20% 的分散竞争），弹性测算必须落到具体环节：

| 买家类型 | 决策特征 | 对网络的含义 |
| --- | --- | --- |
| 北美头部 CSP | 自研交换/网卡 + 白盒混用 | 配比可压（过收敛 1:2.5），压模块需求 |
| GPU 云/AI 实验室 | 跟随 NVIDIA 参考设计 | 配比贴近 1:4–4.5 上限 |
| 国内 CSP/主权算力 | 国产链闭环+出口管制约束 | 国产光模块/交换芯片份额上行（待核实） |

## 单位经济

弹性测算模板：网络 TAM = GPU 出货 × 每卡网络价值量；每卡价值量 = 模块配比 × 模块均价 + 交换/网卡/线缆按端口折算。「每万卡对应网络价值量」推演表（假设全部显式列出）：

| 假设项 | 取值（口径） |
| --- | --- |
| 集群规模 | 10,000 GPU，两层无阻塞 Clos |
| 模块配比 | GPU:800G = 1:4.5（无阻塞口径；过收敛降至 1:2.5） |
| 800G 均价 | $1,000（2025e，$800–1200 区间中值） |
| 交换折算 | 每 GPU 800G → 约 3 个 800G 端口（网卡侧+叶+脊），51.2T 系统约 $4 万/台（估算） |
| 网卡折算 | 每 GPU 1×800G，千美元级单价（估算口径） |

| 推演结果（每万卡） | 价值量（估算口径） |
| --- | --- |
| 800G 光模块 | 45,000 只 × $1,000 ≈ $4,500 万 |
| 交换系统（含芯片） | 约 470 台 51.2T ≈ $1,900 万 |
| 网卡 | 约 $2,000–3,000 万 |
| 线缆与连接器配套 | 模块价值量约 15% 量级（估算） |
| scale-out 器材合计 | 约 $1 亿量级 |
| 集群整网（capex 口径） | $4–8 亿（网络占 capex 10–20%，按万卡 GPU 投资 $30–40 亿推算） |

两口径差额来自 scale-up 域（NVSwitch/铜背板）、存储/带内/管理网、布线集成与冗余余量——引用任何数字前必须先声明口径。

## 关键变量与风险

- 周期分层：光模块价格年降 10–20%、订单与代际强绑定，周期性显著强于交换芯片（CR1 70%+、代际内价格刚性）；GPU 出货波动时模块最先感知、最后恢复。
- 配比假设被证伪：过收敛普及（1:2.5）或 CPO 上量（2026 起，NVIDIA Quantum-X/Spectrum-X Photonics 量产口径）都会下修可插拔模块配比。
- 超节点双刃：NVL144/NVL576 抬升机柜内价值量，但若更多训练流量锁进机内，scale-out 配比面临下修。
- 地缘分叉：出口管制使国内外形成两套需求曲线与定价逻辑，国产链份额与毛利率不能拿全球模型线性外推（待核实）。
