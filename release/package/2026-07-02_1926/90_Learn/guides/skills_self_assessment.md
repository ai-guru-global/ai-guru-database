# AI 技能自评清单 (AI Skills Self-Assessment)

> 系统化的 AI 技能自评工具——帮助你准确定位当前水平，找到学习缺口，制定针对性提升计划。

---

## 使用方法

对每项技能打分：
- ⬜ **0 - 未接触**：完全不了解
- 🟨 **1 - 入门**：知道概念，做过教程
- 🟩 **2 - 熟练**：能独立完成相关任务
- 🟦 **3 - 精通**：能教别人，能解决疑难问题
