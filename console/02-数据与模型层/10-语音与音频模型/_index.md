# 语音与音频模型

> TTS、实时语音与音乐生成的模型层，voice 是下一个交互入口。

## 拆解卡

- **价值来源**：延迟最敏感、粘性最强的交互入口。
- **护城河**：延迟与情感表现力的端到端栈。
- **瓶颈**：全双工延迟与规模化成本。
- **领先指标**：实时语音延迟纪录；语音场景调用时长

## 六层速览

语音与音频模型让机器能听、能说、能唱：语音识别、实时语音对话和音乐生成是三条主线；语音是 agent 最自然的交互层。

**打个比方**：像给 AI 装上「耳朵和嘴巴」——不仅要听懂，还要说得像人、接得上话；延迟超过一秒，对话感就消失了。

**拆开看**：五段链路：ASR（识别）→ LLM（理解）→ TTS（合成）→ 全双工对话（打断、抢话）→ 音乐与音效生成；延迟、情感表现力与打断处理是关键指标，抢话与接话是最难的全双工工程点。

**怎么运转**：API 按字符或分钟计费，语音助手订阅，音乐生成按订阅与版权分成；企业客服与呼叫中心是最成熟的变现场景，按坐席替代量算 ROI，音乐生成的版权谈判决定毛利上限。

**格局与博弈**：ElevenLabs 在 TTS 领先，OpenAI 实时语音绑定 ChatGPT，科大讯飞在中国政企市场占优，Suno、Udio 重塑音乐创作；语音 agent 平台（Retell、Vapi）快速崛起。

**边界与走向**：全双工与低延迟是下一战，声音克隆的伦理与版权监管会收紧；语音会成为智能体的默认交互层，硬件（耳机 / 眼镜 / 玩具）是新的分发入口。

## 关键判断

语音是 Agent 时代的关键接口：ASR 商品化、TTS 有品牌溢价、实时 agent 平台是当前最有定价权的一层（置信度 中，展望 12–24 个月）——核心变量是实时 agent 的付费渗透与端到端模型对中间层的挤压速度；克隆合规是最大尾部风险。

规模口径：语音 AI 约 $150–250 亿（2025e，含客服坐席替代与音频内容）

## 二级细分

- **语音识别** — 听写准确率之战基本收官
- **语音合成** — 克隆与情感，商业化最快
- **实时对话** — 全双工与低延迟，语音 agent 的入口
