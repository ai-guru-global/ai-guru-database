# 先进制程与代工

> 芯片制造的物理上限：先进制程产能与先进封装是算力供给的硬约束。

## 拆解卡

- **价值来源**：算力供给的物理上限：制程与封装产能决定全行业出货天花板。
- **护城河**：十年量级的工艺积累与千亿级资本门槛。
- **瓶颈**：3nm/2nm 产能与 CoWoS 先进封装扩产节奏。
- **领先指标**：台积电 AI 相关营收占比；先进封装扩产与交期

## 六层速览

先进制程与代工把芯片设计变成硅片：制程越先进、封装越强，同样面积的芯片能塞进更多晶体管与算力，良率则决定它贵不贵。

**打个比方**：像印刷厂——设计公司给菲林，代工厂决定你能印多细、良率多高、多久交货；印得越细设备越贵，能接单的厂也越少。

**拆开看**：五段链路：光刻（EUV / DUV）+ 刻蚀与沉积 + 离子注入 + 先进封装（CoWoS / SoIC）+ 良率与产能管理；每一环都是百亿到千亿级资本开支。

**怎么运转**：按晶圆计价，先进制程溢价高；苹果、英伟达、AMD 等大客户提前锁定产能；设备与材料商在上游分走利润，代工厂赚的是利用率与良率的钱，扩产速度则受设备交付周期约束。

**格局与博弈**：台积电一家独大（3nm / 2nm + CoWoS 封装），三星追赶但良率承压，英特尔代工转型；中芯国际受设备管制约束，聚焦成熟制程与国产替代；设备端 ASML 垄断 EUV。

**边界与走向**：制程微缩逼近物理与经济极限，价值向先进封装、芯粒（Chiplet）与设备材料转移；地缘管制把全球产能切成多个阵营，「在哪制造」会像「用什么制程」一样重要。

## 关键判断

强定价权，地缘是最大变量（置信度 高，展望 12–24 个月）——封装产能与 2nm 良率是短期关键；地缘风险难以用估值完全对冲。

规模口径：全球先进制程代工约 $700–900 亿（2025e）；先进封装另计约 $150–250 亿

## 二级细分

- **领先制程（3nm/2nm）** — 性能与能效的前沿，AI 芯片主力
- **成熟制程扩产** — 28nm+ 与车规工业芯片，国产替代主场
- **制程与封装协同** — 先进制程 × CoWoS 一体化交付能力
