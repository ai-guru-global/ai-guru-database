### 核心概念
- **具身智能三大支柱**: 感知层 → 认知层 → 行动层
- **VLA 模型**: 视觉-语言-动作端到端模型
- **Sim-to-Real**: 仿真到现实迁移技术
- **遥操作**: 人类示范数据采集

### 2026 年关键进展
- **人形机器人**: Figure 02、Tesla Optimus、Unitree G1/H1 进入实际部署
- **机器人基础模型**: RT-2、π0、GR00T、Gemini Robotics
- **市场规模**: 46.7 亿→676.3 亿美元 (2033 年预测)
