# 摩尔线程

> 国产全功能 GPU 玩家：以「国产 GPU 全链路训练大模型」为标尺，从显卡替代走向 AI 训练基础设施。

## 概述

摩尔线程 2020 年由前 NVIDIA 全球副总裁、中国区总经理张建中创立，主攻全功能 GPU（MUSA 架构，覆盖图形渲染 + AI 计算），是国产 GPU 三杰（摩尔线程/壁仞/沐曦）中商业化路径最「NVIDIA 形」的一家：自建 MUSA 软件栈对标 CUDA 生态。

2026 年的标志性进展是以国产 GPU 完成代码大模型的全链路训练（MusaCoder），把「国产 GPU 能不能训模型」的验证从推理推进到训练侧。台内独立证据尚薄，本卡作为观察位先行建立。

  报道提及中国侧「昇腾 + 寒武纪 + 摩尔线程」国产算力替代组合——摩尔线程位列国产替代三强。

  IT之家报道：MusaCoder 9B/27B 两档，训练全流程跑在摩尔线程国产 GPU 集群上——国产 GPU 首次以「训练侧全链路」公开实证。

### 2020-10

- **2020-10** · 公司成立
  张建中（前 NVIDIA 全球 VP/中国区总经理）创立，定位全功能 GPU；2021 年起发布多代 MUSA 架构显卡与计算卡。

## 分析

1. **CUDA 生态是主战场**：MUSA 软件栈 + 开源模型（MusaCoder）的组合拳，本质是在复刻「硬件 + 生态」的 NVIDIA 路径，训练侧实证是给开发者信心拼图的关键一块。
2. **与昇腾的分工**：昇腾走 NPU 超节点专攻 AI 负载，摩尔线程坚持通用 GPU（兼顾图形），两条国产路线在智算中心招标中正面竞争。
