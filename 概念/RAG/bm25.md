# BM25

> **一句话理解**: BM25 是按「关键词在文档里出现多少次、在多少文档里出现过」来给文档打分的经典检索算法。

## 核心要点

- **基于 TF-IDF 改进**: 考虑词频饱和和文档长度归一化。
- **两个参数**: k1（控制词频饱和度）、b（控制文档长度影响）。
- **优点**: 对精确匹配和专有名词效果好，解释性强。
- **缺点**: 不理解语义，需要分词。
- **常用引擎**: Elasticsearch、OpenSearch、Lucene。

## 公式简化

```text
score(D, Q) = Σ IDF(q_i) * (f(q_i, D) * (k1 + 1)) / (f(q_i, D) + k1 * (1 - b + b * |D| / avgDl))
```

## 阿里云专有云关联

在阿里云专有云 RAG 系统中，BM25 常与向量检索组成混合检索。OpenSearch 私有化版或 Elasticsearch 均可提供 BM25 关键词召回能力。
