# 07 模型训练 — 小白版 🏋️

> **一句话秒懂**: 模型训练就是 AI 的"学习过程"——把海量数据喂给算法，让算法不断调整自己，直到学会做某件事，就像学生刷题一样，做错了就反思，做对了就继续！

## 为什么要学模型训练？

想象一下：
- 📚 AI 是怎么"学习"的？
- ⚙️ 训练一个模型需要什么？
- 🔧 怎么让模型训练得更快更好？

**模型训练 = AI 的"学习秘笈"**

## 核心概念

### 1. 损失函数

```
【问题】AI 怎么知道自己做错了？

【解决】损失函数

就像考试得分:
- 模型预测 = 你的答案
- 真实答案 = 标准答案
- 损失 = 差距多大（做错了多少）

损失函数:
- 小 → 预测接近正确答案
- 大 → 预测偏离正确答案
```

### 2. 梯度下降

```
【问题】模型做错了，怎么知道该往哪个方向改？

【解决】梯度下降

想象你在下山:
- 当前位置 = 模型现在的参数
- 山顶 = 损失最高的地方
- 山脚 = 损失最低的地方（最优解）
- 梯度 = 下山的方向

梯度下降 = 一步步往山下走，直到最低点
```

### 3. 过拟合 vs 欠拟合

```
【过拟合】= 死记硬背

训练数据: 全做对了
测试数据: 考砸了

原因: 背住了答案，没学会规律
解决: 增加数据、正则化、Dropout

【欠拟合】= 没学会

训练数据: 答对率很低
测试数据: 答对率也很低

原因: 模型太简单/训练不够
解决: 增大模型/训练更久
```

## 训练技术

### 1. 分布式训练

```
【问题】数据太大，一台机器训练不完

【解决】分布式训练

数据并行:
- 把数据分成 N 份
- 每份在不同机器上训练
- 汇总梯度，更新模型

模型并行:
- 把模型分成 N 份
- 每份在不同机器上
- 适合超大模型
```

### 2. 混合精度训练

```
【问题】显存不够，训练慢

【解决】混合精度

- 平时用 FP32（32位浮点）
- 关键计算用 FP16（16位浮点）

优势:
✓ 显存省一半
✓ 训练速度提升 2-3 倍
✓ 精度基本不变
```

### 3. 超参数调优

```
【超参数】需要人工设定的参数

常见超参数:
- 学习率: 每次调整步伐多大
- batch_size: 每次喂多少数据
- epoch: 训练多少轮

调优方法:
- 网格搜索
- 随机搜索
- 贝叶斯优化
```

## 常见问题

### Q: 训练需要多长时间？

**A**: 看情况！
```
小模型: 几分钟到几小时
大模型 (如 LLaMA-7B): 几天到几周
超大模型 (如 GPT-4): 几个月
```

### Q: 训练需要多少显卡？

**A**: 看规模！
```
个人学习: 1 张消费级 GPU (RTX 3090)
研究实验: 1-8 张 A100
工业生产: 几十到几百张 A100/H100
```

### Q: 怎么判断训练好了？

**A**: 看指标！
```
- 训练 loss 下降
- 验证集指标提升
- 评估指标达到预期
```
