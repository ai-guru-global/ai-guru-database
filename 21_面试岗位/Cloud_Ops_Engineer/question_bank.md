| 知识域 | 核心要点 | 考察频率 | 准备优先级 |
|--------|----------|----------|------------|
| 云基础 | 多云/混合云、网络、存储 | 高频 | P0 |
| GPU 基础设施 | 虚拟化、调度、互联 | 每轮必考 | P0 |
| Kubernetes | 架构、调度、Operator、GPU 插件 | 高频 | P0 |
| AI 推理运维 | 推理框架、版本管理、灰度 | 高频 | P0 |
| 可观测性 | 指标、日志、链路、SLO | 中高频 | P1 |
| 成本优化 | Spot、分时复用、归因 | 中频 | P1 |
| 系统设计 | 推理平台、调度、灰度、自愈 | 中高频 | P1 |

## 高频问题与应答策略

| 问题类型 | 典型问题 | 应答策略 |
|----------|----------|----------|
| 概念题 | MIG / RDMA / Operator 原理 | 定义 + 原理 + 适用场景 + 对比 |
| 排查题 | GPU OOM / 推理雪崩 | 现象 + 分层定位（模型/框架/调度）+ 工具 + 根因 |
| 设计题 | 设计 1000 QPS 推理平台 | 需求拆解 + 架构 + 弹性 + 容灾 + 成本权衡 |
| 优化题 | GPU 利用率 / 成本优化 | 现状量化 + 手段栈（量化/batching/路由）+ 收益测算 |
| 经验题 | 大规模故障复盘 | 时间线 + 根因（5 Whys）+ 改进 + 量化成果 |

## 面试评分维度

| 维度 | 优秀表现 | 一般表现 | 不佳表现 |
|------|----------|----------|----------|
| 技术深度 | 深入底层原理 | 知道用法不知原理 | 概念模糊 |
| 故障排查 | 系统化分层定位 | 能定位但缺方法论 | 毫无头绪 |
| 架构能力 | 全面权衡设计 | 基本方案可行 | 忽略关键约束 |
| 自动化意识 | 主动推动 SRE | 能写脚本 | 依赖手工运维 |
| 成本意识 | 量化 ROI 优化 | 知道成本构成 | 忽视成本 |
| 协作沟通 | 跨团队对齐清晰 | 能沟通 | 推诿甩锅 |

## 检查清单

- [ ] 云基础（网络/存储/多 AZ）知识点已系统复习
- [ ] GPU 基础设施（MIG/RDMA/NVLink/调度）已深入理解
- [ ] Kubernetes（架构/Operator/GPU 插件/HPA）已熟练
- [ ] 至少熟悉 1 个推理框架（vLLM / TGI / Triton）的部署与调优
- [ ] 可观测性三大件（Metrics / Logs / Traces）方案已掌握
- [ ] 成本优化手段栈（Spot/分时复用/量化/路由）已梳理
- [ ] 至少 2 个故障复盘案例（含根因与改进）已准备
- [ ] 系统设计题（推理平台 / 调度系统）已演练
