### 定位

│   └── 终端集成工具

## 3. 快速开始

### 3.1 获取 API Key

1. 访问 https://platform.deepseek.com
2. 注册/登录
3. 创建 API Key
4. 充值余额

### 3.2 deepseek-tio 配置

```bash
# deepseek-tio 配置
# 设置 API Key 和模型

export DEEPSEEK_API_KEY=your-api-key
deepseek-tio config set model deepseek-coder
```

## 5. 最佳实践

- 按量付费模式，注意控制单次调用消耗
- DeepSeek-Coder 模型在代码生成方面性价比极高
- 月消费 ¥36 左右，属于低成本工具
- 余额 ¥68 可支撑约 2 个月的正常使用

## 6. 注意事项

- 余额制计费，余额耗尽后服务暂停
- 建议设置余额预警，及时充值
- DeepSeek 的价格优势明显，适合高频日常使用
