# OCR 与文字识别 - 小白版 🔤

> **一句话秒懂**: OCR 就是让 AI "识字"——把图片里的文字变成可编辑的文本，就像给机器装上了"阅读"能力！

## 为什么要学 OCR？

想象一下：
- 📸 你拍了一张名片，AI 自动提取姓名、电话、邮箱
- 📄 你扫描了纸质合同，AI 把内容变成可搜索的 Word
- 🏧 ATM 机自动识别银行卡号码
- 🚗 车牌识别自动记账

这些都用到了 OCR！

## OCR 的工作流程

```
第1步: 图像预处理
        ↓
        原始图片 → 去噪、倾斜校正、二值化
        ↓
第2步: 文本检测
        ↓
        找出文字在哪里（Bounding Box）
        ↓
第3步: 文本识别
        ↓
        把图像文字变成文本字符
        ↓
第4步: 后处理
        ↓
        纠错、格式化、输出
```

## 核心任务

### 1. 文本检测 (Text Detection)

**任务**: 找出图像中文字的位置

```
就像用荧光笔在纸上标出文字位置

输出:
- 文字区域的边界框
- 或者文字的轮廓多边形
- 区分横排和竖排文字
```

### 2. 文本识别 (Text Recognition)

**任务**: 把图像中的文字转成文本

```
两种方法:
1. 整词识别: "hello" → 直接识别整个词
2. 字符识别: "h" "e" "l" "l" "o" → 逐字识别后拼接

深度学习方法:
CNN + RNN + CTC
- CNN: 提取图像特征
- RNN: 序列建模
- CTC: 处理不对齐的输入输出
```

### 3. 端到端 OCR

**任务**: 检测+识别一步完成

```
现代 OCR (如 EasyOCR, PaddleOCR):
输入: 图片
输出: "识别出的文字 + 位置"

优势:
✓ 端到端优化，效果更好
✓ 速度和精度平衡
✓ 支持多语言
```

## 应用场景

### 办公自动化

```
文档扫描:
纸质文件 → 手机拍照 → AI 识别 → 可编辑文本

名片识别:
纸质名片 → 拍照 → AI 提取 →
姓名: 张三
电话: 138-xxxx-xxxx
邮箱: zhangsan@example.com

发票识别:
发票照片 → AI 识别 →
发票号、日期、金额、税额 → 自动入账系统
```

### 身份验证

```
身份证识别:
- 姓名、性别、民族、出生日期、住址、身份证号
- 用于银行开户、快递寄件、酒店入住

银行卡识别:
- 卡号、有效期、银行名称
- 用于支付 App 绑卡

驾驶证/行驶证识别:
- 用于交通执法、二手车交易
```

### 车牌识别

```
停车场:
入口 → 拍照识别车牌 → 记录入场时间
出口 → 拍照识别车牌 → 计算费用 → 抬杆

高速收费:
ETC 识别 或 车牌识别 → 计费

交通执法:
违章拍照 → 自动识别车牌 → 寄罚单
```

### 工业应用

```
生产日期识别:
- 瓶装饮料、药品、食品包装上的生产日期
- 过期自动报警

零件编号识别:
- 生产线上的零件追溯

文档数字化:
- 图书馆书籍数字化
- 历史档案保护
```

## 常见 OCR 挑战

| 挑战 | 例子 | 解决方案 |
|------|------|---------|
| 模糊 | 拍照手抖、运动模糊 | 超分辨率、去噪 |
| 倾斜 | 纸张放歪了 | 倾斜校正 |
| 遮挡 | 文字被遮挡 | 上下文推断 |
| 复杂背景 | 花纹背景上的文字 | 分割网络 |
| 多语言 | 中英日韩混合 | 多语言模型 |
| 手写体 | 手写信、手写表单 | 手写识别专用模型 |
