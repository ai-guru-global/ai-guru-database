# Qoder / QoderWork / QoderWake 使用指南

> **一句话**: Qoder 是面向全栈开发的 AI 编程平台，集成 QoderWork（协作工作台）与 QoderWake（唤醒式 Agent），支持从 miniapp 到 agent project 的快速交付。

---

## 1. 概述

### 定位

| 维度 | 说明 |
|------|------|
| **类型** | AI 全栈编程平台 (Web IDE + Agent) |
| **产品线** | Qoder（核心IDE）、QoderWork（协作工作台）、QoderWake（唤醒式 Agent） |
| **适用** | 快速原型、miniapp 开发、agent project、infograph 生成 |
| **官网** | https://qoder.com |

### 核心能力

```
Qoder 生态:
├── Qoder — 核心编程 IDE
│   ├── AI 驱动的代码生成
│   ├── 多语言支持
│   └── 一键部署
├── QoderWork — 协作工作台
│   ├── 团队协作
│   ├── 项目管理
│   └── 版本控制
└── QoderWake — 唤醒式 Agent
    ├── 自动化任务编排
    ├── 项目级代码生成
    └── 多轮对话式开发
```

## 2. 账户与额度

| 项目 | 详情 |
|------|------|
| **管理页面** | https://qoder.com/account/usage |
| **月度额度** | $200/月 |
| **刷新日期** | 每月 8 号 |
| **状态** | 活跃 |

---

## 3. 快速开始

### 3.1 登录

1. 访问 https://qoder.com
2. 使用账户登录
3. 进入 Dashboard

### 3.2 创建项目

1. 选择 **New Project**
2. 选择项目模板（miniapp / agent project / infograph）
3. 配置项目参数
4. 开始 AI 辅助开发

### 3.3 QoderWake Agent 使用

1. 在项目中启用 QoderWake
2. 描述任务目标
3. Agent 自动编排执行流程
4. 审核并确认输出

---

## 4. 使用场景与输出

| 输出项目 | 说明 | 推荐模式 |
|----------|------|----------|
| **mocici miniapp** | 移动端小程序开发 | Qoder 核心 IDE |
| **agent project** | Agent 项目开发 | QoderWake |
| **infograph** | 信息图生成 | QoderWork |

---

## 5. 最佳实践

- 每月 8 号额度刷新后优先处理重点项目
- 利用 QoderWake 进行项目级自动生成，再在 Qoder 中微调
- 复杂项目拆分为多个子任务，逐步交付
- 定期检查 usage 页面监控额度消耗

---

## 6. 注意事项

- 月度 $200 额度较为充裕，但仍需关注使用进度
- QoderWake 的 Agent 模式消耗额度较快，大项目建议分阶段执行
- 输出质量与 prompt 精确度直接相关，建议使用结构化描述
