# 真武PPU

> 平头哥自研 AI 训推一体芯片（Parallel Processing Unit）：国产首个走通「自用降本 → 对外售卖 → 模型生态绑定」全链路的云厂商自研芯片。本卡是台内入口与证据时间线，系统拆解在深潜子库。

## 概述

真武 PPU 是平头哥（阿里全资半导体子公司）的训推一体 AI 芯片产品线，官方定位原话：「一款为AI应用加速的芯片，具有高易用性，适用于各类大模型和传统模型的训练及推理场景」（[aliyun.com/ppu](https://www.aliyun.com/ppu)，2026-11 检索）。产品线三档：**810E**（96GB HBM2e / 片间互联 700GB/s / 7×ICN 端口 / ≤400W，北京/杭州/上海/乌兰察布商用）、**M890**（2026-05-20 阿里云峰会发布：96/144GB / 800GB/s / 配自研 ICN Switch 1.0 互联芯片 / 64 卡全带宽 + 128 卡超节点 / FP32-FP4 全精度 / 官方口径性能为 810E 的 3 倍，乌兰察布商用、中卫邀测，超节点实例 Day0 适配 Kimi K3.1 Pro）、**V900**（216GB / 1200GB/s，官方路线图 2027 Q3；下一代 J900 列入 2028 Q3，「一年一代」）。自研软件栈 **T-Head SAIL®**（阿里云页称 PPU SDK 2.2.0），**2026-07-23 开源**：五层全开放，「全面适配 PyTorch、TensorFlow、vLLM、SGLang 等 260 余个框架」（官方口径），已基于龙蜥 ANCK 内核原生适配并完成相互兼容认证；许可证与公开仓库未明（❓ 挂账）。官方页未披露峰值算力（TFLOPS）数字。

**命名口径**：官方页为「真武 PPU」；2026-01 官宣初期媒体（TrendForce 等）称「镇宇 810E」。本台以官方页「真武」为准，「镇宇」作别名保留（挂账见 `docs/2026待核实清单.md` 第十节）。

**出货口径族谱**（2026-11-11 整合，同一曲线三个时点，均为转述层级）：阿里财报电话会 **47 万片**（截至 2026-02）→ 阿里云峰会 **56 万片**（截至 2026-05）→ IDC **60 万片**（截至 2026Q1，腾讯新闻转述）。**外部商业化占比**：阿里财报口径 **60% 以上算力已服务外部商业化客户**。外部客户官方页口径 650+（2026-05 峰会口径 400+ 家、20+ 行业）。第三方旗舰模型适配点两例：小米 MiMo-V2.5-Pro（810E，1T/1M，2026-04）、Kimi K3.1 Pro（M890 超节点 Day0）。标杆部署：中国联通三江源绿电智算中心（平头哥算力卡 16384 张）。

本卡作为台内真武 PPU 线索入口与证据时间线；实体拆解、规格对标、软件栈路线、商业模式与竞争格局的系统分析，在深潜子库 [01-算力与硬件层/02-自研 ASIC 与 TPU/真武PPU拆解](../../01-算力与硬件层/02-自研%20ASIC%20与%20TPU/真武PPU拆解/README.md)（15 篇，2026-11-06 建库）中展开，两处互为索引。

## 分析

（观点层）PPU 的结构同构对象是 AWS Trainium 而非华为昇腾：云厂商自研 + 对外售卖 + 框架层适配 + 服务自家旗舰模型四合一，且独有 Qwen 开源生态绑定。卡位是「H20 替代位」而非「H100 对抗位」——单卡峰值算力官方不披露，真实下注在 scale-up 超节点与显存池（互联 700→1200GB/s 三代递进，V900 千卡全带宽）。软件路线钩住 vLLM/Megatron 框架层，迁移摩擦最小但护城河最薄，壁垒必须长在 acext 算子库 / ACCL-P / HolmesLLM 深度上。成熟度判**爬坡期**（商用一年+、出货数十万级、三代 roadmap 清晰；生态差距与第三方基准缺位未证伪）。完整论证见深潜子库 [行业拆解](../../01-算力与硬件层/02-自研%20ASIC%20与%20TPU/真武PPU拆解/行业拆解.md)。
