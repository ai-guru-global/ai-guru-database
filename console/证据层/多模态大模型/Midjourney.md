# Midjourney

> 美学路线的图像生成常青树：不融巨资、不做 API（长期），以 Discord 社区起家靠审美与个性化守住高端创作者市场。

## 概述

Midjourney 2022 年 7 月在 Discord 开放测试，凭独特美学风格成为图像生成第一波浪潮的定义者之一。在 DALL-E、Flux、Nano Banana 等对手相继开放 API/免费化的竞争中，其差异化是审美质量、个性化理解与社区形态（后逐步转向 Web）。自研研究的节奏也独树一帜：V5（2023）→ V6（2023-12）→ V7（2025-04）→ V8 系（2026）。

2026 年 V8 世代的产品动作密集：V8.1 成为默认模型并引入草稿模式，V8.2 主打美学提升与个性化理解、开放图像编辑，同时发布 Scanner（实物/图像解析返程能力），叙事从「生成」扩展到「理解 + 编辑」。

## 分析

1. **不融资、小团队的长期主义样本**：在对手以 API 免费化与多模态全家桶进攻时，Midjourney 以订阅制 + 审美口碑维持高端创作者粘性，节奏慢但从未掉队。
2. **「个性化」是审美护城河的算法化**：V7 起的 Personalization 与 V8.2 的个性化理解，本质是把用户偏好学进模型——风格粘性成为切换成本。
3. **理解侧补课**：Scanner 与图像编辑说明纯生成已不够，双向（理解↔生成）能力闭环是对抗 Nano Banana 系「编辑强敌」的必答卷。→ [[多模态大模型/图像生成与编辑]]
