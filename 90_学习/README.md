# Learn — AI Guru 概念入门路径

> 中文简称：Learn — AI Guru 概念入门路径

> **从"AI 是什么"到"如何构建 AI 系统"，按概念递进，因人施教。**

本目录是 AI Guru 知识库的**学习导航中心**。不同于按技术领域组织的章节结构（00-13），这里按**认知层次**和**角色需求**组织学习内容，帮你找到最适合自己的切入点。

## 快速选择你的路径

不知道该从哪里开始？回答以下 3 个问题：

### Q1: 你现在对 AI 的了解程度？

| 选项 | 描述 |
|------|------|
| A | 完全不了解，想知道 AI 是什么、能做什么 |
| B | 听过 ChatGPT / 大模型，想系统了解原理 |
| C | 有编程基础（Python），想动手做 AI 项目 |
| D | 已经在用 AI 做产品/研究，想深入前沿 |

### Q2: 你的主要目标？

| 选项 | 描述 |
|------|------|
| 1 | 通识了解，能跟上时代对话 |
| 2 | 成为 AI 工程师，构建 AI 应用 |
| 3 | 做 AI 研究，理解前沿论文 |
| 4 | 用 AI 做产品，落地业务场景 |

### Q3: 你愿意投入多少时间？

| 选项 | 描述 |
|------|------|
| a | 每天 30 分钟，轻松入门 |
| b | 每周 5-10 小时，系统学习 |
| c | 全职投入，尽快上手工作 |

## 概念层次总览

所有路径都建立在同一套**概念分层体系**上。理解这个层次结构，你就知道自己在整个知识图谱中的位置：

```
Stage 4: 前沿探索 ────────────────────────────── 多模态 · 世界模型 · VLA具身智能 · AGI · AI安全
    ↑ 学完 Stage 3 并对某一方向有浓厚兴趣
Stage 3: 工程实践 ────────────────────────────── 部署推理 · RAG · 向量数据库 · Agent/Tool Use · MLOps · 评估
    ↑ 学完 Stage 2，想将模型变成可用产品
Stage 2: 核心技术 ────────────────────────────── 神经网络 · 反向传播 · CNN/RNN · Transformer · Attention · LLM · 微调
    ↑ 学完 Stage 1，想理解现代 AI 的核心引擎
Stage 1: 基础概念 ────────────────────────────── 数据与特征 · 模型 · 训练/推理 · 过拟合 · 评估指标 · 损失函数
    ↑ 学完 Stage 0，准备进入技术细节
Stage 0: AI 觉醒 ─────────────────────────────── AI 定义 · 三大类型 · 能力边界 · 经典案例 · 发展历史
    ↑ 起点：零基础从这里开始
```

每个 Stage 的详细概念卡片见 [概念/](./概念/) 目录。

## 学习建议

1. **不要跳级**：每个 Stage 的概念是下一层的前置依赖。如果觉得某个阶段太简单，快速浏览即可，但不要完全跳过。
2. **概念 > 文档**：学习的目标是"理解一个概念"，不是"读完一篇文章"。一个概念可能分散在多篇文档中。
3. **循环渐进**：第一遍不求甚解，建立框架；第二遍填充细节；第三遍动手实践。
4. **按需深入**：不需要掌握所有 Stage。根据你的目标，在合适的深度停下来即可。
