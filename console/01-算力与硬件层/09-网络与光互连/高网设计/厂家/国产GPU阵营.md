# 国产 GPU 阵营 × GPU 高网

> 国产 AI 芯片厂商自建组网生态综述：单厂信息密度不足，合为一篇讲清共性结构与个体差异。

## 在 GPU 高网中的角色

国产 GPU/加速器厂商在 GPU 高网中的角色是「被迫的全栈自建者」：拿不到 NVIDIA 体系，就各自解决 scale-up 互联、scale-out 组网与集合通信库三件事。共性结构高度收敛：

1. **Scale-up**：基于 OAM/UBB 标准形态（对标 NVLink 的开放答案）或自研互联协议。
2. **Scale-out**：几乎清一色 RoCE 以太网（IB 无国产供给）。
3. **集合通信库**：自研 NCCL 兼容语义的通信库（HCCL/MCCL 类），接口向 NCCL 靠拢以降低框架迁移成本。

出口管制趋严提高了这套自建生态的必要性（地缘细节不展开）。

## 技术路线与取舍

- **OAM/UBB 是 scale-up 最大公约数**：普遍从 OAM 模组形态起步，规避 NVLink 类私有协议困境；代价是与 NVLink 的带宽代差（定量对比待核实）。
- **Scale-out 无路线分歧**：RoCE 以太网是唯一现实选项，组网直接复用国内成熟的智算交换机与白盒生态。
- **通信库兼容 NCCL 语义是标配**：框架层迁移成本集中在通信库与算子层，各家均以 NCCL API 兼容为目标（实现质量待核实）。
- **超节点是 2025 年的集体动作**：摩尔线程「夸娥」kUAE 超节点 2025 公开（已核实）；各家超节点卡数与互联带宽普遍待核实。
- **与 NVLink 生态的差距**：定性上是互联带宽代际、在网计算（SHARP 类）缺失、软件工具链成熟度三重差距；定量数字（带宽比、聚合效率对比）待核实。

## 竞争与对标

| 对手 | 交锋面 | 态势 |
|---|---|---|
| NVIDIA | 全体系代差 | 国内市场凭供给安全获得生存空间；性能追赶周期长（定量待核实） |
| 华为昇腾 | 国产生态主导权 | 昇腾闭环最完整；其余厂商更依赖开放标准与第三方交换机 |
| 阵营内部 | 国产替代份额 | 通信库与超节点协议碎片化是内耗点；灵衢等开放互联的整合效果待核实 |

## 近况（2025–26）

- 摩尔线程「夸娥」kUAE 超节点 2025 公开（已核实）。
- 对标锚点：NVIDIA 2026-01 CES 发布 Rubin VR200 NVL72（NVLink 6，3.6 TB/s/卡）——国产 scale-up 互联的代际标尺。
- 其余无已核实增量。
