## 面试内容

### 1. 算法与编程

```
【必考】
- 数据结构：数组、链表、树、图
- 算法：排序、搜索、动态规划
- 刷题平台：LeetCode（重点：Hot 100）

【高频题】
- 反转链表
- 二叉树遍历
- 合并区间
- LRU 缓存
```

### 2. 机器学习基础

```
【核心知识点】
- 监督学习：无监督学习
- 过拟合/欠拟合
- 梯度下降
- 损失函数
- 评估指标（F1、AUC）

【高频问题】
- 逻辑回归的损失函数？
- 如何解决过拟合？
- XGBoost 和随机森林的区别？
```

### 3. 深度学习

```
【核心知识点】
- 反向传播
- CNN/RNN/Transformer
- 优化器（Adam/SGD）
- 正则化（Dropout/BatchNorm）

【高频问题】
- Transformer 的 attention 是什么？
- 为什么 ResNet 效果这么好？
- BERT 和 GPT 的区别？
```

### 4. 系统设计

```
【常见题目】
- 设计一个推荐系统
- 设计一个搜索系统
- 设计一个 AI 推理服务
- 设计一个数据管道

【考察重点】
- 可扩展性
- 容错性
- 成本优化
```

## 准备计划

```
【3个月速成计划】

第1个月：算法 + 基础
├─ 刷完 LeetCode Hot 100（每天 3 题）
├─ 复习 ML 基础（吴恩达课）
└─ 复习 DL 基础（fast.ai）

第2个月：深度 + 项目
├─ 深入 ML/DL 细节
├─ 准备项目经历
└─ 刷系统设计题

第3个月：模拟 + 冲刺
├─ 模拟面试
├─ 准备 behavior questions
└─ 谈 offer 技巧
```
