# 锐捷 × GPU 高网

> 国内智算园区网/数据中心网络主要玩家，互联网大厂智算交换机供货案例最多的国产厂商之一。

## 在 GPU 高网中的角色

锐捷网络（Ruijie，星网锐捷体系，上市公司）在 GPU 高网中的角色：

1. **互联网大厂的智算交换机供应商**：公开报道口径下，其 400G 交换机进入头部互联网厂商（含阿里）智算集群供应链（合作细节与份额待核实）——国内大厂自建智算网络（HPN 类）的直接受益者之一。
2. **智算园区网与数据中心全网供应商**：从园区到数据中心 Leaf/Spine 的全产品线，教育、金融、政企市场为传统基本盘。
3. **白盒化能力的国产代表**：对大客户提供白盒/定制化交换机（客户与出货口径待核实），与台系 ODM 在白盒市场正面竞争。

## 技术路线与取舍

- **以太网 + RoCE 单路线**：全产品线押注以太网，无 IB 负担；大厂客户导向使产品定义贴近 HPN 类双平面/轨道优化组网的实际需求。
- **白盒化与性价比**：以快速定制、成本控制打大厂直采市场，毛利率低于品牌市场（常识性口径，财务数据不展开）。
- **交换芯片外采**：核心交换芯片依赖上游（Broadcom/盛科类，具体采用待核实），自研程度低于华为。
- **渠道结构**：星网锐捷体系的渠道复用带来政企与教育市场的高覆盖密度（口径待核实）。
- **市场结构风险**：互联网大厂资本开支波动直接传导；政企市场利润厚但智算含量低于大厂场景。
