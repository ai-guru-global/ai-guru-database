# 高网运维故障案例

> 中文简称：高网故障案例

> **一句话理解**: 高网故障的惯用破案法是「分层基线对比」——先证明是哪一层（链路/算子/端到端），再动手；本页六个案例覆盖 80% 的日常事故形态。

---

## 案例 1：TP 性能腰斩——设备顺序错位

| 项 | 内容 |
|---|---|
| 现象 | PPU 上 TP=4 训练，通信时间比官方基线高一倍；单卡算力正常 |
| 定位 | L1 链路压测正常；L2 all_reduce_perf 显著低于基线；对比 ACCL-P 官方文档的设备顺序表 |
| 根因 | `CUDA_VISIBLE_DEVICES` 沿用了旧镜像顺序——**逻辑设备号 ≠ 最优物理通信顺序**，TP 组横跨了次优 ICN 路径 |
| 修复 | 按当前实例/镜像版本的官方 TP 2/4/8 设备顺序重排（见 [[01_数学基础/10_AI硬件/09_PPU_High_Performance_Network|PPU 高性能网络与 ICN 互联]] §4.1） |
| 预防 | 升级驱动/镜像后必查官方顺序表；把设备顺序纳入任务模板变量 |

## 案例 2：通信库静默回退 Socket

| 项 | 内容 |
|---|---|
| 现象 | 跨机训练吞吐低且 CPU 占用异常高；两端 perftest 带宽正常 |
| 定位 | `NCCL_DEBUG=INFO` 看 transport：**没有出现 NCCL INFO NET/_RDMA 行，走了 Socket** |
| 根因 | 网卡名/权限/GID 配置不满足 RDMA 建连条件，通信库不报错直接回退 |
| 修复 | 修正 `NCCL_SOCKET_IFNAME`/网卡挂载/权限，确认日志出现 RDMA transport |
| 预防 | 集群准入测试包含「transport 断言」检查项（方法见 [[12_架构基建/08_网络/PPU与高网/05_高网性能测量方法_2026|05 测量方法]]） |

## 案例 3：慢节点拖垮 AllReduce

| 项 | 内容 |
|---|---|
| 现象 | 集群 AllReduce busbw 只有基线 60%；无报错 |
| 定位 | 逐节点 perftest 扫描 → 1 台节点分布在长尾（其余节点正常）；`ibstat`/ethtool 查该节点端口 |
| 根因 | 该节点网卡经历过 link flap 后**降速运行**（400G→100G），未恢复原速率 |
| 修复 | 复位端口/更换线缆模块，确认速率恢复 |
| 预防 | 慢节点巡检纳入日常：链路速率、CRC 计数、温度；相关手册 [[07_模型训练/04_分布式训练/04_分布式训练_Hang_操作手册|分布式训练 Hang 操作手册]] |

## 案例 4：RoCE PFC 风暴

| 项 | 内容 |
|---|---|
| 现象 | 自建 RoCE 集群周期性整网抖动，训练 loss 尖刺 |
| 定位 | 交换机 PFC 队列计数暴涨；ECN 标记率异常；伴随吞吐骤降 |
| 根因 | PFC 死锁/风暴——拥塞在大流量 AllReduce 下沿优先级队列级联 |
| 修复 | 调整 PFC 水位与 ECN 阈值组合；检查是否有主机侧网卡 old firmware 的已知问题 |
| 预防 | RoCE 上线前完成拥塞参数基线（PFC/ECN/MTU 三件套）；大变更后回归 |

## 案例 5：MTU 不一致

| 项 | 内容 |
|---|---|
| 现象 | 小消息 RDMA 压测正常，大消息（≥64KB）直接失败或吞吐坍塌 |
| 定位 | 两端 `ip link` 看 MTU；逐跳检查交换机 jumbo 配置 |
| 根因 | 一端/一跳未开巨帧（9000），大包在路径中被丢弃 |
| 修复 | 端到端统一 MTU 并在路径所有交换机启用 jumbo |
| 预防 | 基线测试必须含大消息档位（见 [[12_架构基建/08_网络/PPU与高网/05_高网性能测量方法_2026|05 测量方法]] §2 要点 3） |

## 案例 6：NCCL 超时的误判

| 项 | 内容 |
|---|---|
| 现象 | 训练任务报 NCCL timeout，团队怀疑「网络断了」 |
| 定位 | 先确认是否有节点真实失联（ibstat/ping）；再看是否**通信域不一致**（部分进程挂/慢导致其他进程干等） |
| 根因 | 多数超时是慢节点或进程异常的**结果**而非网络故障本身 |
| 修复 | 定位真实慢源（回案例 3 方法论）；不要用无限拉大超时掩盖 |
| 预防 | 超时阈值分级（建连/传输），配 watchdog 日志保留完整通信域信息 |

## 排障工具速查

| 层 | 工具 | 用途 |
|---|---|---|
| 链路 | ibstat、ibdev2netdev、ethtool、perftest | 端口状态/速率/带宽时延 |
