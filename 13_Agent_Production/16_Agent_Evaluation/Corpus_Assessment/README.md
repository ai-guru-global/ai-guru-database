## 核心模型

```
COVR 四维模型：
  C - 内容覆盖度 (Coverage)      权重 35%
  O - 场景覆盖度 (Operational)    权重 30%
  V - 版本时效性 (Version)        权重 20%
  R - 语言质量度 (Representation) 权重 15%
```
