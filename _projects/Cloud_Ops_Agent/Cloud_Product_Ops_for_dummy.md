## 如何使用云产品运维 Agent？

### 第一步：部署 Agent

```yaml
# K8s 部署配置 (简化版)
apiVersion: apps/v1
kind: Deployment
metadata:
  name: cloud-ops-agent
spec:
  replicas: 3  # 高可用
  template:
    spec:
      containers:
      - name: agent
        image: cloud-ops-agent:v1
        env:
        - name: CLOUD_PROVIDER
          value: "aws"  # 或 aliyun, azure, gcp
        - name: REGION
          value: "us-east-1"
```

### 第二步：配置权限

```python
# 给 Agent 配置云平台权限
agent_permissions = {
    # Agent 可以做什么
    "allow": [
        "ecs:DescribeInstances",      # 查看服务器
        "ecs:ScaleInstance",          # 扩容
        "rds:DescribeInstances",      # 查看数据库
        "cloudwatch:GetMetrics",      # 查看监控
    ],
    # Agent 不能做什么
    "deny": [
        "ecs:DeleteInstance",         # 不能删服务器
        "rds:DeleteInstance",         # 不能删数据库
    ]
}
```

### 第三步：配置运维策略

```python
# 定义运维策略
policies = [
    {
        "name": "CPU 过高自动扩容",
        "condition": "cpu_utilization > 80",  # 条件
        "action": "scale_out",               # 操作
        "cooldown": 300,                      # 冷却时间 (秒)
    },
    {
        "name": "服务无响应自动重启",
        "condition": "health_check_failed >= 3",
        "action": "restart_service",
        "backup": True,  # 先备份
    }
]
```

### 第四步：启动并监控

```python
# 启动 Agent
agent.start()

# 查看 Agent 状态
status = agent.get_status()
print(f"Agent 状态: {status.state}")  # running
print(f"当前任务: {status.current_task}")
print(f"今日处理: {status.tasks_today} 个任务")

# 查看操作日志
logs = agent.get_recent_logs()
for log in logs[-10:]:
    print(f"{log.time} | {log.action} | {log.result}")
```

## 安全很重要！🔒

```
Agent 的权限要小心配置！

┌─────────────────────────────────────┐
│ ⚠️ 危险配置 (不要这样做!)           │
│                                     │
│ Agent 权限 = admin                   │
│                                     │
│ 意味着 Agent 可以:                   │
│ ❌ 删除所有数据                      │
│ ❌ 修改任何配置                      │
│ ❌ 关闭所有服务                      │
│                                     │
│ 风险: 如果被攻击，后果严重！         │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ✅ 安全配置 (推荐做法)               │
│                                     │
│ Agent 权限 = 最小权限原则             │
│                                     │
│ Agent 可以:                         │
│ ✅ 查看状态                          │
│ ✅ 扩容                            │
│ ✅ 重启服务                         │
│                                     │
│ Agent 不能:                         │
│ ❌ 删除任何资源                      │
│ ❌ 修改安全配置                      │
│ ❌ 访问其他租户数据                  │
│                                     │
│ 高风险操作需要: 人工审批              │
```
