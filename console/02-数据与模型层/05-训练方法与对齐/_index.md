# 训练方法与对齐

> 预训练之上的后训练：RLHF、蒸馏、强化学习决定模型的可用性与性格。

## 拆解卡

- **价值来源**：决定模型可用性与「性格」的环节，能力竞赛的暗线。
- **护城河**：后训练 know-how 与偏好数据资产。
- **瓶颈**：可验证领域之外的奖励设计（开放域收益有限）。
- **领先指标**：新模型行为差异的对比分析；RLVR 与验证器相关披露

## 六层速览

训练方法与对齐是把「原始模型」变成「好用的助手」的工艺：预训练给知识，后训练给行为和性格；同样的底座，后训练不同就是两个产品。

**打个比方**：像培养一个毕业生——课堂学知识（预训练），实习学规矩（SFT），考核定行为（RLHF / RLVR）；同样的知识，不同的带法出来的人完全不同。

**拆开看**：五段链路：SFT（指令微调）→ 偏好优化（RLHF / DPO）→ 可验证奖励 RL（数学、代码、工具调用）→ 蒸馏与量化 → 安全对齐；数据配比与奖励设计决定最终行为。

**怎么运转**：训练框架与数据服务是卖铲人，lab 内部 know-how 是核心资产；后训练成本远低于预训练，但决定产品体验与差异化，也是小团队能做出现差异的地方。

**格局与博弈**：头部 lab 在 RLVR 与推理时计算上领先，开源社区快速跟进；偏好数据与验证器成为稀缺资产，合成环境成为新训练场，专家标注的边际价值在上升。

**边界与走向**：开放域奖励设计仍是难题，训练会更多转向「环境 + 验证器」；对齐与能力将越来越难分开，后训练会从「调行为」走向「造能力」，评测集污染也会逼迫训练方法升级。

## 关键判断

训练工具稳健增长，但价值向算力与数据两端集中（置信度 中，展望 12–24 个月）——核心变量是后训练算力占比与平台整合；RL 环境是当前最稀缺的中间层。

规模口径：训练工具、平台与训练即服务约 $80–150 亿（2025e），RL 环境与后训练服务增速最快

## 二级细分

- **指令微调（SFT）** — 教会模型「听话」的第一步
- **偏好与对齐** — RLHF/DPO 定行为与性格
- **可验证奖励 RL** — 数学、代码与工具调用，后训练当前主战场
