## 知识图谱是什么？

```
【生活中的例子】

想象一座城市:

📍 地点 = 概念
   "咖啡店"、"公园"、"医院"

🛣️ 道路 = 关系
   "咖啡店 位于 商业街"
   "公园 旁边 医院"

📊 属性 = 概念的特征
   "咖啡店": 营业时间、评分、价格
   "医院": 等级、科室数量

知识图谱 = 把 AI 领域的概念用这种方式组织起来
```

## 概念层次总览

```
AI 概念分为 5 个层次:

Stage 0: AI 觉醒 ─── AI 是什么、分类、发展历史
Stage 1: 基础概念 ─── 数据、模型、训练、过拟合
Stage 2: 核心技术 ─── 神经网络、CNN、Transformer
Stage 3: 工程实践 ─── 部署、RAG、Agent、MLOps
Stage 4: 前沿探索 ─── 多模态、世界模型、AGI
```

## 使用场景

### 1. 查术语

```
遇到不懂的词？例如 "Embedding"

步骤:
1. 打开 AI_Full_Stack_Concepts.md
2. 搜索 "Embedding"
3. 看到定义："把离散数据映射到连续向量空间"
4. 看相关概念: Word2Vec, BERT, 向量数据库
```

### 2. 理清关系

```
想理解概念之间的关系？例如 "Attention 在哪里用到"

步骤:
1. 打开 AI_Concept_Knowledge_Graph.md
2. 搜索 "Attention"
3. 看到:
   - 依赖: Softmax, Query, Key, Value
   - 应用: Transformer, BERT, GPT
   - 变体: Multi-Head Attention, Self-Attention
```

### 3. 学习规划

```
想知道学习顺序？

步骤:
1. 查看知识图谱的层次结构
2. 从 Stage 0 开始，按依赖关系学习
3. 每个 Stage 学完再进入下一个
```
