# God Tier Prompts 概览

> **一句话理解**: 高质量提示词集合与社区平台，提供经过社区验证的高效提示词模板，是提示词工程实践灵感的参考来源。

## 简介

God Tier Prompts 是一个社区驱动的提示词（Prompt）分享与投票平台，汇聚经过实际使用验证的高质量提示词模板。与纯理论教程不同，它强调**可复制、已验证**——每个提示词都附带使用场景、预期效果与社区评分，适合从入门到进阶的提示词工程学习者作为灵感库。

**官网**: [godtierprompts.com](https://www.godtierprompts.com/)

## 核心功能

| 功能 | 说明 |
|------|------|
| **提示词库** | 分类整理（写作/编程/分析/创意/营销等）的精选提示词 |
| **社区投票** | 类 Reddit 机制，社区票选最佳提示词，质量可筛选 |
| **模板化** | 可直接复制使用的提示词模板（含变量占位符） |
| **场景标签** | 每个提示词标注适用场景与模型（GPT/Claude/Gemini） |
| **效果展示** | 附带示例输入输出，所见即所得 |

## 价值与定位

```
提示词工程资源光谱：

  理论体系                    实践模板
  ┌──────────┬──────────┬──────────┐
  │ 论文/综述 │ 系统教程  │ 模板社区  │
  │ (CoT论文) │(本知识库) │(本工具)   │
  └──────────┴──────────┴──────────┘
  学原理      学方法      直接拿来用
```

God Tier Prompts 处于"实践模板"端——适合**快速获得可用提示词**，但若要理解原理（为什么这样写有效），应结合知识库的 [[05_NLP_LLMs/Prompt_Engineering|提示词工程]] 系统学习。

## 使用建议

- **入门者**：浏览高分提示词，逆向学习优秀提示词的结构（角色设定→任务→约束→示例）
- **实践者**：直接复用模板，按需替换变量，快速落地
- **注意**：社区提示词的质量参差，高分≠适合你的场景，需自行测试验证
