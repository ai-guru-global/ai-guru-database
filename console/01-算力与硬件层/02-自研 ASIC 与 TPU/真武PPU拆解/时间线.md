# 真武 PPU 时间线（2018–2026）

> 事实层年表，最新在上；观点见 [行业拆解](行业拆解.md)。口径纪律：官方页为一手锚点（2026-11-06 检索），媒体转述逐条标注层级；冲突项挂 [`docs/2026待核实清单.md`](../../../docs/2026待核实清单.md) 第十节。2026-11-11 大扩充：吸收财新/科创板日报/阿里云峰会系列报道与龙蜥社区 SAIL 开源文，出货三口径整合为族谱口径。

## 2026

- **2026-11（建库盘点时状态）** · 官方页产品线现状：810E 北京/杭州/上海/乌兰察布商用；M890 乌兰察布商用、中卫邀测（超节点实例 Day0 适配 Kimi K3.1 Pro）；V900 标「敬请期待」未商用。软件栈 T-Head SAIL（阿里云页称 PPU SDK 2.2.0），**2026-07 已开源**；外部客户 650+（官方页口径）。✅ 一手锚点
- **2026-07-23** · 平头哥自研软件栈 **T-Head SAIL® 正式开源**：五层全开放（Driver&Runtime / 编程语言 / 编译器 / 高性能库 / 开发者工具）；官方口径「全面适配 PyTorch、TensorFlow、vLLM、SGLang 等 260 余个主流训练与推理框架」；已基于龙蜥 ANCK 内核原生适配并完成相互兼容认证。许可证与公开仓库未明（❓ 挂账）
- **2026-05-20** · 阿里云峰会正式发布**真武 M890**：144GB / 800GB/s / FP32-FP4 全精度 / 配自研 ICN Switch 1.0 互联芯片 / 64 卡全带宽 + 128 卡超节点（时延低至百纳秒级）/ 官方口径性能为 810E 的 3 倍。同场披露：真武系列累计出货 **56 万片**（截至 2026-05）、服务 20+ 行业 400+ 企业客户；阿里财报口径**60% 以上算力已服务外部商业化客户**。标杆部署：中国联通三江源绿电智算中心（平头哥算力卡 16384 张，阿里云贡献算力占比 54%）
- **2026-04** · 真武 810E 完成小米 **MiMo-V2.5-Pro**（1T 参数 / 1M 上下文）适配，上架阿里云 PAI-Model Gallery 一键部署——继 Kimi 后第二个第三方旗舰模型适配点
- **2026-02-12** · 腾讯新闻转述 IDC：累计出货突破 60 万片（截至 2026Q1），国内第二、首超寒武纪。🔍 转述层级
- **2026-02** · 出货口径族谱成形：阿里 2026 财报电话会 **47 万片**（截至 2026-02）→ 阿里云峰会 **56 万片**（截至 2026-05，后发）→ IDC **60 万片**（截至 2026Q1）——三口径为同一增长曲线的三个时点，非冲突；均未直接取得一手原文。⚠️ 转述层级；另有观察者网 400+ 客户口径（与官方页 650+ 为时点差）
- **2026-01-29** · TrendForce 报道平头哥「镇宇 810E」发布：性能据称优于 A800、可比肩 H20（「镇宇」为官宣初期媒体用名）；同日财新报道官方公开新一代 AI 芯片、万卡集群部署
- **2026-01-28** · 36氪：阿里首次证实自研 AI 芯片 PPU 存在，大规模出货已有一年
- **2026-01-22** · 财新：阿里已决定**支持平头哥独立上市**——先内部重组为部分员工持股实体，再探索 IPO；未定时间表。⚠️ 权威媒体报道口径，非官方公告
- **2026-01（月末）** · [真武 PPU 官方页](https://www.aliyun.com/ppu) 上线：三产品线 + PPU SDK + 灵骏超节点 GP9A/GP9AS 实例 + ACS 部署方案

## 2025

- **2025-09** · 央视《新闻联播》中国联通三江源绿电智算中心报道中**意外曝光**平头哥 AI 芯片 PPU——PPU 首次公开可见
- **2025（月份未公开）** · 真武在阿里内部规模部署（由「大规模出货已有一年」倒推）；媒体口径服务通义千问训练与推理；财新口径 **2025 年国产 GPU 出货量最高**。🔍 需一手源

## 2021

- **2021-10** · 倚天 710 发布：Armv9 服务器 CPU，128 核，台积电 5nm——平头哥数据中心芯片第二子，不碰 AI 管制红线
- **2021-10** · 玄铁 RISC-V IP 逐步开源，成为中国 RISC-V 生态主力

## 2019

- **2019-09-25** · 含光 800 发布（云栖大会）：阿里首款 AI 推理 NPU，主打视觉推理（城市大脑）
- **2019-07-25** · 玄铁 910 与无剑 SoC 平台发布：平头哥首批产品，确立「RISC-V IP + 设计平台」路线

## 2018

- **2018-09** · 平头哥半导体成立：达摩院芯片业务独立，整合中天微与达摩院自研团队
