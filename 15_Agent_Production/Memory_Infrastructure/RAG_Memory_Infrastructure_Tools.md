```

核心理念:
───────────────────────────────────────────────────────────────────────────
```

### 2.3 核心组件

| 组件 | 描述 |
|------|------|
| **DataConnector** | 数据读取 (50+ 数据源) |
| **Document** | 文档对象 |
| **Node** | 文档切分后的节点 |
| **Index** | 索引 (Vector/Tree/Summary/KG) |
| **Retriever** | 检索策略 |
| **QueryEngine** | 查询引擎 |
| **ChatEngine** | 对话引擎 |

### 2.4 使用示例

```python
# LlamaIndex RAG 示例
from llama_index import (
    SimpleDirectoryReader,
    VectorStoreIndex,
    PromptTemplate
)
from llama_index.llms import OpenAI

# 1. 加载文档
documents = SimpleDirectoryReader("./data").load_data()

# 2. 创建索引
index = VectorStoreIndex.from_documents(documents)

# 3. 配置查询引擎
query_engine = index.as_query_engine(
    similarity_top_k=3,
    llm=OpenAI(model="gpt-4o")
)

# 4. 查询
response = query_engine.query("这份文档的主要内容是什么？")

# 5. 获取来源
sources = response.source_nodes
for node in sources:
    print(f"来源: {node.metadata}")
    print(f"内容: {node.text[:200]}...")
```

### 2.5 高级功能

```python
# 高级: 自定义 RAG

from llama_index import VectorStoreIndex
from llama_index.retrievers import BM25Retriever
from llama_index.postprocessor import Reranker

# 混合检索
retriever = VectorStoreIndex.auto_retrieve(
    index=index,
    query="..."
)

# 重排序
reranker = Reranker(
    model="cross-encoder-ms-marco",
    top_n=5
)

# 查询引擎
query_engine = index.as_query_engine(
    retriever=retriever,
    postprocessor=[reranker],
    response_mode="compact"
)
```

## 4. MemGPT

### 4.1 核心定位

```
MemGPT: 持久记忆 Agent
═══════════════════════════════════════════════════════════════════════════

定位: 解决 LLM 上下文窗口限制的持久记忆系统

核心理念:
───────────────────────────────────────────────────────────────────────────
• 类似操作系统内存管理的分层记忆
• 上下文窗口 = "RAM"
• 外部存储 = "磁盘"
• 自动在上下文和存储间交换
• 支持无限长的对话历史
```

### 4.2 记忆层级

```
MemGPT 记忆层级
═══════════════════════════════════════════════════════════════════════════

┌───────────────────────────────────────────────────────────────────────┐
│                         MemGPT 记忆架构                                 │
├───────────────────────────────────────────────────────────────────────┤
│                                                                        │
│   ┌─────────────────────────────────────────────────────────────────┐ │
│   │                   Core Memory (上下文窗口)                       │ │
│   │   ───────────────────────────────────────────────────────────  │ │
│   │   • 人物档案 (Persona)                                         │ │
│   │   • 当前上下文                                                   │ │
│   │   • 最近的对话                                                    │ │
│   │                                                                   │ │
│   │   容量: ~8K-128K tokens (取决于模型)                            │ │
│   └─────────────────────────────────────────────────────────────────┘ │
│                              │                                          │
│                              │ 「溢出」到外部存储                       │
│                              ▼                                          │
│   ┌─────────────────────────────────────────────────────────────────┐ │
│   │                  External Memory (外部存储)                       │ │
│   │   ───────────────────────────────────────────────────────────  │ │
│   │   • 历史对话摘要                                                 │ │
│   │   • 重要事件                                                    │ │
│   │   • 用户偏好                                                    │ │
│   │   • 知识库                                                      │ │
│   │                                                                   │ │
│   │   容量: 无限                                                    │ │
│   └─────────────────────────────────────────────────────────────────┘ │
│                                                                        │
│   机制:                                                                │
│   • MemGPT 自动管理记忆层级                                           │
│   • 上下文快满时，自动压缩/转移旧记忆                                 │
│   • 检索相关记忆时，自动召回                                          │
│                                                                        │
└───────────────────────────────────────────────────────────────────────┘
```

### 4.3 使用示例

```python
# MemGPT 使用示例
from memgpt import MemGPT
from memgpt.presets import PRESETS

# 创建 Agent
agent = MemGPT(
    preset=PRESETS["chat_with_contacts"],
    model="gpt-4",
    persona="我是小明的 AI 助手",
    human="小明，25岁，软件工程师"
)

# 对话 (自动管理记忆)
while True:
    user_input = input("User: ")
    
    response = agent.send_message(user_input)
    print(f"Agent: {response}")
    
    # 记忆自动管理:
    # - 上下文满时自动压缩
    # - 重要信息自动存档
    # - 检索时自动召回
```

| **复杂度** | 中 | 低 |
| **适用场景** | 长期助手 | 短期对话 |

```python
# LiteLLM 使用示例
from litellm import completion

# 统一接口调用任何模型
response = completion(
    model="claude-3-5-sonnet",  # 或 "gpt-4o", "gemini-pro" 等
    messages=[{"role": "user", "content": "Hello!"}],

from litellm import cost_compare

costs = cost_compare([
    "claude-3-5-sonnet",
    "gpt-4o",
    "gemini-pro"

print(costs)
# {'claude-3-5-sonnet': 0.015, 'gpt-4o': 0.02, 'gemini-pro': 0.01}
```
