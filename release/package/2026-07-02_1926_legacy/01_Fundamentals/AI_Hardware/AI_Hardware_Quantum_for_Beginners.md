# AI 芯片与量子计算入门

> 一句话理解：算法是 AI 的大脑，芯片是让大脑工作的心脏——选错心脏，再聪明的大脑也跑不动。

## 1. 为什么需要专用芯片？

计算 1000 万个数字的平方：

| 方式 | 做法 | 速度 |
|------|------|------|
| **CPU** | 一个一个串行计算 | 1000万 × T |
| **GPU** | 成千上万核心并行 | 分成若干批次，快数百倍 |

GPU 有成千上万个"小计算单元"，每个做同样的事但处理不同数据。

## 2. 三种 AI 芯片

### GPU — 当前统治者

| 属性 | 详情 |
|------|------|
| 厂商 | NVIDIA（市场 ~80%） |
| 产品线 | RTX 4090 → A100/L40S → H100/H200 → B200/GB200 (Blackwell) |
| H100 SXM | FP16 ~1979 TFLOPS (稀疏), 80GB HBM3, 700W, ~$25-40k |
| B200 | Blackwell 架构, 训练性能 ~H100 的 2.5 倍, 推理吞吐 15 倍+ |
| 优势 | 通用性最强，生态最成熟 |
| 劣势 | 昂贵、高功耗、需要大型数据中心 |

### TPU — 效率之王

| 属性 | 详情 |
|------|------|
| 厂商 | Google 自主设计 |
| 产品线 | v4 → v5e/v5p → v6 Trillium → v7 Ironwood → TPU 8t/8i (2026) |
| v5p | BF16 459 TFLOPS, 95GB HBM, 仅 Google Cloud 可用 |
| 优势 | AI 专用优化，每瓦性能优秀 |
| 劣势 | 只能通过 Google Cloud 使用，PyTorch 支持有限 |

### NPU — 隐私省电之王

| 属性 | 详情 |
|------|------|
| 厂商 | Apple (Neural Engine)、高通 (Hexagon)、华为 |
| 性能 | 几瓦功耗，集成在 SoC 中 |
| 优势 | 超省电、本地推理、隐私保护 |
| 劣势 | 性能有限，只能做推理不能训练 |

### 选择指南

| 场景 | 推荐 |
|------|------|
| 大规模云端训练（GPT/Claude） | GPU 集群 (H100/B200) 或 TPU |
| 大规模云端推理（ChatGPT） | GPU/TPU 集群 |
| 本地推理（手机/笔记本） | NPU 或消费级 GPU |
| 企业内部推理（~100人） | 消费级 GPU (RTX 4090) 或云端 TPU |

## 3. 2026 芯片战争格局

**美国**：NVIDIA (H100→B200→B300)、Google TPU (v6→v7→8)、AMD MI300

**中国**：华为昇腾 (910B/910C)、百度昆仑芯、阿里含光芯

中国芯片面临三大挑战：
1. **工艺制程**：先进制程受出口管制约束
2. **生态成熟度**：CUDA 级软件生态仍在追赶
3. **实际效率**：理论性能接近，但实际效率仍有差距

## 4. 量子计算入门

### 量子比特 vs 经典比特

| | 经典比特 | 量子比特 |
|---|---------|---------|
| 状态 | 0 或 1 | 叠加态（同时是 0 和 1） |
| 类比 | 灯：开或关 | 闪烁中的灯 |
| 10 个 | 表示 1024 种之一 | 状态空间 1024 个基态 |

### 量子计算擅长的问题

| 问题 | 经典 | 量子 | 影响 |
|------|------|------|------|
| 因数分解（密码） | 10^40 年 | Shor 算法大幅加速 | RSA 需迁移到抗量子方案 |
| 分子模拟（药物） | 几乎不可能 | 天然适合量子系统 | 更快设计新药/材料 |
| 优化问题（物流） | 组合爆炸 | 量子退火探索较优解 | 物流/电力/金融优化 |

### 量子计算不擅长的问题

- 网络搜索、排序、一般机器学习 → 经典已足够优化

### 硬件进展

```text
2019: Google Sycamore (53 qubit) — 量子优越性
2023: IBM Condor (1121 qubit)
2024: Google Willow (105 qubit) — 纠错重大进展
趋势: 从堆量子比特数量 → 降低误差率 → 容错量子计算
```

### 量子 vs AI：短期不会替代

- **2026-2030**：AI 仍靠 GPU/TPU，量子只是补充
- **2030-2050**：可能出现混合计算（经典 + 量子加速器）
- **对 AI 工程师**：短期无需深入学习；涉及优化/模拟时值得关注
