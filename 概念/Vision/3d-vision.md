# 3D 视觉

> 中文简称：3D 视觉

> 一句话理解：从 2D 图像/视频恢复三维结构，或直接从 3D 传感器获取空间信息。

## 核心概念

3D 视觉是计算机视觉的重要分支，目标是理解和重建三维世界：

- **深度估计**：从单目/双目图像预测像素深度
- **点云处理**：处理 LiDAR/RGB-D 传感器获取的 3D 点云
- **3D 重建**：从多视角图像重建三维模型
- **NeRF/3DGS**：神经辐射场和 3D 高斯溅射新范式

## 技术栈

| 技术 | 说明 | 应用 |
|------|------|------|
| **单目深度估计** | 从单张图像预测深度 | AR/机器人 |
| **立体匹配** | 双目视差计算深度 | 自动驾驶 |
| **SfM/SLAM** | 运动恢复结构/同步定位建图 | 机器人/AR |
| **点云分割** | 3D 点云语义/实例分割 | 自动驾驶 |
| **NeRF** | 神经辐射场新视角合成 | 数字孪生 |
| **3D Gaussian Splatting** | 高斯溅射实时渲染 | 3D 重建 |

## 生产最佳实践

1. **传感器选择**：室内用 RGB-D，室外用 LiDAR，消费级用单目
2. **点云处理**：用 Open3D/PCL 处理点云数据
3. **NeRF vs 3DGS**：实时渲染用 3DGS，高质量用 NeRF
4. **坐标系统一**：多传感器融合需统一坐标系
5. **数据标注**：3D 标注成本高，用自动标注 + 人工校验
