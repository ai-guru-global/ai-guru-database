## 同步机制

1. `tools/pull_snapshot.py` — 首次/恢复时全量 snapshot（已跑完）
2. `tools/pull_changes.py` — 每日增量 `changes`（`op=upsert` / `op=remove`）
3. `tools/build_index.py` — 重生成本目录的可读索引（by-date/）

每日运行建议：先 `pull_changes`，再 `build_index`（均幂等）。
