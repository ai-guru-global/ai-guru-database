# 故障树分析（FTA）

> 中文简称：故障树分析（FTA） ｜ English: Fault Tree Analysis

> **一句话理解**：FTA 故障树把高频生产故障拆成「现象 → 根因 → 底事件」的可执行排查树，是排障技能的故障知识底座。

---

## 本目录定位

本目录是 **LLM 全链路高频故障的故障树（Fault Tree Analysis）集合**，共 25 篇，覆盖从推理部署、微调产物到 Agent / RAG / 评估应用的完整链路。

每篇 FTA 遵循统一结构：**Mermaid 故障树**（顶层故障 → 中间事件 → 底事件）→ 问题现象 → 根因分析 → 诊断步骤 → 解决方案 → 预防措施，可直接作为排障手册使用。

与相邻内容的边界：**通用运维排障**（GPU / K8s / 网络）在 `13_运维/` 各诊断文档；本目录聚焦 **LLM 专属故障**，两者交叉引用互补。

## 使用方法

1. **排障时**：按现象在对应领域表中定位 FTA，沿故障树自顶向下排查（先中间事件、再底事件）。
2. **沉淀时**：新增高频故障按 FTA 模板创建（见 `工具/` 治理规范与 fta-authoring 技能），并同步更新本索引。
3. **联动**：`11_模型运维/12_故障排查/` 与 `13_运维/` 的通用排障文档提供跨领域基础（GPU / K8s / 网络），FTA 聚焦 LLM 专属层。
