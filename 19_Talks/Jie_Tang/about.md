# 唐杰 (Jie Tang) — 智谱 AI 联合创始人

> **一句话概括**: 清华大学教授创办智谱 AI，从 GLM-130B 到 GLM-5.2 (744B MoE)，打造了中国最具学术底蕴的大模型生态。

---

## 核心贡献

- **GLM 预训练框架** (2021): 自回归填空 (Autoregressive Blank Infilling) 统一 NLU 和 NLG
- **GLM-130B** (2022): 中国首个 100B+ 开源模型，DeepNorm 稳定训练
- **ChatGLM-6B** (2023): 首个开源中文对话模型，6GB 显存可运行
- **CogVLM / CogAgent** (2023-2024): 视觉语言模型和 GUI Agent
- **AutoGLM** (2024): 自我进化的 AI Agent
- **GLM-4.5** (2025): 355B/32B MoE，MATH-500 98.2%，AIME 91.0%
- **GLM-5.2** (2026): 744B/40B MoE (256 路由专家 + 1 共享)，1M 上下文 (MLA + DSA + IndexShare)，MIT 纯开源，最强开源编码（Terminal-Bench 81.0、SWE-bench Pro 62.1、AIME 2026 99.2）

## 代表性论文与成果

1. **"GLM: General Language Model Pretraining with Autoregressive Blank Infilling"** (ACL 2022)
   - 引用 1000+，GLM 系列的理论基础
   - 统一了 BERT 式理解和 GPT 式生成

2. **"GLM-130B: An Open Bilingual Pre-trained Model"** (ICLR 2023)
   - DeepNorm + 双语训练
   - 首个在 MMLU 超越 GPT-3 的开源模型

3. **"ChatGLM: A Family of Large Language Models from GLM-130B to GLM-4"** (2024)
   - 系统总结 GLM 技术演进路线
   - 从 130B 到 GLM-4 的架构变革

## 技术观点

- **学术驱动创业**: "好的研究自然会产生好的产品，智谱的根在清华"
- **GLM 框架统一性**: "一个框架同时做理解和生成，不需要两套模型"
- **Agent 是未来**: "AutoGLM 证明了模型可以自我进化，这是 AGI 的方向"
- **开源 + 商业并行**: 开源 ChatGLM 获社区，商业 API 获收入

## 名言金句

> "从论文到产品，中间的距离比想象中短，也比想象中长。"

> "GLM 不只是一个模型，它是一个统一的预训练框架。"

> "中国需要自己的大模型基础设施，智谱就是这个基础设施的一部分。"

> "学术界的自由探索是创新的源泉，工业界的工程能力是创新的放大器。"
