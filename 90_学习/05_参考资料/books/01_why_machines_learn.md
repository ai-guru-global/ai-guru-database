# Why Machines Learn

> 中文简称：机器为何学习

> **一句话理解**: 前沿科技作家 Anil Ananthaswamy 的新作，用历史叙事与直觉讲解 ML 数学之美（从最小二乘法到深度学习与生成模型），是培养数学直觉的绝佳科普读物。

## 书籍概述

### 作者背景

**Anil Ananthaswamy** 是知名科学作家与记者，曾任《新科学家》（New Scientist）杂志顾问，长期为《科学美国人》《自然》等顶级刊物撰稿。他的前作《The Edge of Physics》《Through Two Doors at Once》广受好评，擅长把深奥的物理与数学概念转化为引人入胜的叙事。本书是他将笔触转向机器学习领域的力作，延续了他"用故事讲数学"的独特风格。

### 本书定位

在 ML 数学类书籍中，本书独树一帜：

- **不是**教科书（没有习题、没有代码、不追求完整覆盖）
- **而是**"数学叙事"——用历史故事与几何直觉，让你**理解**数学为什么这样设计
- 它填补了"硬核教材"（如花书）与"纯应用入门"之间的空白：**建立直觉**

最佳用法是作为"硬核教材的配套读物"：读 [[90_学习/05_参考资料/books/11_deep_learning_goodfellow]] 之前或同时，用本书培养对数学的"感觉"。

## 核心内容

全书以**历史**与**数学**双线叙事，每个核心算法都从其诞生的历史背景讲起，再深入到数学本质。

### Part 1 — 学习的起源

#### Ch 1: 最小二乘法

- **历史背景**: 18-19 世纪天文学家如何从带误差的观测中预测天体轨道
- **高斯与勒让德的优先权之争**: 最小二乘法的发明权公案
- **数学本质**:
  - 误差平方和最小化的几何直觉
  - 为什么是"平方"而非"绝对值"
  - 过定方程组的"最佳近似"
- **核心洞察**: 学习 = 在误差中找到最优拟合

#### Ch 2: 曲线拟合与模型选择

- **从直线到曲线**: 多项式拟合的力量与陷阱
- **过拟合的早期认知**: 为什么"拟合得太好"反而是问题
- **奥卡姆剃刀**: 在拟合度与复杂度间权衡
- **偏差-方差权衡的雏形**: 模型复杂度的两难

### Part 2 — 数据的几何

#### Ch 3: 线性代数与向量空间

- **向量的几何直觉**: 数据点作为高维空间中的向量
- **向量空间与子空间**: 数据"居住"的空间结构
- **基与维度**: 如何用更少的维度描述数据
- **线性变换**: 矩阵作为空间的"旋转与拉伸"

#### Ch 4: 主成分分析（PCA）与降维

- **降维的动机**: 高维数据的可视化与压缩
- **PCA 的几何直觉**: 找到数据方差最大的方向
- **特征值与特征向量**: 矩阵的"骨架"
- **从数据到本质**: 用主成分捕捉数据的核心结构

### Part 3 — 不确定性下的推理

#### Ch 5: 概率与贝叶斯

- **概率的两种诠释**: 频率学派 vs 贝叶斯学派
- **贝叶斯定理**: 从先验到后验的信念更新
- **贝叶斯推理的优雅**: 把"学习"建模为"信念更新"
- **历史故事**: 贝叶斯、拉普拉斯与概率论的诞生

#### Ch 6: 高斯分布与信息论

- **正态分布的普遍性**: 中心极限定理的魔力
- **熵与信息**: 香农如何量化"不确定性"
- **KL 散度**: 衡量两个分布的"距离"
- **最大熵原理**: 在约束下最不"武断"的分布

### Part 4 — 神经网络的诞生

#### Ch 7: 感知机与神经网络起源

- **McCulloch-Pitts 神经元**: 用数学模型模拟生物神经元
- **Rosenblatt 的感知机**: 第一个可学习的神经网络
- **感知机的局限**: Minsky 与 Papert 的批评（异或问题）
- **AI 的第一次寒冬**: 感知机争议的历史影响

#### Ch 8: 反向传播革命

- **链式法则的优雅**: 微积分如何驱动神经网络学习
- **反向传播的发现史**: 多次"独立发现"的公案
- **梯度下降的几何直觉**: 沿最陡方向下山
- **深度网络的复兴**: 为什么"深度"很重要

### Part 5 — 高维的力量

#### Ch 9: 支持向量机与核方法

- **分类的几何直觉**: 找到最优分隔超平面
- **最大间隔分类**: 为什么间隔越大越好
- **核技巧（Kernel Trick）**: 在高维空间线性可分
- **从线性到非线性**: 核方法的数学魔法

### Part 6 — 深度学习与前沿

#### Ch 10: 深度学习的崛起

- **卷积神经网络（CNN）**: 利用图像的空间结构
- **从特征工程到表示学习**: 让机器自己学特征
- **深度学习的"炼金术"**: 为什么有效仍是开放问题
- **ImageNet 时刻**: 2012 年 AlexNet 的革命

#### Ch 11: 生成模型与创造

- **从判别到生成**: 不只分类，还要"创造"
- **变分自编码器（VAE）**: 概率视角的生成
- **生成对抗网络（GAN）**: 造假者与鉴别者的博弈
- **扩散模型**: 从噪声中"雕刻"出图像
- **数学之美**: 生成模型背后的概率与几何

#### Ch 12: 当前前沿与未来

- **大语言模型**: 规模涌现的能力
- **Transformer 与注意力**: 序列建模的革命
- **AI 的本质之问**: 机器真的"理解"吗？
- **可解释性与未来**: 理解机器为何学习的持续追求

## 关键概念与公式

### 最小二乘法

```
目标: 最小化误差平方和
min Σ (yi - f(xi))²

几何直觉: 在列空间中找到观测向量 b 的最近投影 Ax
正规方程: AᵀAx = Aᵀb
```

### 贝叶斯定理

```
P(假设 | 数据) = P(数据 | 假设) × P(假设) / P(数据)
   后验            似然              先验        证据

直觉: 学习 = 用数据更新先验信念得到后验
```

### 梯度下降与反向传播

```
参数更新: θ ← θ - η × ∂L/∂θ

反向传播 = 链式法则的系统应用:
∂L/∂θ = ∂L/∂y × ∂y/∂z × ∂z/∂θ  (逐层向后传递梯度)

几何直觉: 沿损失函数下降最快的方向更新参数
```

### 熵与信息

```
香农熵: H(X) = -Σ P(x) log P(x)

直觉: 熵 = 不确定性的度量 = 编码所需的最短平均比特数
```

## 核心思想提炼

本书贯穿始终的几条思想主线，值得反复体会：

### 思想 1: 学习即优化

从最小二乘法到深度学习，所有"学习"本质上都是**在误差中寻找最优**：

- 最小二乘：最小化预测误差的平方和
- 最大似然：最大化观测数据的出现概率
- 梯度下降：沿误差下降最快的方向更新参数
- 这条主线把看似分散的算法统一起来

### 思想 2: 几何直觉是理解 ML 的钥匙

作者反复用几何视角讲解抽象概念：

- 数据是高维空间中的点
- 回归是找最近的投影
- PCA 是找方差最大的方向
- SVM 是找最大间隔的分隔超平面
- 建立几何直觉后，公式不再冰冷

### 思想 3: 概率是处理不确定性的语言

- 贝叶斯定理把"学习"建模为"信念更新"
- 生成模型把"创造"建模为"从分布采样"
- 熵量化了"不确定性"本身
- 概率视角让 ML 从"确定性计算"升华为"不确定性推理"

### 思想 4: 简单规则的复杂涌现

- 反向传播只是链式法则的系统应用，却驱动了整个深度学习革命
- 简单的神经元模型组合成深度网络，涌现出惊人的能力
- 这呼应了复杂系统的核心思想：简单规则 + 大量组合 = 复杂行为

## 经典案例与历史故事

本书的一大魅力是用历史故事承载数学。以下是几个令人印象深刻的案例：

### 案例 1: 谷神星的发现与最小二乘

1801 年，天文学家皮亚齐发现了谷神星，但很快跟丢了它。年轻的高斯用最小二乘法从有限的带误差观测中预测了谷神星的轨道，让天文学家重新找到了它。这个故事生动说明了**最小二乘法的威力**：从噪声中提取信号。

### 案例 2: 感知机的兴衰

1958 年，Rosenblatt 的感知机被媒体誉为"会思考的机器"，但 1969 年 Minsky 与 Papert 证明感知机无法解决异或问题，导致 AI 进入第一次寒冬。这个起伏说明：**理解算法的能力边界与理解算法本身同样重要**。

### 案例 3: 反向传播的多次"发现"

反向传播的思想在历史上被多次独立发现（Werbos 1974、Rumelhart 1986 等），却长期被忽视。这反映了科学发现的复杂性：**一个好想法需要合适的时代土壤才能生根**。

### 案例 4: 贝叶斯定理的战时应用

贝叶斯方法在二战中被用于破解密码、搜索潜艇，却因"主观性"争议长期被统计学主流排斥，直到计算机时代才重获新生。这说明：**算法的价值有时需要等待计算能力的进步**。
