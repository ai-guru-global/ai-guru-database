## 人物/事件概述

### 背景回顾

Andrej Karpathy（1985 年生于前捷克斯洛伐克），斯坦福大学计算机科学博士（2015，师从 [[19_业界观点/09_Fei_Fei_Li_李飞飞/03_索引|Fei-Fei Li]]），OpenAI 创始成员（2015-2017）、Tesla AI 总监（2017-2022，主导 Autopilot 纯视觉方案）、OpenAI 短暂回归（2023-2024）。2024 年创立 Eureka Labs，专注 AI 教育。他是"Software 2.0"（2017）概念提出者、"Vibe Coding"（2025）术语首创者、Stanford CS231n 课程缔造者、nanoGPT/llm.c 作者。被业界公认为"AI 领域最好的老师"。

> "Vibe Coding is not about laziness—it's about a higher level of abstraction. We went from assembly to C to Python, and now we're going from Python to natural language. Each step removes boilerplate and lets us focus on intent."
> "Vibe Coding 不是关于偷懒——它是关于更高层次的抽象。我们从汇编到 C 到 Python，现在从 Python 到自然语言。每一步都去除了样板代码，让我们专注于意图。"
> -- Andrej Karpathy, 2026.03 访谈

| 迭代 | 编译-调试 | 描述-接受 |

| 学习曲线 | 陡峭 | 平缓 |

## 技术观点/行业立场

### 关于 Software 2.0 的演化

Karpathy 在 2026 年更新了其"Software 2.0"框架：

| 时期 | 范式 | 代表 |
|------|------|------|
| Software 1.0 | 人写代码 | C、Java、Python |
| Software 2.0 | 数据训练神经网络 | Tesla Autopilot、CNN |
| Software 2.5 | LLM 提示工程 | GPT-5、Claude |
| Software 3.0 | Vibe Coding + Agent | Cursor、Devin |

> "Software 3.0 is where the 'programmer' becomes a 'director'—you orchestrate AI agents that write, test, and deploy code, while you focus on architecture and intent."
> "Software 3.0 中，'程序员'变成了'导演'——你编排 AI Agent 来编写、测试和部署代码，而你自己专注于架构和意图。"
> -- Andrej Karpathy, 2026.05

### 关于端到端学习

Karpathy 持续捍卫端到端学习哲学：

- Tesla Autopilot 的纯视觉路线验证了这一方向
- 机器人领域也开始转向端到端
- 批评"过度模块化"的工程妥协
- 认为"移除人工组件"是 AI 进步的核心

### 关于 AI 教育

Karpathy 的教育哲学：

| 原则 | 说明 |
|------|------|
| 从零构建 | 理解一个东西最好的方式是重建它 |
| 代码优先 | 实践胜于理论灌输 |
| 免费开放 | 最好的教育内容应免费 |
| 渐进复杂 | 从 nanoGPT 到真实模型 |
| 实战导向 | 教可立即应用的技能 |

### 关于 AI 安全

Karpathy 的中间立场：

- 承认 AI 风险，但不接受"末日论"
- 介于 [[19_业界观点/28_Yann_LeCun_杨立昆/02_索引|LeCun]]（乐观）和 [[19_业界观点/10_Geoffrey_Hinton_辛顿/03_索引|Hinton]]（悲观）之间
- 认为教育是缓解风险的关键
- 关注"AI 素养"而非"AI 恐慌"

### 关于 AGI 时间线

Karpathy 的判断（2026 更新）：

- **2026-2028**: AI 在编程、写作等任务超越多数人类
- **2028-2030**: 出现可靠的自主 Agent
- **2030-2035**: AGI 的实用形态出现
- **关键瓶颈**: 不是算力，而是"世界理解"和"持续学习"
