# 学习日志 (Journal)

> **定位**: 记录 AI 学习过程中的实验笔记、问题发现和反思总结。

## 规划中的内容类型

| 类型 | 说明 | 格式 |
|------|------|------|
| **实验记录** | 模型训练/微调的实验日志 | 日期 + 参数 + 结果 + 分析 |
| **Debug 笔记** | 踩坑记录和解决方案 | 问题 → 原因 → 修复 |
| **论文笔记** | 阅读论文的简要笔记 | 核心贡献 + 个人理解 |
| **学习反思** | 阶段性总结 | 学到了什么 + 下一步计划 |

## 与现有内容的关系

```
学习日志是"过程"，其他目录是"结果"：

90_Learn/ → 学习路径与计划（规划）
91_Notes/ → 精炼的笔记（产出）
journal/  → 学习过程记录（过程） ← 本目录
```
