# 03 · 产品线与规格：810E / M890 / V900

> 三档产品线的规格全景与可用性状态。一手锚点：[真武 PPU 官方页](https://www.aliyun.com/ppu)（2026-11-06 检索）；官方全线未披露峰值算力（TFLOPS）。

## 三档产品线

| | 810E | M890 | V900 |
|---|---|---|---|
| 定位（官方） | 高易用训推一体 AI 芯片 | 全场景训推一体 AI 芯片 | 下一代训推一体 AI 芯片 |
| 发布/亮相 | 2026-01-29 官网正式上线（2025-09 央视《新闻联播》联通三江源报道中意外曝光） | **2026-05-20 阿里云峰会正式发布** | 路线图 **2027 Q3**（官方「一年一代」节奏） |
| 单卡内存 | 96 GB HBM2e | 96 / 144 GB | 216 GB |
| 片间互联带宽 | 700 GB/s | 800 GB/s | 1200 GB/s |
| 互联细节 | 7 个 ICN 片间互联端口（t-head.cn 产品页引用口径） | 配自研 **ICN Switch 1.0** 互联芯片；64 卡全带宽 + **128 卡超节点**，通信时延低至百纳秒级（官方发布口径） | 千卡全带宽 Scale-Up |
| 精度 | — | FP32 / FP16 / FP8 / FP4 全精度；官方称性能为 810E 的 **3 倍**（自述口径） | FP8 / FP4，百 TB 级统一显存；官方口径性能预计为 M890 的 3 倍 |
| 状态 | 北京/杭州/上海/乌兰察布商用 | 乌兰察布商用；中卫邀测 | 「敬请期待」，未商用 |

配套整机：灵骏超节点 GP9A / GP9AS 实例（64 卡，9TB / 6TB 显存口径）。下一代 **J900** 已列入官方路线图（2028 Q3）。

媒体补充口径：810E 整板功耗 ≤400W、PCIe 5.0 ×16（财新/科创板日报转述官网口径，产品页有登录墙未直接核验）；峰值算力 ~120 TFLOPS 仅见于社区口径（❓ 挂待核实清单第十节，不得引用）。

## 命名口径

官方名「真武 PPU（Parallel Processing Unit）」；2026-01 官宣初期 TrendForce 等媒体称「镇宇 810E」。本库以官方页为准，「镇宇」作别名（关系待一手源确认，挂待核实清单第十节）。

## 为什么「不披露 TFLOPS」值得单独一条

两种解读并存（观点层）：

1. **营销路线论**：TPU 式打法——Google 同样从不主打纸面参数，卖单位经济与端到端性价比；对采购决策者，每 token 成本比 TFLOPS 更有意义。
2. **参数不占优论**：训练旗舰市场竞争以峰值算力锚定叙事，不披露意味着 810E 的绝对算力相对 H100/B 级不占优， disclosure 只会强化「替代位」标签。

两种解读不互斥。可操作的推论：**评估 PPU 不要问「算力多少」，要问「同负载下每 token 成本与迁移成本」**——这正是官方希望引导的比较维度（→ [04-规格对标](04-规格对标.md)、[07-售卖与单位经济](07-售卖与单位经济.md)）。

## 产品线递进读出的战略：scale-up 优先 + 一年一代

三档的升级轴不是算力而是**显存 × 互联**：96→216GB、700→1200GB/s、16→千卡全带宽；互联硬件从「卡上端口」升级到专用交换芯片（M890 起配 ICN Switch 1.0）——这是 NVL72 式「机柜级统一显存」路线的国产对位。推理时代大 MoE 模型吃显存池不吃单卡峰值（Kimi K3.1 Pro 在 M890 超节点 Day0 适配、小米 MiMo-V2.5-Pro 1T/1M 上 810E，均为例证）。官方「一年一代」（810E 2026Q1 → M890 2026Q2 → V900 2027Q3 → J900 2028Q3）的迭代承诺若兑现，代际节奏对齐英伟达年更线——兑现率本身即领先指标（→ [12-展望与领先指标](12-展望与领先指标.md)）。
