# Papers with Code 概览

> **一句话理解**: 论文+代码+排行榜的综合平台,追踪各领域 SOTA 结果,AI 研究者的核心工具。

## 核心功能

| 功能 | 说明 |
|------|------|
| **论文索引** | 按领域/任务分类的论文列表 |
| **代码链接** | 每篇论文关联的开源实现 |
| **SOTA 排行榜** | 各任务的最先进结果对比 |
| **数据集** | 常用数据集的索引和统计 |

## 与其他平台对比

| 维度 | Papers with Code | arXiv | Semantic Scholar |
|------|-----------------|-------|-----------------|
| 代码 | 有(核心特色) | 无 | 无 |
| 排行榜 | 有 | 无 | 无 |
| 数据集 | 有 | 无 | 无 |
