# 时间序列分析 - 小白版

> **一句话秒懂**: 时间序列就像看股票走势图 —— 通过研究过去的"涨涨跌跌"，来猜未来会怎么走！

## 你将学到什么

- 你能够理解什么是时间序列以及它为什么特殊
- 你能够识别时间序列的三大组成成分：趋势、季节性、噪声
- 你能够明白为什么普通机器学习方法不适合时间序列
- 你能够掌握几种最基础的预测方法
- 你能够知道什么时候该用什么方法来预测未来

## 为什么这个很重要？

想象一下：

- 你出门前看了**昨天的天气**和**今天的早上天气**，推测下午要不要带伞 —— 这就是时间序列预测！
- 你看**股票过去一年的走势**，判断明天该不该买入 —— 这也是时间序列分析！
- 超市根据**去年同期的销量**，决定今年双十一要备多少货 —— 还是时间序列！

生活中到处都是时间序列数据，学会分析它们，就等于拥有了**预测未来的超能力**！

## 核心概念

### 1. 什么是时间序列？

#### 生活中的例子

你的**体温记录**就是最简单的时间序列：
- 早上 6 点：36.5°C
- 上午 10 点：36.8°C
- 下午 2 点：37.2°C
- 晚上 8 点：36.6°C

按时间顺序排列的数据，就是时间序列。就这么简单！

#### ASCII 图解

```

    值

     0 │╯

       1月      4月      7月      10月     1月
    
    这就是一条时间序列！它有高低起伏，有一定的规律。
```

#### 简单来说

时间序列 = **按时间顺序排列的一串数字**。温度、股价、销量、心跳... 任何随时间变化的数据都是时间序列。

#### 记住这个

> 时间序列的核心特点：**数据点之间有时间顺序关系**。今天的值跟昨天有关，跟明天也有关。

### 2. 三大组成成分

#### 生活中的例子

想象你在看**冰淇淋销量**：
- **趋势**：每年整体销量都在增长（因为品牌越做越大）📈
- **季节性**：夏天卖得多，冬天卖得少 🌞❄️
- **噪声**：某天突然下暴雨，销量意外下降 🌧️

#### 简单来说

任何时间序列都可以拆解成三部分：
1. **趋势** —— 大方向（往上走、往下走、还是持平？）
2. **季节性** —— 规律性波动（每天、每周、每年的重复模式）
3. **噪声** —— 没规律的随机波动（预测不了的部分）

#### 记住这个

> 趋势 = 大方向 📈 | 季节性 = 规律波动 🔄 | 噪声 = 随机抖动 🎲

### 3. 为什么普通机器学习搞不定？

#### 生活中的例子

假设你是一个老师，要预测学生的期末成绩：

- **普通机器学习**的想法：把所有学生的成绩打乱，随机分组训练。就好比把小明的高数成绩和两百年前某个人的考试成绩放在一起比较，毫无意义！
- **时间序列分析**的想法：必须按时间顺序，用过去的成绩预测未来的成绩。就像用小明**上学期**的成绩预测**这学期**的成绩，才有道理。

#### ASCII 图解

```
    ❌ 错误做法（普通机器学习）:
    
    随机打乱时间顺序:
    ┌───────────────────────────────────────────────┐
    │ 训练数据: 3月, 12月, 5月, 1月, 9月, 7月...    │
    │ 测试数据: 8月, 2月, 11月, 6月...               │
    │                                               │
    │ 问题: 用 12月的数据训练去预测 5月？              │
    │       那不等于用"未来"预测"过去"吗？🤔          │
    └───────────────────────────────────────────────┘
    
    ✅ 正确做法（时间序列分析）:
    
    严格按时间顺序划分:
    ┌───────────────────────────────────────────────┐
    │ 训练数据: 1月, 2月, 3月, ..., 9月              │
    │ ═══════════════════════════════              │
    │ 测试数据: 10月, 11月, 12月                     │
    │                              ──────────       │
    │                                               │
    │ 用过去预测未来，这才是正确的！✓                 │
    └───────────────────────────────────────────────┘
```

#### 简单来说

普通机器学习假设数据之间**没有先后关系**，可以随便打乱。但时间序列数据**有时间顺序**，不能打乱，不能用"未来"的数据去预测"过去"。这就是为什么需要专门的时间序列方法。

#### 记住这个

> 时间序列的铁律：**永远只能用过去的数据预测未来**。不能"穿越时空"！

### 4. 移动平均 —— 最简单的预测

#### 生活中的例子

你想知道明天的气温大概是多少？最简单的方法：**看最近几天的平均气温**。
- 最近 3 天的气温：25°C, 27°C, 26°C
- 移动平均预测明天：(25 + 27 + 26) / 3 = 26°C

就这么简单！这就是**移动平均法**。

#### ASCII 图解

```
    移动平均 (窗口大小 = 3)
    
    原始数据:   10  15  12  18  20  16  22  25  21
    
    移动平均:   -   -   │←────────────→│
                         (10+15+12)/3 = 12.3
                             │←────────────→│
                             (15+12+18)/3 = 15.0
                                 │←────────────→│
                                 (12+18+20)/3 = 16.7
    
    值
    25 │                                    ●
    22 │                          ●     ╱
    20 │                    ●  ╱     ╱
    18 │                ●╱     ╱
    16 │          ●  ╱     ╱
    15 │      ●╱     ╱
    12 │  ●     ╱
    10 │●  ╱
       └──────────────────────────────→ 时间
       
       ● 原始数据    ─ 移动平均线（更平滑）
```

#### 简单代码

```python
import numpy as np

# 某商店 10 天的销售额
sales = [120, 135, 128, 142, 155, 148, 160, 172, 165, 180]

# 3天移动平均
window = 3
for i in range(len(sales) - window + 1):
    avg = np.mean(sales[i:i+window])
    print(f"第{i+1}-{i+window}天平均: {avg:.1f}")

# 预测明天的销售额
prediction = np.mean(sales[-window:])
print(f"\n预测明天销售额: {prediction:.1f}")
```

#### 记住这个

> 移动平均 = 取最近 N 个值的平均作为预测。窗口越大越平滑（但反应越慢），窗口越小越灵敏（但容易受噪声影响）。

### 5. 预测未来 —— 核心方法一览

#### 生活中的例子

| 比喻 | 方法 | 什么时候用 |
|------|------|-----------|
| 看最近平均温度猜明天 | 移动平均 | 数据波动不大时 |
| 看趋势线，然后延伸 | 趋势外推 | 有明显趋势时 |
| 参考去年同期的表现 | 季节性预测 | 有周期规律时 |
| 综合考虑趋势+季节+随机 | ARIMA / Prophet | 复杂的真实数据 |

#### ASCII 图解

```
    ┌────────────────────────────────────────────────────┐
    │                预测方法选择指南                       │
    ├────────────────────────────────────────────────────┤
    │                                                    │
    │  你的数据有什么特征？                                 │
    │                                                    │
    │  [没有规律] → 移动平均（最简单）                      │
    │                                                    │
    │  [只有趋势] → 趋势外推 / Holt 指数平滑               │
    │     ↗ 或 ↘                                         │
    │                                                    │
    │  [只有季节性] → 季节性分解 + 预测                     │
    │     ∿∿∿∿∿∿                                         │
    │                                                    │
    │  [趋势 + 季节性] → SARIMA / Holt-Winters            │
    │     ↗ + ∿∿∿                                        │
    │                                                    │
    │  [复杂 + 有节假日] → Prophet (最推荐！)               │
    │     ↗ + ∿∿∿ + 特殊日期                              │
    │                                                    │
    │  [多个相关变量] → 机器学习方法 / Transformer          │
    │     多条线交织在一起                                  │
    │                                                    │
    └────────────────────────────────────────────────────┘
```

#### 简单来说

预测方法从简单到复杂：
1. **移动平均** → 最简单，适合入门
2. **指数平滑** → 最近的值权重更大，比移动平均聪明一点
3. **ARIMA** → 经典统计方法，数学上很严谨
4. **Prophet** → Facebook 出品，又好用又强大，推荐新手用这个！

#### 记住这个

> 不确定用什么方法？**先用 Prophet 试试！** 它简单、好用、还能处理节假日。就像"万能预测器"一样。

### 6. 用 Prophet 预测 —— 最简单的"预言术"

#### 生活中的例子

Prophet 就像一个**聪明的天气预报员**：
- 它会自动识别趋势（"气温整体在上升"）
- 它会自动识别季节性（"每年 7 月最热"）
- 它还能考虑节假日（"春节那周销量会暴增"）
- 最后它把所有这些综合起来给你一个预测

#### 简单代码

```python
# 用 Prophet 预测只需要 5 行代码！

import pandas as pd
from prophet import Prophet

# 准备数据 (Prophet 要求列名必须是 ds 和 y)
df = pd.DataFrame({
    'ds': pd.date_range('2023-01-01', periods=365),  # 日期
    'y': [100 + i*0.1 + 20*(1 if i%7<5 else -1) for i in range(365)]  # 模拟销量
})

# 训练模型
model = Prophet()
model.fit(df)

# 预测未来 30 天
future = model.make_future_dataframe(periods=30)
forecast = model.predict(future)

# 看结果
print(forecast``[ ['ds', 'yhat', 'yhat_lower', 'yhat_upper'] ]``.tail(5))
# ds: 日期
# yhat: 预测值
# yhat_lower / yhat_upper: 预测范围（上下限）
```

> Prophet = Facebook 的"傻瓜式"预测工具。你只需要给它时间和数值两列数据，它就能自动预测未来！

### 7. 怎么知道预测准不准？

#### 生活中的例子

你猜明天温度 30°C，结果实际 28°C，差了 2°C。
这就是**误差**。误差越小，预测越准。

但要注意：
- 如果预测"上海明天气温 30°C"，差 2°C 还算准
- 如果预测"明天彩票中奖号码"，差一个数也是错

所以评估预测要看**相对误差**，不是绝对误差。

#### 评估方法速查

```
    ┌────────────────────────────────────────────────────┐
    │              我猜得准不准？                           │
    ├────────────────────────────────────────────────────┤
    │                                                    │
    │  MAE  (平均绝对误差):                               │
    │    "平均猜错了多少？"                                │
    │    例: 平均差了 3°C                                 │
    │                                                    │
    │  MAPE (平均绝对百分比误差):                          │
    │    "平均猜错了百分之多少？"                           │
    │    例: 平均差了 5%                                  │
    │    → MAPE < 10% = 很不错 ✅                         │
    │    → MAPE 10-20% = 还行 😐                         │
    │    → MAPE > 20% = 不太行 ❌                         │
    │                                                    │
    │  RMSE (均方根误差):                                 │
    │    "有没有离谱的大错误？"                             │
    │    对大误差惩罚更重                                  │
    │                                                    │
    └────────────────────────────────────────────────────┘
```

```python
import numpy as np

# 实际值和预测值
actual =   [100, 120, 115, 130, 125]
predicted = [98, 118, 117, 128, 127]

actual = np.array(actual)
predicted = np.array(predicted)

# MAE
mae = np.mean(np.abs(actual - predicted))
print(f"MAE: {mae:.1f} (平均差了 {mae:.1f})")

# MAPE
mape = np.mean(np.abs((actual - predicted) / actual)) * 100
print(f"MAPE: {mape:.1f}% (平均差了 {mape:.1f}%)")

# RMSE
rmse = np.sqrt(np.mean((actual - predicted) ** 2))
print(f"RMSE: {rmse:.1f}")
```

#### 记住这个

> 评估预测最重要的指标是 **MAPE**（百分比误差）。MAPE < 10% 就是很不错的预测了！

## 给你的小建议

1. **先画图**：拿到时间序列数据，第一件事就是画图！看看有没有趋势和季节性
2. **从简单开始**：先用移动平均试试水，再尝试 Prophet
3. **别忘了基线**：永远跟"直接用上一个值"或"去年同期的值"做比较，确保你的模型比这些简单方法好
4. **不要追求 100% 准确**：时间序列预测永远不可能完美。MAPE < 10% 就值得庆祝了
5. **注意数据质量**：缺失值、异常值、数据格式不对，这些都会搞乱你的预测

> 时间序列分析的本质：**从历史中寻找规律，用规律推测未来**。虽然我们不能 100% 预测未来，但好的预测能帮我们做出更好的决策！
