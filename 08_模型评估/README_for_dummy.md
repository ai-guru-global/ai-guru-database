# 08 模型评估 — 小白版 📝

> **一句话秒懂**: 模型评估就是给 AI "打分"——用各种指标判断 AI 学得好不好，就像考试一样，有选择题、填空题、应用题，AI 成绩好才能上岗！

## 为什么要学模型评估？

想象一下：
- 📊 怎么知道 AI 到底准不准？
- 🎯 怎么比较两个 AI 哪个更好？
- 📈 训练过程中怎么知道模型有没有变好？

**模型评估 = AI 的"成绩单"**

## 评估的基本概念

### 训练集 vs 验证集 vs 测试集

```
【划分数据集】

┌─────────────────────────────────────┐
│           全部数据                    │
├─────────────┬─────────────────────────┤
│   训练集    │     测试集(不动!)      │
│  (模型学习) │                        │
├─────────────┤                        │
│  验证集     │                        │
│ (调参选择)  │                        │
└─────────────┴─────────────────────────┘

比例: 常见 8:1:1 或 7:2:1

注意: 测试集要"藏"起来，最后才用！
```

### 评估流程

```
1️⃣ 训练模型
   用训练集学习

2️⃣ 调参
   用验证集调超参数

3️⃣ 最终评估
   用测试集评估泛化能力

4️⃣ 报告结果
   公开测试集上的指标
```

## 分类任务指标

### 1. 准确率

```
【最直观】预测正确的比例

准确率 = 预测正确数 / 总数

例子:
100 张图片，预测对 90 张
准确率 = 90%

注意:
- 类别不平衡时，准确率可能骗人
- 例如: 99% 是正常，1% 是异常
- 全部预测"正常"也有 99% 准确率！
```

### 2. 精确率 vs 召回率

```
【精确率】预测为正的里面，有多少真对了？

例子:
预测 10 个是癌症，其中 8 个真是癌症
精确率 = 80%

【召回率】所有正的里面，找出了多少？

例子:
实际上有 20 个癌症，找出了 8 个
召回率 = 40%
```

### 3. F1 分数

```
【精确率和召回率的调和平均】

F1 = 2 × (精确率 × 召回率) / (精确率 + 召回率)

为什么用 F1？
- 精确率高 → 保守，不轻易预测为正
- 召回率高 → 激进，尽可能找出正的

F1 平衡两者，得到一个综合分数
```

### 4. 混淆矩阵

```
【直观展示预测结果】

                 预测
              正例  负例
实际  正例   TP    FN
      负例   FP    TN

TP: 真的 Positive (预测对)
FN: 假的 Negative (漏检)
FP: 假的 Positive (误报)
TN: 真的 Negative (预测对)

衍生:
- 精确率 = TP / (TP + FP)
- 召回率 = TP / (TP + FN)
```

## 回归任务指标

### 1. MAE (平均绝对误差)

```
MAE = 平均(|预测值 - 真实值|)

优点: 直观，单位和原始数据一样
```

### 2. MSE (均方误差)

```
MSE = 平均((预测值 - 真实值)²)

优点: 对大误差惩罚更重
```

### 3. RMSE

```
RMSE = √MSE

优点: 和 MAE 同一单位，更容易解释
```

## LLM 评估

### 特定指标

```
【Perplexity】语言模型的质量
- 越低越好
- 衡量模型对文本的"困惑程度"

【BLEU】机器翻译质量
- 0-1，越高越好
- 对比生成文本和参考文本的 n-gram 重合度

【ROUGE】文本摘要质量
- 类似于 BLEU，用于摘要任务
```

### 基准测试 (Benchmark)

```
【常见 LLM 基准】

MMLU:
- 57 个学科，多选题
- 考察知识和推理能力

HumanEval:
- 编程题
- 考察代码能力

BIG-Bench:
- 200+ 任务
- 考察综合能力
```

## 评估实践

### 1. A/B 测试

```
【对比两个模型的真实效果】

方法:
- 随机分配用户到 A/B 两组
- A 组用模型 A，B 组用模型 B
- 比较业务指标（点击率、转化率等）
```

### 2. 影子模式

```
【不影响用户的情况下测试新模型】

方法:
- 新模型在后台运行
- 接收和线上一样的请求
- 但不返回给用户
- 对比新旧模型的输出
```

### 3. 回测

```
【用历史数据验证】

方法:
- 用过去 6 个月的数据
- 模拟当时的模型表现
- 看是否能达到当时的指标
```
