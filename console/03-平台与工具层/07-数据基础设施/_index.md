# 数据基础设施

> 数据湖、湖仓一体、向量库与数据治理：企业 AI 的数据底座，模型越强越依赖数据工程。

## 拆解卡

- **价值来源**：企业 AI 项目大部分工作量在数据侧：RAG、微调与 agent 都吃数据基础设施。
- **护城河**：数据引力（数据在哪计算就在哪）与开放格式生态（Delta/Iceberg）。
- **瓶颈**：云厂自研服务的挤压；非结构化数据治理成熟度。
- **领先指标**：湖仓一体采用率；向量库工作负载增长

## 六层速览

数据基础设施是企业 AI 的「地基工程」：数据湖、湖仓一体、向量库与治理工具——模型能力越强，企业越发现瓶颈在数据侧而不是模型侧。

**打个比方**：像装修前的水电改造：模型是家电，数据管道是水电；水电不通，再贵的家电也是摆设；而且水电一旦铺好，十年不会换厂商。

**拆开看**：四段链路：数据集成（ETL / CDC）→ 存储与计算（湖仓一体、Spark）→ 检索（向量库、全文）→ 治理（目录、血缘、权限）；AI 场景新增向量与治理两层。

**怎么运转**：商业模式三选一：按用量（云数仓）、按订阅（平台软件）、开源 + 企业版；数据引力决定黏性——数据搬不走，客户就走不了。

**格局与博弈**：Databricks 与 Snowflake 双雄对撞，Iceberg 开放格式打破锁定，向量库四强（Pinecone/Milvus/Weaviate/Qdrant）抢 RAG 入口，云厂商全部自研应战。

**边界与走向**：湖仓与向量库会融合成「AI 数据平台」，治理从合规成本变成 agent 的权限层；开放格式让存储层商品化，价值向计算引擎与治理层迁移。

## 关键判断

AI 的隐形地基：留存最好的软件品类，治理层是下一个价值高地（置信度 高，展望 12–24 个月）——评估看「NDR × 非结构化数据工作负载占比」；云厂自研是最大挤压源。

规模口径：全球数据管理与集成约 $900–1000 亿（2025e）

## 二级细分

- **湖仓一体** — Databricks/Snowflake 路线：把数据湖与数仓合并成一个平台。
- **向量与检索** — Pinecone/Milvus 类：为 RAG 与语义搜索提供检索底座。
- **数据治理与合规** — 目录、血缘与权限：企业敢不敢用数据的先决条件。
