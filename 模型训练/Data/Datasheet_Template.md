# 数据集文档模板 (Datasheet for Datasets)

> 标准化的数据集文档模板——记录数据集的来源、构成、偏差和使用限制，是负责任 AI 开发的基础。

> 参考论文: Gebru et al., "Datasheets for Datasets", 2021

---

## 模板

```markdown
# Datasheet: [数据集名称]

## 1. 基本信息

| 字段 | 内容 |
|------|------|
| 数据集名称 | [名称] |
| 版本 | [v1.0] |
| 发布日期 | [YYYY-MM-DD] |
| 许可证 | [CC-BY-4.0/...] |
| 创建者 | [团队/机构] |
| 联系方式 | [email] |
| 下载地址 | [URL] |
| 大小 | [XX GB] |

## 2. 动机 (Motivation)

### 创建目的
- [目的描述]

### 资金来源
- [资助方]

### 创建者角色
- [创建者背景]

## 3. 组成 (Composition)

### 数据实例
- 每个实例代表什么: [说明]
- 总实例数: [N]
- 是否有标签: [是/否]
- 标签类型: [分类/连续/多标签]

### 字段说明

| 字段名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| text | string | 文本内容 | "..." |
| label | int | 分类标签 | 0/1/2 |
| timestamp | datetime | 时间戳 | 2024-01-01 |

### 数据分布

| 类别 | 数量 | 占比 |
|------|------|------|
| 类别A | 10000 | 40% |
| 类别B | 8000 | 32% |
| 类别C | 7000 | 28% |

### 语言与地域
- 语言: [中文/英文/多语言]
- 地域覆盖: [全球/中国/美国/...]

## 4. 收集过程 (Collection Process)

### 数据来源
- [来源1]: [说明]
- [来源2]: [说明]

### 收集方式
- [人工标注/爬虫/传感器/合成]

### 收集时间
- 起止时间: [YYYY-MM 至 YYYY-MM]

### 采样策略
- [随机采样/分层采样/便利采样]

## 5. 预处理 (Preprocessing)

### 清洗步骤
1. [步骤1]
2. [步骤2]

### 标注过程
- 标注人员: [N人]
- 标注工具: [Label Studio/...]
- 一致性检查: [Cohen's Kappa = 0.85]
- 质量控制: [双人标注+仲裁]

## 6. 用途 (Uses)

### 预期用途
- [用途1]
- [用途2]

### 不建议用途
- [场景1]
- [场景2]

### 下游影响
- [潜在影响说明]

## 7. 分发 (Distribution)

### 分发方式
- [HuggingFace Hub / Kaggle / 自建]

### 使用条款
- [许可证条款]

### 访问限制
- [公开/申请/付费]

## 8. 维护 (Maintenance)

### 维护者
- [团队/个人]

### 更新频率
- [每月/每季度/不定期]

### 已知问题
- [问题1]
- [问题2]

## 9. 偏差与伦理 (Bias & Ethics)

### 已知偏差
- [偏差1]: [说明]
- [偏差2]: [说明]

### 敏感属性
- [性别/种族/年龄/地域]

### 缓解措施
- [措施1]
- [措施2]
```

## 实践指南

| 步骤 | 行动 | 工具/方法 | 预期产出 |
|------|------|-----------|----------|
| 1. 学习 | 系统学习核心知识 | 教材/课程/文档 | 知识体系建立 |
| 2. 练习 | 动手实践加深理解 | 实验/项目/练习 | 技能熟练 |
| 3. 应用 | 在实际项目中应用 | 工作项目/开源 | 经验积累 |
| 4. 优化 | 持续改进和优化 | 性能分析/重构 | 质量提升 |
| 5. 分享 | 输出和分享知识 | 博客/演讲/教学 | 影响力建设 |

## 常见误区

| 误区 | 正确认知 | 建议 |
|------|----------|------|
| 只学理论不实践 | 实践是检验理解的唯一标准 | 每学一个概念就动手验证 |
| 追求完美再开始 | 完成比完美更重要 | 先做MVP再迭代 |
| 忽视基础知识 | 基础决定上限 | 定期回顾基础 |
| 盲目追新 | 新技术需要验证 | 评估后再采用 |
| 单打独斗 | 协作效率更高 | 积极参与社区 |
