# FDE 工具栈大全

## 全栈工具矩阵

| 类别 | 工具 | 用途 |
|---|---|---|
| LLM 框架 | LangChain, LlamaIndex, Dify | 应用开发 |
| Agent | LangGraph, AutoGen, CrewAI | 多 Agent 编排 |
| 模型部署 | vLLM, Ollama, llama.cpp | 推理服务 |

| Prompt | LangSmith, 自建管理 | Prompt 版本管理 |

| 类别 | 工具 | 用途 |
|---|---|---|

| IaC | Terraform, Ansible, Helm | 基础设施管理 |
| GitOps | ArgoCD, FluxCD | 声明式部署 |
