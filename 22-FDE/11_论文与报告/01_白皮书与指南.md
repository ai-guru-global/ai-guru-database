# 白皮书与指南

## 核心 FDE 文献

### 1. yeasy/forward_deployed_engineering_guide

**来源**：GitHub - github.com/yeasy/forward_deployed_engineering_guide

**概述**：目前国内最系统的 FDE 指南，涵盖 FDE 的定义、能力模型、交付方法论、团队建设、工具栈等完整内容。

**核心贡献**：
- FDE 的系统化定义和能力框架
- DADI 交付方法论（Discovery-Architecture-Delivery-Iteration）
- 中国本土化的 FDE 实践建议
- 完整的 FDE 工具栈推荐

**必读指数**：⭐⭐⭐⭐⭐

### 2. Palantir AIP FDE 官方文档

**来源**：palantir.com/docs/foundry/ai-fde/overview

**概述**：Palantir AIP（AI Platform）的 FDE 部署指南，是 FDE 鼻祖的官方方法论。

**核心内容**：
- AI 平台的 FDE 部署模式
- Ontology（本体论）驱动的 AI 应用构建
- AIP Logic 和 AIP Automate 的使用
- 安全与治理框架

**必读指数**：⭐⭐⭐⭐

### 3. OpenAI Deployment Company（DeployCo）

**来源**：[openai.com/index/openai-launches-the-openai-deployment-company](https://openai.com/index/openai-launches-the-openai-deployment-company/)

> ⚠️ **日期更正**：早期版本误记为「2025 年 9 月」。经核实，正式宣布日期为 **2026 年 5 月 11 日**。

**概述**：OpenAI 于 2026 年 5 月 11 日启动的 Deployment Company（业内简称 DeployCo），由 TPG 主导（~$4B 初始投资），通过创始收购 Tomoro 带入约 150 名 FDE，标志大模型公司正式以独立实体进入 FDE 领域。

**核心信息**：
- OpenAI 意识到仅提供 API 不够，需要帮客户落地
- TPG 领投，Brookfield 参与，共 19 家投资方
- 收购伦敦/爱丁堡应用 AI 咨询公司 Tomoro（带入~150 名 FDE）
- 与咨询公司合作扩大覆盖面

**补充来源**：[HPCwire 2026.5.11](https://www.hpcwire.com/aiwire/2026/05/11/openai-launches-deployment-company-to-scale-enterprise-ai-adoption/) · [Tomoro 公告](https://tomoro.ai/insights/tomoro-acquired-by-openai-deployment-company) · [Aventis Advisors](https://aventis-advisors.com/ai-services-ma-2026/)

**必读指数**：⭐⭐⭐⭐⭐

### 4. Anduril 的 FDE 实践

**来源**：anduril.com/careers

**概述**：国防科技公司 Anduril 大量使用 FDE 模式部署边境监控、反无人机等系统。

**核心特点**：
- 硬件 + 软件的 FDE 交付
- 军事级安全要求
- 快速迭代（数周而非数月）

**必读指数**：⭐⭐⭐

### 6. Anthropic 企业级 AI 服务公司（2026.05.04）

**来源**：[anthropic.com/news/enterprise-ai-services-company](https://www.anthropic.com/news/enterprise-ai-services-company)

**概述**：Anthropic 与 Blackstone + Hellman & Friedman + Goldman Sachs 合作成立企业级 AI 服务公司（媒体报~$1.5B），把 Claude 嵌入被投组合公司及中型企业。比 OpenAI DeployCo 早一周宣布。

**补充来源**：[Goldman Sachs 新闻稿](https://am.gs.com/en-us/advisors/news/press-release/2026/anthropic-partners-with-blackstone-hf-and-goldman-sachs-ai-services) · [CNBC](https://www.cnbc.com/2026/05/04/anthropic-goldman-blackstone-ai-venture.html)

**必读指数**：⭐⭐⭐⭐

### 7. a16z《Services-Led Growth》

**来源**：[a16z.com/services-led-growth](https://a16z.com/services-led-growth/)

**概述**：论述企业 AI 公司如何用「服务主导增长」建立护城河——主动牺牲短期毛利换取高切换成本，FDE 正是这种打法的核心载体。

**必读指数**：⭐⭐⭐⭐⭐

### 8. Agent 协议学术综述

**来源**：[arxiv.org/html/2505.02279v1](https://arxiv.org/html/2505.02279v1)

**概述**：系统综述 MCP / A2A / AG-UI 三大 Agent 协议的设计目标、层次关系与互操作性。FDE 在 2026 年做多 Agent 系统部署的必读背景资料。

**必读指数**：⭐⭐⭐⭐

## 推荐阅读顺序

```
入门：
1. yeasy/forward_deployed_engineering_guide（全面系统）
2. Indeed/BI FDE 岗位数据（市场真实数据，注意 BI 已更正）

进阶：
3. Palantir AIP FDE 文档（行业鼻祖）
4. OpenAI Deployment Company 公告（2026.5.11 最新实践）
5. Anthropic 企业级 AI 服务公司公告（2026.5.4）

深度：
6. Anduril FDE 实践（硬件+软件）
7. a16z《Services-Led Growth》（商业模式理论）
8. Agent 协议学术综述（arxiv 2505.02279）
```

---

> **关键**：FDE 是一个非常新的领域，文献有限。**最好的学习方式是在实践中总结**——每做一次交付，自己写一篇方法论沉淀。
