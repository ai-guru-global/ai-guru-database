## 一、书名与定位

**书名（已定稿，2026-11-25）**：《大模型运维指南：LLM-Ops 稳定性工程技术实战》

> 使用口径：正文统称「本书」；营销物料可单独使用副题《LLM-Ops 稳定性工程技术实战》。书名关键词即全书承诺——**「稳定性」不是一章，是全书组织方式**。

**定位一句话**：中文第一本以「稳定性工程」为主轴的大模型运维书——不讲训练、不讲调参，按「看得见 → 跑得稳 → 扛得住 → 改得动 → 救得回 → 新战场 → 治得久」的稳定性生命周期，回答「怎么跑得稳、出了事怎么救、怎么让『稳』成为默认态」。

**四个差异化卖点**：

1. **稳定性七字诀结构**：市面运维书按技术栈罗列；本书按稳定性生命周期组织——每篇对「稳」的一个动词负责，读者可按自身阶段直接翻到对应篇。
2. **贯穿案例**：虚构「磐石平台」（一家中型公司的 LLM 服务平台）从第一台 GPU 到多租户 Agent 平台的全旅程——每章推进一个阶段并引爆一个真实故障，字典式知识库转化为叙事式图书的关键手法。
3. **统一章模板（四件套）**：开篇场景 → 稳定性目标 → 原理机制 → 故障场景与决策树 → 速查表 → 稳定性检查单——本库 37 性能专题验证过的可复用范式升格为全书体例。
4. **Agent 时代新故障面**：传统运维书写到推理服务为止；本书延伸到 Agent Runtime/沙箱/记忆的稳定性——超前 6–12 个月窗口。

## 三、素材规则与章模板

- **素材映射**：每章标注 repo 素材页（约 55% 可改写），新写比例 = 磐石案例叙事 + 章间连贯 + 稳定性框架提炼。
- **三条红线**：① 被映射素材标 `book-used` 防双改漂移；② 代际数字付印前 web 全量复核；③ 行业研判不入书（归 console）。
- **统一章模板**（四件套体例）：①开篇磐石场景 → ②本章稳定性目标（保什么指标、破稳方式）→ ③原理与机制 → ④故障场景与决策树 → ⑤速查表 → ⑥稳定性检查单 → ⑦习题三问。
- **体量**：正文 30–32 万字（30 章 × 8–10K），纸质 480–540 页；附录 3.5 万字。
