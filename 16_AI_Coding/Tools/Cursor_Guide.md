# Cursor 使用指南

> **一句话**: Cursor 是 2026 年最佳全能 AI IDE，Pro 版 $20/月，代码接受率 72% 行业最高，适合大型项目开发。

---

## 1. 概述

### 定位

| 维度 | 说明 |
|------|------|
| **类型** | AI IDE（集成开发环境） |
| **订阅等级** | Pro |
| **月费** | ¥120/月（$20/月） |
| **适用** | 大型项目、多文件重构 |
| **官网** | https://cursor.com |

### 核心能力

```
Cursor:
├── Composer — 多文件编辑
│   ├── 跨文件重构
│   ├── 自动生成测试
│   └── 代码审查建议
├── Tab — 智能补全
│   ├── 72% 代码接受率（行业最高）
│   └── 上下文感知
├── @ 引用系统
│   ├── @file / @folder
│   ├── @web
│   └── @code
└── Agent Mode
    ├── 自动化任务执行
    └── 多步骤工作流
```

## 4. 最佳实践

- 额度刷新后优先处理高价值项目
- Composer 模式适合大型项目，Tab 模式适合日常编码
- Agent Mode 可自动化复杂任务，但消耗额度较快
