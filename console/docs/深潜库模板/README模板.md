## 编写与维护约定

1. **事实纪律**：数字必须带世代/年代锚点；不确定的型号、数字、日期一律标「（待核实）」，核实后删标注并更新 `更新:` 字段。
2. **新增条目**：新知识点放对应两位数域目录；新厂家进 `厂家/`；写完在本 README 和相关篇的 `## 关联` 补链接。
