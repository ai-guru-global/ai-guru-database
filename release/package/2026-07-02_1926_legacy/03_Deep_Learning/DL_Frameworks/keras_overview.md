## 简介

Keras 是深度学习领域的核心框架。

**官网**: [Keras](https://keras.io/)

- 详见官方文档

## 框架对比

| 框架 | 计算图 | 优势 | 生态 |
|------|--------|------|------|
| PyTorch | 动态 | 研究首选、调试方便 | Hugging Face |
| TensorFlow | 静态/动态 | 生产部署、TF Lite/JS | TF Serving |
| Keras | 抽象层 | API 简洁、快速原型 | TF 集成 |
