# 网卡与 DPU

> 一句话定位：利润池约 8%、毛利 50%+、NVIDIA 份额 60%+——被 GPU 生态绑定程度最高的环节，ConnectX 谱系跟着每代 GPU 走，GPUDirect 直连与集合通信库构成软性锁定；DPU 是云侧多租户的第二曲线，AI 训练集群内渗透率仍低（估算口径）。

## 规模与驱动

配比逻辑：网卡需求与 GPU 出货 1:1–1:2 绑定，端口速率随 GPU 代际翻倍；DPU 需求主要来自通用云与推理多租户平台。

| 世代 | 网卡 | 端口 | 典型配比 |
| --- | --- | --- | --- |
| H100 世代（2022–2023） | ConnectX-7 | 400G | 每 GPU 1–2 张 |
| B200/GB200 世代（2024–2025） | ConnectX-8 | 800G | 每 GPU 800G 直配 |
| DPU 侧 | BlueField-3（2023，400G） | — | 通用云/多租户为主 |

谱系锚点：CX-6 Dx 200G（2020）→CX-7 400G（2022）→CX-8 800G——与交换芯片 25.6T→51.2T、光模块 400G→800G 的代际严格同频，是「网络价值量随算力代际抬升」的组成部分。

DPU 的差异化在多租户隔离与存储/网络虚拟化卸载——训练集群基本不用，推理服务平台与通用云才是主力场景（估算口径）。

## 竞争格局

| 玩家 | 谱系 | 定位 |
| --- | --- | --- |
| NVIDIA | ConnectX + BlueField | 份额 60%+（口径基线），与 GPU/Rail 打包销售 |
| Broadcom | Thor 800G NIC（2024 发布口径，待核实） | 非 NV 生态的以太网选项 |
| AMD | Pensando DPU 系列 | 主机侧卸载+开放生态（UEC 阵营） |
| Intel | E810 等 | 通用段为主，AI 后端存在感弱（待核实） |
| 国产 | 中科驭数等 DPU/NIC | 商用规模待核实 |

## 单位经济

- 毛利 50%+（口径基线）：高速 SerDes、RDMA 卸载与 GPUDirect P2P 的工程壁垒支撑溢价；高端 400G/800G 单价千美元级（估算口径）。

| 产品 | 毛利位置 | 定价逻辑 |
| --- | --- | --- |
| ConnectX 高端 | 50%+ 带内上沿 | 随 GPU 代际同步定价、同单采购 |
| BlueField DPU | 50%+ 带内 | 卸载价值+DOCA 软件栈 |
| 通用以太网 NIC | 显著更低（估算） | 红海竞争 |

- 锁定三件套：GPUDirect（NIC-GPU 直连免 CPU 拷贝）、NCCL 对 ConnectX 的深度优化、与 GPU 整机/整机柜同单采购。换 NIC 不只换硬件，等于重验全集群通信栈。
- 软件叠加：DOCA 等软件栈把 DPU 从网卡升级为主机侧加速平台，订阅收入叠加在硬件毛利之上。

## 关键变量与风险

- 生态开放化：UEC 1.0（2025-06）/UALink 1.0（2025）推动 NIC 与上层解耦，开放式 NIC 需先过性能基线验证才有采购资格。
- 云厂自研：AWS Annapurna 等体系内自研长期压缩 TAM（口径待核实）。
- 国产化：国产 DPU 在国内多租户云的商用规模（待核实）是国产链条完整性的一环。
- 传导风险：GPU 出货波动 1:1–1:2 直接传导；非 NV GPU 阵营（AMD/国产）的高端网卡配套选项有限（待核实）。
- 世代叠加：400G→800G 切换期内 SKU 并行，库存与认证成本上升。
