# 中兴 × GPU 高网

> 运营商系设备商中把「十万卡级组网」方法论讲得最系统的一家：交换机是生意，白皮书是旗帜。

## 在 GPU 高网中的角色

中兴（ZTE）的 GPU 高网角色分三层：

1. **智算交换机供应商**：面向运营商、政企与第三方智算中心的数据中心交换机产品线（ZXR10 品牌，智算款型号待核实），国内智算网络第二梯队（份额口径待核实）。
2. **AI 服务器/整机柜供应商**：GPU 服务器与机架方案是其在智算中心价值量的另一支柱（具体机型与出货口径待核实），具备「服务器 + 网络」打包交付能力。
3. **组网方法论输出者**：2026-02 发布白皮书，提出十万卡级集群互联协议需预留 GPU ID 标识位空间等可扩展性设计（已核实）——把「协议字段留余量」这类架构级判断公开发布，是其区别于纯产品厂商的姿态。

与华为的全栈闭环不同，中兴没有自研 AI 芯片做需求锚点，其高网叙事依托运营商与政企市场的采购主渠道。

## 技术路线与取舍

- **依托运营商与政企市场**：以集中采购、框架合作驱动，讲究可交付与可演进，而非互联网大厂式的极限参数。
- **协议可扩展性优先**：白皮书的 GPU ID 预留观点直指十万卡规模下标识/地址空间不够用的协议层风险——与超以太网（UEC）在协议头部做扩展空间的思路同向（对照关系待核实）。
- **以太网 RoCE 单路线**：无 IB 阵营背书；交换芯片自研程度（是否自研 51.2T ASIC）待核实。
- **服务器 + 网络协同**：以整机柜和整体交付为卖点，代价是与专业交换机厂商相比单点深度不足。
- **国际渠道**：借运营商客户关系在海外承接智算中心与网络项目（口径待核实）。
- **代际风险**：51.2T 级平台上量节奏若落后头部（待核实），将直接影响运营商智算项目竞标。
