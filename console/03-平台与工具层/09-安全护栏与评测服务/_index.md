# 安全护栏与评测服务

> 红队、护栏与安全评估的产业化：前沿能力 commercialize 的前提。

## 拆解卡

- **价值来源**：前沿能力商业化的合规前提，监管直接创造的市场。
- **护城河**：评测方法学与监管互认。
- **瓶颈**：标准未定，采购意愿滞后于合规压力。
- **领先指标**：AI Act 执法案例；红队/评估服务采购额

## 六层速览

安全护栏是给 AI 应用装的「刹车与安全带」：拦截越狱、敏感内容和危险工具调用；Agent 时代还要管住它能碰哪些系统、能花多少钱。

**打个比方**：像机场安检——不能保证绝对安全，但能把大部分风险挡在登机口之外；检查越严，通行越慢，误杀与漏检之间永远要平衡。

**拆开看**：五段链路：输入过滤 → 提示词注入检测 → 输出审核 → 工具权限控制 → 红队与持续评测；内容过滤相对成熟，行为约束与权限控制才是难点。

**怎么运转**：按调用量收费的安全 API、企业安全平台订阅、红队服务项目制；监管合规是需求驱动，保险与审计也在推高预算，事故则是最大的获客来源。

**格局与博弈**：传统安全厂商（Palo Alto、CrowdStrike）把 AI 安全并入平台，专精厂商（Lakera、Robust Intelligence）做模型侧防护，模型原厂内置护栏；三股力量互相挤压，OWASP LLM Top 10 等标准提供共同语言。

**边界与走向**：护栏会从「内容过滤」转向「行为约束与权限」：Agent 调用哪些工具、能写哪些数据、花多少钱，都要有策略与审计；安全会成为 agent 平台的基础能力而非外挂，独立厂商的空间在跨平台治理。

## 关键判断

合规驱动型市场，增长确定但天花板受模型内置能力与云厂免费捆绑限制；agent 运行时防护是最有增量的细分（置信度 中，展望 12–24 个月）——核心变量是监管执行力度与 agent 安全事件；独立厂商的差异化必须建立在「行为监控 + 证据链」而非基础内容过滤。

规模口径：AI 安全与护栏约 $20–40 亿（2025e）

## 二级细分

- **输入输出护栏** — 越狱与敏感内容的内容过滤
- **工具权限** — agent 能碰什么、花什么的边界
- **红队与评测** — 持续对抗测试与安全认证
