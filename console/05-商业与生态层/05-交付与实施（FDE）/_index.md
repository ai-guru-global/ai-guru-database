# 交付与实施（FDE）

> 把模型接进客户现场：FDE 人力、服务伙伴认证与交付毛利，AI 应用的乙方层。

## 拆解卡

- **价值来源**：把模型接进客户现场的乙方层，交付产能即行业瓶颈。
- **护城河**：认证体系与交付方法论复用。
- **瓶颈**：人力规模与毛利的矛盾（规模化困难）。
- **领先指标**：FDE 认证与伙伴体系扩展；交付毛利披露

## 六层速览

交付与实施（FDE）是把模型能力装进客户真实业务的最后一公里：卖的不是模型，是「能跑起来的结果」；模型越通用，交付越值钱。

**打个比方**：像装修队：材料（模型）在市场上谁都能买，但把水电、动线、柜子按你的户型装好，才是别人替代不了的价值。

**拆开看**：六段链路：需求诊断 → 数据接入与清洗 → 流程改造 → 系统集成 → 上线与培训 → 持续迭代与运维，每一段都消耗人天，也每一段都可能成为亏损点。

**怎么运转**：前向部署工程师（Forward Deployed Engineer）常驻客户现场，把通用模型接到客户的 ERP、CRM、专有数据上；交付周期从数月缩到数周才是竞争力，复用模板才能提毛利。

**格局与博弈**：咨询公司有客户关系但缺模型能力，模型厂有模型但缺行业纵深，系统集成商两头都不占优；于是出现「模型厂 + 咨询」的联盟，以及 Palantir 式的高价驻场模式。

**边界与走向**：标准化 Agent 平台会吃掉一部分实施工作，但越是非结构化、越涉及组织变革的场景，人的交付价值越高；FDE 会从项目制走向「订阅式驻场」，交付经验会沉淀成产品与模板。

## 关键判断

交付是 AI 落地的必要环节，产品化决定长期价值；FDE 是当前最有效的转化机制（置信度 中，展望 12–24 个月）——核心变量是产品化比例与 FDE 人才供给；评估交付商应看「复购与模板复用率」。

规模口径：AI 实施与服务约 $150–300 亿（2025e），咨询、SI 与 FDE 合计

## 二级细分

- **前向部署（FDE）** — 驻场交付，Palantir 模式扩散
- **系统集成** — 传统交付主力，毛利承压
- **产品化** — 交付经验沉淀为模板与产品
