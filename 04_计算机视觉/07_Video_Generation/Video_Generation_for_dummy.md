# AI 视频生成 - 小白版 🎬

> **一句话秒懂**: AI 视频生成就是让 AI 当"导演"——你给一段文字描述，AI 就能生成对应的视频，就像有个好莱坞特效团队在你电脑里，24 小时待命！

## 为什么要学视频生成？

想象一下：
- 🎬 你说"一只猫在弹钢琴"，AI 就画出一段猫咪弹琴的短视频

- 🎨 你画个草图，AI 生成专业级动画

这就是 2026 年的 AI 视频生成技术！

## 核心概念

### 1. 什么是视频生成？

```
【对比静态图生成】
文字 → AI画图: 1张图片
文字 → AI生成视频: 多张图片 + 时间连贯

【视频 = 空间 + 时间】
空间: 图片的每一帧
时间: 帧与帧之间的变化（动作、运镜）

AI需要同时理解:
1. 空间（这个东西长什么样）
2. 时间（它应该怎么动）
```

### 2. 主流模型对比

| 模型 | 分辨率 | 时长 | 价格 | 特色 |
|------|--------|------|------|------|
| Veo 3.1 | 4K | 60 秒 | 订阅制 | 原生音频 |
| Kling 3.0 | 1080p | 120 秒 | $0.10/秒 | 最佳人像 |
| Seedance 2.0 | 1080p | 60 秒 | $0.14/秒 | 12 模态 |
| Gen-4.5 | 4K | 60 秒 | 积分制 | 专业控制 |
| MiniMax | 1080p | 60 秒 | $0.004/秒 | API 友好 |

### 3. 技术趋势（2026）

```
【原生音频生成】NEW!
之前: 视频生成后需要单独配音
现在: Veo 3.1 可以同时生成画面和配乐
效果: AI生成的音乐和画面完美同步

【实时生成】NEW!
之前: 生成10秒视频需要3-8分钟
现在: Runway <100ms 首帧
意义: 从"等待结果"变成"实时预览"

【物理正确性】NEW!
之前: 物体可能穿墙、漂浮
现在: 模型理解重力、碰撞
效果: 更真实的物理世界模拟

【一致性控制】IMPROVED!
之前: 角色在不同镜头可能"变脸"
现在: 跨镜头一致性大幅提升
意义: 可以生成长序列故事
```

## Prompt 技巧

```
【好的Prompt要素】
1. 主体: 谁/什么在画面里
2. 动作: 发生了什么
3. 场景: 在哪里
4. 风格: 什么风格
5. 镜头: 怎么拍

【示例】
❌ 差的: "一只狗在跑"
✓ 好的: "一只金毛犬在夕阳下的海滩上奔跑，
        镜头跟随其后，电影感色调，
        4K画质，景深效果"

【镜头语言】
- "pan left/right" — 平移
- "zoom in/out" — 推拉镜头
- "dolly shot" — 移动镜头
- "aerial view" — 航拍视角
- "close-up" — 特写
```

## 常见问题

### Q: AI 视频能代替电影制作吗？

**A**: 暂时不能！
```
现在的AI视频:
✓ 15-60秒短片段
✓ 单个场景/镜头
✓ 创意预览和辅助

现在的AI视频做不到:
✗ 长电影（连贯性会崩）
✗ 复杂剧情（难以控制）
✗ 专业级特效（物理仿真）
```

### Q: 生成视频要多少钱？

**A**: 看需求！
```
【免费/便宜】
- Wan 2.6: 开源免费
- MiniMax: $0.004/秒（最便宜）
- Runway基础: 积分制

【中等价格】
- Kling 3.0: $0.10/秒
- Seedance 2.0: $0.14/秒

【高端】
- Veo 3.1: 订阅制（贵但质量最好）
- Runway Pro: 按项目收费
```

### Q: 视频有版权问题吗？

**A**: 取决于平台！
```
【一般原则】
- 个人使用: 大多数平台允许
- 商业使用: 要看平台条款
- 音乐/配音: 可能有额外限制

【建议】
- 用平台提供的音乐
- 注意平台的商业授权
- 涉及真人形象要谨慎
```
