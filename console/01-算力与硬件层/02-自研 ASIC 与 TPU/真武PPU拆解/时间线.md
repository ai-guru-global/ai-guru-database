# 真武 PPU 时间线（2018–2026）

> 事实层年表，最新在上；观点见 [行业拆解](行业拆解.md)。口径纪律：官方页为一手锚点（2026-11-06 检索），媒体转述逐条标注层级；冲突项挂 [`docs/2026待核实清单.md`](../../../docs/2026待核实清单.md) 第十节。

## 2026

- **2026-11（建库盘点时状态）** · 官方页产品线现状：810E 北京/杭州/上海/乌兰察布商用；M890 乌兰察布商用、中卫邀测（超节点实例 Day0 适配 Kimi K3.1 Pro）；V900 标「敬请期待」未商用。PPU SDK 2.2.0；外部客户 650+（官方页口径）。✅ 一手锚点
- **2026-02-12** · 腾讯新闻转述 IDC：累计出货突破 60 万片（截至 2026Q1），国内第二、首超寒武纪。❓ 转述层级
- **2026-02-02** · 新浪财经：「真武」发布，阿里自研芯片「黄金三角」（含光 800/倚天 710/真武 PPU）叙事成型；同期传平头哥分拆上市，公司低调回应。❓ 传闻不采信
- **2026-02** · 观察者网口径：累计出货 47 万颗、服务 400+ 客户。⚠️ 与官方页 650+ 口径存在时点差
- **2026-01-29** · TrendForce 报道平头哥「镇宇 810E」发布：性能据称优于 A800、可比肩 H20（「镇宇」为官宣初期媒体用名）
- **2026-01-28** · 36氪：阿里首次证实自研 AI 芯片 PPU 存在，大规模出货已有一年
- **2026-01（月末）** · [真武 PPU 官方页](https://www.aliyun.com/ppu) 上线：三产品线 + PPU SDK + 灵骏超节点 GP9A/GP9AS 实例 + ACS 部署方案

## 2025

- **2025（月份未公开）** · 真武在阿里内部规模部署（由「大规模出货已有一年」倒推）；媒体口径服务通义千问训练与推理，无官方自供占比披露。🔍 需一手源

## 2021

- **2021-10** · 倚天 710 发布：Armv9 服务器 CPU，128 核，台积电 5nm——平头哥数据中心芯片第二子，不碰 AI 管制红线
- **2021-10** · 玄铁 RISC-V IP 逐步开源，成为中国 RISC-V 生态主力

## 2019

- **2019-09-25** · 含光 800 发布（云栖大会）：阿里首款 AI 推理 NPU，主打视觉推理（城市大脑）
- **2019-07-25** · 玄铁 910 与无剑 SoC 平台发布：平头哥首批产品，确立「RISC-V IP + 设计平台」路线

## 2018

- **2018-09** · 平头哥半导体成立：达摩院芯片业务独立，整合中天微与达摩院自研团队
