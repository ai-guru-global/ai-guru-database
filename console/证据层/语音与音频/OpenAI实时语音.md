# OpenAI实时语音

> 语音交互的「GPT 时刻」：从 GPT-4o 实时语音演示到 Realtime API 平台化，再到 GPT-Realtime-2 的语音控制操作系统。

## 概述

OpenAI 2024 年 5 月 GPT-4o 发布时的实时语音对话演示（端到端低延迟、情感、可打断）重定义了语音交互预期；此后路线分两步：消费端 Advanced Voice 进 ChatGPT，开发者端 Realtime API（2025-09 GA）把「语音到语音」变成可购买的能力。2026 年的 GPT-Realtime-2 把语音 Agent 推向操作系统控制层。

该赛道已成红海：Qwen-Audio-Realtime（AA 语音榜第一）、字节 SeedRealtime、蚂蚁 Realtime-Venus、Grok Voice 等中外玩家密集发布，语音从「助手功能」升格为智能体的原生交互界面。

## 分析

1. **语音是 Agent 的原生 UI**：GPT-Realtime-2 操控操作系统、Qwen-Audio 接管 ASR/TTS/Realtime 全栈——2026 年的共识是「键盘是过渡形态」，实时语音是智能体交互的终局候选。
2. **全双工是技术分水岭**：从「轮次切换」到「可打断、可插话」的全双工架构（SeedRealtime、Realtime-Venus）是当前工程竞争焦点，延迟与轮次策略直接决定体验档位。
3. **开源追平速度极快**：Qwen/蚂蚁/字节把实时语音开源化，语音能力从差异化卖点变为基础设施——商业空间向「语音 Agent 的场景与合规层」上移。
