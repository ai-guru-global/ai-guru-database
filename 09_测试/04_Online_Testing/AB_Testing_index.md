## 附录：样本量计算示例

```python
from statsmodels.stats.power import TTestIndPower

# 参数设置
baseline_rate = 0.75  # 基线转化率
mde = 0.05           # 最小可检测效果 5%
alpha = 0.05         # 显著性水平
power = 0.80         # 统计功效

# 计算样本量
analysis = TTestIndPower()
effect_size = mde / (baseline_rate * (1 - baseline_rate)) ** 0.5
sample_size = analysis.solve_power(
    effect_size=effect_size,
    alpha=alpha,
    power=power,
)
print(f"每组需要: {int(sample_size)} 样本")
```

## 附录：常见陷阱与应对

| 陷阱 | 说明 | 应对策略 |
|------|------|----------|
| 过早停止 | 未达样本量就下结论 | 预设实验时长 |
| 多重比较 | 多指标增加假阳性 | Bonferroni 校正 |
| 新奇效应 | 用户短期行为变化 | 延长实验周期 |
| 样本污染 | 组间信息泄露 | 严格隔离 |
| LLM 方差 | 输出不确定性大 | 增大样本量 |
