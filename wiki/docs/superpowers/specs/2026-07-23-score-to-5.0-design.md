## 2. 满分文档标准（写法规范）

所有新建/扩充文档须满足以下标准，对齐现有满分样本（如 `Zuckerberg_AI_Pivot_2026.md` 565行、`Machine_Learning_Engineer/` 题库套件）。

### 2.1 深度内容文档标准（人物专题/技术深度页）

- **行数**: 450-650 行（对齐样本）
- **frontmatter**: 完整含 title/category/tags/summary/created/updated/tier/aliases/sources
- **summary**: 必含"一句话概括"加粗
- **结构**: 概述 → 时间线/背景 → 核心内容分多级标题 → 对比表 → 前沿/争议 → 关联wikilink
- **wikilink**: 每篇 7-14 条 `[[ ]]` 交叉引用
- **表格密度**: 每篇至少 3 个对比/概览表
- **mermaid 图**: 适用处加 flowchart/timeline

### 2.2 题库套件标准（面试岗位）

每个岗位目录含 5 文件：
- `索引.md` — 岗位概览、技能矩阵、晋升路径
- `question_bank.md` — 30-50题分类题库（基础/进阶/场景/系统设计）
- `interview_answers.md` — 重点题深度答案
- `interview_preparing.md` — 备考路线、资源、陷阱
- `company_level_question_bank.md` — 按公司分级（大厂/独角兽/外企）

### 2.3 索引.md 导航页标准

- 描述本目录是什么（非模板占位）
- 文件导航表（文件 | 说明）
- 子目录导航
- 核心知识体系表（知识域|内容|重要程度|优先级）
- 至少 5 条 wikilink 指向相关章节

## 核心术语速查

| 术语 | 含义 | 关联概念 |
|------|------|----------|
| Loss Function | 衡量预测与真实值差距 | 交叉熵/MSE/对比损失 |
| Gradient Descent | 沿负梯度方向更新参数 | SGD/Adam/学习率 |
| Overfitting | 模型在训练集过好但泛化差 | 正则化/Dropout/早停 |
| Batch Size | 每次更新的样本数 | 收敛速度/显存/噪声 |
| Epoch | 完整遍历训练集一次 | 训练轮次/早停 |
| Fine-tuning | 在预训练模型上继续训练 | 迁移学习/LoRA/全量 |
| Inference | 模型前向传播产生输出 | 延迟/吞吐/量化 |
| Token | 文本处理的最小单元 | BPE/SentencePiece |
