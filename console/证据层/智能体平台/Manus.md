# Manus

> 2025 年最出圈的中国 Agent 产品：从刷屏发布到「Meta 收购—监管叫停—恢复独立」的地缘过山车，通用工作 Agent 的定义样本。

## 概述

Manus 由连续创业者肖弘的蝴蝶效应（Butterfly Effect）团队打造，2025 年 3 月以「通用 AI Agent」演示视频刷屏出圈——自主完成简历筛选、股票分析、网站搭建等端到端任务。产品形态是多智能体编排（规划-执行-验证循环）+ 云端虚拟机沙箱。

2025-12 官宣以约 20 亿美元加入 Meta，2026-04 被中国国家发改委以「洗澡式出海」名义禁止该外资收购，交易撤销，2026-08 恢复独立运营并发布 Manus 2.0——一起完整呈现跨境 AI 资产并购地缘约束的案例。

## 分析

1. **「洗澡式出海」第一案**：Manus 案确立了中资 AI 资产被外资收购的监管红线——架构在海外、用户在境内、创始人在境内走避税/合规套利的路径被显式封堵，对后续中国 AI 公司的资本路径设计影响深远。
2. **产品化快于商业化**：从演示刷屏到常驻云电脑、定时任务、连接器矩阵，Manus 的产品节奏是第一梯队；但独立后的营收能力（订阅 + API）仍待验证。
3. **通用 Agent 的定位之争**：Manus 的「云端多智能体 + 虚拟机」路线与 Claude Code 系「终端单智能体」路线代表了通用 Agent 的两种形态学。
