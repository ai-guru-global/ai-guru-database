## 一、具身智能概述

### 1.1 定义

**具身智能 (Embodied AI)** 是指具有物理实体、能够与真实世界交互的智能系统。它强调智能来源于**身体与环境的交互**，而非纯粹符号计算。

> **一句话理解**: 具身智能让 AI "走出屏幕"，通过物理身体感知世界、理解世界、改变世界。

### 1.2 具身智能 vs 非具身 AI

| 维度 | 非具身 AI (ChatGPT/LLM) | 具身智能 (机器人) |
|------|------------------------|-------------------|
| **感知** | 文本/图像输入 | 多模态传感器 (视觉、力觉、触觉) |
| **输出** | 文本/图像生成 | 物理动作、运动控制 |
| **环境** | 静态数据集 | 动态物理世界 |
| **反馈** | 即时响应 | 延迟反馈、部分可观测 |
| **安全** | 信息安全 | 物理安全 |
| **学习** | 离线训练 | 在线适应、终身学习 |

## 六、Sim2Real 迁移

### 6.1 迁移策略

| 策略 | 方法 | 效果 |
|------|------|------|
| **Domain Randomization** | 随机化仿真参数 | 提升鲁棒性 |
| **Domain Adaptation** | 对抗适应、特征对齐 | 缩小域差距 |
| **System Identification** | 辨识真实系统参数 | 仿真更真实 |
| **Residual Learning** | 学习仿真到真实的残差 | 精细调整 |
| **Digital Twin** | 构建精确数字孪生 | 高保真迁移 |

### 6.2 Domain Randomization

```python
class DomainRandomization:
    """
    域随机化配置
    """
    
    def __init__(self):
        self.randomizations = {
            # 视觉随机化
            'lighting': {
                'brightness': (0.5, 1.5),
                'contrast': (0.8, 1.2),
                'saturation': (0.8, 1.2),
            },
            
            # 相机随机化
            'camera': {
                'position': 0.05,  # ±5cm
                'orientation': 0.1,  # ±0.1 rad
                'fov': (50, 70),
            },
            
            # 物理随机化
            'physics': {
                'friction': (0.3, 1.2),
                'mass': (0.8, 1.2),
                'damping': (0.9, 1.1),
            },
            
            # 物体随机化
            'object': {
                'position': 0.02,
                'color': True,
                'texture': True,
            }
        }
    
    def apply(self, env):
        """应用到环境"""
        for category, params in self.randomizations.items():
            env.randomize(category, params)
```
