## 1. 公司背景与战略定位

### 平头哥是谁?

平头哥半导体有限公司（T-Head）成立于 **2018 年 9 月**，是阿里巴巴集团全资控股的芯片设计公司，总部位于上海张江。名字取自「蜜獾」（平头哥），寓意「生死看淡、不服就干」的攻坚精神。

**成立脉络**:
- 2018 年 4 月：阿里全资收购杭州中天微系统有限公司（中国大陆唯一自主嵌入式 CPU IP Core 公司）
- 2018 年 9 月：云栖大会上，张建锋宣布将中天微与达摩院自研芯片业务整合为「平头哥半导体」
- 2023 年：阿里「1+6+N」组织改革后，RISC-V 团队（玄铁）并入达摩院，平头哥更聚焦企业级芯片设计与商业化

### 战略定位

| 阶段 | 时间 | 核心任务 |
|------|------|---------|
| 内部降本 | 2018-2023 | 为阿里云定制 AI/CPU/SSD 主控芯片 |
| 规模部署 | 2023-2025 | 倚天 710、含光 800 在阿里云规模化部署 |
| 对外销售 | 2025 起 | 真武 PPU 走出阿里，服务外部客户 |
| 独立上市 | 2026 起 | 阿里决定支持平头哥未来独立上市 |

> **核心使命**: 让阿里云拥有资源可控、技术可控的基础设施芯片，并逐步形成独立面向市场的芯片供应能力。

## 3. 真武 PPU 系列详解

### 3.1 真武 810E

2025 年 9 月，央视《新闻联播》在中国联通三江源绿电智算中心报道中意外曝光了平头哥最新 AI 芯片 PPU。2026 年 1 月 29 日，平头哥官网正式上线「真武 810E」。

#### 核心规格

| 参数 | 规格 |
|------|------|
| 显存 | **96GB HBM2e** |
| 片间互联带宽 | **700GB/s** |
| ICN 互联端口 | **7 个片间互联端口** + 自研互联加速库 |
| 接口 | **PCIe 5.0 ×16** |
| 功耗 | **≤ 400W** |
| 定位 | AI 训练 / AI 推理 / 自动驾驶 |
| 架构 | 自研并行计算架构 + 片间互联技术 |
| 软件栈 | 全栈自研 |

#### 性能定位

- 整体性能 **超过 NVIDIA A800**
- 整体性能 **与 NVIDIA H20 相当**
- 据外媒报道，升级版性能 **强于 NVIDIA A100**

### 3.2 真武 M890

2026 年 5 月 20 日，在 2026 阿里云峰会上，平头哥发布新一代训推一体 AI 芯片「真武 M890」。

#### 核心规格

| 参数 | 规格 |
|------|------|
| 显存 | **144GB** |
| 片间互联带宽 | **800GB/s** |
| 性能 | **真武 810E 的 3 倍** |
| 精度支持 | FP32 / FP16 / FP8 / FP4 等 |
| 定位 | 高精度训练、低精度/超低精度推理全场景 |
| 互联芯片 | 配合自研 **ICN Switch 1.0** |
| 集群能力 | **64 卡全带宽互联**，128 卡超节点 |
| 通信时延 | 低至百纳秒级 |

#### 精度支持是什么意思？FP32 → FP4 有啥区别？

真武 M890 说「原生支持 FP32 到 FP4 等多种数据精度」，这里的「精度」可以理解为：**数字用多少位二进制来表示**。

位数越多，表示得越精细；位数越少，表示得越粗糙，但计算更快、更省内存。

| 精度 | 全称 | 每位参数占多少字节 | 通俗理解 | 适用场景 |
|------|------|------------------|---------|---------|
| **FP32** | 32 位浮点 | 4 字节 | 小数点后保留很多位，最精确 | 模型训练初期、对精度要求极高的场景 |
| **FP16** | 16 位浮点 | 2 字节 | 精度减半，但速度/省内存翻倍 | 主流训练、推理 |
| **FP8** | 8 位浮点 | 1 字节 | 再减半，大部分情况下几乎看不出质量损失 | 大模型推理加速 |
| **FP4** | 4 位浮点 | 0.5 字节 | 最粗糙，但最快、最省显存 | 超大模型推理、边缘部署、对速度要求极高的场景 |

**大白话类比**：

想象你在记录一个人的身高：
- FP32 = 记录到 **1.75321 米**
- FP16 = 记录到 **1.75 米**
- FP8 = 记录到 **1.8 米**
- FP4 = 记录到 **约 1.8 米** 或 **约 1.7 米**

对于大部分 AI 任务，FP16 甚至 FP8 已经足够「看不出差别」，但 FP4 可以让同样大小的显存装下 **8 倍** 于 FP32 的参数，推理速度也更快。

**真武 M890 支持全精度的意义**：
- **训练时用 FP32/FP16**：保证模型学得更准、更稳
- **推理时用 FP8/FP4**：让同样硬件跑得更快、服务更多用户
- 一块芯片覆盖「高精度训练」到「超高速推理」全部场景

> 想了解更多数值精度的通用概念：[[概念/model-precision|模型精度 (Model Precision & Accuracy)]]

## 4. 技术架构

### 4.1 设计哲学

真武 PPU 采用 **软硬件全自研** 路线：

- **自研并行计算架构**：针对 AI 训练/推理中的矩阵运算、数据并行优化
- **自研片间互联技术**：解决多卡扩展中的通信瓶颈
- **全栈自研软件栈**：从驱动、运行时到框架适配层
- **CUDA 兼容**：降低模型迁移成本（据财新报道）

### 4.2 与 NVIDIA 路线对比

| 维度 | 平头哥真武 | NVIDIA H20 |
|------|-----------|-----------|
| 显存 | 96GB HBM2e | 96GB HBM3 |
| 片间互联 | 700GB/s | ~900GB/s (NVLink) |
| 接口 | PCIe 5.0 ×16 | PCIe 5.0 ×16 |
| 功耗 | ≤ 400W | 400W |
| 软件生态 | 自研 + CUDA 兼容 | CUDA |
| 制程/代工 | 国内供应链推进 | TSMC 4nm |

## 7. 软件生态

### 7.1 全栈自研软件栈

平头哥为真武 PPU 构建了 **T-Head SAIL** 全栈自研软件栈，覆盖驱动、运行时、通信、框架适配等层次：

| 层次 | 组件 | 说明 |
|------|------|------|
| 驱动层 | PPU Driver | 硬件驱动 |
| 运行时 | PPU Runtime | 任务调度、内存管理 |
| 通信库 | 自研集合通信 / 互联加速库 | 多卡/多机通信，配合 ICN 7 端口互联 |
| 框架适配 | PyTorch / TensorFlow / vLLM / SGLang | 主流训练/推理框架适配 |
| 模型优化 | 量化、编译优化 | 支持 FP16/FP8/FP4 等 |

**T-Head SAIL 的特点**：
- 统一编程接口，降低开发和迁移成本
- 兼容主流 AI 生态应用
- 支持 vLLM、SGLang 等主流推理引擎
- 与阿里云 PAI-Model Gallery 等云平台集成

### 7.2 CUDA 兼容性

据行业报道，真武 PPU **与 CUDA 生态兼容**，这意味着：

- 已有 CUDA 代码迁移成本较低
- 可运行大量基于 PyTorch/TensorFlow 的开源模型
- 对开发者和云客户更友好

### 7.3 与阿里云协同

真武 PPU 深度结合阿里云「芯-云-模型-推理」技术体系：

- 通义大模型训练/推理优化
- 阿里云百炼平台推理服务
- 阿里云灵骏智算集群调度
