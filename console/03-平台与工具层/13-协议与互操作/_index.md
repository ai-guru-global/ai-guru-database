# 协议与互操作

> MCP 等协议把工具调用标准化：agent 生态的 USB 接口。

## 拆解卡

- **价值来源**：工具调用的 USB 接口：把 N×M 集成降为 N+M。
- **护城河**：协议事实标准的网络效应。
- **瓶颈**：安全与授权模型尚不完善。
- **领先指标**：主流平台原生支持数；MCP 服务器生态增速

## 六层速览

协议与互操作让不同 AI 系统、工具和数据源「说同一种语言」，MCP 是当前最受关注的开放协议；它要解决的是 N×M 的集成爆炸。

**打个比方**：像 USB-C 接口——设备各异，但插口统一，谁都能接；接口统一后，配件生态才会爆发，而定义接口的人拿走生态租金。

**拆开看**：五段结构：传输层（stdio / SSE / HTTP）→ 能力声明（tools / resources / prompts）→ 权限与认证 → 服务发现 → 多 Agent 协作（A2A）；安全边界是落地前提。

**怎么运转**：协议本身开源免费，商业价值在托管服务、网关、安全审计与生态集成；谁运营「最常用的连接器目录」，谁就掌握分发权与默认推荐位。

**格局与博弈**：Anthropic 发起 MCP，OpenAI、Google、Microsoft 跟进，A2A 争多 Agent 协作标准；云厂商与工具厂商用协议扩大生态，企业最关心的是审计、权限与数据边界。

**边界与走向**：协议会从「工具接入」扩展到「身份、支付与权限」：agent 代表谁、能花多少钱、能访问什么，都会写进协议；标准之争决定谁能成为 Agent 时代的入口，协议分裂与治理中立性同样关键。

## 关键判断

协议层赢家通吃，但变现属于治理与网关而非协议本身；安全是这一层最大的不确定性与机会（置信度 中高，展望 12–24 个月）——核心变量是安全事件与企业治理需求；观察指标应是「企业网关的付费渗透」，而非 server 数量。

规模口径：协议层本身无直接收入，其带动的工具、网关与注册表市场约 $10–30 亿（2025e）

## 二级细分

- **工具协议** — MCP：模型接工具的 USB-C
- **Agent 协作** — A2A：跨 agent 的任务交接
- **身份与支付** — agent 代表谁的授权与结算
