# 群核科技

> 「杭州六小龙」里最像软件公司的一家（⚠️ 媒体口径）：主业是酷家乐——云端 3D 室内设计 SaaS，靠 GPU 云渲染引擎把家居效果图变成分钟级生意；2025 年起以 SpatialLM/SpatialGen 开源把存量室内场景数据与渲染管线重述为「空间理解 + 场景生成」的空间智能叙事——「物理世界模拟器」的世界模型牌，打在家装工具的现金流上。

## 是什么

**杭州群核信息技术有限公司**（官网 [kujiale.com](https://www.kujiale.com/) 署名「酷家乐 - 全场景在线3D云设计平台 - 群核科技旗下」，页脚版权口径 2011-2026 ✅）是国内家居家装垂直设计软件的头部玩家。媒体口径称 2011 年创立于杭州、创始团队有 GPU 算力背景 ⚠️，与 DeepSeek、宇树科技等同被媒体归入「杭州六小龙」⚠️（媒体归纳，非官方名单）。招股书转述口径援引灼识咨询：按 2023 年收入计为全球最大云端 3D 空间设计平台、中国最大空间设计软件提供商 ⚠️ 二手转述，本卡未核得招股书原文 🔍。

**主业与商业模式**：酷家乐覆盖户型/硬装/软装建模、效果图与漫游渲染、施工与生产清单对接的在线化闭环，收入来自订阅与渲染资源消耗 ⚠️ 行业通识口径；客单结构、付费客户数未核得一手披露 🔍。海外版 Coohom（[coohom.com](https://www.coohom.com/) ✅）定位「基于云的 3D 室内设计平台」，自述办公地点覆盖纽约/伦敦/上海/东京/新加坡/首尔，宣称 60 万+ 3D 模型库、G2 评分 4.4/5（132 条评论）✅ 官网页面口径。

**平台 AI 化**（官网首页核得 ✅）：AI 建模（「一句话或一张图，秒生3D模型」）、AI 设计、AI 渲染、AI 视频四条工具线，同时接入第三方生成模型——AI 建模列 Lux3D、混元3D、Tripo，AI 渲染列 Seedream 等，AI 视频列可灵、Seedance ✅ 官网导航口径；Lux3D 对应该司 GitHub 组织下的 ComfyUI-Lux3D / Aholo-Lux3D 仓库（推断自研 ⚠️）。官网当前还列出酷家乐 CLI（Beta，「让你的 AI 助手直连酷家乐，通过对话创建和设计方案」）与「酷家乐Skills」「AI造物」栏目 ✅（上线时点未核 🔍）——把设计平台开放为智能体可调用工具是明确的最新方向。

**IPO 进展**：2021 年曾推进赴美上市后搁置 ⚠️ 媒体回溯口径 🔍；2025-02 递表港交所（媒体口径联席保荐人摩根大通、建银国际，具体递表日报道为 2025-02-28 ⚠️），并被称为「杭州六小龙」首家递表港交所的公司 ⚠️。递表材料披露的营收/亏损具体数字，本卡未核得一手原文，**不转引、严禁补数**，以披露易 A1 申请版本文件为准 🔍；截至本卡更新（2026-11-12）未核得通过聆讯或挂牌的一手记录——递表 ≠ 上市，后续以 HKEXnews 与公司公告为准 🔍。

**AI/空间智能动作**：开源研究以 GitHub 组织 [Manycore-Research](https://github.com/Manycore-Research) 名义进行（媒体常称其 KooLab 实验室，官网未核得该名目 🔍）。两条主线：SpatialLM（2025-03 首发 ✅ repo News 口径）——3D 点云输入、输出墙体/门窗/带语义类别物体框的结构化场景理解，底座 Llama3.2-1B 与 Qwen2.5-0.5B 两档，2025-06 技术报告（[arXiv:2506.07491](https://arxiv.org/abs/2506.07491) ✅）并升级 1.1 版（点云分辨率翻倍、开放类别检测），2025-09 数据集开源并中稿 NeurIPS 2025 ✅，repo 5.1k stars；SpatialGen（[arXiv:2509.14981](https://arxiv.org/abs/2509.14981)，2025-09-18 提交、v4 至 2026-01-15 ✅）——布局条件的多视角多模态扩散模型，从 3D 语义布局 + 文本/图像生成外观/几何/语义一致的真实感室内场景，3DV 2026 接收 ✅。组织下另有 SpatialCrafter（自述「Single Image World Modeling with Generative 3D Proxies」，Apache-2.0，2026-11 仍在推送）、InteriorGS 室内 3DGS 数据集等 ✅ API 口径。

**「世界模拟器」叙事与主业的关系**：群核的叙事路径是「室内设计模拟器 → 物理世界模拟器」——主业多年积累的结构化室内场景数据与渲染工程（Structured3D 数据集即出自该组织，论文 ECCV 2020 ✅）被重新定价为具身智能/机器人训练的空间数据底座。但两条线的收入距离尚远：SpatialLM 许可含 CC-BY-NC 研究组件（repo 许可说明 ✅），开源本身不产生收入；设计 SaaS 收入是否受益于空间智能叙事，是这条线索的核心观察变量。

## 怎么看

1. **「世界模型」叙事的实质是存量资产重定价。** 主业多年积累的不是装修客户名单，而是结构化室内场景数据管线（户型→布局→语义→渲染）与 GPU 渲染工程。SpatialLM/SpatialGen 把这套资产转写为空间智能研究产出，叙事从「装修工具」跃迁为「物理世界模拟器」；但开源许可偏研究向（CC-BY-NC 组件），叙事与收入之间隔着未经验证的商业化路径。
2. **它的世界模型路线被主业数据形态塑造。** WorldLabs 从单图生成可导航 3D 世界（[[世界模型/WorldLabs]]），Genie 走视频隐式世界（[[世界模型/Genie]]），NVIDIA Cosmos 做物理仿真平台（[[世界模型/NVIDIACosmos]]）；SpatialGen 以**结构化布局为条件**生成场景——输入端是精确可控的语义布局而非纯文本。这正是室内设计 SaaS 的数据形态，也决定其天然面向具身智能训练场（可控、可复置、带语义）而非消费级内容生成。
3. **生成能力 commodity 化反噬渲染卖点，群核的应对是把入口移到智能体。** 官网 AI 建模/渲染/视频同时接入混元3D、Tripo、Seedream、可灵等第三方模型——渲染不再是独占壁垒；酷家乐 CLI（Beta）/Skills 与 Coohom-Freeform（Codex 直连）把平台重构成「智能体的设计工具调用层」。这是垂直 SaaS 在 Agent 时代的求生动作，也是观察点：设计师工作流入口是否会被通用 Agent 绕过。
4. **IPO 要按「程序」读，不按「叙事」读。** 递表（2025-02 媒体口径）后截至 2026-11 未核得聆讯/挂牌记录：港股 A1 有效期 6 个月，失效后更新递表属常态程序，失效与重新递表本身是信息；「六小龙首家上市」的媒体叙事与实际发行窗口是两回事。财务面（亏损收窄与否、订阅 vs 渲染收入结构）需以披露易文件逐字核对后补入本卡 🔍。
5. **反方记录：垂直设计工具的 AI 替代风险真实存在。** 若通用生成式模型把「效果图/方案生成」价格打到趋近于零，酷家乐护城河收缩为行业结构化数据（户型库/模型库/生产对接）与施工交付工作流——这部分最难被模型直接替代，但增速与客单价能否撑住招股书估值口径，取决于主业与 AI 叙事能否互相兑现。
6. **台内观察价值：垂直行业 SaaS 转型空间智能的中国样本。** 与 [[行业应用/中望软件]]（工业 CAD）同属「行业深度数据 + 工作流」型公司面对 AI 的转型对照；具身智能需求侧见 [[具身智能/宇树科技]]（同为「杭州六小龙」媒体口径 ⚠️）；上市窗口背景见 [[商业与投融资/AI的IPO窗口]]。
