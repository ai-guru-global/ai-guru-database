# 开源多智能体平台盘点 2026

> 中文简称：开源多智能体平台盘点

> **一句话理解**: AgentScope 之外，开源多智能体生态分为框架层（AutoGen/CrewAI/LangGraph/MetaGPT 等）和平台层（Dify/Coze 开源版等），按协作模式和场景选型。

---

## 1. 主流开源多智能体框架

| 框架 | 出品方 | 协作模式 | 特点与最佳场景 |
|------|--------|---------|----------------|
| **AutoGen** | Microsoft | 对话式 Group Chat | 多角色讨论、代码协作、Human-in-the-loop；生产就绪度高 |
| **CrewAI** | 独立团队 | 角色 + 任务编排 | Role/Goal/Backstory 定义 Agent，学习曲线低，适合快速原型 |
| **LangGraph** | LangChain | 状态机 + DAG | 原生支持循环、checkpoint 持久化、条件分支，复杂工作流首选 |
| **MetaGPT** | DeepWisdom | SOP 软件公司模拟 | 把多 Agent 组织成"软件公司"（产品/架构/工程师角色） |
| **CAMEL-AI** | CAMEL 社区 | Role-Playing 对话 | 最早的多智能体研究框架之一，偏研究/数据生成 |
| **Semantic Kernel** | Microsoft | 插件 + 编排 | 企业级，.NET/Java/Python 多语言支持 |
| **agno** | Agno 团队 | 知识 + 记忆内置 | 内置知识库/记忆系统，适合文档问答、个人助手 |
| **SmolAgents** | HuggingFace | 代码驱动 | 轻量级，Agent 用代码而非 JSON 调用工具 |
| **OpenAI Agents SDK（原 Swarm）** | OpenAI | 轻量编排 + Handoff | 官方轻量框架，适合快速原型 |
| **AutoGPT** | Significant Gravitas | 自主规划执行 | 目标分解、自主执行、反思改进 |
| **XAgent / OpenManus** | 社区 | 自主任务执行 | Manus 类通用 Agent 的开源复刻 |

---

## 2. 平台层（低代码/可视化，含多 Agent）

| 平台 | 说明 |
|------|------|
| **Dify**（开源） | 可视化工作流 + Agent 编排 |
| **Coze 开源版（coze-studio）** | 字节开源的 Agent 开发平台 |
| **FastGPT** | 偏 RAG 工作流 |
| **n8n** | 偏自动化集成 |

---

## 3. 与 AgentScope 定位最接近的

AgentScope 的差异化是 **Actor 模型 + 消息驱动 + 大规模并发**（狼人杀等多智能体模拟场景），以及配套的生产部署方案 AgentRun。定位最接近的同类：

- **AutoGen** — 同样消息/对话驱动，研究味重
- **CAMEL** — 同样强调多智能体社会模拟
- **LangGraph** — 同样生产级，但走状态机而非 Actor 模型

---

## 4. 选型速查

| 场景 | 推荐 |
|------|------|
| 对话式多 Agent 协作 | AutoGen |
| 角色分工、快速原型 | CrewAI |
| 复杂工作流、需要循环/持久化 | LangGraph |
| 大规模并发、中文场景、模拟类游戏/社会实验 | AgentScope |
| 模拟软件公司做代码生成 | MetaGPT |
