# LLM Data Engineering

> 中文简称：大模型数据工程 ｜ English Name: LLM Data Engineering

LLM 数据工程（LLM Data Engineering）— 预训练数据清洗（data cleaning）、数据配比（data mixture）、合成数据与数据质量评估。

## 子域简介

本子域聚焦 LLM 训练的数据工程环节：

- **数据清洗**: 去重、过滤、质量筛选
- **数据配比**: 多源数据混合策略
- **合成数据**: 使用 LLM 生成训练数据
- **质量评估**: 数据质量指标和监控

## 数据清洗流程

```
原始数据 →
├── 语言识别 → 过滤非目标语言
├── 质量过滤 → 去除低质量内容
├── 去重 → MinHash/SimHash
├── 敏感信息 → PII 移除
└── 有害内容 → 安全过滤
→ 清洗后数据
```

## 附录：去重算法对比

| 算法 | 原理 | 复杂度 | 适用场景 |
|------|------|------|------|
| MinHash | 局部敏感哈希 | O(n) | 大规模去重 |
| SimHash | 局部敏感哈希 | O(n) | 近似去重 |
| Exact Dedup | 精确匹配 | O(n) | 完全重复 |
| Suffix Array | 后缀数组 | O(n log n) | 子串去重 |
