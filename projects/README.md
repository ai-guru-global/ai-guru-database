# 项目案例库 (Projects)

> **定位**: 动手实战的 AI 项目教程，每个项目包含完整的需求分析、实现代码、部署方案和评估结果。

## 规划中的项目类别

| 难度 | 类别 | 示例项目 |
|------|------|----------|
| ⭐ 入门 | ML 基础 | 房价预测、垃圾邮件分类 |
| ⭐⭐ 初级 | 深度学习 | 图像分类器、文本情感分析 |
| ⭐⭐⭐ 中级 | NLP/LLM | 构建 RAG 系统、微调 LLaMA |
| ⭐⭐⭐⭐ 高级 | Agent 工程 | 构建 AI Agent、多 Agent 协作 |
| ⭐⭐⭐⭐⭐ 专家 | 生产部署 | K8s 上的 LLM 服务、MLOps 流水线 |

## 项目模板结构

```
projects/
├── project-name/
│   ├── README.md          # 项目概述、目标、前置知识
│   ├── requirements.txt   # 依赖
│   ├── src/               # 源代码
│   ├── notebooks/         # Jupyter 笔记本
│   └── docs/              # 详细文档
```
