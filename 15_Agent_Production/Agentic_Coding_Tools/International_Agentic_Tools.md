## 2. Aider

### 2.1 核心定位

```
Aider: 终端 AI 编程搭档
═══════════════════════════════════════════════════════════════════════════

定位: 终端-first 的 AI 编程工具，强调"人在回路"

核心理念:
───────────────────────────────────────────────────────────────────────────
• 不替换你的工作流，而是增强它
• 无需 IDE，直接在终端编程
• 深度集成 git，支持 undo
• 多模型支持，可切换
```

### 2.2 核心特性

| 特性 | 描述 |
|------|------|
| **多模型支持** | GPT-4o, Claude 3.5, Gemini, 本地模型 |
| **Git 集成** | 自动 commit, branch, undo |
| **文件编辑** | 精确编辑，不乱改 |
| **多文件修改** | 一次性修改多个相关文件 |
| **上下文管理** | 自动追踪依赖 |
| **终端操作** | 执行命令，解释输出 |

### 2.3 使用示例

```bash
# 启动 aider
aider

# 或指定模型
aider --model claude-3-5-sonnet

# 直接编辑文件
aider src/app.py

# 多文件修改
aider src/auth.py tests/test_auth.py

# 带初始指令
aider --model gpt-4o --message "重构用户认证模块"
```

### 2.4 核心配置

```yaml
# ~/.aider.conf.yml
model: claude-3-5-sonnet
editor: vim
auto-commits: true
commit-message: "AI-assisted refactor"
map-tokens: 6000
no-detect-urls: false
```

### 2.5 与 Claude Code 对比

| 维度 | Aider | Claude Code |
|------|-------|-------------|
| **交互方式** | 终端 | 终端+UI |
| **Git 集成** | 深度集成 | 一般 |
| **Undo 支持** | 完整 | 有限 |
| **多模型** | 灵活切换 | Claude 为主 |
| **上下文** | 自动管理 | 手动提示 |

## 3. Continue

### 3.1 核心定位

```
Continue: VS Code/JetBrains 的 AI 扩展
═══════════════════════════════════════════════════════════════════════════

定位: 首个开源的 AI 代码助手扩展，完全可定制

核心理念:
───────────────────────────────────────────────────────────────────────────
• 100% 开源，可自托管
• 支持任何 LLM API
• 深度 IDE 集成
• 完全可定制
```

### 3.2 核心特性

| 特性 | 描述 |
|------|------|
| **IDE 集成** | VS Code + JetBrains | 
| **多模型** | OpenAI, Anthropic, Local, 自定义 |
| **代码库索引** | LanceDB 向量索引 |
| **Slash Commands** | /edit, /chat, /custom |
| **Context Providers** | 文件、代码段、文档 |
| **私有部署** | 完全自托管 |

### 3.3 使用示例

```python
# Continue 配置示例
# ~/.continue/config.py
from continue import Continue

config = Continue(
    models=[
        {"name": "claude-3-5-sonnet", "provider": "anthropic"},
        {"name": "codestral", "provider": "mistral"},
    ],
    index=[
        {"name": "code", "type": "LanceDB"},
        {"name": "docs", "type": "FileSystem"}
    ]
)
```

```
CodeRabbit: AI 代码审查专家
═══════════════════════════════════════════════════════════════════════════

定位: 专注于代码审查和 PR 讨论的 AI 工具

核心理念:
───────────────────────────────────────────────────────────────────────────
• 不是通用的编程助手，而是审查专家
• 支持 GitHub PR 自动化审查
• 自动化建议和 human-in-the-loop

```

### 4.2 核心特性

| 特性 | 描述 |
|------|------|
| **PR 审查** | 自动审查 PR，提出改进建议 |
| **讨论线程** | 在代码行级别讨论 |
| **变更摘要** | 自动生成 changelog |
| **问题检测** | Bug, 性能, 安全问题 |
| **CI 集成** | GitHub Actions |
| **多语言** | Python, JS, TS, Go, Rust |

## 8. 对比与选型

### 8.1 工具对比表

| 工具 | 类型 | 核心定位 | 定价 | 开源 |
|------|------|----------|------|------|
| **Aider** | 终端 | 命令行编程搭档 | 免费 | ✓ |
| **Continue** | IDE 扩展 | 可定制扩展 | 免费 | ✓ |
| **CodeRabbit** | 审查工具 | PR 审查 | 免费/Pro | 部分 |
| **Cody** | IDE 扩展 | 代码库理解 | 免费/Pro | - |
| **Tabnine** | 补全 | 本地隐私 | 免费/Pro | - |
| **Codeium** | 补全 | 快速免费 | 免费 | - |

### 8.2 场景选型

```
场景选型
═══════════════════════════════════════════════════════════════════════════

日常补全 ────────────────────────────────────────────────────────────────
│ Codeium (免费快速)
│ Tabnine (隐私优先)
└── GitHub Copilot (功能全面)

终端编程 ────────────────────────────────────────────────────────────────
│ Aider (深度 git 集成)
│ Claude Code (Claude 官方)
└── Continue (多模型切换)

IDE 扩展 ────────────────────────────────────────────────────────────────
│ Continue (高度可定制)
│ Cody (代码库深度理解)
└── Windsurf (代理架构)

代码审查 ────────────────────────────────────────────────────────────────
│ CodeRabbit (PR 审查专家)
│ Cody (代码图谱)
└── Claude Code (Review 模式)
```

### 8.3 开源 vs 闭源

```
开源工具优势:
───────────────────────────────────────────────────────────────────────────
✓ 完全可定制
✓ 可自托管，数据不外传
✓ 社区驱动，持续改进
✓ 无供应商锁定

闭源工具优势:
───────────────────────────────────────────────────────────────────────────
✓ 开箱即用，无需配置
✓ 专业支持
✓ 可能质量更高 (大规模训练)
✓ 更完善的产品体验
```
