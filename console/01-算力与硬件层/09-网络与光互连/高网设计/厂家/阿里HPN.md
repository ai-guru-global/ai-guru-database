# 阿里 HPN × GPU 高网

> 国内首个以顶会论文（SIGCOMM 2024）完整公开的大规模 AI 训练网络架构：双 ToR、双平面，15,000 GPU 单集群。

## 在 GPU 高网中的角色

HPN（High-Performance Network）是阿里为 LLM 训练自建的高性能网络，也是国内互联网大厂中第一个把万卡级组网架构决策写成学术论文公开的案例：

1. **架构样本**：双平面双 ToR 拓扑成为国内后续智算集群「多平面设计」的事实参照系。
2. **工程方法样本**：论文展示「用简化换确定性」的组网哲学——不是堆功能，而是删约束。
3. **产业外溢**：其供应商体系（国产交换机厂商）借 HPN 级需求完成打磨（合作细节为公开报道口径，待核实）。

## 架构要点（论文口径）

| 要素 | 内容 | 备注 |
|---|---|---|
| 规模 | 15,000 GPU 单集群（已核实） | 以 8 卡服务器为组网单元（具体配置待核实） |
| 双 ToR | 每服务器上联两台 ToR，分属两个平面 | 单 ToR 故障只损失带宽不失联 |
| 双平面 | 两平面物理隔离，自下而上互不交叉 | 消除跨平面 in-network 路径 |
| 汇聚层 | 单平面内汇聚交换机之间无横向互联 | 平面内保持两级 Clos 极简结构（细节以论文为准） |
| 端侧汇合 | 跨平面流量只发生在服务器网卡侧 | 负载均衡在端侧/NIC 层解决（机制细节待核实） |
| 带宽代际 | 400G 为基础代际（论文口径） | 具体网卡数与上行配比待核实；800G 代际演进待核实 |

## 技术路线与取舍

- **以分片换确定性**：双平面把单平面规模与哈希域减半，ECMP 极化与微突发冲突域随之减半；代价是单平面容量上限固定，扩容需整体加平面。
- **以隔离换故障域**：两平面物理隔离，任何网络器件故障的爆炸半径被限制在单平面内；端侧双归属保证服务器可达性。
- **做减法的工程取舍**：论文口径包括简化路由与负载均衡、快速故障收敛，以及对部分链路层可靠性机制（纠错/重传相关取舍）的削减（具体机制以论文为准，待核实）。
- **与应用耦合**：集合通信（NCCL Ring/Tree）的分 plane/chunk 行为与双平面对齐——网络为训练通信模式定制，而非通用云网络复用。
- **验证口径**：论文级公开意味着数字可复核（15,000 GPU 为论文口径），这是 HPN 区别于宣传稿的价值所在。
- **后续演进**：论文后续版本、800G 代际与更大规模集群（待核实）。

## 竞争与对标

| 对照对象 | 差异 |
|---|---|
| 字节 MegaScale（NSDI 2024） | HPN 讲「网怎么建」（拓扑/隔离/简化），MegaScale 讲「网上怎么稳」（拨测/慢节点/放置），两篇互补构成国内大厂公开实践双子星 |
| 传统单平面 Clos | 万卡级单平面哈希域过大、故障半径大；HPN 用物理分片替代算法调优 |
| NVIDIA IB 方案 | HPN 证明以太网 + 简化架构可支撑 15k GPU 训练，是以太网统一路线的国内证据 |
| NVIDIA NVL72 级超节点 | 超节点把 scale-up 压进机柜以规避 scale-out 复杂度，HPN 用双平面简化 scale-out——两条路线殊途同归：用架构分片换确定性 |
| 自研通用云网络 | 通用云网络（VPC/隧道/重叠虚拟化）与训练网分治，HPN 为 LLM 训练单独建网，不复用既有设施 |

## 近况（2025–26）

- 无已核实增量（SIGCOMM 2024 论文为既有事实；HPN 后续代际与更大规模集群的公开细节待核实）。
