# 自研 ASIC 与 TPU

> 云厂商与头部 lab 为特定 workload 自研的专用芯片，追求性价比与供应自主。

## 拆解卡

- **价值来源**：云厂商把推理成本曲线握回自己手里、对冲 GPU 供给风险的手段。
- **护城河**：与自家 workload 和采购规模深度耦合，外部难以复制。
- **瓶颈**：软件生态（CUDA 迁移成本）与代工产能分配。
- **领先指标**：TPU/Trainium 对外开放比例；自研芯片对内部负载的替代率

## 六层速览

自研 ASIC 与 TPU 是为特定 AI 负载定制的芯片：砍掉通用电路与冗余功能，用更低的成本与功耗换更高的有效吞吐。

**打个比方**：GPU 像全能运动员，ASIC 像为某一个项目定制的器械——只练一件事，但把这件事做到极致；代价是换项目就得重做器械。

**拆开看**：矩阵计算单元（MXU / 脉动阵列）+ 片上缓存与 HBM + 片间互连 + 编译器与框架（XLA / Neuron / CANN）；硬件与「它只服务的那类模型」深度绑定。

**怎么运转**：云厂商用自研芯片承接内部训练与推理，省下 GPU 溢价；部分对外开放租用；芯片团队与业务负载团队深度绑定，编译器把模型图翻译成专用指令，软件适配的投入往往超过硬件本身。

**格局与博弈**：谷歌 TPU 最成熟（Gemini 全栈自用），AWS Trainium 追赶，Meta MTIA 服务推荐与推理，微软 Maia 起步；中国以昇腾为核心，寒武纪、燧原补位；生态迁移成本是最大门槛。

**边界与走向**：胜负取决于「负载规模 × 软件成熟度」：负载越大、模型越稳定，专用化越划算；推理成为主负载后性价比优势放大，但通用性短板限制其对外销售，长期形成「通用 GPU + 云自研 ASIC」的双轨格局。

## 关键判断

结构性受益，但赢家是云厂而非独立芯片商（置信度 中高，展望 24–36 个月）——关键看推理负载占比与软件栈成熟度；独立 ASIC 厂商难分享这一红利。

规模口径：全球 AI 加速器约 $2000–2500 亿，自研 ASIC 占 15–25%（2025e），且份额逐年抬升

## 二级细分

- **云自研（TPU/Trainium/MTIA）** — 头部云厂商的定制路线，成本优势随规模放大。
- **国产替代（昇腾等）** — 供给自主驱动的第二条供给曲线，生态成熟度是差距所在。
