## 3. 知识增强预训练框架

### 3.1 ERNIE 1.0: 知识掩码策略

ERNIE 的核心创新是将外部知识融入预训练过程，而非简单的 token 级掩码。

```
传统 BERT 掩码 vs ERNIE 知识掩码:
════════════════════════════════════════════════════════════════════

  输入: "哈尔滨是黑龙江省的省会"

  BERT (Token-Level Masking):
  ────────────────────────────────────
  [哈尔滨]是[黑龙][江省]的[MASK][会]
           ↑ 随机掩码单个 token

  ERNIE (Entity-Level Masking):
  ────────────────────────────────────
  [哈尔滨]是[MASK][MASK][MASK]的[MASK][MASK]
           ↑ 掩码整个"黑龙江省"实体

  ERNIE (Phrase-Level Masking):
  ────────────────────────────────────
  [哈尔滨]是[MASK][MASK][MASK][MASK][MASK][MASK]
           ↑ 掩码整个"黑龙江省的省会"短语
```

三种掩码策略的区别：

| 掩码级别 | 掩码单位 | 示例 | 知识粒度 |
|----------|----------|------|----------|
| Token 级 | 单个字/词 | 黑 → [MASK] | 无结构 |
| Phrase 级 | 完整短语 | 黑龙江省 → [MASK] | 句法结构 |
| Entity 级 | 命名实体 | 哈尔滨市 → [MASK] | 语义知识 |

### 3.2 ERNIE 2.0: 持续学习框架

ERNIE 2.0 引入了持续学习 (Continual Learning) 框架，支持增量添加预训练任务。

```
ERNIE 2.0 多任务持续学习:
───────────────────────────────────────────────────────────────────

  任务队列 (Task Queue):
  ┌──────────────────────────────────────────────┐
  │  Task 1: 大写词预测 (Capitalization Prediction)  │
  │  Task 2: 关键词预测 (Key-Value Prediction)       │
  │  Task 3: 句子重排序 (Sentence Reordering)        │
  │  Task 4: 句子距离预测 (Sentence Distance)         │
  │  Task 5: 词距离预测 (Token-Document Distance)     │
  │  Task 6: 掩码语言模型 (MLM)                       │
  │  Task 7: NSP (Next Sentence Prediction)          │
  │  ...更多任务持续添加                               │
  └──────────────────────────────────────────────┘
           ↓
  多任务预训练 → 增量学习新任务 → 持续迭代
```

核心思想：预训练不是一次性任务，而是持续从不同维度的任务中学习语言知识。

### 3.3 ERNIE 3.0: 统一预训练框架

ERNIE 3.0 将自然语言理解 (NLU) 和自然语言生成 (NLG) 统一在同一个预训练框架中。

```
ERNIE 3.0 统一架构:
════════════════════════════════════════════════════════════════════

  ┌─────────────────────────────────────────────────┐
  │               Universal Representation          │
  │              (通用表示模块 - 共享)                │
  │                                                  │
  │   Transformer Layers (共享参数)                  │
  │   ┌─────┐ ┌─────┐ ┌─────┐     ┌─────┐         │
  │   │ L1  │ │ L2  │ │ L3  │ ... │ Ln  │         │
  │   └──┬──┘ └──┬──┘ └──┬──┘     └──┬──┘         │
  │      │       │       │           │              │
  └──────┼───────┼───────┼───────────┼──────────────┘
         │       │       │           │
    ┌────┴───┐   │  ┌────┴───┐  ┌───┴────┐
    │  NLU   │   │  │  NLG   │  │  知识  │
    │ 任务头 │   │  │ 任务头 │  │ 增强头 │
    └────────┘   │  └────────┘  └────────┘
                 │
          统一预训练目标
```
