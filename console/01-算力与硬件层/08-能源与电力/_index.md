# 能源与电力

> AI 的终极约束正从芯片转向电力：兆瓦级供电成为选址第一变量。

## 拆解卡

- **价值来源**：AI 的终极约束正从芯片转向兆瓦：电力即产能。
- **护城河**：电网接入权与长协核电等稀缺资源位。
- **瓶颈**：并网周期与电网容量（以年计），跑不赢负载增长。
- **领先指标**：核电与长期购电协议签约量；数据中心用电审批节奏

## 六层速览

能源与电力是 AI 的终极约束：一座十万卡集群的用电量抵得上一座中型城市，电不够、并网慢，卡再多也开不满；电力正在取代芯片成为扩张的第一瓶颈。

**打个比方**：算力是工厂，电力是水；水管不够粗、水厂不肯接，机器再多也转不起来——而且新铺一根水管要排好几年队，审批比施工更慢。

**拆开看**：四段链路：发电（核电 / 燃气 / 可再生）→ 输电与并网 → 变配电与备用电源 → 机房散热；每一段都有容量上限与审批周期，最慢的一段决定整体进度。

**怎么运转**：数据中心签长期购电协议（PPA）锁定电价，核电与燃气提供基荷，储能削峰；电力成本直接进入 token 成本模型，电价差决定区域算力竞争力。

**格局与博弈**：美国核电重启与 SMR 受资本追捧，燃气轮机订单排到数年之后；中国以国家电网与绿电直供支撑智算中心；中东用主权资本加廉价能源换算力，形成「能源套利」。

**边界与走向**：短期靠燃气与储能过渡，中期看核电 / SMR 落地，长期取决于电网投资与电价机制；「算力跟随电力」会成为选址铁律，离网供电与自备电厂会增多，电价波动直接传导到 token 价格。

## 关键判断

电力是 AI 的终极瓶颈，资产重估进行中（置信度 中，展望 24–36 个月）——并网速度比发电技术更关键；SMR 是期权而非近期变量。

规模口径：全球数据中心用电约 400–500 TWh（2025e），2030 年或翻倍；美国数据中心用电占比已超 4%

## 二级细分

- **核电与长期购电** — 基荷供电的主流解：核电新建、重启与多年期 PPA。
- **燃气轮机与备用电源** — 并网慢的过渡解：现场燃气轮机与储能。
- **电网与选址** — 并网队列与电价结构决定选址，主权算力布局的一环。
