# 三网平面：计算 / 存储 / 带外管理

> 计算网、存储网、带外管理网分离设计（或融合承载但严格隔离），其中存储网必须按 checkpoint 突发建模。

## 解决什么问题

GPU 集群同时跑三类流量：RDMA 集合通信（对时延与无损极度敏感）、并行文件系统读写（吞吐型、突发剧烈）、管理面（PXE/固件/遥测，要求在任何数据面故障下存活）。三类流量 QoS 语义冲突，混跑一张网时互相伤害；但全分离又增加设备与运维成本。平面划分是网络架构的第一刀。

## 核心原理

- **计算网**：RDMA（IB 或 RoCE）承载 NCCL 流量，Clos 拓扑、400/800G、按 1:1 或过收敛设计，无损调优全部围绕它。
- **存储网**：承载并行文件系统客户端流量（Lustre / GPFS(Spectrum Scale) / DAOS 类）。
  - 读模型：训练数据加载有读放大——原始数据经解码/增强后进样本流水线，epoch 冷启动时集群突发顺序读 + 元数据小 IO 并发。
  - 写模型：checkpoint 是全集群显存状态的瞬时倾泻。核心公式：checkpoint 时长 T = 状态总量 S × 副本数 r ÷ min(存储网有效带宽, 存储系统聚合写吞吐)；可用率损失 ≈ T / checkpoint 间隔。例（量级估算）：万卡 H100、每卡状态 60–80GB、双副本共约 1.2–1.6PB，要求 T ≤ 5 分钟则需约 4–5.3TB/s 聚合写带宽，按 70% 协议与写放大效率折算需 6–7.5TB/s 量级口径。
  - GPU 直存（GPUDirect Storage）路径决定存储 NIC 是否也要与 GPU PCIe 亲和。
- **带外管理网（OOB）**：BMC（IPMI/Redfish）、PXE 装机、固件升级、NTP、日志与遥测采集；1G/10G/25G 量级、双上联冗余。铁律：计算网/存储网瘫痪时 OOB 必须仍能触达每台设备——它是唯一能救火的通道。
- **融合承载**：也可单网融合 + QoS 隔离（DSCP/PFC class、租户级限速），省设备但策略复杂、故障域耦合，适合中小规模或云上多租户。

## 关键数字

| 维度 | 计算网 | 存储网 | 带外管理网 |
| --- | --- | --- | --- |
| 流量类型 | RDMA 集合通信 | 并行 FS 读写、checkpoint 突发 | PXE/固件/遥测/BMC |
| 带宽量级 | 400/800G 端口 | 100–400G 端口 | 1G/10G/25G |
| 关键指标 | 时延、无损、完成时间 | 聚合吞吐、突发承载 | 可达性、独立性 |
| 拓扑 | Clos（1:1 或过收敛） | 扁平/小规模 Clos | 冗余双上联 |
| 带宽建模 | 由通信量估算 | 由 checkpoint SLA 反推 | 由并发升级/装机流量反推 |

| 维度 | 三网分离 | 融合承载 + QoS 隔离 |
| --- | --- | --- |
| 故障域 | 隔离彻底 | 计算网 PFC 风暴可能波及存储 |
| QoS | 天然分域 | 依赖 DSCP/PFC class 规划正确 |
| 成本 | NIC/交换机/线缆三套 | 带宽复用省设备 |
| 运维 | 拓扑与监控分三套但语义清晰 | 一套但策略复杂、排障耦合 |
| 适用 | 大型训练集群（千卡以上） | 中小规模、云上多租户 |

## 设计要点与权衡

- 存储网按 checkpoint SLA 反推带宽，而不是按「均值带宽够用」设计；同时核对存储系统本身聚合写吞吐，避免网络留量被存储卡死。
- OOB 与带内管理分离：交换机带内管理口若只依赖计算网，故障时连排障入口都没有；核心交换机管理口也要有带外路径。
- 融合网里无损语义冲突：PFC class 多了互相反压，少了隔离失效；融合方案必须做 PFC 风暴演练。
- 遥测走带外保底：性能遥测（INT/带内）+ 带外 BMC 采集双通道，防止数据面故障时监控致盲。
- 万台规模固件并发升级（BMC/BIOS/CPLD/NIC）对 OOB 带宽与 PXE 服务的压力要做压测。

## 常见坑

- 存储网按均值设计，checkpoint 突发打满导致训练集体等待，可用率按「步时 × checkpoint 频率」持续失血。
- OOB 与计算网共用设备/上联，计算网瘫痪时无法远程救火，只能进机房。
- 忘了 GPUDirect Storage 路径：存储 NIC 与 GPU 的 PCIe 亲和没做，直存收益归零。
- 融合网 PFC class 规划错误：存储大流量触发 PFC 反压计算网 RDMA，训练掉速难定位。
- NTP/PXE 走计算网，装机与时间同步在大流量期抖动。
