## 简介

CatBoost 是机器学习领域的重要工具/框架。

**官网**: [CatBoost](https://catboost.ai/)

- 详见官方文档

## 与其他框架对比

| 框架 | 优势 | 适用场景 |
|------|------|---------|
| Scikit-learn | API 统一、文档完善 | 入门、快速原型 |
| XGBoost | 精度高、社区活跃 | 结构化数据竞赛 |
| LightGBM | 速度快、内存低 | 大规模数据 |
| CatBoost | 类别特征原生支持 | 高基数类别数据 |
