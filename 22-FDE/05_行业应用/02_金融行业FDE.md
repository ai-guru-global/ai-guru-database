# 金融行业 FDE

## 金融 AI 的特殊性

金融是 FDE 第二大战场（仅次于政企）。**有钱、有数据、有痛点、有监管**。

## 典型场景

### 1. 智能风控
- **需求**：实时交易反欺诈、信用评估、反洗钱
- **技术**：图神经网络 + 规则引擎 + 大模型解释
- **挑战**：模型可解释性（监管必须）、实时性（毫秒级）
- **定价**：200-800 万/项目

### 2. 智能投顾/投研
- **需求**：研报摘要、财务分析、投资建议
- **技术**：RAG + 金融知识图谱 + 多模态（图表理解）
- **挑战**：合规边界（不能给投资建议？）、数据版权
- **定价**：100-500 万/项目

### 3. 合规审计 AI
- **需求**：自动化合规检查、监管报告生成
- **技术**：RAG + 规则引擎 + 文档解析
- **挑战**：监管规则频繁变化、零容忍错误
- **定价**：150-400 万/项目

### 4. 智能客服
- **需求**：银行业务咨询、保险理赔指导
- **技术**：RAG + 多轮对话 + 工单系统集成
- **挑战**：回答准确性（金融容错率极低）
- **定价**：50-200 万/项目

## 金融 FDE 的特殊要求

| 要求 | 说明 |
|---|---|
| **可解释性** | 每个 AI 决策必须能解释原因 |
| **数据隔离** | 不同客户/部门数据严格隔离 |
| **审计追踪** | 全链路操作可审计 |
| **监管报备** | 模型变更可能需要监管审批 |
| **SLA 极高** | 交易系统 99.99% 可用性 |
| **安全等级** | 等保三级 + 行业额外要求 |

## 金融客户关系

```
金融客户的决策链：
IT 部门 → 业务部门 → 风控/合规 → CIO → CEO

关键：合规部门有一票否决权。在项目初期就把合规拉进来。
```

---

> **金融 FDE 第一法则**：**宁可回答"我不知道"，不要给出一个可能错误但看起来对的答案。** 在金融领域，错误的代价是天文数字。
