# 自动驾驶视觉

> 中文简称：自动驾驶视觉

> 一句话理解：利用摄像头、LiDAR、雷达等传感器实现车辆环境感知、定位和决策的视觉系统。

## 核心概念

自动驾驶视觉是计算机视觉最复杂的工业应用之一：

- **2D/3D 检测**：检测车辆、行人、交通标志等目标
- **语义分割**：像素级道路/车道线/可行驶区域分割
- **深度估计**：从单目/多目摄像头估计距离
- **多传感器融合**：摄像头 + LiDAR + 雷达融合
- **BEV 感知**：鸟瞰图统一表示多视角信息
- **端到端驾驶**：感知-规划-控制一体化

## 技术栈

| 技术 | 说明 | 应用 |

## 生产最佳实践

1. **安全冗余**：多传感器冗余，单一传感器失效不影响安全
2. **corner case**：重点处理长尾场景（异形障碍物、极端天气）
3. **实时性**：感知延迟 < 100ms，端到端 < 200ms
4. **数据闭环**：建立自动标注 + 仿真 + 回灌的数据闭环
5. **功能安全**：符合 ISO 26262 功能安全标准
