## 五、优先级矩阵（按"本岗区分度 × 我当前掌握度"排序）

**P0 —— 面试必考且最能区分候选人（本岗分水岭）**
- Agent Runtime 机制：Checkpoint 设计、幂等重试、长任务恢复（专题 03）
- 沙箱隔离五方案对比：Firecracker / Kata / gVisor / Wasm / Docker（专题 04）
- MCP / A2A 协议原语与选型（专题 06）

**P1 —— 大概率被问到，需要能展开 3 分钟**
- K8s 多租户与配额、Agent 工作负载调度特点（专题 05）
- 六大 Agent 产品/框架的定位与对比（专题 07）
- Agent 可观测三支柱与失败归因（专题 08）

**P2 —— 加分项，能讲出框架即可**
- 企业级交付（IAM/审计/灰度/容灾）（专题 09）
- 执行平台形态迁移叙事（专题 10）
- 语言选型 + AI-Native SDLC（专题 11）
