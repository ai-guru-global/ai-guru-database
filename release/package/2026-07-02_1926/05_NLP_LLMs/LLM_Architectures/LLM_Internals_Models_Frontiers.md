# 大模型家族与前沿架构：从 BERT 到推理模型

> **核心命题**：编码器、解码器、编码器-解码器三条路线如何演化？MoE、SSM、推理时计算扩展如何重塑大模型格局？

本文系统提炼《大模型原理与架构》第四部分（模型与前沿篇，第 12–14 章），覆盖主流模型家族与架构创新趋势。相关深入内容可参见 [[LLM_Architecture_Evolution]]、[[LLM_Fundamentals]]、[[Transformer_Deep_Dive]] 与 [[Context_Engineering_Guide]]。

## 1. 编码器系列模型：双向理解的突破

### 1.1 BERT：完形填空的智慧

**BERT**（Bidirectional Encoder Representations，2018）使用 Transformer 编码器，通过**掩码语言模型（MLM）**预训练——随机遮蔽 15% 词元让模型预测。全双向注意力让每个位置同时利用前后文。

BERT 的两大预训练任务：① **MLM**（完形填空）；② **NSP**（下一句预测，判断两句是否连贯）。

> BERT 与 GPT 几乎同时期但方向相反：BERT 用双向编码器做理解，GPT 用单向解码器做生成。当时 BERT 在 11 项 NLP 任务上刷新记录，推动"预训练-微调"范式普及。后续发现 NSP 任务作用有限，且 BERT 的能力随规模持续提升。

### 1.2 BERT 的改进之路

| 模型 | 改进点 | 核心 |
|------|--------|------|
| **RoBERTa** | 去掉 NSP、更大批次、更多数据、动态 MLM | 证明 BERT 欠训练 |
| **ALBERT** | 因式分解嵌入、跨层参数共享 | 参数量大幅减少 |
| **ELECTRA** | 用"替换词检测"替代 MLM（生成器-判别器） | 训练效率更高 |

### 1.3 长文本编码器

标准 BERT 限制 512 词元。**Longformer** 用局部窗口注意力 + 少量全局注意力降至 $O(n)$；**BigBird** 加入随机注意力连接。这些稀疏方案是早期长上下文探索，后被解码器 + RoPE 外推取代。

> 编码器模型在理解类任务（分类、抽取、嵌入）仍有价值，但生成时代的通用智能主线已转向仅解码器模型。

## 2. 解码器系列与主流 LLM

### 2.1 GPT 系列：从语言模型到通用智能

| 版本 | 参数 | 关键贡献 |
|------|------|----------|
| GPT-1 | 117M | 仅解码器 + 预训练-微调范式 |
| GPT-2 | 1.5B | **零样本能力**——不微调即可完成多任务 |
| GPT-3 | 175B | **少样本学习** + 提示工程时代 + 涌现现象 |
| GPT-4 | — | 首个广泛认可的多模态 LLM，接近人类专业考试水平 |
| GPT-4o | — | 跨文本/图像/音频原生多模态 |
| **o1/o3** | — | **推理时计算扩展**——显式长思维链 |
| **GPT-5.x** | — | 编码、通用推理、可调推理预算整合 |

> **GPT-3 的两大深远影响**：① 提示工程取代微调；② 涌现能力的发现。但"涌现"是否真实仍有争议——可能是准确率等非线性指标的错觉，改用连续指标（每词元交叉熵）则平滑可预测。
>
> **o1 系列开辟了 Scaling 的第二条曲线**：当训练时扩展（更大模型/数据）收益递减时，推理时投入更多计算让模型在回答前显式长链推理。o1 在 AIME 数学竞赛正确率从 GPT-4o 的 13% 跃升至 83%。

### 2.2 Llama 家族：开放权重改变格局

Llama 确立了现代 LLM 的**"标准配方"**：RoPE 位置编码 + Pre-Norm/RMSNorm + SwiGLU + GQA。

| 版本 | 规格 | 训练数据 | 上下文 | 关键改进 |
|------|------|---------|--------|---------|
| Llama 1 | 7B/13B/33B/65B | 1.4T | 2K | 首批高质量开放研究权重 |
| Llama 2 | 7B/13B/70B | 2T | 4K | RLHF 对齐；70B 引入 GQA |
| Llama 3 | 8B/70B | 15T | 8K | 128K 词汇表 |
| Llama 3.1 | 8B/70B/405B | 15T+ | 128K | 405B 追平 GPT-4，开放里程碑 |
| Llama 3.2 | 1B/3B/11B/90B | — | 128K | 多模态 + 端侧 |
| Llama 3.3 | 70B | — | 128K | 70B 追平 405B 对齐 |
| **Llama 4** | MoE | — | 1M–10M | MoE 架构（Scout/Maverick） |

> **Llama 3.1 405B** 是开放权重 LLM 里程碑——首次证明开放权重可达顶级闭源水平。**Llama 3.3** 70B 以不到五分之一资源达 405B 水平。**Llama 4** 全面转向 MoE：Scout（109B 总参/17B 激活/16 专家/10M 上下文）、Maverick（400B 总参/17B 激活/128 专家）。

**开放生态繁荣**：Llama 权重开放催生数百微调模型——Vicuna、Alpaca、Code Llama 及医疗/法律/金融垂直模型，推动 LLM 普惠化。

### 2.3 DeepSeek：效率创新的标杆

DeepSeek 以极致工程效率著称，在有限算力下达顶尖水平。

- **DeepSeek-V2**：引入 **MLA**（KV 缓存压缩到低维潜空间）+ **DeepSeekMoE**（160 路由专家 + 2 共享专家）
- **DeepSeek-V3**（2024.12）：671B 总参/37B 激活（5.5%）、FP8 混合精度训练、多词元预测、训练 run 成本 < 600 万美元
- **DeepSeek-R1 / R1-Zero**（2025.01）：推理能力里程碑

> **R1-Zero 的"顿悟时刻"**：纯 RL（GRPO 算法，不依赖任何推理过程示范数据、不先 SFT）训练后，模型**自发涌现**出：自发的思维链、自我验证、自我纠错、反思与元认知。这些从未被显式教授——证明 RL 可激发深度推理。
>
> 正式 R1 用少量高质量长思维链冷启动 + 推理 RL + 拒绝采样 SFT + 偏好 RL 多阶段，缓解 R1-Zero 可读性差、语言混杂。还将推理能力**蒸馏**到 1.5B–70B 小模型，各量级远超同量级模型。
>
> DeepSeek 证明：**架构和工程创新可大幅降低达前沿能力的训练成本**，打破"只有算力巨头才能训练前沿模型"的单一路径认知。

## 3. 架构创新与未来趋势

### 3.1 高效注意力：突破平方复杂度

需区分两类"高效"：① **改变数学结构**（稀疏、线性、SSM）；② **保持精确注意力但优化 IO/缓存/部署**（FlashAttention、PagedAttention、MQA/GQA、MLA、Ring Attention）。

> 到 2026 年，后者在生产中更关键——许多近似注意力虽降理论复杂度，却未必在真实 GPU kernel、质量和生态上优于精确注意力优化栈。

**稀疏注意力**：局部窗口（Longformer $O(n\cdot w)$）、分块、哈希（Reformer LSH $O(n\log n)$）。

**线性注意力**：核函数近似将 $\text{softmax}(QK^T)V\approx\phi(Q)(\phi(K)^TV)$，先算括号内避免 $O(n^2)$ 中间矩阵。Performer（随机特征）、Linear Transformer（ELU 替 softmax）。精度通常不如精确 softmax，采用率有限。

**混合方案**：底层全注意力（精细局部），高层稀疏/线性（高效全局），分层降复杂度。

### 3.2 混合专家模型（MoE）

核心洞察：**模型不必每次推理用所有参数。** 将 FFN 替换为一组并行专家 + 路由器：

$$y=\sum_{i\in\text{TopK}} g_i\cdot\text{Expert}_i(x)$$

**解耦容量与成本**：总参数（容量）决定知识量，激活参数（成本）决定推理速度。DeepSeek-V3：671B 容量 / 37B 激活。

**路由机制两大范式**：① **词元选专家**（Token-Choice，主流，简单但易负载不均）；② **专家选词元**（Expert-Choice，天然均衡但词元可能被丢/重复）。

**Top-K 权衡**：Top-1（最高效但表达受限）、Top-2（Mixtral，平衡）、Top-8（DeepSeek-V3，配细粒度小专家）。

> **负载均衡核心挑战**：路由器倾向将多数词元路由到少数专家（负载坍塌）。
> - **辅助损失**：$\mathcal{L}_{\text{balance}}=\alpha N\sum f_i p_i$，但 $\alpha$ 调节敏感（过大压制学习、过小止不住坍塌）
> - **无辅助损失路由**（DeepSeek-V3）：为每专家维护动态偏置 $b_i$，路由决策用 $g_i+b_i$ 但权重用原 $g_i$；偏置按负载规则更新（过载则降、不足则升）。路由器主梯度不受干扰。

**细粒度 MoE + 共享专家**（DeepSeek 开创）：将参数拆为 256 个小专家（更精细路由、更多组合空间 $\binom{256}{8}\gg\binom{8}{2}$、更好均衡），加共享专家（始终激活，处理通用能力，避免路由专家浪费容量学通用知识）。

| 模型 | 总参 | 激活 | 路由专家 | 每词元路由 | 共享专家 | 粒度 |
|------|------|------|---------|-----------|---------|------|
| Mixtral 8x7B | 47B | 13B | 8 | 2 | 无 | 粗 |
| Mixtral 8x22B | 141B | 39B | 8 | 2 | 无 | 粗 |
| DeepSeek-V2 | 236B | 21B | 160 | 6 | 2 | 细 |
| **DeepSeek-V3** | 671B | 37B | 256 | 8 | 1 | 细 |
| Llama 4 Maverick | 400B | 17B | 128 | 1+共享 | 1 | 细 |

> 两条演化路线：**Mixtral 路线**（少量大专家、Top-2，部署简单）vs **DeepSeek/Qwen 路线**（大量小专家+共享专家，性能上限更高）。Llama 4 Maverick 的"1 路由+1 共享"不是 Mixtral 式 Top-2，勿混淆。

**推理挑战**：所有专家参数须常驻显存（671B FP8 需约 670GB，远超单卡）；批量推理需 All-to-All 通信。**专家并行（EP）**将专家分布到不同设备，常与 TP/DP 组合（注意力层 TP 保延迟，MoE 层 EP 提吞吐）。特有优化：专家预取、专家缓存、动态批处理。

### 3.3 状态空间模型（SSM）与混合架构

自注意力的平方复杂度与 KV 缓存线性增长在超长序列受限。SSM 用**线性递推**替代全连接：

$$h_t=Ah_{t-1}+Bx_t,\quad y_t=Ch_t+Dx_t$$

每步 $O(1)$，整序列 $O(n)$，无 $O(n^2)$ 注意力矩阵。**S4**（HiPPO 初始化结构化 $A$）首次在长序列达 Transformer 水平。

**Mamba**（2023）核心创新是**选择性机制**——让 $B_t, C_t, \Delta_t$ 依赖输入，模型动态决定"记住什么、忘记什么"：

$$B_t=f_B(x_t),\quad C_t=f_C(x_t),\quad \Delta_t=f_\Delta(x_t)$$

$\Delta_t$ 是输入相关的"快进/保持"旋钮（大步长快遗忘、小步长保留历史）。优势：推理无需 KV 缓存、增量生成状态固定、并行扫描训练、超长序列快数倍。

> **Mamba 2** 揭示 SSM 与注意力的深层数学联系——选择性 SSM 可视为"结构化的线性注意力"。

**混合架构**（取两者之长）：**Jamba**（AI21，交替 Transformer/Mamba 层，256K 上下文兼顾检索精度与效率）、**Griffin**（Google，局部注意力 + 门控线性循环）、**Zamba**（共享注意力层 + Mamba 块）。

> 务实方向：不替代 Transformer，而是引入高效组件处理特定场景。SSM 在效率占优但精细检索（大海捞针）不如注意力；混合架构正在探索最佳配比。

### 3.4 推理时计算扩展（Test-time Scaling）

引入**系统 2 思维**——回答前进行显式、可追踪的中间推理。与训练时扩展互补：

| 维度 | 训练时扩展 | 推理时扩展 |
|------|-----------|-----------|
| 成本结构 | 一次性高投入，后续固定 | 每次推理按需增加 |
| 灵活性 | 部署后能力固定 | 按问题难度动态调整 |
| 适用任务 | 通用能力 | 需深度推理的复杂任务 |

**思维链（CoT）**：让模型在答案前输出中间推理步骤，显著提升复杂推理。零样本只需加"让我们一步一步思考"。

> **为何有效**：① **计算深度增加**——生成中间步骤使等效计算深度从固定 $L$ 层扩展到 $L\times T$；② **工作记忆外化**——中间结果写入文本绕开隐藏状态容量限制；③ **问题分解**。ToT/GoT 进一步把线性链扩展为树/图搜索。

**长思维链 RL 训练**（o1、DeepSeek-R1）：奖励直接来自答案正确性（数学算对、代码通过测试），非人类偏好。流程：冷启动 SFT → RL 优化推理策略 → 拒绝采样精炼。

**GRPO 算法**（DeepSeek-R1）：用组内标准化优势替代价值网络——同题采样 $G$ 个回答，组内平均作基线：

$$A_i=\frac{r_i-\mathrm{mean}(\{r_j\})}{\mathrm{std}(\{r_j\})}$$

> **验证策略**：① **Best-of-N 采样**（生成 $N$ 候选，多数投票或 RM 打分选最优，并行生成延迟可控）；② **结果奖励模型 ORM**（只评最终答案，无法区分"碰巧对的错误推理"）vs **过程奖励模型 PRM**（评每一步，能定位最早出错步骤，搜索中可剪枝，但标注成本高，PRM800K 约 80 万步骤标签）。
>
> **关键洞察**：推理时扩展对"难题"边际收益高于"易题"。未来最优策略是**动态混合**——简单问题快速响应，复杂问题深度思考。Claude 3.7 的 Extended Thinking 即此范式。

**上界与突破**：当前 RL/搜索更像**能力放大器**——在基础模型已有表征中找更可靠路径。若基础模型缺必要知识、奖励无法区分好坏、工具不给真实反馈，单纯增加推理词元难补足。前沿方向：① **隐空间推理**（Coconut，隐空间连续状态推进推理，减少逐词开销）；② **并行推理**（识别独立子任务并发处理）。下一代提升可能来自"想得更高效"而非"想得更久"。

### 3.5 其他重要趋势

- **多模态 Transformer**：统一不同模态的表示。Gemini 原生多模态（预训练即统一架构），非拼接视觉编码器与语言模型
- **AI Agent 与工具调用**：让模型从"说"到"做"——ReAct 范式（推理+行动）、函数调用、Computer Use。Claude 3.5 Sonnet 是首个公开 beta 提供计算机使用的前沿模型
- **长上下文技术**：RoPE 外推（位置内插、NTK、YaRN）、稀疏注意力、Ring Attention、KV 缓存压缩（GQA/MLA）。Gemini 1.5 的百万上下文是工程重大成就，实现需解决平方复杂度、KV 缓存、跨设备通信
- **机制可解释性**：打开黑箱——研究注意力头功能、FFN 作为键值存储、Superposition（叠加态）、激活 steering。Anthropic 在 Claude 上做了大量稀疏自编码器研究

## 4. 大模型格局总结

### 4.1 三条扩展曲线

1. **训练时计算扩展**（规模定律）：更大模型 + 更多数据，可预测的幂律提升——但收益递减
2. **推理时计算扩展**（o1/R1）：固定模型，推理投入更多计算——对难题边际收益高
3. **架构效率扩展**（MoE/SSM）：解耦容量与成本——在不增加推理成本下扩大模型容量

### 4.2 开放 vs 闭源

- **闭源**（OpenAI、Anthropic、Google）：最强能力、最快迭代，但架构不公开
- **开放权重**（Meta Llama、DeepSeek、Qwen、Mistral）：推动生态繁荣、可定制、可审计
- **趋势**：开放权重已达接近闭源水平（Llama 3.1 405B、DeepSeek-V3），并在推理能力（DeepSeek-R1）上首次公开可与闭源抗衡的方案

### 4.3 设计哲学的收敛

现代主流 LLM 架构已高度收敛：**仅解码器 + RoPE + PreNorm/RMSNorm + SwiGLU + GQA/MLA**，前沿模型叠加 **MoE** 与**推理时扩展**。但底层组件仍在持续演进——从"想得更久"到"想得更高效"，从密集到稀疏，从单一注意力到混合架构。

> 理解架构演进的**驱动力**比记住具体方案更重要：每一项创新都是对某个具体瓶颈（效率、质量、安全、成本）的回应。把握这些第一性原理，才能预判下一代设计的方向。
