# CodeBuddy / WorkBuddy 使用指南

> 中文简称：CodeBuddy / WorkBuddy 使用指南

> **一句话**: CodeBuddy 是 AI 编程助手，WorkBuddy 是其办公延伸，适合文档和项目脚手架生成。

---

## 1. 概述

### 定位

| 维度 | 说明 |
|------|------|
| **类型** | AI 编程助手 + 办公辅助 |
| **产品线** | CodeBuddy（编程）、WorkBuddy（办公） |
| **适用** | 文档生成、项目脚手架 |
| **官网** | https://www.codebuddy.ai |

### 核心能力

```
CodeBuddy 生态:
├── CodeBuddy — 编程助手
│   ├── 代码生成
│   ├── 代码解释
│   ├── Bug 修复
│   └── 多语言支持
└── WorkBuddy — 办公助手
    ├── 文档生成
    ├── 内容处理
    └── 中国版（未充值）
```

## 3. 快速开始

### 3.1 登录

1. 访问 https://www.codebuddy.ai
2. 注册/登录账户

### 3.2 使用

1. 在编辑器中安装 CodeBuddy 插件
2. 通过 Chat 或 Inline 模式进行编程辅助
