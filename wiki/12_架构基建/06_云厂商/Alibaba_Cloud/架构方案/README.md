# 客户架构方案 (Customer Architecture Blueprints)

> 中文简称：客户架构方案

> **一句话理解**: 给客户讲"阿里能帮你做什么"的标准化方案库——从训练模型到跑推理、从搭知识库到做智能客服，每套方案都有架构图、选型表、架构师要点。

| 文档 | 内容 | 适用读者 |
|------|------|----------|
| [方案 1：大模型训练平台](./11_架构方案_大模型训练平台.md) | 灵骏 + PAI DLC + CPFS + eRDMA | 需要自训/大规模微调 |
| [方案 2：大模型推理服务](./12_架构方案_大模型推理服务.md) | GPU ECS + ACK + vLLM + EAS + 网关 | 生产推理、高并发 |
| [方案 3：企业知识库 RAG](./13_架构方案_企业知识库RAG.md) | 百炼 + 向量库 + 混合检索 + Rerank | 知识密集型企业 |
| [方案 4：Agent 智能体平台](./14_架构方案_Agent智能体平台.md) | 千问AI平台 + Skills + MCP + 治理 | 运维/客服/流程自动化 |
| [方案 5：智能客服](./15_架构方案_智能客服.md) | 晓蜜/伶鹊 + RAG + 工单 + 人工接管 | 客服团队 |
| [方案 6：私有化部署](./16_架构方案_私有化部署.md) | AI Stack 一体机 + 百炼专属版 + 开源模型 | 金融/政务/涉密 |
| [方案 7：多模态内容生成](./17_架构方案_多模态内容生成.md) | 万相/Wan + 听悟 + 星尘 + 语音矩阵 | 营销/会议/直播 |
| [方案 8：模型微调与行业定制](./18_架构方案_模型微调与行业定制.md) | PAI + LoRA/QLoRA + 评估体系 | 行业术语/风格对齐 |
| [方案 9：AI 安全与合规](./19_架构方案_AI安全与合规.md) | 内容安全 + 安全护栏 + 隐私计算 + 合规框架 | 金融/政务/出海 |
| [方案 10：边缘推理与全球化](./20_架构方案_边缘推理与全球化.md) | ENS + GA + 模型压缩 + 云边端三级架构 | IoT/全球 SaaS/工厂 |

> 每篇方案文档都遵循"客户痛点 → 目标架构（Mermaid 图） → 选型对比 → 关键设计决策 → 价值测算"结构，面试直接拿来用。
