# Comate 使用指南

> 中文简称：Comate 使用指南

> **一句话**: 百度 Comate 是基于文心大模型的 AI 编程助手，个人专业版提供月度额度，适合多项目并行开发。

---

## 1. 概述

### 定位

| 维度 | 说明 |
|------|------|
| **类型** | AI 编程助手（IDE 插件） |
| **开发商** | 百度 (Baidu) |
| **适用** | 多项目并行、全栈开发 |
| **官网** | https://comate.baidu.com |

### 核心能力

```
Comate:
├── 代码生成与补全
├── 代码解释与重构
├── 单元测试生成
├── 中文场景优化
└── 多 IDE 支持（VS Code / JetBrains）
```

---

## 2. 账户与额度

| 项目 | 详情 |
|------|------|
| **订阅等级** | 个人专业版 |
| **额度状态** | 5 月额度已用尽 |
| **当前方案** | 使用加量包 |
| **状态** | 额度耗尽，使用加量包维持 |

---

## 3. 使用场景与输出

| 输出项目 | 说明 |
|----------|------|
| **SBOKR** | OKR 管理系统 |
| **ResolveAgent** | Agent 解决方案 |
| **pannaarts** | 艺术类项目 |
| **hushAI** | AI 相关项目 |

---

## 4. 最佳实践

- 个人专业版额度有限，多项目并行时注意额度分配
- 加量包是额度耗尽后的应急方案，长期建议升级套餐
- Comate 在中文编程场景下表现优秀

---

## 5. 注意事项

- 月度额度消耗较快，高项目负载时建议配合其他工具使用
- 加量包成本需纳入预算考量
