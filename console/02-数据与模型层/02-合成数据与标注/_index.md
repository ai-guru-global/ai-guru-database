# 合成数据与标注

> 用模型生成训练数据缓解数据墙，标注产业随之转型。

## 拆解卡

- **价值来源**：用生成缓解数据墙：质量闸门决定它是补药还是毒药。
- **护城河**：过滤漏斗与验证闭环的工程资产。
- **瓶颈**：模式坍缩与分布多样性损失。
- **领先指标**：前沿模型训练中合成占比披露；合成数据工具与论文热度

## 六层速览

合成数据与标注用模型生成训练数据，突破「真实语料不够用」的数据墙，同时为模型提供可验证的练习环境；它的价值不在数量，而在「能自动验证对错」。

**打个比方**：像用飞行模拟器练飞行员——不用真飞机也能积累大量小时数，但模拟器失真会带偏技术；数据质量就是模拟器的保真度，验证器就是教练。

**拆开看**：五段链路：种子数据 → 生成（LLM / 物理仿真）→ 过滤与验证（规则、奖励模型、执行结果）→ 配比与去偏 → 回流训练；质量闸门是核心，没有验证器的合成数据只是噪声放大器。

**怎么运转**：数据服务商按项目收费，模型公司内建合成管线；验证器决定数据能不能用，可验证任务（代码、数学、工具调用、agent 轨迹）最先规模化，开放域写作最难。

**格局与博弈**：Scale AI、Surge AI 转向专家数据与强化学习环境，NVIDIA Omniverse 做具身仿真；开源工具降低门槛，但高质量验证器与长尾专家数据仍稀缺，也是护城河所在。

**边界与走向**：合成数据从「补量」转向「造环境」（可验证任务、agent 轨迹、仿真场景）；模式坍缩与版权风险仍需管理，未来训练更像「设计课程」而非「收集文本」。

## 关键判断

结构性受益，但独立工具商面临模型厂与算力巨头夹击（置信度 中，展望 12–24 个月）——核心变量是验证器质量与模型自生成能力；价值向仿真环境与验证器集中。

规模口径：全球合成数据与标注服务约 $120–200 亿（2025e）；合成数据本身约 $30–50 亿，专家标注约 $60–100 亿

## 二级细分

- **合成数据** — 模型生成 + 质量闸门，补真实语料缺口
- **人类反馈数据** — 偏好与专家标注，对齐的原料
- **可验证环境** — 代码、数学与 agent 轨迹的训练场
