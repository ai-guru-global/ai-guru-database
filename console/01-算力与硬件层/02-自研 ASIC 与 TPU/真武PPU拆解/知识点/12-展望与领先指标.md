# 12 · 展望与领先指标

> 把「看多/看空」转成可观察的领先指标清单与证伪条件——判断的修正机制，比判断本身重要。

## 近期观察哨（未来 6–12 个月）

| # | 指标 | 触发含义 |
|---|---|---|
| 1 | **V900 商用时间表**（当前「敬请期待」） | 216GB/1200GB/s 若如期商用且进超节点 → scale-up 下注兑现；跳票 → 三代 roadmap 可信度受损 |
| 2 | **M890 中卫邀测转正式** | 全场景档放量信号；继续仅乌兰察布 → 供给或良率受限 |
| 3 | **第三方基准出现**（MLPerf 类或头部客户公开 case） | 打破「全部数字为自述」状态——性价比叙事的第一块独立锚 |
| 4 | **Qwen 下一代旗舰训练平台披露** | 继续在 PPU → 生态绑定升级；回迁 GPU → 绑定降级为推理托管（→ [08-模型生态绑定](08-模型生态绑定.md) 脆弱性条款） |
| 5 | **出货量官方口径统一**（47 万 vs 60 万 ❓） | 阿里/IDC 任一方发布可审计口径 → 市场透明度信号 |
| 6 | **外部客户数与标杆复购**（当前 650+，官方页口径） | 停滞数百级 → 「对外售卖」转折证伪；出现第二个 Kimi 级 Day0 → 生态引力成立 |
| 7 | **自供率披露**（当前 🔍 无） | 任何官方数字都是阿里云毛利曲线的关键输入（→ [07-售卖与单位经济](07-售卖与单位经济.md)） |
| 8 | **制程/代工信息落地**（当前 E） | 三情景收敛（→ [11-制程与供应链](11-制程与供应链.md)），直接改写放量天花板 |

## 证伪条件汇总（出现即修正「爬坡期」判断）

1. V900 跳票且无第三方背书 → scale-up 叙事降级；
2. Qwen 旗舰训练回迁英伟达 → 生态绑定失效；
3. 外部客户停滞 + 无复购标杆 → 外卖转折证伪；
4. 第三方实测性价比显著低于昇腾 910C/寒武纪 → 「H20 替代位」卡位证伪；
5. 管制延伸至代工+HBM 组合 → 放量物理截断，进入「受制裁梯队」叙事。

## 上行期权（市场尚未定价的可能）

- **V900 若进旗舰训练分摊**：把「替代位」升级为「混合算力（GPU 训练 + PPU 分摊）」——全球云厂均在走的混合路线，PPU 有 Qwen 负载做试验田；
- **平头哥分拆上市**（❓传闻不采信）：若落地，PPU 线的披露义务将强制补齐当前所有口径缺口（出货/自供率/性价比），市场透明度跃升；
- **Day0 适配常态化**：若头部开源模型发布默认提供 PPU 适配（如同今日默认 CUDA 版本），PPU 将从「替代选项」变为「默认平台之一」——这是生态引力的终局形态。
