# 详细定价模型

> 商业计划书中定价章节的深度展开。  
> **核心原则**：**让客户觉得贵得不离谱，又留出议价空间**。

---

## 🎯 定价哲学

1. **价值定价，不是成本定价**——客户买的是"数据安全感 + AI 能力"
2. **版本化定价**——3 个版本覆盖不同预算
3. **续费锁定**——年费 15-20% 是核心利润
4. **增值不降价**——绝不打价格战，只加价值

## 💰 价格策略

### 1. 议价空间

- **底线**：基础版 25 万 / 企业版 70 万 / 行业版 180 万
- **首年让步**：不超过 15%
- **多项目让步**：2 个项目以上 8 折

### 2. 付款方式

```
合同签订 ............ 30%
部署完成验收 ........ 50%
稳定运行 30 天 ....... 20%
```

**年费**：
```
续费前 30 天 ......... 100%
```

## ✅ 定价原则（最后核对）

- [x] **客户视角**：让 CIO 觉得"花得值"
- [x] **市场对照**：低于云厂商，高于纯软件
- [x] **利润空间**：毛利率 50%+
- [x] **续费设计**：年费 15-20% 是核心
- [x] **议价空间**：底线 + 15% 让步
- [x] **可解释**：每个数字都能说出为什么

> **核心理念**：**客户买的不是"装个软件"，是"数据安全感 + AI 能力 + 长期合作伙伴"**。
