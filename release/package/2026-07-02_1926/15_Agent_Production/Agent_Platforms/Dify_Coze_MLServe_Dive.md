# Agent 平台与部署: Dify / Coze / LocalAI

> **一句话理解**: Dify 和 Coze 是当前最流行的 Agent 开发平台——Dify 以开源和私有部署见长，Coze 以字节跳动为背书强调企业级工作流编排，LocalAI 则让一切在本地运行。

## 2. Dify

### 2.1 核心概念

```
Dify 核心概念
═══════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────┐
│                         Dify 架构                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  应用类型:                                                       │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐        │
│  │  Chatbot    │  │   Agent      │  │  Workflow   │        │
│  │  (对话应用) │  │  (Agent)    │  │  (工作流)   │        │
│  └──────────────┘  └──────────────┘  └──────────────┘        │
│                                                                  │
│  核心组件:                                                       │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐        │
│  │   Dataset   │  │   Plugin    │  │   API      │        │
│  │  (知识库)   │  │  (扩展)    │  │  (接口)    │        │
│  └──────────────┘  └──────────────┘  └──────────────┘        │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 核心功能

| 功能 | 描述 |
|------|------|
| **可视化编排** | 无代码/低代码构建应用 |
| **RAG 管道** | 内置知识库检索增强 |
| **Agent** | 支持 ReAct / 函数调用 |
| **工作流** | 复杂业务流程编排 |
| **多模型** | 支持 30+ 模型 |
| **API 暴露** | 一键生成 API |

### 2.3 使用场景

```yaml
# Dify 应用示例: 客服 Agent

# 1. 创建 Chatbot 应用
name: "智能客服"
model: "gpt-4o"

# 2. 配置 RAG
dataset:
  name: "产品知识库"
  embedding: "text-embedding-3"

# 3. 配置 Agent
agent:
  type: "function_call"
  tools:
    - "product_search"
    - "order_query"
    - "escalation"

# 4. 发布为 API
api:
  endpoint: "/v1/chatbot"
  auth: "api_key"
```

### 2.4 部署架构

```bash
# Dify Docker 部署
git clone https://github.com/langgenius/dify.git
cd dify/docker
docker-compose up -d

# 访问
# 前端: http://localhost:80
# API: http://localhost:80/api
```

## 3. Coze

### 3.1 核心概念

```
Coze (扣子) 核心概念
═══════════════════════════════════════════════════════════════════

字节跳动旗下企业级 Agent 平台:

┌─────────────────────────────────────────────────────────────────┐
│                         Coze 架构                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Bot Store                                                      │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │                                                          │    │
│  │   ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐     │    │
│  │   │ Bot 1  │  │ Bot 2  │  │ Bot 3  │  │ Bot N  │     │    │
│  │   └────────┘  └────────┘  └────────┘  └────────┘     │    │
│  │                                                          │    │
│  └─────────────────────────────────────────────────────────┘    │
│                                                                  │
│  工作流引擎                                                     │
│  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐              │
│  │ Trigger│→ │  Node  │→ │  Node  │→ │ Output │              │
│  └────────┘  └────────┘  └────────┘  └────────┘              │
│                                                                  │
│  插件生态                                                       │
│  ┌────────┐  ┌────────┐  ┌────────┐                           │
│  │ 飞书   │  │ 微信   │  │ Slack  │  + 更多                    │
│  └────────┘  └────────┘  └────────┘                           │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 核心功能

| 功能 | 描述 |
|------|------|
| **Bot 创建** | 可视化 + 插件化 |
| **工作流** | 强大的条件分支和循环 |
| **插件市场** | 丰富的内置插件 |
| **多渠道** | 飞书、微信、Slack 等 |
| **记忆** | 对话记忆 + 知识库 |
| **多模态** | 图像、语音支持 |

### 3.3 与 Dify 对比

| 维度 | Dify | Coze |
|------|------|------|
| **部署** | 可私有 | 云端为主 |
| **开源** | 完全开源 | 不开源 |
| **插件生态** | 一般 | 丰富 |
| **企业特性** | 较弱 | 强大 |
| **国内生态** | 一般 | 强大 (飞书等) |

## 4. LocalAI

### 4.1 核心概念

```
LocalAI: 本地 LLM 推理
═══════════════════════════════════════════════════════════════════

LocalAI 让开源模型在本地运行:

┌─────────────────────────────────────────────────────────────────┐
│                      LocalAI 架构                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   请求 ──► LocalAI Gateway ──► 本地 Model                       │
│                  │                                                  │
│                  ├── 兼容 OpenAI API                            │
│                  ├── 多模型支持                                    │
│                  └── 量化优化                                     │
│                                                                  │
│   支持的模型:                                                    │
│   ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐    │
│   │  Llama   │  │  Mistral  │  │  Qwen   │  │  Phi    │    │
│   └──────────┘  └──────────┘  └──────────┘  └──────────┘    │
│                                                                  │
│   支持的硬件:                                                    │
│   ┌──────────┐  ┌──────────┐  ┌──────────┐                    │
│   │ NVIDIA   │  │ Apple M  │  │  CPU    │                    │
│   │  GPU     │  │  Metal   │  │ (量化)  │                    │
│   └──────────┘  └──────────┘  └──────────┘                    │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 核心功能

| 功能 | 描述 |
|------|------|
| **API 兼容** | OpenAI 兼容 API |
| **多模型** | Llama, Mistral, Qwen 等 |
| **量化** | Q4, Q5, Q8 量化支持 |
| **推理优化** | GPU 加速、批处理 |
| **工具调用** | Function calling 支持 |
| **TTS/STT** | 语音支持 |

### 4.3 使用示例

```bash
# LocalAI 启动
docker run -p 8080:8080 \
  -v $PWD/models:/models \
  quay.io/go-skynet/local-ai:latest

# 使用 OpenAI 兼容 API
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "llama-3",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

### 4.4 与云端 API 对比

| 维度 | LocalAI | OpenAI API |
|------|---------|------------|
| **成本** | 一次性硬件 | 按量付费 |
| **隐私** | 完全本地 | 数据上传云端 |
| **延迟** | 取决于硬件 | 低延迟 |
| **模型选择** | 开源模型 | GPT 系列 |
| **维护** | 需自己运维 | 全托管 |
| **质量** | 取决于模型 | SOTA |

## 5. 对比与选择

### 5.1 选择指南

```
Agent 平台选择指南
═══════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────┐
│  你需要什么？                                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Q1: 部署方式？                                                 │
│  ├── 完全本地 → LocalAI                                        │
│  ├── 私有部署 + 开源 → Dify                                     │
│  └── 云端 + 企业特性 → Coze                                     │
│                                                                  │
│  Q2: 主要用途？                                                 │
│  ├── RAG + 知识库 → Dify / Coze                                │
│  ├── 工作流编排 → Coze / Dify                                  │
│  ├── 隐私敏感 → Dify + LocalAI / LocalAI                      │
│  └── 快速原型 → Coze                                            │
│                                                                  │
│  Q3: 技术能力？                                                 │
│  ├── 非技术用户 → Coze (低代码)                                 │
│  ├── 有开发能力 → Dify (灵活)                                   │
│  └── 追求完全控制 → LocalAI + 自建                              │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

| 平台 | 部署成本 | 使用成本 | 维护成本 |
|------|---------|---------|---------|
