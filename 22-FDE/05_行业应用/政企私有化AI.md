# 政企私有化 AI - FDE 实践指南

## 政企场景的特殊性

政企客户是 FDE 最重要的战场，也是最具挑战性的战场。

### 核心特征

| 特征 | 影响 | FDE 应对 |
|---|---|---|
| **数据不出内网** | 必须私有化部署 | 离线部署包 + 离线模型 |
| **信创要求** | 国产 CPU/OS/DB | 信创适配测试 |
| **等保合规** | 安全等级保护 | 安全方案前置设计 |
| **多层决策** | 决策周期长 | 多方关系维护 |
| **预算制** | 年底突击花钱 | 把握预算节奏 |

## 典型政企 AI 场景

### 1. 政务 AI 助手

```
场景：公务员日常办公助手
需求：公文写作、政策查询、数据填报
技术：RAG + 政务知识库 + 国产大模型
挑战：政策时效性、多部门知识隔离
```

### 2. 智慧城市 AI 中台

```
场景：城市运行管理
需求：事件分拨、舆情分析、应急指挥
技术：多 Agent 协作 + 时空数据分析
挑战：多源数据融合、实时性要求
```

### 3. 央企知识管理平台

```
场景：集团级知识沉淀与共享
需求：制度查询、经验传承、合规审查
技术：企业知识图谱 + RAG + 权限管理
挑战：多级权限、跨系统集成
```

## 政企 FDE 交付清单

### 技术清单
- [ ] 国产 OS 兼容（麒麟/统信/UOS）
- [ ] 国产 CPU 兼容（鲲鹏/飞腾/海光）
- [ ] 国产数据库适配（达梦/人大金仓/OceanBase）
- [ ] 国密算法支持（SM2/SM3/SM4）
- [ ] 等保三级要求满足
- [ ] 离线部署方案（无互联网环境）
- [ ] SSO/LDAP 对接（现有身份系统）
- [ ] 审计日志完整

### 商务清单
- [ ] 招投标资质准备
- [ ] 保密协议签署
- [ ] 驻场人员政审
- [ ] 数据安全责任界定
- [ ] 验收标准明确
