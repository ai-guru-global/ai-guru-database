# 电力与散热视角

> 一句话：网络功耗的大头是光模块不是交换机；风冷/液冷决定布线形态，「电力先于芯片」把机房选址与拓扑布局提前锁死。

## 核心问题清单

1. 网络与光模块的功耗模型：每口多少 W、每只模块多少 W？
2. 万卡网络总功耗怎么估（引用配比公式）？
3. 风冷与液冷下网络布线与维护有什么差异？
4. 单柜功率怎么在计算/网络/存储之间分配？
5. 「电力先于芯片」对网络设计的约束是什么（密度换距离）？

## 评估框架

### 功耗模型（行业典型值，具体以 datasheet 为准，待核实）

| 器件 | 典型功耗 | 备注 |
|---|---|---|
| 51.2T 交换机整机（64×800G） | 1.2–1.8 kW（不含模块） | 折合 ~20–28 W/口 |
| 800G 可插拔模块（DR8/SR8） | 16–25 W/只 | LPO 约 4–8 W，省电 60%+ |
| 400G 模块 | 8–12 W/只 | 存量主力 |
| 400G/800G PCIe 网卡 | 15–30 W | DPU 形态更高 |
| AEC/DAC | 3–10 W/条 | 铜替光的主要省电点 |

### 万卡网络总功耗估算（口径示意）

1. 假设：10,000 卡、每卡 1×800G、三层 1:1、模块配比约 5 只/卡（公式见光模块配比经济学）。
2. 模块：5 万只 × 20 W ≈ 1.0 MW——网络功耗大头，且热集中在交换机面板。
3. 交换机：三层 1:1 约 500–600 台 × 1.5 kW ≈ 0.75–0.9 MW。
4. 网卡 + 线缆：≈ 0.2–0.3 MW。
5. 合计 ≈ 1.9–2.2 MW（不含 PUE），约为计算侧（万卡 × ~700 W/卡 ≈ 7 MW）的 25–30% 量级；全部为估算口径，按实际配置复核。

### 风冷 vs 液冷下的网络布线差异

| 维度 | 风冷 | 液冷（冷板为主） |
|---|---|---|
| 机内互联 | 节点间 AOC/光模块 | 柜内 NVLink 铜背板（GB200 NVL72 类形态），铜替光省功耗 |
| 交换机位置 | 柜顶/列头均可 | 交换机仍风冷，集中放网络柜；光模块集中在可维护侧 |
| 维护模型 | 换线/换模块自由 | 液冷柜内动线需评估放水/下电；柜顶模块维护面是设计重点 |
| 背板可维护性 | 常规 | 整柜铜背板故障近似整柜级处置，备件按柜考虑 |
| 走线空间 | 与风道共用 | 进出水管占用柜后空间，与高密连接器、弯曲半径冲突要提前排布 |

### 机柜功率分配（单柜示意）

| 用途 | 功率量级 | 说明 |
|---|---|---|
| 计算（风冷） | 30–40 kW/柜 | 8 卡 SXM 节点 4–6 台 |
| 计算（液冷） | 80–130 kW/柜 | 整柜超节点（NVL72 类）上限更高 |
| 网络柜 | 15–30 kW/柜 | leaf + 模块密度决定，模块热集中 |
| 存储柜 | 5–15 kW/柜 | 视容量配置 |

### 电力先于芯片：对网络设计的约束

1. 机房可用电力先于 GPU 选型确定：拿不到的 MW 数，再好的拓扑也是纸面设计。
2. 密度换距离：GPU 柜密度越高（液冷超节点），越要把网络柜贴近计算柜，缩短光纤、降低模块功耗与链路衰减——但受楼板承重、电力分配与维护通道约束，两者必须联评。
3. scale-up 铜背板把「距离」从网络设计题变成机房布局题：整柜交付意味着柜位、电力、水管一次定死，后期不可调。
4. PUE 与电价直接进 TCO：LPO/CPO 每口省下的瓦数 × 8.76 kWh/W·年 即年省电量，折价口径见采购与TCO篇。

## 关键指标与基线

| 指标 | 基线 | 口径 |
|---|---|---|
| 网络功耗/万卡 | 1.9–2.2 MW（800G 三层，估算） | 上文模型 |
| 网络占集群总功耗 | 15–30% | 同上 |
| 模块占网络功耗 | 50%+ | 模块数 × 单只瓦数 |
| LPO 每口省电 | ~10–15 W（800G 口径） | 行业典型值（待核实） |

## 常见误区

1. 只算交换机不算模块：模块才是大头，且面板热集中加速老化、推高故障率。
2. 液冷项目把交换机一并浸没：主流交换机仍风冷，机房必须保留网络柜的风冷制冷。
3. 机柜功率按铭牌加总：模块、风扇、网卡的实际功耗与铭牌差异大，按实测口径。
4. 电力不留网络扩容余量：扩容时网络柜先于计算柜无电可用。
