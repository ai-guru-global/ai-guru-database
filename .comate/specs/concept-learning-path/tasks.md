# 概念入门路径 — 任务计划

## 总览

在 `learn/` 目录下创建一套完整的**概念驱动型学习路径系统**，包含路径总览、5条分角色路径、5层概念卡片、以及里程碑自测。

- [x] Task 1: 创建 `learn/README.md` 总览页
    - 1.1: 编写项目定位与使用说明
    - 1.2: 编写 5 条路径对比表（目标人群、前置要求、预计时间、核心产出）
    - 1.3: 编写路径选择决策树（问答式引导）
    - 1.4: 编写概念层次总览图（Stage 0-4 关系）
    - 1.5: 添加快速开始入口链接

- [x] Task 2: 创建 `learn/concepts/` 概念卡片（Stage 0-4）
    - 2.1: 创建 `stage-0-awakening.md` — AI觉醒层：AI定义、类型、能力边界、经典案例
    - 2.2: 创建 `stage1-foundation.md` — 基础层：数据、特征、模型、训练/推理、过拟合、评估指标
    - 2.3: 创建 `stage2-core-tech.md` — 核心技术层：神经网络、反向传播、CNN/RNN、Transformer、Attention、LLM、预训练+微调
    - 2.4: 创建 `stage3-engineering.md` — 工程实践层：部署推理、RAG、向量数据库、Prompt Engineering、MLOps、Agent/Tool Use
    - 2.5: 创建 `stage4-frontier.md` — 前沿方向层：多模态、世界模型/JEPA、VLA/具身智能、AI安全对齐、AGI路径

- [x] Task 3: 创建 `learn/pathways/` 分角色学习路径（5条）
    - 3.1: 创建 `absolute-beginner.md` — 零基础通识路径
    - 3.2: 创建 `ml-practitioner.md` — ML从业者路径
    - 3.3: 创建 `llm-engineer.md` — LLM工程师路径
    - 3.4: 创建 `ai-researcher.md` — AI研究者路径
    - 3.5: 创建 `product-manager.md` — AI产品经理路径

- [x] Task 4: 创建 `learn/milestones.md` 里程碑与自测
    - 4.1: 为 Stage 0-4 各编写 3-5 个自测问题
    - 4.2: 为每条路径编写阶段性检查点
    - 4.3: 编写未通过时的补救建议（链接回对应概念卡片）
