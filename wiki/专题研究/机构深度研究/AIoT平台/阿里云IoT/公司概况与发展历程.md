# 阿里云 IoT：公司概况与发展历程

> **模块**：机构深度研究 / AIoT 平台 / 阿里云 IoT｜**方面**：公司概况与发展历程
> **层级**：入门｜**数据时点**：财务截至 FY2027Q2（2026-11-19 披露）；事件时点以报道/公告日期为准

⚠️ 本文基于公开资料整理，仅供学习研究，不构成投资建议。

## 导读

阿里云 IoT 不是一家公司，而是阿里巴巴集团云智能体系内的业务单元。它的十二年经历了三次定位改写：消费智能生态的尝试（阿里小智/天猫精灵）、物联网基础设施（2018 年"全面进军 IoT"）、AI 全栈战略的接入层（2023 年后）。每次改写都不是 IoT 团队自己决定的——这是大厂附属业务与独立公司最根本的区别。

## 一、发展大事记（2014–2026）

| 时点 | 事件 |
|------|------|
| 2014 年 | 智能家居 App"阿里小智"起步（依托阿里云，后升级为"阿里智能"平台），消费入口先行 |
| 2017-07-05 | 阿里 AI 实验室发布天猫精灵 X1（499 元，内置 AliGenie 语音系统，2017-08-08 发售） |
| 2018-03-28 | 云栖大会深圳峰会，时任阿里云总裁胡晓明宣布全面进军物联网，定位"物联网基础设施的搭建者"，目标 5 年连接 100 亿台设备；同期发布首款边缘计算产品 Link Edge |
| 2019-01 | 生活物联网平台智能设备连接数过亿（C114 报道口径，2019-01-22） |
| 2020-01 | 天猫精灵升级为独立事业部，隶属阿里云 IoT 体系，库伟负责 |
| 2022 年 | 成立智能互联一级业务部门，核心品牌为天猫精灵（2025-01 行业报道回溯口径） |
| 2023-04 | 张勇宣布阿里全线产品接入通义千问（2023-04-11 云峰会）；天猫精灵接入千问开启内测（2023-04-21，AliGenie 6.0） |
| 2023-11/12 | "AI 驱动、公共云优先"战略下，IoT 业务线砍掉硬件集成业务（见 [[专题研究/机构深度研究/AIoT平台/阿里云IoT/合规风控与争议事件|合规风控与争议事件]]） |
| 2025-12 | 原智能信息与智能互联事业群合并为"千问 C 端事业群"（千问、夸克、UC 等），天猫精灵随之进入千问 C 端体系 |
| 2026-06 | 财报分部重组：云智能集团与平头哥合并为"AI 云与计算服务"分部，天猫精灵归属"AI Labs 与应用"分部下的千问消费事业群 |

## 二、三次定位迁移的逻辑

| 阶段 | 定位 | 驱动力 | 结局 |
|------|------|--------|------|
| 2014–2017 | 消费智能生态（App+音箱） | 对标 Amazon Echo，抢占家庭入口 | 音箱登顶中国份额第一，但硬件盈利难以为继 |
| 2018–2023 | 物联网基础设施（平台+边缘） | 云业务寻找第二增长曲线 | 平台能力沉淀（亿级连接），硬件集成被砍 |
| 2023 至今 | AI 全栈的接入层 | "AI 驱动、公共云优先" | IoT 不再单列，价值并入云分部收入与 AI 叙事 |

**直觉**：**直觉**——三次改写的方向一致：离硬件越来越远、离云和 AI 越来越近；IoT 在阿里体系内的地位，取决于它给云带来了多少"连接带来的算力消耗"，而非自身营收。
