# Agentic 编码

> AI 编码是模型变现最快、竞争最白热的场景：IDE、终端与云端智能体三条路线。

## 拆解卡

- **价值来源**：模型变现最快、能力兑现最直接的场景。
- **护城河**：采纳/重试信号的数据飞轮 + 入口卡位。
- **瓶颈**：长任务可靠性与企业采购合规。
- **领先指标**：编码工具 ARR 与估值锚；SWE 基准与真实仓库通过率

## 六层速览

Agentic 编码让 AI 自己读仓库、改代码、跑测试、提 PR——从「补全一行」升级为「交付一个任务」；衡量指标也从接受率变成合并率。

**打个比方**：像从「副驾驶提示」升级到「代驾」：你给目的地，它自己开车、处理路况；你只负责验收，而不是每个动作都盯。

**拆开看**：六段链路：代码索引与检索 → 计划与编辑 → 终端执行 → 测试反馈 → 多轮修复 → PR 交付；上下文管理、工具沙箱与权限边界是核心，长任务的上下文衰减是主要失败来源。

**怎么运转**：三种收费模式：IDE 订阅（Cursor、Copilot）、终端 Agent（Claude Code、Codex）、云端异步 Agent（Devin）；按席位或按任务收费，企业版加治理、私有部署与审计。

**格局与博弈**：Cursor 领跑 AI IDE，Claude Code、Codex 抢占终端与 CI，GitHub Copilot 靠分发守擂，Devin 代表异步交付；模型能力仍是胜负手，但工具链、上下文工程与评测数据的差距在缩小。

**边界与走向**：长任务可靠性与企业合规是瓶颈，编码 Agent 会向「软件工程平台」演进（需求、实现、测试、发布一体）；按结果收费可能颠覆席位制，初级编码岗位的需求结构会被改写，而架构与验收能力更值钱。

## 关键判断

编码是 AI 商业化最成熟的场景，需求确定性最高；但价值正向模型厂与 IDE 分发方两端集中，中间工具层毛利被推理成本压制（置信度 高，展望 12–24 个月）——核心变量是 agent 可靠性与模型厂垂直整合；这是全行业最好的「付费意愿验证场」，其定价走势可外推到其他 agent 场景。

规模口径：全球 AI 编码工具约 $80–150 亿（2025e），2030 年可达 $300–500 亿

## 二级细分

- **AI IDE（Cursor 类）** — 编辑器入口 + 商业化最成熟，被收购整合后进入巨头棋局。
- **终端 Agent（Claude Code/Codex）** — 开发者自有环境里的常驻智能体，扩展机制成为新平台。
- **云端自主 Agent（Devin 类）** — 异步整机沙箱形态，按任务交付而非按席位收费。
