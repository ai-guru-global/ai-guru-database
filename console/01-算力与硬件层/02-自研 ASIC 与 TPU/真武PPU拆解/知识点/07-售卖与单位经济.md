# 07 · 售卖形态与单位经济

> PPU 已从「自用降本工具」转折为「云差异化产品」：售卖形态、定价机制与官方性价比口径的读法。

## 售卖形态（官方页口径，2026-11-06 检索）

- **接入面**：ACS（容器计算服务）标准 K8s 零改造接入；灵骏超节点 / ACS 控制台 / PAI 控制台三个入口；
- **规格弹性**：810E 实例支持 1–16 卡弹性规格；
- **计费模式**：按量 / Spot / 容量预留——与 GPU 实例完全同构的售卖机制；
- **部署形态**：Serverless 私有化部署、智能扩缩容、PD 分离、EP 并行、vLLM 推理服务一键化、CPFS 挂载。

**判断**：这套售卖面与 AWS 上 Trainium 实例的形态完全同构——不是「 мы 也卖芯片」，而是「芯片作为云的一种实例类型」。1–16 卡弹性 + Spot 的存在说明阿里预期 PPU 有足够供给量做抢占式定价。

## 官方性价比口径（自述，未第三方验证）

- ACS PD 分离 + EP 并行：「推理性能最高提升 200%」；
- 训练性价比：「提升 50% 以上」；
- M890 FP8/FP4：「性能提升 3 倍」。

读法纪律（三条）：

1. 全部为**官方自述口径**，无第三方基准——引用必须带限定语；
2. 「提升 200%」的基线未披露（对比自家用 GPU？对比上代 PPU？）——**无基线的百分比不具备采购决策价值**；
3. 真实单位经济要看「同负载每 token 成本」——这正是 [推理账单（台内成本模拟器）](../../../../console/index.html) 该补 PPU 档位的理由（记入待办视角）。

## 自供经济学：PPU 对阿里云损益表的意义（观点层）

阿里云采购英伟达的每一张 H20/B 级，成本 = 芯片溢价 + 政策不确定性风险溢价。PPU 自供替换后的成本 = 平头哥 BOM + 已摊销研发。两个直接后果：

1. **推理价格战弹药**：Qwen API 的降价空间部分来自自供推理的更低成本线（与 TPU×Gemini 关系同构）；
2. **capex 内部化**：3800 亿级 AI capex（公开报道口径）中原本流向英伟达的部分，有一块转平头哥循环——这部分不体现在出货量新闻里，但体现在阿里云毛利里。

**量化缺口**：自供率无官方披露（🔍 挂待核实清单视角）——这是评估阿里云未来毛利曲线最该跟踪却最难跟踪的单一变量。
