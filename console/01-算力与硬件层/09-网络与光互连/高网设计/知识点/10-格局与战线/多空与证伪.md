# 多空与证伪：高网总判断的多空对照与证伪体系

> 一句话定位：台内主判断——带宽是集群的隐形税、光互连最受益、价值向机柜内 scale-up 互连再分配——的多空论证与可证伪化：每条论点配公开可跟踪口径，五条证伪线各配前置信号，六项 watch 定看数口径与频率。

## 多头论证（5 条展开）

1. 带宽超线性：网络是集群 capex 的结构性上行项
   - 证据：网络占集群 capex 10–20%、万卡整网约 $4–8 亿（估算口径）、GPU:800G 光模块配比约 1:4–4.5（无阻塞两层）（均为口径基线）。
   - 机制：并行度上升使集合通信量随规模超线性增长，带宽预算只能加不能省——"隐形税"的税率随集群规模上升。
   - 证据钩子：头部云厂 capex 指引中网络占比、交换芯片代际（102.4T，2025）放量节奏。
2. scale-up 价值层做厚：机柜内互连从配套变主角
   - 证据：NVLink 900GB/s（H100）→1.8TB/s（NVL72，2024）→3.6TB/s（Rubin VR200 NVL72，2026-01 CES 口径）；NVL72 单柜 5000+ 铜缆；scale-up 互连 2026e 数十亿美元级（估算口径）。
   - 机制：域扩张把网络价值从"跨机交换"搬进"机柜内互连"，NVL144（2026H2 计划）与 NVL576（Kyber 规划）延续该曲线。
   - 证据钩子：NVL 机柜出货节奏、铜缆/背板供应商营收结构变化。
3. 1.6T 量价齐升：代际红利窗口
   - 证据：光模块 400G（2020）→800G（2023）→1.6T（2025H2 导入、2026 上量）；光模块利润池约 25%、毛利 25–35%，中国厂商占全球出货大头（口径基线）。
   - 机制：代际切换初期供不应求，均价与毛利双升，先发产能吃窗口红利。
   - 证据钩子：光模块龙头月度营收（watch 项）、1.6T 出货爬坡斜率（watch 项）。
4. UEC 标准化 + 白盒 + 国产链：开放阵营的量
   - 证据：UEC 1.0（2025-06）发布；以太网交换芯片 CR1（Broadcom）70%+、光模块 CR5 约 60%、中国厂商占出货大头、网卡 NVIDIA 60%+（均为口径基线）——开放化的每一环都有多源供应商受益。
   - 机制：标准化降低采购锁定，白盒与国产链拿量；AI 后端网络增速 40%+（口径基线）提供增量摊薄。
   - 证据钩子：UEC 商用集群规模（watch/证伪线）、白盒代工与国产光模块出货。
5. 国内方法论成熟：从制造红利走向工程红利
   - 证据：阿里 HPN 15k GPU 双 ToR 双平面（SIGCOMM 2024）、字节 MegaScale 12,288 GPU（NSDI 2024）、中兴 2026-02 十万卡白皮书（GPU ID 空间预留）、夸娥 kUAE 超节点（2025）（均为口径基线）。
   - 机制：公开方法论把大机组网从黑科技变成工程手册，国内交付能力外溢可期。
   - 证据钩子：国产超节点商用规模、白皮书方案的实际部署进度。

## 空头论证（5 条展开）

1. CPO 垂直整合去中间化
   - 机制：CPO 把光引擎并入交换机 BOM，光引擎利润池仅约 3% vs 光模块 25%（口径基线）——形态切换即利润池向系统厂转移。
   - 证据：NVIDIA Quantum-X/Spectrum-X Photonics 2026 起量（量产口径）；Broadcom 亦有 CPO 布局（待核实）。
   - 证据钩子：CPO 端口爬坡（watch 项）；证伪线"2027 前占新部署端口超 20%"。
2. 以太网统一致配比双降
   - 机制：以太网统一 + 过收敛设计（配比 1:4–4.5→1:2.5）与调度补偿，使单 GPU 光端口需求与单价同时承压——量的逻辑被架构逻辑对冲。
   - 证据：过收敛配比锚与 Meta Raptor 24 小平面（SIGCOMM 2024，细节待核实）代表的工程方向（口径基线）。
   - 证据钩子：云厂新集群配比口径（招标/论文披露）、800G/1.6T 均价年降幅度。
3. 云厂自研压商用份额
   - 机制：Google TPU ICI Torus+OCS（口径基线）证明自研互连可行；自研把商用市场切割成"剩下的小客户"，商用厂商份额与议价双降。
   - 证据：头部云厂自研加速卡/互连的代际投入持续（占比量级待核实）。
   - 证据钩子：自研 ASIC 出货与商用交换/模块厂的大客户集中度变化。
4. 代际价格战
   - 机制：光模块/交换芯片每代以价换量，若 800G/1.6T 年降超 30%（证伪线），量价齐升叙事失效，退回制造业常态。
   - 证据：光模块毛利带 25–35%（口径基线）距离证伪线（破 25%）缓冲有限。
   - 证据钩子：1.6T 爬坡期是否提前开打价格战、光模块龙头毛利率环比走势。
5. capex 周期回落
   - 机制：AI capex 若周期性回落，网络作为 10–20% 占比项首当其冲被砍，弹性放大向下。
   - 证据：属机制主导型论点；网络占 capex 10–20%（口径基线）决定其下行弹性大于整体（历史回撤幅度待核实）。
   - 证据钩子：头部云厂 capex 指引下修、GPU 出货指引、万卡级整网订单可见度。

| 证伪线（口径基线） | 前置信号（领先 2–4 个季度可观察） |
|---|---|
| 800G/1.6T 年降超 30% | 1.6T 爬坡期提前价格战；龙头毛利率环比连降两季；招标价跌破上一代同期水位 |
| CPO 2027 前占新部署端口超 20% | NVIDIA Photonics 端口爬坡斜率陡于预期；Broadcom CPO 商用客户名单扩大；ELS 供应链提前成熟 |
| IB 份额回升 | 云厂新招标回流 IB；UEC 试点项目收缩；NVL 整机柜（IB 内嵌）占比上升 |
| UEC 商用集群停在试点 | UEC 1.x 规范延期；无万卡级商用部署公告；联盟核心成员转向私有方案 |
| 光模块龙头毛利率破 25% | 25–35% 毛利带下沿失守（连续两季）；CPO 订单从模块厂流向系统厂 |
