# FDE行业调研

> FDE 从 Palantir 的一个岗位名，两年内长成一个有招聘市场、薪资行情、认证培训、研究报告与开源著作的完整行业生态。本线索做行业横切面调研：已有企业格局、发展路径、达人与机构分析；岗位定义与交付经济学的纵深论证见 [[交付与组织/FDE前沿部署工程师]]，本文件不重复其事实底座。

## 是什么

**调研范围与方法**：本文件是 2026-10-02 的一次行业横切面快照，素材来自三处——① 本库既有取证（[[交付与组织/FDE前沿部署工程师]] 及其两份来源档案，取证日 2026-09-30）；② 本轮新增网络调研（WebSearch + WebFetch，取证日 2026-10-02，各源抓取状态逐条标注）；③ aihot 镜像既有沉淀。所有薪资、增速、规模数字沿用本库纪律：**标明口径与来源，不做跨口径换算与比较**；单源数字带 ⚠️；抓取失败登记 ✗ 不引正文。

**行业定义**：FDE（Forward Deployed Engineer，前沿/前线/前置部署工程师，中文译名尚未统一，本身即是行业早期的信号）指驻场客户环境、把通用 AI 模型接成客户业务系统的工程师角色。Perspective 的操作化定义是「在客户环境里生活 60–180 天、交付集成、把模糊需求转化为可上线系统的工程师」（[founder playbook](https://getperspective.ai/blog/how-to-build-forward-deployed-engineering-function-founder-playbook-2026)，2026-05-14，摘要级取得）。

**行业形成的标志**：一个岗位变成行业，看它是否长出配套生态。截至 2026-10，FDE 已具备——招聘市场（多平台岗位聚合与薪资行情）、认证与培训（海外 fde.academy / GSD Council，中国侧腾讯云 ADP 认证 + 五家以上培训机构）、行业研究报告（Plank《The State of FDE as a Service, 2026》、Perspective《2026 FDE Hiring Trends》）、开源著作（XDash 二十余万字开源书、yeasy 实践指南）、创业衍生（Palantir 校友 111+ 家创业公司）。生态完整度已超过多数同期新岗位（如 Prompt Engineer 从未长出认证市场）。

## 怎么看

1. **FDE 行业的「数据层」已被利益方全面污染，可信信息只剩三类**：官方公告（腾讯云 ADP 认证）、学术基准（Workspace-Bench）、复核型博客（lowtouch.ai）。榜单、报告、盘点文、认证机构的每一个数字都来自「卖品类」的人。本线索的方法论结论比数据结论更重要：**进入 FDE 生态做调研，默认所有规模数字降一级。**
2. **增速口径至少五种（42 倍 / 800% / 729% / 1165% / >1000%），且全部无法回溯一手**——42 倍指向 LinkedIn 报告（原件未取得），800% 指向财联社转述外媒（原外媒未点名），729% 与 1165% 分别见于 sina 与 Instagram 短视频。一个健康行业不需要五种增速叙事；五种叙事并存恰恰说明**热度由传播驱动而非测量驱动**。任何引用都必须带口径与来源，凡出现「FDE 需求增长 X 倍」的裸数字即为污染。
3. **薪资口径同样至少五套且量级分裂**：mixlab $200-300K（年薪）/$220-400K（用工总成本）、Plank $153-220K（中位）、GSD $215K-$465K（分公司 TC 中位）、Perspective $300-550K（mid）/$600K-1.2M（principal）、中国侧 15-30K 元/月（阿里云政企挂牌）至 96 万元/年（杭州个案）。分裂的根源是**统计对象不同**（岗位年薪 vs 总包 vs 用工成本 vs 挂牌区间）与**市场不同**（硅谷前沿实验室 vs 中国政企交付）。本库延续 [[交付与组织/FDE前沿部署工程师]] 分析 4 的纪律：只做同口径内的引用，永不换算。
4. **中美路径分叉的本质是「谁为交付毛利定价」**：美国侧由劳动力市场定价（$465K 的 OpenAI FDE 意味着对应合同的 ACV 必然数百万美元起），中国侧由云厂商渠道体系定价（认证 + 返点 + 培训机构 5K-29K 元的课程），两者相差一个数量级的人力成本决定了**中国侧 FDE 更接近「AI 化的政企交付工程师」而非硅谷意义上的前沿驻场**。用美国 FDE 叙事套中国市场（或反之）都是范畴错误。
5. **达人生态的空位**：中文世界已有开源书（XDash）、实践指南（yeasy）、百科词条、培训课程，但仍缺三样——① 独立的 FDE 交付质量度量（全球空白，见 FDE 线索分析 6 追踪信号⑥）；② 认证与合同资格绑定的公开证据（腾讯云侧 ❓）；③ 一手就业数据（LinkedIn 报告原件始终未取得）。三个空位中的任何一个被填上，都会成为本线索的下一个 ✅ 节点。
6. **下一步追踪信号**：① Plank/Perspective 之外是否出现无利益关联的第三方 FDE 行业报告（如 Indeed/猎聘官方数据）；② fde.academy / GSD Council 认证的实际通过率与雇主认可度证据；③ 中国五家培训机构是否出现与腾讯云 FDE 认证的课程对齐（培训—认证打通的信号）；④ XDash 开源书的社区影响力（star/翻译/课程引用）；⑤ Salesforce 等传统 SaaS 是否把「FDE」写进正式职级序列（岗位名称制度化的信号）。
