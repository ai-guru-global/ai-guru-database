# Deep Learning

> **一句话理解**: 深度学习领域的"圣经"（花书），由 GAN 之父 Ian Goodfellow 与图灵奖得主 Yoshua Bengio 等撰写，以数学严谨性著称，是建立深度学习理论根基的最佳参考书。

## 书籍信息

| 属性 | 说明 |
|------|------|
| **书名** | Deep Learning（Adaptive Computation and Machine Learning 系列） |
| **作者** | Ian Goodfellow、Yoshua Bengio、Aaron Courville |
| **出版社** | MIT Press（2016） |
| **页数** | 约 800 页 |
| **难度** | ⭐⭐⭐⭐（高级/理论） |
| **免费在线版** | [deeplearningbook.org](https://www.deeplearningbook.org/) |
| **链接** | [官方在线版](https://www.deeplearningbook.org/) |

## 核心内容概要

全书三大部分：

**Part 1 — 应用数学与机器学习基础**
1. 线性代数
2. 概率与信息论
3. 数值计算
4. 机器学习基础

**Part 2 — 深度网络：现代实践**
5. 深度学习中的反向传播
6. 深度前馈网络
7. 深度学习的正则化
8. 训练的优化算法
9. 卷积网络
10. 序列建模（RNN）

**Part 3 — 深度学习研究**
11. 实践方法论
12. 应用（NLP、推荐系统等）
13. 线性因子模型
14. 自编码器
15. 表示学习
16. 深度生成模型（含 VAE、GAN）
17. Monte Carlo 采样
18. 直面配分函数
19. 近似推断
20. 深度生成模型进阶

## 适合人群

- **级别**: 高级（研究生/研究人员）
- **前置知识**: 扎实的线性代数、概率论、微积分
- **适合**: 需要理解"为什么"的研究者、博士、算法工程师

## 亮点与局限

- ✅ **亮点**: 理论深度无出其右、免费在线版、作者权威（Bengio 为图灵奖得主）
- ⚠️ **局限**: 2016 年出版，未覆盖 Transformer（2017）、扩散模型等前沿；纯理论无代码；数学门槛高
