# SLA（Service Level Agreement）

> 中文简称：服务等级协议

> **一句话理解**: SLA 是写进合同里的服务承诺，做不到可能要赔钱。

## 定义

SLA（Service Level Agreement）是服务提供方与客户之间的正式服务水平协议，具有合同/法律效力，包含具体的服务指标承诺和未达标时的补偿条款。

## SLI / SLO / SLA 三者关系

```
SLI（指标）→ SLO（目标）→ SLA（协议）
  测量什么     目标多少     对外承诺+赔偿
```

| 维度 | SLI | SLO | SLA |
|------|-----|-----|-----|
| **定义** | 测量指标 | 内部目标 | 对外合同 |
| **示例** | 可用性=99.95% | 目标 99.9% | 承诺 99.9% |
| **约束力** | 无 | 内部 | 法律/合同 |
| **补偿** | 无 | 无 | 有 |
| **严格度** | 实际值 | 可激进 | 保守 |

## 常见 SLA 指标（AI 服务）

| 指标 | 典型承诺 | 补偿 |
|------|----------|------|
| **可用性** | 99.9% / 99.95% | 服务积分 |
| **API 延迟** | P99 < 2s | 折扣 |
| **故障恢复** | < 30min | 赔偿 |
| **数据持久性** | 99.999999999% | 赔偿 |

## 生产最佳实践

1. **SLA 比 SLO 保守**：内部目标 99.95%，对外承诺 99.9%
2. **用 Error Budget 管理**：SLO - 实际 = 可释放的变更空间
3. **自动化监控**：SLI 采集 → SLO 计算 → SLA 报告
4. **明确免责条款**：计划维护、不可抗力不计入
5. **定期审视**：每季度根据实际数据调整 SLA

## SLA 合同模板要素

| 要素 | 说明 | 示例 |
|------|------|------|
| 服务定义 | 明确服务范围 | LLM API 推理服务 |

## AI 服务 SLA 特殊考虑

| 维度 | 传统云服务 | AI 推理服务 | 建议 |
|------|----------|------------|------|
| 可用性 | 99.99% | 99.9% | 考虑模型加载时间 |
| 延迟 | P99 < 100ms | P95 < 2s | 用 P95 而非 P99 |
| 吞吐量 | 固定 QPS | 波动大 | 承诺基线 + 突发 |
| 模型更新 | N/A | 可能导致行为变化 | 纳入免责条款 |
| GPU 故障 | N/A | 硬件故障 | 明确恢复时间 |

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| SLA 过于激进 | 销售承诺超出工程能力 | SLO 比 SLA 严格 0.05% |
| 测量争议 | 客户端 vs 服务端数据 | 明确测量点和方法 |
| 补偿不清晰 | 合同条款模糊 | 明确补偿计算公式 |
| 多依赖服务 | 下游故障影响 SLA | 设置依赖服务独立 SLA |

## 总结

SLA 是服务提供方与客户之间的正式合同承诺，具有法律效力。在 AI 服务场景中，需要特别考虑模型推理延迟波动、GPU 故障和模型更新等因素。


## SLA 合规报告模板

```markdown
# 月度 SLA 报告 - 2026年7月

## 服务概览
| 服务 | SLA 承诺 | 实际达成 | 状态 |
|------|----------|----------|------|
| LLM 推理 API | 99.9% | 99.95% | ✅ 达标 |
| 向量检索服务 | 99.9% | 99.87% | ❌ 未达标 |

## 未达标分析
- 向量检索服务: 7月15日 GPU 节点故障导致 18min 不可用
- 补偿: 按合同条款补偿 10% 服务积分

## 改进措施
1. GPU 节点增加冗余
2. 自动故障转移优化
```

## SLA 谈判要点

| 要点 | 说明 | 建议 |
|------|------|------|
| 指标可测量 | 避免模糊描述 | 明确测量方法和工具 |
| 窗口合理 | 避免过短窗口 | 月度滚动窗口 |
| 免责清晰 | 避免争议 | 列举所有免责场景 |
| 补偿可执行 | 避免空头承诺 | 明确补偿计算和发放流程 |
| 定期审视 | 避免过时 | 每季度审视一次 |

## AI 服务 SLA 最佳实践

1. **分层 SLA**：基础设施层、平台层、应用层分别定义
2. **模型版本锁定**：SLA 绑定特定模型版本
3. **预热时间豁免**：模型冷启动时间不计入 SLA
4. **批量 vs 实时**：批量推理和实时推理分开定义 SLA
5. **GPU 类型影响**：不同 GPU 型号的延迟承诺不同
