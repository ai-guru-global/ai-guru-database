# Agent-to-Agent Protocol (A2A)

## 定义

Agent-to-Agent Protocol (A2A) 是 Google 提出的智能体互操作协议，用于标准化 Agent 与 Agent 之间的协作通信。如果说 MCP 是"AI 的 USB-C"（连接工具和数据），那么 A2A 是"AI 的 LinkedIn"——让不同来源的智能体能够发现彼此、协商任务、协同工作。
