# AI 职业指南 (AI Career Guide)

> 中文简称：AI 职业指南

## 1. 2026 AI 岗位全景

```
热门岗位 (按需求排序):

1. LLM/AI 应用工程师
   - 职责: 基于 LLM API 构建应用 (RAG/Agent/Chatbot)
   - 技能: Python + LangChain/LlamaIndex + Prompt Engineering
   - 门槛: 中 (不需要训练模型)
   - 薪资: 30-80万 (中国) / $120-200K (美国)

2. ML 工程师
   - 职责: 07_模型训练/微调/部署/优化
   - 技能: PyTorch + 分布式训练 + MLOps
   - 门槛: 高
   - 薪资: 40-100万 / $150-300K

3. Agent 开发者
   - 职责: 设计和构建 AI Agent 系统
   - 技能: LLM + 工具调用 + 状态管理 + 评估
   - 门槛: 中高
   - 薪资: 35-90万 / $130-250K

4. MLOps/平台工程师
   - 职责: AI 基础设施/训练平台/推理服务
   - 技能: K8s + GPU + 分布式系统
   - 门槛: 高
   - 薪资: 40-100万 / $150-280K

5. AI 产品经理
   - 职责: AI 产品规划/需求/落地
   - 技能: 产品思维 + AI 理解 + 行业知识
   - 门槛: 中
   - 薪资: 30-70万 / $120-200K

6. 数据工程师/标注管理
   - 职责: 数据管道/标注质量/数据治理
   - 门槛: 中低
   - 薪资: 20-50万 / $80-150K
```

## 5. AI 岗位全景图

| 岗位方向 | 典型职位 | 核心技能 | 薪资范围(年) |
|----------|----------|----------|----------------|
| AI 研发 | 算法工程师、研究员 | 深度学习、论文复现 | 40-120W |
| AI 应用 | LLM 应用工程师 | RAG、Agent、Prompt | 30-80W |
| MLOps | ML 平台工程师 | K8s、CI/CD、监控 | 35-90W |
| 数据工程 | 数据工程师 | Spark、ETL、数据质量 | 30-70W |
| AI 产品 | AI 产品经理 | 需求分析、AI 认知 | 30-80W |
| AI 安全 | 安全研究员 | 红队测试、对齐 | 40-100W |

## 6. 技能树与学习优先级

| 技能层级 | 必备技能 | 加分技能 | 学习时间 |
|----------|----------|----------|----------|
| 基础层 | Python、数学、ML基础 | 统计学、线代 | 3-6月 |
| 核心层 | 深度学习、NLP/CV | 分布式训练 | 3-6月 |
| 应用层 | LLM、RAG、Agent | 微调、评估 | 2-3月 |
| 工程层 | 部署、监控、优化 | K8s、云原生 | 2-3月 |

## 8. 面试准备要点

| 面试环节 | 考察重点 | 准备建议 |
|----------|----------|----------|
| 算法题 | 编程能力 | LeetCode 中等难度 |
| ML 基础 | 理论理解 | 经典算法原理 |
| 系统设计 | 架构能力 | AI 系统设计案例 |
| 项目经验 | 实践能力 | 深入理解自己项目 |
| 论文讨论 | 研究深度 | 精读 3-5 篇核心论文 |

## 9. 常见问题

| 问题 | 解答 |
|------|------|
| 非科班能转 AI 吗？ | 可以，但需补充数学和编程基础 |
| 需要读研读博吗？ | 研发岗建议硕士+，应用岗本科可 |
| AI 岗位会饱和吗？ | 应用层需求持续增长，研发层竞争激烈 |
| 如何积累项目经验？ | 开源贡献、Kaggle、个人项目 |
| 远程工作机会多吗？ | AI 岗位远程比例较高，尤其是应用层 |
| 如何保持竞争力？ | 持续学习新技术、深耕垂直领域 |
