# 华为（Huawei，非上市员工持股民营企业）
> 中文简称：华为
> **模块**：机构深度研究 / AIoT 平台｜**机构速览卡**
> **数据时点**：财务为 2025 年年度报告（毕马威审计报告日 2026-03-27，公司惯例 3 月底发布）；持股与治理为年报披露（截至 2025-12-31，董事会/监事会 2026-03 换届口径）｜本文不构成投资建议

> **一句话理解**: 与涂鸦"帮别人做智能"的中立平台相反，华为把芯片—操作系统—设备—云做成全栈自研的 AIoT 闭环，用 21.8% 的研发强度和超 10 亿台鸿蒙生态设备，把行业默认的"生态中立性"公理改写成了"生态自主性"。

| 最新业绩 | 2025 年收入 8,809.41 亿元（+2.2%）、净利润 680.36 亿元（净利率约 7.7%）、经营现金流 1,273.84 亿元 |
| 关键指标 | 研发费用 1,923 亿元占收入 21.8%（2025）；研发员工约 11.4 万名占 53.7%；有效授权专利约 16.5 万件（2025 年底） |
| 业务标签 | ICT 基础设施 3,750 亿 + 终端 3,445 亿 + 数字能源 773 亿 + 智能汽车解决方案 450 亿（+72.1%）+ 云 322 亿（2025；集团不单独披露 IoT/鸿蒙分部收入） |
| 代表产品或资产 | HarmonyOS 5/6 终端超 3,600 万台、开源 OpenHarmony 衍生 1,300 多款软硬件产品、鸿蒙生态设备超 10 亿台（2024 年报口径）、昇腾/鲲鹏算力底座 |
| 代表人物 | 创始人任正非（出资占比约 0.59%）；董事长梁华；副董事长兼轮值董事长兼 CFO 孟晚舟（2025 年报致辞）；常务董事余承东（终端） |
