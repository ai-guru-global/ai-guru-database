# AIoT 平台行业总览
> 中文简称：AIoT 平台行业总览

> **一句话理解**: IoT 平台是一门"帮别人做智能硬件"的抽佣生意——客户越集中、AI 渗透越高，平台越值钱。

---

## 商业模式主线

**平台收入 = 接入设备量 × 单设备云服务价值 × 留存系数（DBNER）**

**直觉**：平台自己不卖硬件，卖的是"让硬件变智能"的云与开发工具，所以设备出货是行业景气度的先行指标，DBNER 是客户用脚投票的温度计。

| 玩家类型 | 代表 | 生态位 |
|----------|------|--------|
| 中立第三方平台 | 涂鸦智能 | 不碰终端品牌，靠中立性吃品牌方/OEM 的跨生态需求 |
| 云大厂 IoT 分支 | AWS IoT、Azure IoT、阿里云 | 云资源强，但 IoT 只是云业务的附属 |
| 终端巨头自有生态 | 小米 Vela、华为、Google/Amazon/Apple | 平台服务自家终端，天然不中立 |
| 协议联盟 | Matter（CSA） | 统一应用层语言，压缩单家平台的锁定价值 |

## 竞争的三个观察维度

1. **中立性**：品牌方不愿把命脉交给有终端业务的对手——这是涂鸦对小米/华为/亚马逊的差异化根基，也是其最需要防守的资产
2. **协议变量**：Matter 统一生态后，"接入能力"贬值，竞争上移到"AI 能力 + 场景 SaaS"
3. **AI 重定价**：AI 应用毛利率（70%+）显著高于 PaaS（46% 左右），AI 渗透率决定平台毛利率中枢
