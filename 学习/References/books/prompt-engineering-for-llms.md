# Prompt Engineering for LLMs

> **一句话理解**: O'Reilly 出品的提示工程系统指南，从基础提示模式到 ReAct、思维链、工具调用全覆盖，并讲解提示的自动化测试与评估，是 Prompt 工程师的标准参考。

## 核心内容概要

1. **提示工程基础** — Token、上下文窗口、模型行为
2. **基础提示模式** — 零样本、少样本、角色提示
3. **思维链（CoT）** — 让模型"想清楚再回答"
4. **高级推理技术** — 自我一致性、Tree of Thoughts
5. **ReAct 与工具调用** — 让 LLM 使用工具
6. **RAG 与提示结合** — 检索增强的提示策略
7. **提示的自动化测试** — 评估指标、回归测试
8. **提示安全与注入防护** — Prompt Injection 攻防

## 适合人群

- **级别**: 初级 → 中级
- **前置知识**: 了解 LLM 基本概念
- **适合**: Prompt 工程师、产品经理、需要高效使用 LLM 的开发者

## 学习建议

- **阅读顺序**: 顺序阅读，边读边在真实模型上实验

## 亮点与局限

- ✅ **亮点**: 覆盖全面、含自动化测试方法（多数书忽略）、实战模板丰富
- ⚠️ **局限**: 提示工程领域变化极快，书中部分技术可能已被新模型原生能力替代
