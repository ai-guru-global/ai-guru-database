# 多模态模型 for Dummy

> 中文简称：多模态模型大白话

> **一句话理解**: 多模态模型 = 给只会「读文字」的大模型装上眼睛和耳朵——把图片、音频先翻译成它认识的「语言」，再一起思考。

---

## 🤔 先搞懂一个问题：模型怎么「看见」图片？

大模型原本只认识文字（token）。多模态的诀窍分三步：

1. **👀 编码**：用视觉编码器（如 ViT）把图片切成小方块，变成一串「图像 token」；
2. **🔌 对齐**：用一个 adapter / 投影层，把图像 token 翻译到文字 token 同一个「语义空间」；
3. **🧠 一起推理**：文字 token + 图像 token 拼在一起，交给大模型统一思考。

> 类比：外交翻译。模型只听懂「中文」（文字 token），ViT 把「图片」同声传译成中文，模型就能聊照片了。

---

## 🧬 三代技术路线（2026 视角）

| 代际 | 思路 | 代表 | 特点 |
|------|------|------|------|
| 第一代 | 两只桶拼接：视觉编码器 + LLM | CLIP、LLaVA | 简单有效，但「视力」天花板低 |
| 第二代 | 桥接强化：高分辨率 + 更强 adapter | Qwen-VL 系列 | 能看图表、小字、截图 |
| 第三代 | **原生多模态**：出生就混着训练 | GPT-4o 类 | 看、听、说一体，延迟低 |

深入第三代：[[05_大模型/09_多模态模型/07_Native_多模态_架构|Native 多模态架构]]；拼接式代表作拆解：[[05_大模型/09_多模态模型/04_LLaVA_深入分析|LLaVA 深入分析]]。

## 🛠️ 能干什么（高频场景）

- 📄 **截图问答**：把报错截图 / 表格截图扔给模型，直接要答案；
- 📊 **图表理解**：读财报图、监控大盘，输出结构化结论；
- 🖼️ **以图搜图 / 内容审核**：向量化的图像可检索、可审查；
- 🎬 **视频理解**：抽帧 + 时序建模，见 [[05_大模型/09_多模态模型/09_视频_Understanding_架构|视频理解架构]]。

30 行代码也能玩：用 OpenAI 兼容 API 把图片转 base64 传给 `image_url` 字段即可——工程难点从来不在「调通」，在「稳定看清」。

---

## ⚠️ 三大误区

1. **「多模态 = 更聪明」**❌：看图能力和文字推理是两条腿，看图强不代表数学强；
2. **「分辨率越高越好」**❌：token 数量随分辨率暴涨，成本与延迟一起爆炸——工程上是权衡题；
3. **「原生多模态一定碾压拼接式」**❌：拼接式（LLaVA 系）开源生态成熟、可私有化，生产选型看场景而非代际。
