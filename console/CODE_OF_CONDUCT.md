# 社区行为准则

AI GURU 工作台（ai-guru-console）致力于成为一个开放、友好、包容的技术社区。我们希望每一位参与者都能在这里获得尊重和帮助。

## 我们的承诺

作为社区成员、贡献者和维护者，我们承诺：

- 对所有人保持尊重和礼貌，无论其经验水平、性别、性别认同和表达、性取向、残疾、个人外貌、体型、种族、民族、年龄、宗教信仰或国籍
- 欢迎新成员，耐心回答初学者的问题
- 专注于对社区最有益的建设性讨论
- 接受善意的批评，并从中学习

## 不可接受的行为

以下行为在社区中是不可接受的：

- 使用带有性暗示的语言或图像，以及不受欢迎的性关注或性挑逗
- 发表煽动性、歧视性、侮辱性或仇恨言论
- 针对他人的骚扰、公开羞辱或人身攻击
- 发布他人的私人信息（如住址、电子邮件地址等）
- 其他在专业环境中被合理认定为不恰当的行为

## 执行责任

社区维护者有权利和责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、问题编辑和其他贡献。维护者也可以暂时或永久禁止任何他们认为有不当、威胁、冒犯或有害行为的贡献者。

## 适用范围

本行为准则适用于所有 AI GURU 工作台（ai-guru-console）社区空间，包括但不限于：

- GitHub 仓库（Issues、Pull Requests、Discussions）
- 社区聊天群组（Discord、Telegram、微信群等）
- 官方社交媒体账号
- 线上和线下社区活动

## 举报方式

如果你目击或经历了不可接受的行为，请联系社区维护者：

- 在 GitHub 上私信任意 Maintainer
- 或在 [GitHub Discussions](https://github.com/ai-guru-global/ai-guru-console/discussions) 联系维护者

所有举报将被保密处理。
