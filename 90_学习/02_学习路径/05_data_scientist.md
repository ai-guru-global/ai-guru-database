# 数据科学家学习路径 (Data Scientist Learning Path)

> 中文简称：数据科学家学习路径

> 数据科学家是 AI 领域最成熟的职业路径之一——从统计基础到端到端 ML 项目，系统规划数据科学家的成长路径。

---

## 1. 角色定位

| 维度 | 说明 |
|------|------|
| 核心职责 | 从数据中提取洞察、构建预测模型、驱动业务决策 |
| 技能重心 | 统计学 + 编程 + 业务理解 |
| 与ML工程师区别 | 更偏分析和实验，ML工程师偏工程化和生产部署 |
| 典型产出 | 分析报告、原型模型、A/B测试结论、数据产品 |
