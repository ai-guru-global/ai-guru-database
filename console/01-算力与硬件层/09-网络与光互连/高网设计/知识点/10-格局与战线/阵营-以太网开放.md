# 阵营：以太网开放——用供应链开放与标准旗帜围攻全栈

> 一句话定位：以 Broadcom 芯片为军火库、UEC 1.0（2025-06）为规范旗帜、Arista/Cisco 为系统门面、云厂多平面实践为弹药松散而进攻性的联盟，赌"够用的性能 × 开放的供应链"终将稀释 NVIDIA 全栈溢价。

## 体系构成

| 层位 | 玩家/载体 | 事实锚点（口径基线） |
|---|---|---|
| 交换芯片军火库 | Broadcom Tomahawk/Jericho 系 | 以太网交换芯片 CR1 份额 70%+；TH6 102.4T（2025）；代际 12.8T(2018)→25.6T(2020)→51.2T(2022)→102.4T(2025) |
| 规范旗帜 | UEC 1.0 | 2025-06 发布，AI 后端以太网规范 |
| scale-up 标准位 | UALink 1.0 | 2025 发布，补机柜内开放标准空位 |
| 系统双雄 | Arista、Cisco | 高端数据中心交换机主力（份额量级待核实） |
| 云厂实践 | Meta Raptor 等 | Raptor 24 小平面（SIGCOMM 2024，细节待核实）；多平面/轨道优化成云厂标配方法论 |
| 白盒+网络OS | ODM + SONiC | 超大规模客户自有方案主力，成本锚 |
| 光互连 | 可插拔为主 | 800G（2023）→1.6T（2025H2 导入、2026 上量）；LPO 为低功耗中间路线 |
| 网卡侧 | Broadcom/Marvell/NVIDIA（以太网模式） | NVIDIA 网卡 60%+ 份额中相当部分跑在以太网上（估算口径） |

- 结构本质：没有单一 owner，联盟各层皆可替换——这是对配给制与溢价的天然免疫，也是协同作战的天然弱点。
- 阵营模糊地带：NVIDIA Spectrum-X 也是"以太网"，以太网赢不完全等于开放阵营赢——云厂用以太网但买 NVIDIA 盒子的比例在上升（量级待核实）。

## 打法与护城河

1. 供应链开放：芯片（Broadcom CR1 70%+）、系统（Arista/Cisco/白盒）、网卡多源可换，云厂以第二供应商策略压价，这在对 NVIDIA 的全局谈判中价值巨大。
2. 成本与规模经济：以太网沿袭数十年企业网/云网供应链，整机成本显著低于同代 IB（幅度待核实）；白盒把系统压到 10–20% 毛利带（口径基线）仍有人做，成本锚极深。
3. 生态多元：阿里 HPN 15k GPU 双 ToR 双平面（SIGCOMM 2024）、字节 MegaScale 12,288 GPU（NSDI 2024）证明以太网 RoCE 扛得住万卡级工程，方法论已论文级公开。
4. 标准卡位：UEC 1.0（2025-06）把"AI 后端以太网"从各家私有调优收敛为规范；UALink 1.0（2025）再补 scale-up 标准位，两头挤压专有标准。
5. 借力打力：Broadcom 同时向光模块厂供 DSP/PHY、向 NVIDIA 之外的系统厂供芯片——任何一条战线开打它都卖军火。

## 软肋

1. 互操作碎片：UEC 1.0 刚发布，商用验证集群少；多厂商 RoCE 参数对齐成本高，出了问题责任界面模糊。
2. 无损调优门槛：RoCE 的 PFC/ECN 调优是工程脏活，云厂靠自研工具链消化，外部客户复用难——这是 IB"开箱即用"溢价仍存的根因。
3. 端到端差距：在网计算（SHARP 类集合加速）与极限时延上，以太网对 IB 仍有代差；UEC 是否补齐待商用验证。
4. 联盟无主：Broadcom 卖芯片不扛集成责任，Arista/Cisco 各有算盘，云厂自研再拿走一块——胜利时分配机制天然紧张。

## 胜负手与观察点

| 观察点 | 多头信号 | 空头信号 |
|---|---|---|
| UEC 商用集群规模 | 2026–2027 出现数万卡级商用集群（非试点） | 停在试点/POC（台内证伪线之一） |
| 以太网 RDMA 对 IB 的侵蚀 | 头部云厂新部署后端以太网占比持续上行 | IB 份额回升（证伪线） |
| 在网计算下放 | SHARP 类聚合在以太网商用（UEC 框架内或厂商私有） | 集合通信绕不过端侧，以太网 MFU 劣势固化 |
| 以太网进 scale-up | UALink 商用芯片落地；注意 Spectrum-XGS 是 NVIDIA 产品，归属易混淆 | scale-up 仍由 NVLink 定义 |
| 招标结构 | 云厂后端招标拆分 GPU 与网络独立包 | 机柜级整体采购（NVL 类）占比上升 |

- 关键推理：开放阵营的胜利条件不是"以太网赢"，而是"非 NVIDIA 的以太网赢"；任何以以太网之名的 NVIDIA 份额提升（Spectrum-X/XGS）都是联盟的局部失败。
