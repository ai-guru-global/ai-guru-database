## 业务场景：我们的教育初创公司

生成式人工智能（AI）代表了人工智能技术的巅峰，突破了曾经被认为不可能的界限。生成式 AI 模型具有多种功能和应用，但在本课程中，我们将通过一个虚构的初创公司来探讨它如何革新教育领域。我们将这个初创公司称为 **"我们的初创公司"**。

### 初创公司的使命声明

> 在全球范围内提高学习的可及性，确保教育的公平获取，并根据每个学习者的需求提供个性化的学习体验。

我们的初创公司团队深知，如果不利用现代最强大的工具之一——大型语言模型（LLMs），我们将无法实现这一目标。

### 生成式 AI 如何改变教育

生成式人工智能有望彻底改变我们今天的学习和教学方式：

- **学生端**：学生可以随时随地通过虚拟教师获取大量信息和示例。AI 可以为不同水平的学生提供个性化的辅导、解释和练习题
- **教师端**：教师可以利用创新工具评估学生并提供反馈，自动生成教学材料，辅助课程规划

这种变革的核心在于——生成式 AI 让任何人只需输入一个文本提示（即用自然语言写的一句话），就可以使用它。你不需要学习像 Java 或 SQL 这样的编程语言来完成有价值的事情，只需用自己的语言表达需求，AI 模型就会给出建议。它的应用和影响是巨大的，你可以在几秒钟内撰写或理解报告、编写应用程序等等。

## 生成式人工智能的发展历程

尽管最近生成式人工智能模型的发布引发了极大的热潮，但这项技术的研发已经历了数十年的时间。了解这段历史有助于我们更好地理解当前技术的本质和未来发展方向。

### 第一阶段：基于规则的系统（1960 年代）

最早的人工智能原型是基于文本输入的聊天机器人，它们的工作原理是：

1. **知识库构建**：从专家组中提取知识，将其表示为计算机可读的形式
2. **关键词匹配**：用户输入文本后，系统通过关键词触发知识库中的答案
3. **固定回复**：每个关键词对应一个预定义的回答

**局限性**：这种方法很快就暴露了严重的扩展性问题。知识库需要人工维护和更新，无法处理未预见的问题，且随着知识库增大，管理成本急剧上升。这种基于规则的系统本质上不具备真正的"理解"能力。

### 第二阶段：统计方法与机器学习（1990 年代）

转折点出现在 20 世纪 90 年代，当时统计方法被应用于文本分析。这一阶段的核心变化是：

- **从规则到数据驱动**：不再依赖人工编写的规则，而是让算法从数据中自动学习模式
- **机器学习算法**：开发了新的机器学习算法，它们能够从数据中学习模式，而无需明确编程
- **统计模型**：通过在文本和标签配对上训练统计模型，使其能够根据预定义的标签对未知输入文本进行分类

这种方法使机器能够模拟人类的语言理解，但仍局限于相对简单的分类和预测任务。

### 第三阶段：神经网络与深度学习（2000 年代 - 2010 年代）

近年来，硬件技术的进步（特别是 GPU 的普及）使得处理更大规模的数据和更复杂的计算成为可能。这推动了人工智能领域的重大突破：

- **神经网络**：也称为深度学习算法，是一种受人脑结构启发的计算模型
- **循环神经网络（RNNs）**：显著提升了自然语言处理的能力，能够更好地理解句子中单词的上下文，使文本含义的表示更加有意义
- **虚拟助手**：RNN 技术推动了 21 世纪初虚拟助手的发展，这些助手能够理解人类语言、识别需求并采取行动（如回答问题或调用第三方服务）

**RNN 的局限**：RNN 虽然在处理序列数据方面取得了进展，但它们在处理长文本时存在"遗忘"问题——难以记住序列开头的信息。

### 第四阶段：Transformer 与生成式 AI（2017 年至今）

这是现代生成式 AI 的基石。2017 年，Google 研究团队发表了里程碑式的论文《Attention Is All You Need》，提出了一种全新的模型架构——**Transformer**。

**Transformer 的核心创新**：

1. **注意力机制**：使模型能够对接收到的输入赋予不同的权重，"更加关注"文本序列中最相关的信息，而不受其顺序的影响
2. **并行处理**：Transformer 可以并行处理输入序列中的所有位置，极大地提高了训练效率
3. **长距离依赖**：克服了 RNN 的局限性，能够接受更长的文本序列作为输入，更好地捕捉长距离依赖关系

大多数最近的生成式 AI 模型——也被称为大型语言模型（LLMs），因为它们处理的是文本输入和输出——实际上都是基于这种 Transformer 架构。

**技术层级关系**：

生成式 AI 可以被视为深度学习的一个子集，而深度学习又是机器学习的子集，机器学习又是人工智能的子集：

| 层级 | 范围 | 说明 |
|------|------|------|
| 人工智能（AI） | 最外层 | 让机器模拟人类智能的广泛领域 |
| 机器学习（ML） | AI 的子集 | 通过数据训练模型，无需显式编程 |
| 深度学习（DL） | ML 的子集 | 使用多层神经网络处理复杂模式 |
| 生成式 AI | DL 的子集 | 专注于生成新内容的 AI 技术 |

**现代生成式 AI 的标志性产品**：

- **OpenAI ChatGPT**：基于 GPT 系列模型的对话式 AI，展示了类似人类的对话能力
- **Bing Chat**：微软的搜索引擎集成了 GPT 模型，实现了对话式搜索体验
- **GitHub Copilot**：AI 编程助手，将自然语言描述转换为代码

这些模型的有趣之处在于，它们通过从书籍、文章和网站等多种来源的大量未标注数据中进行训练，可以适应各种任务，并生成语法正确且具有一定创造性的文本。

## 大型语言模型是如何工作的

在下一章中，我们将深入探讨不同类型的生成式 AI 模型，但现在让我们先了解大型语言模型的核心工作原理，重点是 OpenAI 的 GPT（生成式预训练 Transformer）模型。

### 第一阶段：分词——将文本转化为数字

大型语言模型接收文本作为输入，并生成文本作为输出。然而，作为统计模型，它们处理数字比处理文本序列更为高效。因此，每个输入都需要先通过**分词器（Tokenizer）**处理。

**什么是 Token？**

一个 token 是一个文本片段，由可变数量的字符组成。它可能是一个完整的词、一个词的一部分、甚至是一个标点符号。分词器的主要任务是将输入分割成一个个 token 数组，然后将每个 token 映射为一个 **token 索引**（即原始文本片段的整数编码）。

**分词过程示例**：

假设输入文本是 "I love AI"：

```
原始文本: "I love AI"
         ↓ 分词器处理
Token 数组: ["I", " love", " AI"]
         ↓ 映射为索引
Token 索引: [40, 3017, 9608]
```

注意以下分词特点：
- 不同模型可能使用不同的分词方式，因此同一个词在不同模型中可能被分成不同数量的 token
- 空格、标点符号都会影响分词结果
- 分词方式直接影响模型的理解和生成质量
- 每个模型有一个最大 token 数限制（称为上下文窗口），超过限制的输入会被截断

你可以使用 [OpenAI Tokenizer](https://platform.openai.com/tokenizer) 工具直观地了解分词过程。

### 第二阶段：预测输出 Token

给定 n 个输入 token（每个模型的最大 n 值不同），模型能够预测一个输出 token。

**生成过程详解**：

1. **初始输入**：模型接收 token 序列作为输入
2. **预测下一个 token**：基于输入序列，模型预测最可能出现的下一个 token
3. **扩展窗口**：预测出的 token 被纳入下一次迭代的输入中，模型继续预测下一个 token
4. **持续生成**：这个过程以扩展窗口的模式持续运行，生成一个或多个句子作为回答

**这解释了什么现象？**

如果你曾使用过 ChatGPT，可能会注意到它有时会在句子中途停止。这正是这种逐步生成机制导致的。模型每次只预测一个 token，然后将这个 token 加入输入，再预测下一个，如此循环。当模型判断生成应停止时（如遇到结束标记），输出就会终止。

### 第三阶段：概率分布与选择过程

输出的 token 是根据其在当前文本序列之后出现的**概率分布**由模型选择的。

**概率分布的含义**：

模型基于其训练数据，计算了所有可能"下一个 token"的出现概率。例如，给定输入 "The cat sat on the"，模型可能计算出以下概率分布：

| Token | 概率 |
|-------|------|
| mat | 0.35 |
| floor | 0.20 |
| couch | 0.15 |
| roof | 0.08 |
| ... | ... |

**模型不总是选择最高概率的 token**。为了模拟创造性思维的过程，选择中加入了一定程度的随机性。这种随机性通过一个名为**温度（Temperature）**的模型参数来调整。

**温度参数详解**：

| 温度值 | 行为特征 | 适用场景 |
|--------|----------|----------|
| 0 | 几乎确定性地选择最高概率 token | 需要精确、一致输出的场景（如代码生成、事实问答） |
| 0.3-0.5 | 较低随机性 | 需要基本准确但允许少量变化的场景 |
| 0.7（默认） | 适中的随机性 | 通用对话和文本生成 |
| 1.0 | 较高随机性 | 创意写作、头脑风暴 |
| >1.0 | 极高随机性 | 实验性场景，输出可能不太连贯 |

## 大型语言模型的应用场景

现在我们对大型语言模型的内部工作原理有了更好的了解，让我们看看它们可以执行的一些常见任务，并结合我们的教育业务场景进行探讨。

### 提示与完成的概念

大型语言模型的主要功能是**从零生成文本，从用自然语言编写的文本输入开始**。这里有两个核心术语：

- **提示（Prompt）**：大型语言模型的输入，即你发送给模型的文本
- **完成（Completion）**：大型语言模型的输出，这个术语指的是模型通过生成下一个 token 来"完成"当前输入的机制

### 应用场景一：摘要与信息提取

**指令类型**：提供一段文本，要求模型进行摘要或从中提取关键信息。

**教育场景示例**：

- 管理员要求 AI 分析课程数据，识别课程覆盖的空白领域
- AI 可以总结冗长的学术文章，提取核心观点
- 从非结构化的学生反馈中提取有价值的见解

**示例提示**：

```
请总结以下关于太阳系的教学内容，提取3个关键知识点：
[长文本内容]
```

### 应用场景二：创意写作与内容生成

**指令类型**：提供创作方向，让模型生成原创内容。

**教育场景示例**：

- 教育者要求 AI 为特定受众和主题生成课程计划
- 生成练习题、测验题目
- 创建教学案例和示例

**示例提示**：

```
请为初中二年级学生生成一份关于光合作用的教案，包含教学目标、重点难点、教学步骤和课后练习。
```

### 应用场景三：对话式问答

**指令类型**：以与代理对话的形式提出问题。

**教育场景示例**：

- 学生在难学科目上寻求辅导
- AI 可以根据学生的水平提供个性化的解释和引导
- 通过多轮对话深入探讨某个概念

**示例对话流程**：

```
学生：什么是光合作用？
AI：光合作用是植物利用阳光、水和二氧化碳制造食物的过程...
学生：那叶绿素在其中起什么作用？
AI：叶绿素是植物细胞中的一种绿色色素，它的主要作用是...
```

### 应用场景四：文本补全

**指令类型**：提供部分文本，隐含要求补全。

**教育场景示例**：

- 写作辅助：学生写了文章开头，AI 帮助续写
- 代码补全：开发者写了部分代码，AI 完成剩余部分
- 实验报告模板的自动填充

### 应用场景五：代码生成与解释

**指令类型**：提供代码或要求生成代码，同时要求解释或文档。

**教育场景示例**：

- 编程教师要求 AI 生成特定任务的示例代码
- AI 可以解释复杂代码的工作原理
- 为现有代码添加注释和文档

## 大型语言模型的局限性

虽然生成式 AI 展现了巨大的潜力，但了解其局限性同样重要。在后续课程中，我们将深入探讨如何应对这些问题。

### 非确定性

LLM 的输出具有随机性。相同的提示在不同时间运行可能产生不同的结果。这是由模型的概率选择机制和温度参数决定的。

**影响**：
- 不适合需要精确、可重复结果的场景
- 每次运行可能得到质量不同的输出
- 需要人工验证和筛选

### 幻觉问题

有时模型的创造性可能适得其反，导致输出是人类用户可能解读为"现实扭曲"的词语组合。

**幻觉的典型表现**：
- 生成看似合理但完全错误的事实
- 编造不存在的引用和来源
- 将错误信息与正确信息混合，以令人信服的方式呈现

**在教育场景中的风险**：学生可能不会质疑 AI 生成的错误答案，将其当作事实来记忆。

### 不是真正的智能

生成式 AI 并不智能——至少在更全面的智能定义中：
- 缺乏批判性和创造性推理能力
- 没有情感智能
- 不具备真正的理解能力
- 不是确定性的，也不完全可信

**正确使用方式**：将 LLM 视为一个强大的辅助工具，而不是最终的权威。它的输出应该被视为"初稿"，需要人类的专业判断来验证和改进。

## 知识检查

**问题**：关于大型语言模型，以下哪些是正确的？

1. 每次都会得到完全相同的回答
2. 它能完美地完成任务，非常擅长计算、生成可用代码等
3. 回答可能会因相同的提示而有所不同。它也非常擅长为你提供某些内容的初稿，无论是文本还是代码。但你需要对结果进行改进

**答案**：3

**解析**：

大型语言模型是非确定性的，回答会有所变化，但你可以通过调整温度设置来控制其变化程度。温度越低，输出越稳定一致。同时，你不应期望它能完美完成任务。它的作用是为你完成繁重的工作，通常意味着你会得到一个不错的初稿，然后需要逐步改进。这正是"提示工程"的核心——学会如何更好地引导模型生成高质量的初稿。
