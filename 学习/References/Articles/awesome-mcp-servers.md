## 什么是 MCP?

Model Context Protocol (MCP) 是 Anthropic 提出的开放标准,用于连接 AI 模型与外部数据源和工具。MCP 服务器提供工具和资源,MCP 客户端(如 Claude Desktop、Cursor)可以调用这些服务。
