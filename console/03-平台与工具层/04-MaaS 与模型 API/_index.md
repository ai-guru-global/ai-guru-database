# MaaS 与模型 API

> 把模型按调用卖的开发者入口，价格战与生态锁定的主阵地。

## 拆解卡

- **价值来源**：开发者入口与价格战主阵地：卖模型的方式正在被重写。
- **护城河**：生态锁定与企业合同。
- **瓶颈**：同质化与毛利压缩，开源权重平价冲击。
- **领先指标**：API 降价节奏；聚合/路由层份额

## 六层速览

MaaS 与模型 API 把模型能力做成按量售卖的服务：开发者不用自己部署，调用即用；它卖的是「把模型变成水电」的那层封装。

**打个比方**：像自来水厂——模型是水，API 是管道，按用量缴费；水厂负责水质、压力与稳定供应，你只负责用水，但水价和停水都由它定。

**拆开看**：五段链路：模型托管 → 推理集群（GPU 调度与批处理）→ 网关与限流 → 计费与配额 → 企业合规与审计；多模型路由、缓存与批处理是差异化来源。

**怎么运转**：按 token 计费 + 企业合同 + 预留吞吐；云厂商用 MaaS 带动算力与存储消费，模型厂靠 API 毛利反哺训练，价格战时期则用用量增长对冲单价下滑。

**格局与博弈**：OpenAI、Anthropic、Google 是第一梯队，AWS Bedrock、Azure AI、Vertex 做多模型聚合，中国阿里百炼、火山方舟、百度千帆分层竞争；开源模型托管与自建推理持续压低价格。

**边界与走向**：MaaS 会从「卖模型」转向「卖智能体运行时」：单纯转发 API 的中间层利润会被压到零，价值向分发、治理、评测与垂直场景迁移；能提供稳定 SLA 与合规审计的平台才能留住企业客户。

## 关键判断

云 MaaS 是稳定的分销层，但本质是转售，加价空间被模型厂与价格战双向压缩；真正有溢价的是企业网关与 agent 运行时（置信度 中高，展望 12–24 个月）——核心变量是模型厂直销比例与云厂能否把 MaaS 升级为治理平台；评估时应区分「托管转售收入」与「平台增值收入」。

规模口径：全球云 MaaS 约 $250–400 亿（2025e）

## 二级细分

- **公云 API** — 模型厂商直营的开发者入口，价格战的第一现场。
- **聚合与路由（OpenRouter 类）** — 多模型代理与按效果路由，比价层捕获弃留决策。
- **私有化部署** — 数据主权与合规驱动的自持路线，vLLM 栈的主场。
