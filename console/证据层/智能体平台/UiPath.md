# UiPath

> RPA 龙头的「自我革命」样本：2021-04 以 $56.00/股完成 NYSE IPO（公司净募资 $687.9M ✅）后增速逐年失速（FY2022 营收 +47% → FY2025 +9%），靠两轮裁员重组 + agentic 平台（Maestro / Agent Builder）换出 FY2026 营收 16.11 亿美元（+13%）、GAAP 营业利润与净利双双转正（+5,676 万 / +2.82 亿 ✅）——但市值 68.5 亿美元、股价 $13.14（2026-11-11 收盘 ✅）仍远低于发行价，市场尚未为「盈利的失速者」付溢价。

## 概述

**UiPath, Inc.**（纽交所 PATH，官网 [uipath.com](https://www.uipath.com/) ✅）2005 年起家于罗马尼亚布加勒斯特、2015 年在特拉华注册为公司，从计算机视觉驱动的 RPA 起步（FY2026 10-K 口径 ✅）。FY2026（财年 1 月底截止）营收 16.106 亿美元，其中 license 6.06 亿（+3%）、订阅服务 9.54 亿（+19%）、专业服务 0.50 亿 ✅ [10-K](https://www.sec.gov/Archives/edgar/data/1734722/000173472226000012/path-20260131.htm)。公司自称已从「agentic automation」改口径为「business orchestration and automation」（2026-05 财报起 ✅），定位「AI agents 推理、robots 执行、人决策」的企业执行层。

**增长失速史是这条线索的主线**：营收 FY2021 6.08 亿 → FY2022 8.92 亿（+47%，上市峰值）→ FY2023 10.59 亿（+19%）→ FY2024 13.08 亿（+24%）→ FY2025 14.30 亿（**+9%**）→ FY2026 16.11 亿（+13%）✅ 各年 10-K。FY2025 减速一半是模式切换——license 收入减少 3,420 万、公司归因于「转向 Flex Offerings」的 license 转订阅阵痛 ✅ [FY2025 10-K](https://www.sec.gov/Archives/edgar/data/1734722/000173472225000007/path-20250131.htm)；单季谷底在 Q1 FY2026（+6%，2025-05-29 财报 ✅），此后回升至 Q1 FY2027 +17%、Q2 FY2027 4.10 亿（+13%）✅。市场重估更残酷：发行价 $56.00 对应今天 $13.14（2026-11-11 ✅ [stockanalysis](https://stockanalysis.com/stocks/PATH/)），52 周区间 $9.20–19.84——盈利改善没有兑换成估值修复。

**Agentic 转型按「重组 → 产品 → 品牌」三步走**。重组：2022-06-24 裁约 5%、2022-11-10 追加 6%（简化 GTM）；2024-07-08 再裁（FY2025 Workforce Restructuring，R&D 转向 AI，Q2 FY2026 完成，FY2025 重组费 2,470 万美元）✅ 10-K 重组节。产品：2024-11 平台 24.10 上线 Autopilot for Everyone；2024-12 Agent Builder 私有预览；2025-03 Agentic Orchestration 公开预览（均见 [FY2025 10-K](https://www.sec.gov/Archives/edgar/data/1734722/000173472225000007/path-20250131.htm) ✅）；2025-05-29「首个企业级 agentic 自动化平台」GA（Maestro、controlled agency、IXP、UI Agent computer use ✅ [Q1 FY26 财报](https://www.sec.gov/Archives/edgar/data/1734722/000173472225000026/path-20250430xex991.htm)）；2026-09 接着发 Maestro Case 与面向 coding agent 的 Maestro Flow ✅。组织同步换血：2026-03-25 CTO Raghu Malpani 升任 Chief Product and Technology Officer ✅ [8-K](https://www.sec.gov/Archives/edgar/data/1734722/000173472226000015/raghu-ctoxcpoexpansionxfin.htm)，2026-09-03 Hitesh Ramani 升任 CFO、Ashim Gupta 专任 COO ✅；创始人 Dines 自 Q2 FY2023 起与 Robert Enslin 共任 CEO、至 Q2 FY2025 收回 sole CEO（10-K 定义词口径 ⚠️）。

**盈利转变是成本纪律下的真实会计事实**：GAAP 营业利润 FY2024 -1.65 亿 → FY2025 -1.63 亿 → FY2026 **+5,676 万**，销售费用占收入 52% → 42%、员工降至 3,981 人（2026-01-31 ✅）[10-K](https://www.sec.gov/Archives/edgar/data/1734722/000173472226000012/path-20260131.htm)；FY2026 净利 +2.82 亿但税前利润仅 1.01 亿，差额是 1.82 亿所得税收益（递延所得税资产估值备抵释放类一次性因素，持续性存疑 ⚠️）。2026-03-11 完成累计 10 亿美元回购后再授权 5 亿 ✅ [Q4 FY26 财报](https://www.sec.gov/Archives/edgar/data/1734722/000173472226000007/path-2026131xex991.htm)。FY2027 全年指引：营收 17.89–17.94 亿、ARR 20.65–20.70 亿、非 GAAP 营业利润约 4.45 亿 ✅ [Q2 FY27 财报](https://www.sec.gov/Archives/edgar/data/1734722/000173472226000047/path-2026731xex991.htm)。

**客户结构（installed base）既是护城河也是试验场**：≥10 万美元 ARR 客户 2,565 家（贡献收入 89%）、≥100 万美元 357 家（52%）（2026-01-31 ✅）——决定它卖的不是 agent 单价而是存量流程的编排权。ARR 18.53 亿（2026-01-31，+11%）→ 19.38 亿（2026-07-31，+12%），NRR 从 123%（2023-01）滑到 107%（2026-01）后回升至 109%（2026-07）✅ 各季 10-K/8-K。垂直补强走收购：2026-02-05 以 1.895 亿收购 WorkFusion（金融犯罪合规 AML/KYC agents ✅ [10-Q](https://www.sec.gov/Archives/edgar/data/1734722/000173472226000050/path-20260731.htm)）、2025-03-07 以 4,010 万收购英国 Peak AI（零售/制造定价库存智能 ✅）、FY2025 以 3,580 万可转债投资法国 agentic 创业 H Company ✅ 10-K。注意：线索输入中的「Buyst」在任何 SEC 文件中不存在，证伪；正确标的是 Peak 与 WorkFusion。

**竞争位是「编排层入口论」与「品类替代论」的正面对撞**。10-K 把竞争对手分成七类，首次单列「AI 模型研究机构」与「专有/开源模型提供商及 coding agents」✅——即在编 LLM-native 框架（[[智能体平台/Agent框架]] 的 CrewAI/LangGraph 一类）和模型方都是对手；趋势章节更自认风险：agents 让企业「能内建过去需要采购的软件」✅。反方叙事（品类替代：通用 agent + browser/computer-use 吞掉 RPA）与正方叙事（deterministic automation + 治理 + 存量集成的编排层不可替代，Gartner 把 RPA MQ 重命名为 BOAT MQ、UiPath 称 Leader ⚠️ 公司口径，报告 2026-09-14）各有数据支撑：NRR 企稳回升 vs 股价腰斩后的 19 倍 TTM 市盈率（2026-11-11 ✅）。生态集成（Microsoft Copilot Studio 双向、经 [[智能体平台/MCP协议]] 的 Talkdesk 集成、Databricks、Google Cloud/Gemini）是它对开放性质疑的回答 ✅ 各季财报亮点。

## 分析

1. **增长失速是「模式切换 × 宏观 × agent 叙事」三因素叠加，不是单纯需求崩塌。** FY2025 +9% 中 license 减少 $34.2M 归因 Flex 切换（10-K 原文 ✅），NRR 123%→107% 的下滑与续约节奏、宏观预算收紧同步；但 FY2026 重新加速至 +13%、Q1 FY2027 +17% 说明需求没有消失，而是被重新定义——这直接证伪「RPA 已被 agent 判死刑」的简单叙事，品类替代论要靠 NRR 再次趋势性下滑来确认，目前证据不支持。
2. **盈利转变是真的，但要拆开看质量。** GAAP 营业利润 -$162.6M → +$56.8M 靠 S&M 砍 7.5%（52%→42%）与两轮裁员（员工 3,981）；净利 +$282.3M 中 $181.7M 是所得税收益，税前利润仅 $100.6M——利润表弹性主要来自费用端与税基修复，收入端的经营杠杆还没接棒。FY2027 指引非 GAAP 营业利润约 $445M（约 24.8% 利润率）是下一个验证点。
3. **installed base 是护城河与替代风险的同一个载体。** 89% 收入来自 ≥$100k ARR 客户：切换成本来自存量流程、凭证管理、文档理解与治理（10-K 自述的差异化 ✅），但同一批企业正是 agent 时代「内建替代采购」的第一现场（10-K 趋势语言自认）。NRR 是观察品类替代的单一最好指标——107%→109% 的回升是目前对护城河论最有利的信号。
4. **它的竞争位是「编排层入口」，但边界在松动。** 对 LLM-native 框架（[[智能体平台/Agent框架]] 里的 CrewAI/LangGraph 类），UiPath 卖 deterministic automation + 治理 + 存量系统连接；对 [[智能体平台/Manus]] 一类无存量的通用 agent，它是企业侧的对照组。10-K 把「模型提供商与 coding agents」列入竞争分类、又自己推出 UI Agent 和 Maestro Flow 拥抱 coding agent——说明威胁已被内化成产品策略，「框架层不会上探」的假设它自己都不信。
5. **收购是小额补强而非转型豪赌。** Re:infer（2022-07，未披露额）→ Peak $40.1M → WorkFusion $189.5M，全部用利润表买得起的对价补垂直场景（金融犯罪合规、零售定价），另以 $35.8M 可转债持有 H Company 期权。对照 [[商业与投融资/AI人才与并购潮]] 的天价人才收购，这是现金牛化的旧龙头买场景的标准姿势，买不来第二增长曲线，但也没透支资产负债表（现金 $1.405B ✅）。
6. **台内观察价值：它是「旧品类龙头向 agent 平台转型」的唯一上市全样本。** 与 [[开发者工具/ServiceNow]]（BOAT 同位竞品）、[[交付与组织/神州数码]]（渠道交付侧载体）互为印证。跟踪四个硬指标：NRR 能否回 110%+；FY2027 ARR 指引 $2.065–2.070B 兑现度；BOAT MQ 地位是否守住（2026-09-14 报告）；公司是否开始披露 agentic 收入专项口径（迄今未披露 🔍）。
