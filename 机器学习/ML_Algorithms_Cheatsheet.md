# 经典机器学习算法速查表: 10 分钟建立算法直觉

> **一句话理解**: 选对算法就像选对工具——用锤子钉钉子，用螺丝刀拧螺丝。本文帮你建立"看到问题就知道该用什么算法"的直觉。

---

## 1. 算法选择决策树

```
你要解决什么问题?
│
├─→ 有标签? (知道正确答案)
│   │
│   ├─→ 预测连续数值? → 回归问题
│   │   ├── 特征与目标近似线性? → 线性回归
│   │   ├── 需要可解释性? → 线性回归 / 决策树回归
│   │   └── 特征关系复杂? → 随机森林 / XGBoost
│   │
│   └─→ 预测离散类别? → 分类问题
│       ├── 只有2个类别? → 逻辑回归 / SVM
│       ├── 需要知道概率? → 逻辑回归 / 朴素贝叶斯
│       ├── 需要可解释规则? → 决策树
│       └── 追求最高准确率? → 随机森林 / XGBoost / 神经网络
│
└─→ 没标签? (自己找规律)
    │
    ├─→ 想分组? → 聚类
    │   ├── 知道要分几组? → K-Means
    │   └── 不知道分几组? → DBSCAN / 层次聚类
    │
    └─→ 想降维/压缩? → PCA / t-SNE
```

## 2. 监督学习算法

### 2.1 线性回归 (Linear Regression)

```
核心思想: 画一条直线，让直线尽量靠近所有数据点

生活类比: 根据房屋面积预测房价
├── 面积越大 → 房价越高 (线性关系)
└── 找到最佳拟合线: 让所有点到线的距离之和最小

公式: ŷ = w₁x₁ + w₂x₂ + ... + b
      └── 预测值 = 特征加权求和 + 偏置

适用场景:
├── 房价预测、销量预测、温度预测
└── 特征与目标有明显线性趋势

优点: 简单、可解释、计算快
缺点: 只能拟合线性关系，对异常值敏感
```

### 2.2 逻辑回归 (Logistic Regression)

```
核心思想: 用 S 形曲线把线性输出压缩成概率

生活类比: 判断邮件是不是垃圾邮件
├── 计算"是垃圾邮件的概率"
├── 概率 > 0.5 → 判定为垃圾邮件
└── 概率 < 0.5 → 判定为正常邮件

公式: P(是垃圾邮件) = 1 / (1 + e^-(wx+b))
      └── Sigmoid 函数把任意数值映射到 0-1

适用场景:
├── 二分类问题 (是/否)
├── 医学诊断 (患病/健康)
└── 广告点击预测 (点/不点)

优点: 输出概率、可解释、训练快
缺点: 只能处理线性可分问题
```

### 2.3 决策树 (Decision Tree)

```
核心思想: 像玩"20个问题"一样，通过一系列判断缩小范围

生活类比: 判断今天要不要带伞
├── 下雨概率 > 80%? → 是 → 带伞
├── 否 → 有云吗? → 是 → 带伞 (以防万一)
└── 否 → 不带伞

树结构:
          [湿度 > 70%?]
            /        \
         是          否
        /             \
   [下雨?]        [温度 > 30?]
   /    \           /       \
 是      否       是         否
 带伞   不带伞   不带伞      带伞(防晒)

适用场景:
├── 需要可解释决策规则 (风控审批、医疗辅助诊断)
└── 特征混合类型 (数值 + 类别)

优点: 极其直观、无需特征缩放、能捕捉非线性关系
缺点: 容易过拟合 (对训练数据死记硬背)
```

### 2.4 随机森林 (Random Forest)

```
核心思想: 三个臭皮匠顶个诸葛亮——多棵决策树投票

生活类比: 专家会诊
├── 找 100 个医生 (决策树)
├── 每个医生看一部分检查结果 (随机选特征)
├── 每个医生独立诊断
└── 最终结果 = 多数医生的意见

为什么比单棵树好?
├── 单棵树: 容易对训练数据"死记硬背"
└── 森林: 100 棵树的错误互相抵消，更稳健

适用场景:
├── 表格数据的通用首选算法
├── 作为基准模型 (baseline)
└── 需要特征重要性排序

优点: 准确率高、不易过拟合、能处理高维数据、自带特征重要性
缺点: 训练慢 (要训练100棵树)、黑盒 (比单棵树难解释)
```

### 2.5 支持向量机 (SVM)

```
核心思想: 找到最佳"分割线"，让两类数据离得越远越好

生活类比: 在混乱的停车场画停车线
├── 不是随便画一条线
└── 而是让两车之间的通道最宽的那条线

核心概念:
├── 支持向量: 离分界线最近的数据点
├──  margin (间隔): 分界线到最近点的距离
└── 核技巧 (Kernel): 把数据映射到高维空间，让它变得线性可分

适用场景:
├── 高维数据 (特征数 > 样本数)
├── 图像分类 (人脸识别)
├── 文本分类

优点: 高维表现好、泛化能力强、数学基础优美
缺点: 大数据集训练慢、对参数敏感、黑盒
```

### 2.6 朴素贝叶斯 (Naive Bayes)

```
核心思想: 用贝叶斯定理 + "特征互相独立"的假设快速分类

生活类比: 医生根据症状判断疾病
├── P(感冒|发烧+咳嗽) = P(发烧+咳嗽|感冒) × P(感冒) / P(症状)
├── "朴素"假设: 发烧和咳嗽互相独立 (实际不一定，但效果好)

为什么叫"朴素"?
└── 假设所有特征互相独立——现实中很少成立，但 miraculously 效果好

适用场景:
├── 文本分类 (垃圾邮件、情感分析)
├── 实时分类 (计算极快)
└── 特征独立性大致成立时

优点: 训练极快、对小数据集友好、天然支持多分类
缺点: "独立性"假设太强、对特征相关性强的数据效果差
```

### 2.7 K 近邻 (K-Nearest Neighbors, KNN)

```
核心思想: 物以类聚——你看你邻居是谁，你就是谁

生活类比: 判断一个新学生的成绩水平
├── 找和他最像的 5 个学生 (成绩、出勤、作业相似)
├── 看这 5 个学生的平均水平
└── 他的水平 ≈ 这 5 个人的平均

K 的选择:
├── K=1: 只看最近的一个 (容易受噪声影响)
├── K=5: 看最近的 5 个 (更稳健)
└── K=全部: 变成简单投票 (太粗糙)

适用场景:
├── 推荐系统 (找相似用户)
├── 异常检测 (远离群体的就是异常)
└── 小数据集、低维数据

优点: 直观、无训练过程、能捕捉复杂边界
缺点: 预测慢 (要算和所有样本的距离)、对高维数据失效
```

### 2.8 XGBoost / LightGBM / CatBoost

```
核心思想:  Gradient Boosting —— 用多棵弱树组成强模型，每棵新树专门修正前一棵树的错误

生活类比: 学生错题本
├── 第1次考试: 错了 30 题
├── 第2次: 专门练这 30 题 → 错 10 题
├── 第3次: 专门练这 10 题 → 错 3 题
└── 最终成绩 = 三次考试的综合

三大工具对比:
┌───────────┬────────────┬────────────┬────────────┐
│           │  XGBoost   │  LightGBM  │  CatBoost  │
├───────────┼────────────┼────────────┼────────────┤
│ 速度      │  快        │  极快      │  快        │
│ 内存      │  中        │  低        │  中        │
│ 类别特征  │  需预处理  │  需预处理  │  原生支持  │
│ 默认参数  │  一般      │  好        │  极好      │
│ 竞赛表现  │  强        │  极强      │  强        │
└───────────┴────────────┴────────────┴────────────┘

适用场景:
├── 表格数据竞赛的首选 (Kaggle 神器)
├── 结构化数据的预测任务
└── 需要最高准确率、可牺牲可解释性

优点: 准确率通常最高、自动处理缺失值、支持并行
缺点: 容易过拟合 (需仔细调参)、黑盒
```

## 3. 无监督学习算法

### 3.1 K-Means 聚类

```
核心思想: 把数据分成 K 组，每组内的点尽量靠近，组间尽量远离

生活类比: 整理衣柜
├── 先把衣服随机分 3 堆
├── 每堆计算"中心风格" (均值)
├── 每件衣服归到最近的风格堆
├── 重新计算中心 → 重新分配
└── 重复直到稳定

K 怎么选?
├──  elbow 法: 找拐点
└──  业务知识: 客户分群通常 3-5 个

适用场景:
├── 客户分群 (RFM 模型)
├── 图像压缩 (颜色聚类)
└── 文档主题发现

优点: 简单快速、易于实现
缺点: 需要预设 K、对初始点敏感、假设簇是圆形
```

### 3.2 DBSCAN

```
核心思想: 密度达峰——把紧密挨在一起的点归为一类，稀疏的点标记为噪声

生活类比: 城市聚落识别
├── 高楼密集区 → 城市中心
├── 稀疏郊区 → 边界
├── 荒野中的孤房 → 噪声 (异常点)

两个参数:
├── eps (半径): 多近算"邻居"
└── min_samples: 多少邻居算"密集"

适用场景:
├── 异常检测 (噪声点 = 异常)
├── 不规则形状的簇
└── 不知道要分几类时

优点: 自动发现簇数量、能识别异常点、任意形状簇
缺点: 对参数敏感、高维数据效果差
```

### 3.3 PCA (主成分分析)

```
核心思想: 降维——在保留最多信息的前提下，减少特征数量

生活类比: 压缩照片
├── 原图: 4000×3000 像素 (1200万维)
├── 压缩后: 1920×1080 (200万维)
└── 肉眼几乎看不出区别——保留了 95% 的信息

PCA 做什么?
├── 找到数据中方差最大的方向 (主成分)
├── 第1主成分: 包含最多信息
├── 第2主成分: 与第1垂直，包含次多信息
└── 只保留前 K 个主成分 → 降维

适用场景:
├── 特征太多 (维度灾难)
├── 可视化高维数据 (降到 2D/3D)
└── 去噪 (丢弃噪声方向)

优点: 去相关、降维、降噪
缺点: 主成分可能难以解释
```

| **线性回归** | 回归 | 拟合直线 | 连续值预测、趋势分析 | ⚡极快 | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| **逻辑回归** | 分类 | Sigmoid 概率 | 二分类、需要概率 | ⚡极快 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| **决策树** | 分类/回归 | if-else 规则 | 需要可解释规则 | ⚡快 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| **随机森林** | 分类/回归 | 多树投票 | 通用表格数据首选 | ⭐⭐快 | ⭐⭐⭐ | ⭐⭐⭐⭐ |
| **SVM** | 分类 | 最大间隔分割 | 高维数据、图像文本 | ⭐⭐慢 | ⭐⭐ | ⭐⭐⭐⭐ |

## 5. 初学者建议

```
第一步: 从简单开始
├── 分类问题 → 先试试逻辑回归 / 决策树
├── 回归问题 → 先试试线性回归
└── 聚类问题 → 先试试 K-Means

第二步: 建立基准
├── 用随机森林作为 strong baseline
└── 如果数据量大 → 换 XGBoost/LightGBM

第三步: 迭代优化
├── 调参 (Grid Search / Random Search)
├── 特征工程
└── 集成多个模型

避坑指南:
├── ❌ 一上来就用神经网络 (小数据反而更差)
├── ❌ 忽视数据预处理 (Garbage In, Garbage Out)
├── ❌ 在测试集上调参 (数据泄露)
└── ✅ 先可视化数据，理解问题再选算法
```
