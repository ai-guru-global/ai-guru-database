# Trae 使用指南

> **一句话**: Trae 是字节跳动推出的 AI IDE，支持 Pro+ 订阅，适合全栈项目开发。

---

## 1. 概述

### 定位

| 维度 | 说明 |
|------|------|
| **类型** | AI IDE (集成开发环境) |
| **开发商** | 字节跳动 (ByteDance) |
| **订阅等级** | Pro+ |
| **适用** | 全栈项目开发、前后端一体化 |
| **官网** | https://www.trae.ai |

### 核心能力

```
Trae IDE:
├── AI 代码生成与补全
├── 多模型支持（内置 + 外接）
├── 项目级上下文理解
├── 内置终端与调试
└── 插件生态
```

---

## 2. 账户与额度

| 项目 | 详情 |
|------|------|
| **管理页面** | https://www.trae.ai/account-setting#usage |
| **月度额度** | $30/月（约 180 元） |
| **订阅等级** | Pro+ |
| **刷新日期** | 每月 10 号 |
| **状态** | 活跃 |

---

## 3. 快速开始

### 3.1 安装

1. 访问 https://www.trae.ai 下载客户端
2. 支持 macOS / Windows / Linux
3. 登录账户并激活 Pro+ 订阅

### 3.2 创建项目

1. 打开 Trae → **New Project**
2. 选择框架模板（[[_concepts/ai-agents|React]] / Vue / Node 等）
3. 使用 AI Chat 或 Inline Edit 进行开发

### 3.3 AI 辅助开发流程

1. 在 Chat 面板描述需求
2. AI 生成代码片段或整个模块
3. 使用 Inline Edit 微调
4. 终端运行测试

---

## 4. 使用场景与输出

| 输出项目 | 说明 |
|----------|------|
| **sb-okr** | OKR 管理系统 |
| **klaw** | 法律/合规相关项目 |

---

## 5. 最佳实践

- Pro+ 额度 $30/月，中大型项目建议优先使用高性价比工具
- 利用 Trae 的项目级上下文理解能力处理全栈项目
- 每月 10 号刷新后优先安排高优先级开发任务
- 结合内置终端进行快速验证

---

## 6. 注意事项

- 额度刷新周期为每月 10 号，注意跨月项目的额度规划
- Pro+ 等级享有更快的模型响应和更长的上下文窗口
