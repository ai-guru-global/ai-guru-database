# 信息论基础: 从香农熵到 LLM 的交叉熵损失

> **一句话理解**: 信息论是 AI 的数学灵魂——交叉熵是几乎所有分类模型的损失函数，KL 散度衡量两个分布的距离，互信息发现特征与标签的关联，没有信息论就没有现代机器学习。

---

## 1. 概述 (Overview)

### 1.1 信息论与 AI 的关系

```
信息论 (Shannon, 1948) 的核心问题:
├── 信息如何量化？ → 熵 (Entropy)
├── 信息如何压缩？ → 无损/有损压缩
├── 信息如何可靠传输？ → 信道编码
└── 信息如何度量差异？ → KL散度 / 交叉熵

与 AI 的深度关联:
┌─────────────────────────────────────────────────────────────────┐
│  信息论概念              AI 中的应用                             │
├────────────────────────┬────────────────────────────────────────┤
│  熵 (Entropy)          │  决策树分裂标准、不确定性度量           │
│  交叉熵 (Cross-Entropy)│  分类损失函数 (几乎所有模型)            │
│  KL 散度               │  VAE 正则化、知识蒸馏、PPO              │
│  互信息 (MI)           │  特征选择、对比学习 (InfoNCE)           │
│  信息瓶颈              │  表示学习理论、模型压缩                  │
│  编码定理              │  模型压缩、量化、Tokenization            │
│  率失真理论            │  VAE、扩散模型的损失函数设计             │
└────────────────────────┴────────────────────────────────────────┘
```

## 2. 熵 (Entropy)

### 2.1 香农熵

```
香农熵 (Shannon Entropy):

    H(X) = -Σᵢ p(xᵢ) · log₂ p(xᵢ)

物理意义: 随机变量 X 的「不确定性」或「平均信息量」

┌─────────────────────────────────────────────────────────────────┐
│  直觉理解:                                                       │
│                                                                 │
│  例1: 均匀硬币 (p=0.5)                                          │
│  H = -(0.5·log₂0.5 + 0.5·log₂0.5) = 1 bit                    │
│  → 每次抛掷带来 1 bit 信息                                      │
│                                                                 │
│  例2: 有偏硬币 (p=0.99)                                         │
│  H = -(0.99·log₂0.99 + 0.01·log₂0.01) ≈ 0.08 bit            │
│  → 几乎确定是正面，信息量很少                                    │
│                                                                 │
│  例3: 均匀骰子 (6面)                                             │
│  H = -6 · (1/6 · log₂(1/6)) = log₂6 ≈ 2.58 bits              │
│  → 比硬币更不确定                                               │
│                                                                 │
│  性质:                                                           │
│  ├── H(X) ≥ 0 (非负性)                                         │
│  ├── H(X) = 0 当且仅当 X 是确定的                                │
│  ├── H(X) 在均匀分布时最大: H_max = log₂(|X|)                  │
│  └── 连续版本: 微分熵 h(X) = -∫ p(x) log p(x) dx              │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 联合熵与条件熵

```
联合熵 (Joint Entropy):
    H(X,Y) = -Σₓ Σᵧ p(x,y) · log₂ p(x,y)
    
    度量: (X,Y) 组合的总不确定性

条件熵 (Conditional Entropy):
    H(Y|X) = -Σₓ Σᵧ p(x,y) · log₂ p(y|x)
    H(Y|X) = H(X,Y) - H(X)
    
    度量: 已知 X 后，Y 还剩多少不确定性

链式法则:
    H(X₁, X₂, ..., Xₙ) = H(X₁) + H(X₂|X₁) + H(X₃|X₁,X₂) + ...
    
    AI 应用: 自回归语言模型的分解
    ┌──────────────────────────────────────────────────────┐
    │  LLM 的目标:                                         │
    │  最小化 H(X₁,X₂,...,Xₙ)                             │
    │  = H(X₁) + H(X₂|X₁) + ... + H(Xₙ|X₁,...,Xₙ₋₁)   │
    │                                                      │
    │  每一步都在最小化下一个 token 的条件熵                 │
    │  = 让模型对下一个 token 的预测尽可能确定               │
    │  = 交叉熵损失函数                                    │
    └──────────────────────────────────────────────────────┘
```

## 3. 相对熵与交叉熵

### 3.1 KL 散度 (Kullback-Leibler Divergence)

```
KL 散度: 度量两个概率分布的「距离」

    D_KL(P || Q) = Σᵢ p(xᵢ) · log(p(xᵢ) / q(xᵢ))
                 = E_P[log P - log Q]

┌─────────────────────────────────────────────────────────────────┐
│  性质:                                                           │
│  ├── D_KL ≥ 0 (Gibbs 不等式)                                   │
│  ├── D_KL = 0 当且仅当 P = Q                                   │
│  ├── D_KL(P||Q) ≠ D_KL(Q||P) (非对称！)                       │
│  └── 不是真正的「距离」(不满足三角不等式)                        │
│                                                                 │
│  两种 KL 的方向:                                                 │
│                                                                 │
│  前向 KL: D_KL(P||Q) → Q 要覆盖 P 的所有模式                   │
│  ├── "Q 宁可多估，不可漏估"                                     │
│  ├── 应用: 变分推断 (VI) 的 ELBO                                │
│  └── 结果: 均值寻求 (mean-seeking)                              │
│                                                                 │
│  反向 KL: D_KL(Q||P) → Q 集中在 P 的某个模式                   │
│  ├── "Q 宁可漏估，不可多估"                                     │
│  ├── 应用: VAE 的正则化项                                       │
│  └── 结果: 模式寻求 (mode-seeking)                              │
│                                                                 │
│  AI 中的 KL 散度应用:                                            │
│  ├── VAE: D_KL(q(z|x) || p(z)) → 正则化后验接近先验             │
│  ├── 知识蒸馏: D_KL(教师分布 || 学生分布)                        │
│  ├── PPO (RL): D_KL(新策略 || 旧策略) → 限制策略更新幅度        │
│  └── 信息瓶颈: 最小化 D_KL → 压缩表示                          │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 交叉熵 (Cross-Entropy)

```
交叉熵: 用分布 Q 编码分布 P 的平均码长

    H(P, Q) = -Σᵢ p(xᵢ) · log q(xᵢ)
    
    关系: H(P, Q) = H(P) + D_KL(P || Q)
    
    ┌──────────────────────────────────────────────────────┐
    │  H(P)   = 真实分布的熵 (不可压缩的最低码长)          │
    │  D_KL   = 用 Q 近似 P 的额外代价                    │
    │  H(P,Q) = 总码长 = 理论最优 + 浪费                  │
    └──────────────────────────────────────────────────────┘

交叉熵损失 (ML 中最重要的损失函数):

    L_CE = -Σᵢ yᵢ · log(ŷᵢ)
    
    其中: y = 真实标签 (one-hot), ŷ = 模型预测概率

┌─────────────────────────────────────────────────────────────────┐
│  为什么交叉熵是分类的标准损失:                                    │
│                                                                 │
│  1. 信息论解释:                                                  │
│     最小化交叉熵 = 让模型分布 Q 尽可能接近真实分布 P             │
│     因为 H(P) 是常数，最小化 H(P,Q) 等价于最小化 D_KL(P||Q)   │
│                                                                 │
│  2. 极大似然解释:                                                │
│     交叉熵 = 负对数似然 (NLL)                                   │
│     最小化交叉熵 = 最大化数据在模型下的似然                      │
│                                                                 │
│  3. 梯度特性:                                                    │
│     ∂L/∂ŷ 在预测错误时梯度大，预测正确时梯度小                  │
│     (对比 MSE: sigmoid 饱和区梯度消失)                          │
│                                                                 │
│  变体:                                                           │
│  ├── 二元交叉熵 (BCE): L = -[y·log(ŷ) + (1-y)·log(1-ŷ)]      │
│  ├── Focal Loss: L = -(1-ŷ)^γ · y·log(ŷ) (困难样本加权)      │
│  ├── Label Smoothing: y_smooth = (1-ε)·y + ε/K                │
│  └── 加权交叉熵: 类别不平衡时给少数类更高权重                    │
└─────────────────────────────────────────────────────────────────┘
```

### 3.3 LLM 中的交叉熵

```python
import torch
import torch.nn.functional as F

# LLM 的交叉熵损失计算
def llm_cross_entropy_loss(logits, targets):
    """
    logits: 模型输出 [batch, seq_len, vocab_size]
    targets: 目标 token ID [batch, seq_len]
    """
    # 展平
    logits = logits.view(-1, logits.size(-1))  # [B*T, V]
    targets = targets.view(-1)                  # [B*T]
    
    # 标准交叉熵
    loss = F.cross_entropy(logits, targets,
                           ignore_index=-100,   # 忽略 padding
                           label_smoothing=0.1) # 标签平滑
    return loss


# 困惑度 (Perplexity): LLM 的核心评估指标
# PPL = exp(交叉熵) = 2^(H(P,Q))
# 物理意义: 模型在每个位置平均「犹豫」多少个 token
def compute_perplexity(cross_entropy_loss):
    """交叉熵 → 困惑度"""
    return torch.exp(cross_entropy_loss).item()

# 例: CE loss = 3.2 → PPL = exp(3.2) ≈ 24.5
# 含义: 模型平均在 24.5 个 token 间犹豫
# GPT-4 级别: PPL ~ 5-10 (非常确定)
```

## 4. 互信息 (Mutual Information)

### 4.1 定义与性质

```
互信息: 度量两个变量之间的「信息共享量」

    I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)
           = Σₓ Σᵧ p(x,y) · log(p(x,y) / (p(x)·p(y)))
           = D_KL(p(x,y) || p(x)·p(y))

┌─────────────────────────────────────────────────────────────────┐
│  直觉理解:                                                       │
│                                                                 │
│  I(X;Y) = 知道 Y 后 X 减少的不确定性                            │
│         = X 和 Y 共享的信息量                                    │
│                                                                 │
│  维恩图:                                                         │
│  ┌──────────────┐                                               │
│  │  H(X)        │                                               │
│  │    ┌──────┐  │                                               │
│  │    │I(X;Y)│  │                                               │
│  │    └──────┘  │                                               │
│  │        ┌──────────────┐                                      │
│  │        │  H(Y)        │                                      │
│  │        └──────────────┘                                      │
│  └──────────────┘                                               │
│  H(X,Y) = H(X) + H(Y) - I(X;Y)                                 │
│                                                                 │
│  性质:                                                           │
│  ├── I(X;Y) ≥ 0                                                │
│  ├── I(X;Y) = 0 当且仅当 X 与 Y 独立                           │
│  ├── I(X;Y) = I(Y;X) (对称)                                    │
│  └── I(X;Y) ≤ min(H(X), H(Y))                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 互信息在 AI 中的应用

```
应用1: 特征选择
├── 选择与标签 Y 互信息最大的特征 X
├── I(X;Y) 高 → X 包含大量关于 Y 的信息
├── 优于相关系数: 互信息捕捉非线性关系
└── sklearn.feature_selection.mutual_info_classif

应用2: 对比学习 (Contrastive Learning)
┌──────────────────────────────────────────────────────┐
│  InfoNCE 损失 = 互信息的下界估计                      │
│                                                      │
│  I(X;Y) ≥ E[log p(y|x) / p(y)]                     │
│         = E[log exp(sim(x,y⁺)/τ)                    │
│              / Σ exp(sim(x,yᵢ)/τ)]                  │
│                                                      │
│  CLIP: 最大化图像与文本的互信息                       │
│  SimCLR: 最大化同一图像不同增强的互信息               │
│  MoCo: 动量对比学习                                  │
└──────────────────────────────────────────────────────┘

应用3: 信息瓶颈理论 (Information Bottleneck)
┌──────────────────────────────────────────────────────┐
│  目标: 找到压缩表示 Z，使得:                          │
│                                                      │
│  min I(X;Z) - β·I(Z;Y)                              │
│                                                      │
│  ├── 最小化 I(X;Z): 压缩 (Z 尽可能少地保留 X 的信息) │
│  └── 最大化 I(Z;Y): 保留 (Z 尽可能多地保留关于 Y 的信息) │
│                                                      │
│  解释深度学习泛化:                                    │
│  ├── 深层网络逐层压缩输入信息                        │
│  ├── 只保留与任务相关的信息                           │
│  └── 压缩越好 → 泛化越好                             │
└──────────────────────────────────────────────────────┘
```

## 5. 编码理论与模型压缩

### 5.1 无损压缩与有损压缩

```
香农信源编码定理:
    最优压缩率 = H(X) bits/symbol
    不可能压缩到低于熵

┌─────────────────────────────────────────────────────────────────┐
│  无损压缩 (可逆):                                                │
│  ├── Huffman 编码: 根据频率构建最优前缀码                       │
│  ├── Lempel-Ziv (LZ77/LZ78): 字典压缩 (ZIP/GZIP)              │
│  ├── Arithmetic Coding: 将整个序列编码为一个实数                 │
│  └── ANS (Asymmetric Numeral Systems): 现代最优编码 (Zstandard) │
│                                                                 │
│  有损压缩 (不可逆，但失真可控):                                   │
│  ├── 率失真理论: R(D) = 在失真 D 下的最低码率                   │
│  ├── JPEG: DCT + 量化 (图像)                                    │
│  ├── MP3/AAC: 心理声学模型 + 量化 (音频)                        │
│  └── 神经压缩: 用神经网络学习最优压缩 (Balle 2017)              │
│                                                                 │
│  与 AI 模型压缩的关联:                                            │
│  ├── 量化 (INT8/INT4): 有损压缩模型权重                          │
│  ├── 知识蒸馏: 用大模型信息指导小模型 (信息瓶颈)                 │
│  ├── Tokenization (BPE): 文本的最优压缩 → 语言模型的输入         │
│  └── KV Cache 压缩: 有损压缩注意力缓存                           │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 BPE Tokenization 的信息论解释

```python
# BPE (Byte Pair Encoding) 的信息论本质:
# 目标: 找到一种 tokenization，使得:
#   1. 词表大小固定 (V tokens)
#   2. 文本编码后的 token 数最少 (接近信息熵下界)

# BPE 算法 = 贪心地合并最高频的相邻 token 对
# 等价于: 逐步构建最优的编码字典

import tiktoken

# GPT-4 的 tokenizer
enc = tiktoken.get_encoding("cl100k_base")

text = "Information theory is the foundation of AI"
tokens = enc.encode(text)
print(f"文本: {text}")
print(f"Token 数: {len(tokens)}")
print(f"Token IDs: {tokens}")
print(f"解码: {enc.decode(tokens)}")

# 信息论视角:
# 英文: ~4.7 bits/character (香农实验)
# BPE: 每个 token 平均编码 ~4 个字符
# GPT-4 词表: 100,256 tokens → log₂(100256) ≈ 16.6 bits/token
# 压缩率: 16.6 bits / (4 chars × 4.7 bits/char) ≈ 0.88
# 接近最优压缩!
```

## 6. 信道容量与 LLM 的知识容量

```
信道容量 (Channel Capacity):
    C = max_{p(x)} I(X;Y)
    
    信道能可靠传输的最大信息率

┌─────────────────────────────────────────────────────────────────┐
│  LLM 的「知识容量」类比:                                         │
│                                                                 │
│  问题: 一个 N 参数的 LLM 能「记住」多少知识？                     │
│                                                                 │
│  估算:                                                           │
│  ├── 每个参数 ≈ 2 bytes (FP16)                                  │
│  ├── 7B 参数模型 ≈ 14 GB 存储空间                               │
│  ├── 但实际知识容量 << 14 GB                                    │
│  │   (大量参数用于学习语法、推理模式等「元知识」)                 │
│  └── 经验估计: 7B 模型 ≈ 几 MB 有效事实知识                     │
│                                                                 │
│  Scaling Laws (Kaplan et al., 2020):                            │
│  ├── 损失 L ∝ N^(-0.076) (模型参数)                             │
│  ├── 损失 L ∝ D^(-0.095) (训练数据)                             │
│  ├── 损失 L ∝ C^(-0.050) (计算量)                               │
│  └── 最优: 参数量 ≈ 20 × 训练 token 数                          │
│                                                                 │
│  Chinchilla 定律 (Hoffmann et al., 2022):                       │
│  └── 最优训练: 每个参数对应 ~20 个训练 token                     │
│      7B 模型需要 ~140B tokens                                    │
│      70B 模型需要 ~1.4T tokens                                   │
└─────────────────────────────────────────────────────────────────┘
```

## 7. 关键公式速查表

| 概念 | 公式 | AI 应用 |
|------|------|---------|
| 熵 | H(X) = -Σ p(x) log p(x) | 不确定性度量、决策树 |
| 联合熵 | H(X,Y) = H(X) + H(Y\|X) | 自回归分解 |
| 条件熵 | H(Y\|X) = H(X,Y) - H(X) | LLM 下一个token预测 |
| KL散度 | D_KL(P\|\|Q) = Σ p·log(p/q) | VAE正则化、知识蒸馏 |
| 交叉熵 | H(P,Q) = -Σ p·log q | **分类损失函数** |
| 互信息 | I(X;Y) = H(X) - H(X\|Y) | 特征选择、对比学习 |
| 困惑度 | PPL = exp(H(P,Q)) | LLM 评估指标 |
| 信道容量 | C = max I(X;Y) | 模型知识容量 |
