# 3D 视觉 - 小白版 🏗️

> **一句话秒懂**: 3D 视觉就是让 AI "看懂"立体世界——不仅识别这是什么物体，还能知道它在 3D 空间里的位置、形状、朝向，就像人类用两只眼睛看世界一样！

## 为什么要学 3D 视觉？

想象一下：
- 🚗 自动驾驶汽车需要知道行人离它多远、多高
- 🤖 机器人抓取物品要知道从哪个角度伸手
- 🎮 游戏里需要重建真实世界的 3D 模型
- 🏥 医生看 CT 片需要"立体"理解器官位置

这些都是 3D 视觉的应用！

## 2D vs 3D：多一个维度的挑战

```
【2D 图像】
- 宽 × 高 = 像素阵列
- 回答: "这是什么？"
- 任务: 分类、检测、分割

【3D 场景】
- 宽 × 高 × 深度
- 回答: "这是什么？在哪？多远？朝向如何？"
- 任务: 深度估计、3D 检测、点云分割、NeRF
```

## 核心任务

### 1. 深度估计 (Depth Estimation)

**任务**: 从 2D 图像推断每个像素的距离

```
生活例子:
就像你学开车时，教练说"前面的车离你大约10米"
——你从视觉经验中估计出了距离

AI 学习:
输入: 2D 街道照片
输出: 深度图（近处亮，远处暗）
```

### 2. 3D 目标检测 (3D Object Detection)

**任务**: 不仅检测物体，还要知道它在 3D 空间中的位置和尺寸

```
2D 检测: [x1, y1, x2, y2, 类别, 置信度]
3D 检测: [x, y, z, 长, 宽, 高, 朝向角, 类别, 置信度]

多了:
- z: 高度位置
- 长/宽/高: 真实尺寸
- 朝向角: 物体面向哪个方向
```

### 3. 点云分割 (Point Cloud Segmentation)

**任务**: 将 3D 点云中的每个点分类到不同物体

```
点云 = 无数个 3D 点组成的"云"
(来自激光雷达 LiDAR 或深度相机)

分割 = 给每个点打标签
"这个点是人，那个点是车，那片是建筑"
```

### 4. NeRF (Neural Radiance Fields)

**任务**: 从多角度 2D 照片重建 3D 场景

```
生活例子:
就像电影特效里，演员站在绿幕前，
后期人员从多角度照片重建出他的 3D 模型

NeRF:
输入: 一个场景的多角度 2D 照片
输出: 可以从任意角度"观看"的 3D 场景

应用:
- 文化遗产数字化（敦煌莫高窟）
- 电商 3D 商品展示
- 游戏场景重建
```

## 技术方法对比

| 方法 | 输入 | 输出 | 特点 |
|------|------|------|------|
| 单目深度估计 | 单张 2D 图 | 深度图 | 简单，但深度绝对值不准 |
| 双目立体匹配 | 双目图像 | 深度图 | 精度高，需要校准 |
| LiDAR | 点云 | 3D 物体 | 精确，但稀疏 |
| NeRF | 多角度照片 | 3D 场景 | 逼真，但慢 |
| 3D 检测 | 图像+点云 | 3D 框 | 多传感器融合 |

## 生活中的 3D 视觉

### 自动驾驶

```
传感器组合:
┌─────────────────────────────────────┐
│  相机 × 8     → 2D 感知            │
│  激光雷达 × 1  → 精确深度           │
│  毫米波雷达 × 5 → 远距离检测        │
│  超声波 × 12   → 近距离停车         │
└─────────────────────────────────────┘

3D 视觉的作用:
✓ 行人和车辆检测（知道在哪、多远）
✓ 可通行区域分割（路面在哪）
✓ 车道线检测（往哪开）
✓ 建筑和障碍物（不能撞什么）
```

### 手机 AR

```
iPhone 的 LiDAR 扫描:
1. 发射激光脉冲
2. 测量反射时间计算深度
3. 重建房间的 3D 模型

应用:
- 测距仪 App（精确测量长度）
- AR 游戏（虚拟物体放置）
- 室内设计（家具摆放预览）
```

### 医疗影像

CT 和 MRI:
- 本来就是 3D 数据
- 3D 重建: 从切片重建器官 3D 模型
- 手术导航: 在 3D 模型上规划手术路径

## 常见问题

### Q: 为什么需要深度估计？

**A**: 因为单目相机没有深度信息！
```
人的眼睛:
- 两只眼睛 → 视差 → 立体视觉
- 经验 → "近处的东西大，远处的小"

单目相机:
- 只有一张图，没有视差
- 需要 AI 学习估计深度
- 但绝对深度不准确（相对深度 OK）
```

### Q: NeRF 和 3D 高斯溅射 (3DGS) 有什么区别？

| 对比 | NeRF | 3DGS |
|------|------|------|
| 渲染方式 | 神经辐射场 | 3D 高斯点云 |
| 速度 | 慢（分钟级） | 快（秒级） |
| 质量 | 细节好 | 细节略差 |
| 2024 年主流 | 研究用 | 工程落地 |
