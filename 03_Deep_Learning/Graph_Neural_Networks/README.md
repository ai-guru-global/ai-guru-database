# 图神经网络 (Graph Neural Networks)

> **核心定位**: 深度学习三大架构之一（CNN/RNN/GNN），处理图结构数据的核心方法论。

## 学习路径

```
入门 (1-2h)
├── 1. 图的基本概念 (节点、边、邻接矩阵)
├── 2. GCN: 最简图卷积
└── 3. 动手: PyG 节点分类实验

进阶 (3-4h)
├── 4. GAT: 图注意力网络
├── 5. GraphSAGE: 归纳学习
├── 6. 消息传递范式
└── 7. GIN: 表达力分析 (WL 测试)

高级 (4-6h)
├── 8. Graph Transformer
├── 9. GNN + LLM 融合
├── 10. 分子属性预测实践
└── 11. 知识图谱补全
```
