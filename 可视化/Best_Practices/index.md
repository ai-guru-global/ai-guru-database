# 可视化最佳实践（Best Practices）

> **一句话理解**: 可视化最佳实践是"图表的宪法"——选对图、配好色、标清楚、讲成故事，让数据从"看得见"升级为"看得懂、用得上"。

可视化最佳实践（Visualization Best Practices）覆盖图表选择原则（chart selection）、配色方案（color）、标注与叙事（annotation & storytelling），以及常见反模式（anti-patterns）。本子域面向全体数据可视化实践者，是所有可视化输出的质量底线。

---

## 一、为什么需要最佳实践

| 反模式 | 后果 | 最佳实践 |
|--------|------|----------|
| 截断 y 轴 | 夸大差异 | 柱状图从 0 起 |
| 3D 图表 | 误读数值 | 用 2D |
| 配色无序 | 色盲不友好 | 色盲安全调色板 |
| 信息过载 | 看不出重点 | 一图一观点 |
| 无标注 | 读不懂 | 关键点加注释 |

## 三、图表选择速查

### 按数据关系选图

| 关系 | 推荐图表 | 避免 |
|------|----------|------|
| 比较 | 柱状图/条形图 | 饼图（>5 类） |
| 趋势 | 折线图/面积图 | 柱状图（连续） |
| 占比 | 饼图/堆叠条形（≤5 类） | 3D 饼图 |
| 分布 | 直方图/箱线图/小提琴图 | 折线 |
| 相关 | 散点图/热力图 | 折线 |
| 层级 | 树图/旭日图 | 表格 |
| 地理 | 地图/ choropleth | 散点 |

### 按目的选图

| 目的 | 推荐图表 |
|------|----------|
| 对比大小 | 柱状图 |
| 看变化 | 折线图 |
| 看构成 | 饼图/堆叠图 |
| 看分布 | 直方图/箱线图 |
| 看关系 | 散点图 |
| 看多维 | 雷达图/平行坐标 |

## 四、配色原则

| 原则 | 说明 | 示例 |
|------|------|------|
| 色盲安全 | 避免红绿组合 | 用 Viridis/ColorBrewer |
| 语义一致 | 色彩有含义 | 红=降/绿=升 |
| 克制 | 限 5-7 色 | 类别多用形状区分 |
| 顺序型 | 有序数据用渐变 | 顺序色板 |
| 发散型 | 有正负用双色 | 蓝-白-红 |
| 强调 | 突出一个系列 | 其余灰化 |

## 五、标注与叙事

| 元素 | 作用 | 规范 |
|------|------|------|
| 标题 | 点明观点 | 结论式而非描述式 |
| 副标题 | 补充背景 | 数据来源/时间 |
| 轴标签 | 说明量纲 | 含单位 |
| 图例 | 区分系列 | 直接标注优于图例 |
| 注释 | 突出关键点 | 标箭头+文字 |
| 数据来源 | 可追溯 | 角注 |

## 六、数据叙事（Data Storytelling）

| 步骤 | 内容 |
|------|------|
| 1. 受众 | 明确给谁看、关心什么 |
| 2. 观点 | 一图一核心结论 |
| 3. 证据 | 用图表支撑 |
| 4. 对比 | 与基准/历史对比 |
| 5. 行动 | 引出下一步决策 |

## 八、质量检查清单

- [ ] 图表类型与数据关系匹配
- [ ] 配色色盲安全且克制
- [ ] 坐标轴含单位、未截断（柱状）
- [ ] 关键点有标注
- [ ] 标题是结论式
- [ ] 标注数据来源
- [ ] 无 3D/无信息冗余

## 十、常见反模式图鉴

| 反模式 | 问题 | 改进 |
|--------|------|------|
| 双 Y 轴误导 | 关联假象 | 拆双图或明确标注 |
| 饼图过多扇区 | 难比较 | 改条形图 |
| 无序条形 | 找不到重点 | 排序 |
| 渐变填充 | 干扰读数 | 纯色 |
| 动画过度 | 分散注意 | 克制动效 |
| 缺单位 | 读不懂 | 标全单位 |
| 默认配色 | 色盲不友好 | 色盲安全板 |

## 十三、常见问题（FAQ）

| 问题 | 解答 |
|------|------|
| 多少个系列该换图？ | 折线 > 5 条考虑分面或高亮一条。 |
| 配色怎么快速选？ | 用 Viridis（顺序）/ ColorBrewer（分类）/ 色盲安全板。 |
| 标题写什么？ | 写结论而非描述，如"收入 Q3 环比涨 20%"。 |
| 什么时候用交互图？ | 探索阶段用交互，汇报/论文用静态。 |
| 数据墨水比是什么？ | 数据信息占用的墨水比例，越高越好。 |
| 小图表怎么排？ | 同尺度、同色编码，便于横向对比。 |
