## 架构决策速查

| 场景 | 首选 | 备选 | 关键约束 |
|------|------|------|---------|
| 高并发低延迟 | 闭源 API + 缓存 | 自部署量化小模型 | P99/成本 |
| 数据敏感 | 私有化开源模型 | VPC 内闭源 | 合规/不出域 |
| 长上下文 | 长窗口模型 + RAG | 分段+MapReduce | 成本/精度 |
| 多模态 | 闭源多模态 API | 自部署 LLaVA 类 | 能力/成本 |
| 低预算 | 小模型 + LoRA | API + 语义缓存 | TCO |
