# 面试复盘模板 (Interview Notes Template)

> **使用方法**: 每次面试后复制下方模板，填写本次面试记录，保存为 `notes_YYYYMMDD_公司名.md`。

## 复盘最佳实践

### 时间原则

```
面试结束 → 5 分钟内: 趁记忆新鲜，填写问题记录和回答
当天晚上: 补充参考答案和改进点
一周内:  回顾查漏补缺表，完成复习计划
```

### 复盘的复利效应

```
第 1 次面试: 暴露 20 个知识盲区
第 3 次面试: 盲区降到 10 个 (前两次已复习)
第 5 次面试: 盲区降到 3 个 (自信从容)
第 N 次面试: 开始关注"讲得好"而非"会不会"
```

### 常见复盘误区

| 误区 | 正确做法 |
|------|---------|
| 只记问题不记答案 | 问题+答案+改进一起记 |
| 只关注技术问题 | 行为面试同样重要 |
| 不追踪模式 | 多次面试后分析"哪类题总考不好" |
| 复盘了不复习 | 每次面试前翻阅之前的复盘笔记 |
