## 3. 核心技术架构

### 3.1 Hunyuan-Large MoE 架构

```
Hunyuan-Large (389B) 架构:
════════════════════════════════════════════════════════════════════

  参数: 389B 总参数, ~52B 激活参数
  架构: Sparse MoE Transformer

  ┌──────────────────────────────────────────────────┐
  │               Transformer Layer                   │
  │  ┌──────────────────────────────────────────┐    │
  │  │  Attention (GQA)                         │    │
  │  │  • 32 Query Heads → 8 KV Heads           │    │
  │  │  • RoPE 位置编码                          │    │
  │  └──────────────────────────────────────────┘    │
  │                    ↓                              │
  │  ┌──────────────────────────────────────────┐    │
  │  │  MoE FFN                                 │    │
  │  │  • Router: Top-2 Expert Selection         │    │
  │  │  • 共享专家: 1 (始终激活)                  │    │
  │  │  • 路由专家: ~64 (稀疏激活)               │    │
  │  │  • 激活: 2 路由 + 1 共享 = 3 per token   │    │
  │  └──────────────────────────────────────────┘    │
  └──────────────────────────────────────────────────┘
```

### 3.2 关键参数

| 参数 | Hunyuan-Large | DeepSeek-V3 | Mixtral 8x22B |
|------|--------------|-------------|---------------|
| 总参数 | 389B | 671B | 141B |
| 激活参数 | 52B | 37B | 39B |
| 专家数 | ~64+ | 256 | 8 |
| 共享专家 | 1 | 1 | 0 |
| 激活专家 | Top-2+1 | Top-8+1 | Top-2 |
| 层数 | 64 | 61 | 32 |
| 隐藏维度 | 6400 | 7168 | 6656 |
| 上下文 | 32K | 128K | 64K |

### 3.3 共享专家机制

```
Hunyuan 共享专家设计:
════════════════════════════════════════════════════════════════════

  传统 MoE:
  ┌───┐ ┌───┐ ┌───┐ ┌───┐
  │ E1│ │ E2│ │ E3│ │ E4│  ← 全部路由选择
  └─┬─┘ └─┬─┘ └─┬─┘ └─┬─┘
    └──────┴──────┘      ← 仅激活 Top-K

  Hunyuan MoE (共享专家):
  ┌───┐ ┌───┐ ┌───┐ ┌───┐
  │ E1│ │ E2│ │ E3│ │ E4│  ← 路由选择
  └─┬─┘ └─┬─┘ └─┬─┘ └─┬─┘
    └──────┴──────┘
         +
  ┌───────────────┐
  │  Shared Expert │  ← 始终激活，处理通用知识
  └───────┬───────┘
          ↓
    Combined Output

  好处: 共享专家提供通用能力基线，路由专家负责专精
```

## 5. HunyuanVideo 视频生成

### 5.1 视频生成架构

```
HunyuanVideo 技术架构:
════════════════════════════════════════════════════════════════════

  文本输入
      ↓
  ┌──────────────────────────────────────┐
  │         文本编码器 (T5 + CLIP)        │
  └──────────────────┬───────────────────┘
                     ↓
  ┌──────────────────────────────────────┐
  │      双流 DiT (Diffusion Transformer) │
  │                                       │
  │  ┌─────────────────────────────────┐ │
  │  │  前景流: 精细视频内容生成         │ │
  │  │  背景流: 环境与上下文生成         │ │
  │  │  融合层: 前景+背景自然融合        │ │
  │  └─────────────────────────────────┘ │
  └──────────────────┬───────────────────┘
                     ↓
  ┌──────────────────────────────────────┐
  │       时序注意力 + 空间注意力          │
  │       (3D Full Attention)            │
  └──────────────────┬───────────────────┘
                     ↓
              视频输出 (720p, 30fps)
```

### 5.2 HunyuanVideo 性能

| 指标 | HunyuanVideo | Sora | Kling | CogVideoX |
|------|-------------|------|-------|-----------|
| 分辨率 | 720p | 1080p | 1080p | 720p |
| 帧率 | 30fps | 30fps | 24fps | 24fps |
| 视频长度 | ~10s | ~60s | ~10s | ~6s |
| 质量 (VBench) | ~86% | ~90% | ~85% | ~80% |
| 开源 | 是 | 否 | 否 | 是 |

### 5.3 视频生成特色

```
HunyuanVideo 核心能力:
───────────────────────────────────────────────────────────────────
• 文生视频: 文本描述 → 高质量视频
• 图生视频: 图片 + 描述 → 动态视频
• 运动控制: 指定相机运动方向
• 风格控制: 电影、动漫、写实等风格
• 多主体生成: 单视频中多个角色/物体
```
