# 公共安全 AI 应用 (Public Safety)

> 中文简称：公共安全 AI 应用

## 1. 行业概况

```
公共安全 + AI 2026:
- 全球公共安全 AI 市场: ~$25B
- 中国智慧安防市场: 超 3000 亿元
- 核心方向: 预防 → 响应 → 恢复 全链路 AI 化

关键场景:
1. 智能安防: 视频监控 AI / 人脸识别 / 行为分析
2. 应急管理: 灾害预警 / 资源调度 / 指挥决策
3. 舆情监控: 社交媒体分析 / 谣言检测 / 情绪预警
4. 犯罪预测: 热点预测 / 关联分析 / 线索发现
5. 网络安全: 威胁检测 / 溯源 / 自动响应
6. 交通安全: 事故预测 / 智能信号 / 自动驾驶
```
