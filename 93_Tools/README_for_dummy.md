# 93 Tools — 小白版 🛠️

> **一句话秒懂**: 这一章是 AI Guru 知识库的"工具箱"——提供文档模板、导入指南、自动化脚本，帮助你高效管理和维护知识库内容。

## 为什么要了解这些工具？

想象一下：
- 📝 你要写一个新文档，不知道用什么格式？→ 文档模板来帮忙
- 🔗 你想检查知识库有没有断链？→ 自动化链接检查器
- ✅ 你想知道文档质量怎么样？→ 内容质量评分脚本
- 📚 你想导入新内容？→ 导入指南告诉你怎么做

## 文档模板体系

不管你要写什么类型的文档，都有对应的模板：

| 模板类型 | 用途 | 何时使用 |
|---------|------|---------|
| README | 章节入口，介绍整体内容 | 每个新章节都要有 |
| for_dummy | 小白版，用生活例子解释 | 需要面向零基础读者时 |
| nutshell | 速查版，30 分钟快速浏览 | 想快速了解一个领域时 |
| Deep Dive | 深度技术解读 | 需要深入理解原理时 |
| 实战指南 | 动手操作的步骤文档 | 需要实践操作时 |

## 工具实战指南

### 1. 如何写一个新文档？

```
第1步: 确定文档类型（README/for_dummy/nutshell/Deep Dive）
第2步: 找到对应模板
第3步: 按模板格式填写内容
第4步: 检查术语一致性（参考 91_Notes/AI_Full_Stack_Concepts.md）
第5步: 添加到对应章节的目录中
```

### 2. 如何检查内容质量？

```
质量检查清单:
□ 是否有清晰的标题和一句话概括？
□ 是否有目录/导航结构？
□ 是否有代码示例（如果适用）？
□ 是否有交叉引用（链接到相关文档）？
□ 术语是否一致（对照 AI Full Stack Concepts）？
□ 行数是否达标（nutshell 300-600 行，Deep Dive 1000+ 行）？
```

### 3. 如何贡献新内容？

```
步骤1: 阅读 IMPORT_GUIDE.md 了解导入规范
步骤2: 选择合适的文档模板
步骤3: 按模板编写内容
步骤4: 运行自动化检查（如果有）
步骤5: 提交 Pull Request
```
