# Web 前端项目 — 小白版 🌐

> **一句话秒懂**: Web 目录是 AI Guru 知识库的"网上展示厅"——一个现代化的前端网站，让你可以用浏览器搜索和浏览整个知识库，就像使用图书馆的目录检索系统！

## 为什么要学 Web 前端？

想象一下：
- 🔍 你想搜索知识库里关于 "Transformer" 的所有内容？
- 📱 你想在手机上查看知识库内容？
- 🎨 你想要一个更友好的界面而不是文件夹？

**Web 前端让知识库更好用！**

## 技术栈

```
【前端技术】
- React — 构建用户界面
- Vite — 快速构建工具
- TypeScript — 类型安全的 JavaScript
- Tailwind CSS — 快速样式设计
- shadcn/ui — 漂亮的 UI 组件

【功能特性】
- 全文搜索（基于 Fuse.js）
- 暗黑/亮色模式
- 响应式设计（手机、平板、电脑）
- 目录树导航
```

## 如何运行

```bash
# 进入 Web 目录
cd Web

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 访问 http://localhost:4567
```

## 功能介绍

### 1. 全文搜索

```
输入关键词 → 实时搜索 → 展示结果

支持:
- 模糊匹配（输入错别字也能搜到）
- 高亮关键词
- 按章节筛选
```

### 2. 目录导航

```
├── 00_AI_Introduction
├── 01_Fundamentals
├── 02_Machine_Learning
├── ...
└── 93_Tools

点击展开/折叠
点击进入子目录
```

### 3. 主题切换

```
🌙 暗黑模式 — 晚上阅读更舒服
☀️ 亮色模式 — 白天阅读更清晰

一键切换！
```

## 项目结构

```
Web/
├── src/
│   ├── components/ — UI 组件
│   ├── pages/ — 页面
│   ├── hooks/ — React hooks
│   └── utils/ — 工具函数
├── public/ — 静态资源
├── index.html — 入口 HTML
└── package.json — 依赖
```
