## 2. Chain-of-Thought (2022)

```
核心思想: 在回答前生成中间推理步骤

传统 Prompt:
  Q: Roger 有 5 个球, 买了 2 罐, 每罐 3 个, 现在有几个?
  A: 11

CoT Prompt:
  Q: Roger 有 5 个球, 买了 2 罐, 每罐 3 个, 现在有几个?
  A: Roger 一开始有 5 个球。2 罐每罐 3 个, 就是 2×3=6 个。
     5+6=11。答案是 11。

关键发现:
- 只需在 few-shot 示例中展示推理过程
- 大模型 (≥100B) 效果显著
- 数学/逻辑/常识推理都有效

变体:
- Zero-shot CoT: "Let's think step by step"
- Auto-CoT: 自动生成推理链
- Self-Consistency: 多条推理链投票

影响:
- 开启了 "推理增强" 研究方向
- 后续所有推理工作的基础
```

## 3. DeepSeek-R1 / GRPO (2025)

```
核心思想: 用强化学习 (而非 SFT) 训练推理能力

GRPO (Group Relative Policy Optimization):
- 对同一问题生成一组回答 (group)
- 组内相对比较 (不需要价值网络)
- 正确的回答获得正奖励
- 比 PPO 更简单/更稳定

R1 训练流程:
1. 冷启动: 少量高质量 CoT 数据 SFT
2. 推理 RL: GRPO + 规则奖励 (答案正确性)
3. 拒绝采样: 用 R1 生成数据 → 过滤 → SFT
4. 全场景 RL: 对齐 + 推理联合训练

关键发现:
- RL 可以 "激发" 模型的推理能力
- 模型自发学会: 反思/回溯/验证
- 不需要大量人工标注的推理数据
- "Aha moment": 模型突然学会新推理策略

影响:
- 证明了 RL > SFT 用于推理训练
- 开源模型首次匹敌 o1
- 后续: R1-Distill / 各厂跟进
```

## 4. 推理 Scaling Law

```
核心发现 (OpenAI o1/o3):

推理时计算 (Test-time Compute) 可以替代模型规模:
- 小模型 + 长思考 > 大模型 + 短思考 (某些任务)
- 推理预算增加 → 性能对数增长

三种 Scaling 维度:
1. 预训练计算 (传统): 更大模型/更多数据
2. 后训练计算 (微调): RL/更多 SFT
3. 推理时计算 (新): 更长思考/更多搜索

o3 的突破:
- 在 ARC-AGI 上: 更多推理时间 → 87.5% (vs 之前 30%)
- 证明推理时 scaling 的巨大潜力
```
