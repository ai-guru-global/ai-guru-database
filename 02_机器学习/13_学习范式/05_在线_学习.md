# 在线学习 (Online Learning)

> 中文简称：在线学习

## 1. 在线学习 vs 批量学习

### 1.1 核心区别

```
批量学习 (Batch/Offline):
- 一次性收集所有数据 → 训练 → 部署
- 模型固定，不随新数据更新
- 适合: 数据稳定、可离线处理

在线学习 (Online/Incremental):
- 数据逐条/逐批到达 → 实时更新模型
- 模型持续适应新分布
- 适合: 数据流式、分布变化、实时决策

关键挑战:
- 数据不可重放 (one-pass)
- 分布可能变化 (concept drift)
- 需要即时决策 (不能等所有数据)
- 内存有限 (不能存所有历史)
```

### 1.2 应用场景

| 场景 | 数据特点 | 在线学习需求 |
|------|----------|-------------|
| 推荐系统 | 用户行为实时产生 | 实时适应用户兴趣变化 |
| 广告竞价 | 每秒百万次请求 | 实时调整出价策略 |
| 金融风控 | 交易流实时到达 | 检测新型欺诈模式 |
| 网络监控 | 日志流持续产生 | 实时异常检测 |
| IoT 传感器 | 高频时序数据 | 边缘实时推理+更新 |
| 社交内容 | 热点快速变化 | 实时趋势捕捉 |

## 2. 在线学习算法

### 2.1 在线梯度下降 (OGD)

```python
import numpy as np

class OnlineGradientDescent:
    """
    在线梯度下降: 每来一个样本更新一次
    """
    def __init__(self, n_features, learning_rate=0.01):
        self.w = np.zeros(n_features)
        self.lr = learning_rate
        self.t = 0
    
    def predict(self, x):
        return np.sign(x @ self.w)
    
    def update(self, x, y):
        """收到一个样本后立即更新"""
        self.t += 1
        y_pred = self.predict(x)
        
        if y_pred != y:  # 预测错误才更新
            # 感知器更新规则
            self.w += self.lr * y * x
        
        # 学习率衰减 (保证收敛)
        self.lr = 1.0 / np.sqrt(self.t)
    
    def partial_fit(self, X_batch, y_batch):
        """小批量在线更新"""
        for x, y in zip(X_batch, y_batch):
            self.update(x, y)
```

### 2.2 在线贝叶斯更新

```python
class OnlineBayesianClassifier:
    """
    在线朴素贝叶斯: 逐样本更新后验
    """
    def __init__(self, n_features, n_classes):
        self.class_counts = np.ones(n_classes)  # 拉普拉斯平滑
        self.feature_sums = np.ones((n_classes, n_features))
        self.total_counts = np.ones(n_classes) * n_features
    
    def update(self, x, y):
        """收到新样本，更新统计量"""
        self.class_counts[y] += 1
        self.feature_sums[y] += x
        self.total_counts[y] += x.sum()
    
    def predict(self, x):
        """基于当前统计量预测"""
        log_prior = np.log(self.class_counts / self.class_counts.sum())
        log_likelihood = np.zeros(len(self.class_counts))
        
        for c in range(len(self.class_counts)):
            probs = self.feature_sums[c] / self.total_counts[c]
            log_likelihood[c] = np.sum(x * np.log(probs + 1e-10))
        
        return np.argmax(log_prior + log_likelihood)
```

### 2.3 指数加权平均 (EMA)

```python
class ExponentialWeightedModel:
    """
    指数加权: 近期数据权重更大
    适应分布变化的基础技术
    """
    def __init__(self, alpha=0.99):
        self.alpha = alpha  # 衰减因子
        self.ema = None
    
    def update(self, new_value):
        if self.ema is None:
            self.ema = new_value
        else:
            self.ema = self.alpha * self.ema + (1 - self.alpha) * new_value
        return self.ema
    
    # 有效窗口大小 ≈ 1/(1-alpha)
    # alpha=0.99 → 最近 ~100 个样本
    # alpha=0.9  → 最近 ~10 个样本
```

## 3. 概念漂移 (Concept Drift)

### 3.1 漂移类型

```
┌─────────────────────────────────────────────────┐
│  突变漂移 (Sudden):                             │
│  分布突然改变 (如: 疫情后消费模式)              │
│  ──────|══════════                              │
│                                                 │
│  渐变漂移 (Gradual):                            │
│  分布缓慢变化 (如: 用户兴趣迁移)               │
│  ──────╲══════════                              │
│                                                 │
│  增量漂移 (Incremental):                        │
│  分布持续微小变化 (如: 季节性趋势)             │
│  ──────╲╲╲╲══════                              │
│                                                 │
│  循环漂移 (Recurring):                          │
│  分布周期性变化 (如: 工作日/周末)              │
│  ──╱╲──╱╲──╱╲──                                │
└─────────────────────────────────────────────────┘
```

### 3.2 漂移检测方法

```python
class ADWIN:
    """
    ADWIN (ADaptive WINdowing): 自适应窗口漂移检测
    核心思想: 维护一个可变窗口，当窗口内两部分
    统计差异显著时，丢弃旧部分
    """
    def __init__(self, delta=0.002):
        self.delta = delta
        self.window = []
        self.total = 0
        self.variance = 0
        self.width = 0
    
    def add(self, value):
        self.window.append(value)
        self.total += value
        self.width += 1
        
        # 检测是否需要收缩窗口
        self._check_drift()
    
    def _check_drift(self):
        """检查窗口内是否存在显著差异"""
        if self.width < 10:
            return False
        
        # 尝试所有切分点
        for i in range(5, self.width - 5):
            left = self.window[:i]
            right = self.window[i:]
            
            mean_left = np.mean(left)
            mean_right = np.mean(right)
            
            # Hoeffding 界
            n = len(left) + len(right)
            m = 1.0 / (1.0/len(left) + 1.0/len(right))
            epsilon = np.sqrt(np.log(4/self.delta) / (2*m))
            
            if abs(mean_left - mean_right) >= epsilon:
                # 检测到漂移! 丢弃旧数据
                self.window = right
                self.width = len(right)
                self.total = sum(right)
                return True
        
        return False
    
    def estimate(self):
        return self.total / self.width if self.width > 0 else 0
```

### 3.3 漂移适应策略

| 策略 | 方法 | 适用漂移类型 |
|------|------|-------------|
| 滑动窗口 | 只用最近 N 个样本 | 突变/渐变 |
| 指数衰减 | 近期样本权重大 | 渐变/增量 |
| 集成方法 | 多模型投票，淘汰旧模型 | 所有类型 |
| 触发重训 | 检测到漂移后重新训练 | 突变 |
| 自适应学习率 | 漂移时加大学习率 | 所有类型 |

## 4. Bandit 算法

### 4.1 多臂老虎机 (Multi-Armed Bandit)

```python
class UCB1:
    """
    UCB1 (Upper Confidence Bound):
    平衡探索 (exploration) 与利用 (exploitation)
    """
    def __init__(self, n_arms):
        self.n_arms = n_arms
        self.counts = np.zeros(n_arms)  # 每个臂被拉的次数
        self.values = np.zeros(n_arms)  # 每个臂的平均收益
        self.total_count = 0
    
    def select_arm(self):
        """选择下一个要拉的臂"""
        # 确保每个臂至少被拉一次
        if 0 in self.counts:
            return np.argmin(self.counts)
        
        # UCB 公式: 平均收益 + 探索奖励
        exploration = np.sqrt(2 * np.log(self.total_count) / self.counts)
        ucb_values = self.values + exploration
        
        return np.argmax(ucb_values)
    
    def update(self, arm, reward):
        """更新统计量"""
        self.counts[arm] += 1
        self.total_count += 1
        # 增量平均更新
        self.values[arm] += (reward - self.values[arm]) / self.counts[arm]

class ThompsonSampling:
    """
    汤普森采样: 贝叶斯方法
    维护每个臂收益的后验分布，按概率采样选择
    """
    def __init__(self, n_arms):
        self.alphas = np.ones(n_arms)  # Beta 分布参数
        self.betas = np.ones(n_arms)
    
    def select_arm(self):
        """从后验分布采样，选最大的"""
        samples = np.random.beta(self.alphas, self.betas)
        return np.argmax(samples)
    
    def update(self, arm, reward):
        """更新后验"""
        if reward > 0.5:  # 二值奖励
            self.alphas[arm] += 1
        else:
            self.betas[arm] += 1
```

### 4.2 上下文 Bandit (Contextual Bandit)

```python
# 上下文 Bandit: 根据上下文特征选择动作
# 应用: 个性化推荐、广告选择、动态定价

class LinUCB:
    """
    LinUCB: 线性上下文 Bandit
    假设: 期望收益 = 上下文特征 × 权重
    """
    def __init__(self, n_arms, d_features, alpha=1.0):
        self.n_arms = n_arms
        self.alpha = alpha
        # 每个臂维护一个线性模型
        self.A = [np.eye(d_features) for _ in range(n_arms)]
        self.b = [np.zeros(d_features) for _ in range(n_arms)]
    
    def select_arm(self, context):
        """给定上下文，选择最优臂"""
        ucb_values = []
        for arm in range(self.n_arms):
            A_inv = np.linalg.inv(self.A[arm])
            theta = A_inv @ self.b[arm]
            
            # 预测 + 不确定性
            mean = context @ theta
            uncertainty = self.alpha * np.sqrt(context @ A_inv @ context)
            ucb_values.append(mean + uncertainty)
        
        return np.argmax(ucb_values)
    
    def update(self, arm, context, reward):
        self.A[arm] += np.outer(context, context)
        self.b[arm] += reward * context
```

### 5.2 River 实战

```python
from river import linear_model, optim, metrics, evaluate

# 在线逻辑回归
model = linear_model.LogisticRegression(optimizer=optim.SGD(0.01))

# 流式评估
accuracy = metrics.Accuracy()

for x, y in data_stream:
    # 先预测 (用当前模型)
    y_pred = model.predict_one(x)
    accuracy.update(y, y_pred)
    
    # 再学习 (更新模型)
    model.learn_one(x, y)

print(f"在线准确率: {accuracy.get():.2%}")
```
