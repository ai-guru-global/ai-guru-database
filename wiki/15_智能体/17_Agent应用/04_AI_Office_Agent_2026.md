# AI 办公 Agent 赛道拆解 2026（WorkBuddy / 千问办公 / 豆包工作）

> 中文简称：AI办公Agent赛道

> **一句话理解**: 2026 年腾讯、阿里、字节在五个月内先后把「AI 办公」从聊天助手升级为「自主拆解任务、调用工具、交付可验收成品」的智能体——竞争焦点不再是模型谁更强，而是谁与你已有的工作环境（微信/企微、钉钉、飞书）最合拍。

---

## 1. 赛道定义：什么叫「办公 Agent」

区别于上一代「AI 对话 + 写作」工具，办公 Agent 的判定标准是三条：

1. **自主拆解** —— 输入工作目标，自动拆成多步骤任务序列
2. **工具调用** —— 操作本地文件、Office 文档、浏览器、IM 等真实工具，而非只输出文字建议
3. **成品交付** —— 产出可直接验收的 Word/Excel/PPT/网页/报告，而不是「建议你用透视表」

> 定位：办公 Agent 是 [[概念/Agent/computer-use|Computer Use]] 能力的办公化变体——动作空间收窄到办公软件与文件系统，换取更低风险与更高交付稳定性。

## 3. 三强拆解

### 3.1 WorkBuddy（腾讯）

| 维度 | 事实（时点） |
|------|--------------|
| 出身 | 腾讯云代码助手 CodeBuddy 的支线产品，2026-03 公测——「从开发者工具长出来的办公台」 |
| 生态绑定 | 微信/企微 1 分钟直连下发指令；2026-10 与企业微信 5.0.12 深度打通 |
| 规模 | 易观口径：2026-06 月访问 2,097 万居首（超过二三名之和）；2026-09 月访问 8,534 万，约为第二名 2 倍 |
| 爱分析口径 | 2026-10 综合榜第二，用户提及度最高；月活超 2,500 万 |
| 生态开放 | 「Buddy 应用」开放平台：30+ 伙伴共建、覆盖金融/法律/医疗等 20+ 领域；扩展模块约 2.2 万个 Skill |
| 组织 | QClaw 产品中心并入 WorkBuddy 体系（2026-09 报道）；配套办公场景模型 Hy4 preview（2026-09） |

### 3.2 千问办公（阿里，QwenWork）

| 维度 | 事实（时点） |
|------|--------------|
| 出身 | 2026-07-22 由 QoderWork + 悟空 + MuleRun 三款智能体整合升级，独立于通义千问之外 |
| 负责人 | 钉钉新任 CEO 陈宇森；2026-08 划归阿里「AI 实验室与应用」分部 |
| 增速 | 上线首月用户破 3,000 万、企业用户占比过半（2026-09-04 界面新闻）；日均迭代 4 次版本 |
| 流量 | 易观 2026-09 月访问 4,655 万，第二 |
| 差异点 | 深度融入钉钉；多人工作台（业内首个，2026-09-07）；接入企业微信；蚂蚁集团接入（2026-09-17）；国际版覆盖亚洲/中东/拉美 |
| 模型 | 基于千问系列，兼容 GLM-5.3、DeepSeek V4 Pro 等第三方模型；积分制定价（个人/企业积分池隔离） |

### 3.3 豆包工作（字节）

| 维度 | 事实（时点） |
|------|--------------|
| 出身 | 2026-08-25 发布，整合飞书、TRAE、扣子能力——「豆包 C 端流量转向 B 端变现」的载体 |
| 生态绑定 | 与飞书深度打通，可读取聊天记录、文档、会议纪要等企业上下文；手机远程操控是独有能力 |
| 规模 | 爱分析 2026-10 综合榜**第一**（月活 5,512 万）；易观 2026-09 桌面端月访问 3,039 万（第三，新上榜） |
| 模型策略 | 「模型超市」：接入 Kimi K3.1 Pro、GLM-5.3、DeepSeek-V4.1 Flash 等第三方模型，用户可挑 |
| 协同 | 飞书 8.0（2026-09-15）发布团队智能体「豆包工作伙伴」，主攻组织级场景 |

> 三者口径差异提示：易观只统计**桌面端主动对话/任务次数**（网页、插件、移动端不计），爱分析用**用户月活**——所以豆包工作在爱分析登顶、在易观仅第三（移动端优势无法计入）。引用数字必须带口径。

## 5. 竞争主线：三个回合

1. **入口回合**（已开打）：企微 vs 钉钉 vs 飞书的生态导流，决定了获客成本的量级差
2. **交付回合**（进行中）：谁能稳定交付可验收成品，而非 demo 惊艳、返工常态
3. **企业回合**（胜负手）：企业版、权限/审计、行业方案——WorkBuddy 企业版、千问办公企业积分池均已卡位

**直觉**：这轮竞争的本质是「**谁的办公 IM 里住着一个可信的数字同事**」——模型能力会被追平，工作流上下文（谁跟谁聊了什么、文档在哪）才是别人抄不走的护城河。
