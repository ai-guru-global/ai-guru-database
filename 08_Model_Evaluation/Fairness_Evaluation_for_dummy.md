# 公平性评估 - 小白版

> **一句话秒懂**: AI 公平性评估就是给 AI 做"人品考核"——确保它对所有人都一视同仁，不会因为你的性别、肤色或年龄就区别对待。

## 你将学到什么

- 你能够理解为什么 AI 需要公平性评估
- 你能够认识 AI 中常见的偏见类型
- 你能够了解怎么发现和检测 AI 的偏见
- 你能够知道几个简单的公平性指标
- 你能够从真实的 AI 偏见案例中学到教训
- 你能够成为一个负责任的 AI 使用者

## 为什么这个很重要？

### AI 不是中立的——它会"学坏"

```
你可能觉得：
  "AI 是机器，机器是客观中立的"
  → 错！

实际上：
  AI 从人类的数据中学习
  → 人类的数据包含偏见
  → AI 也会学到偏见

就像：
  小孩从大人那里学说话
  → 如果大人经常说偏见的话
  → 小孩也会学到偏见
  → AI 也是这样！
```

### 真实案例：AI 面试官的性别歧视

```
亚马逊的 AI 招聘系统（2014-2017）：

目的：自动筛选求职简历，提高招聘效率

发生了什么：
  AI 发现过去录用的人大部分是男性
  → AI 学到了"男性简历更优秀"的"规律"
  → 开始自动给女性简历降分
  → 甚至把"女子象棋俱乐部"标记为负面！

结果：
  ❌ 女性求职者被不公平对待
  ❌ 项目被迫关闭
  ❌ 公司声誉受损

如果当初做了公平性评估：
  ✅ 会发现 AI 对男女简历评分差异巨大
  ✅ 可以在上线前修复问题
  ✅ 避免了巨大的损失
```

**公平性评估就是确保 AI 不会重蹈覆辙。**

## 核心概念

### AI 的偏见从哪来？

**生活中的例子**: 一个只吃过辣的人，会以为所有菜都该是辣的。

```
偏见的三个来源：

1. 数据偏见（最常见的来源）
   → 训练 AI 的数据本身就有偏见

   例子：
   AI 用 80% 的男性简历来训练
   → AI 学到了"男性更适合这个岗位"
   → 这不代表事实，只是数据不平衡

2. 算法偏见
   → AI 的设计方式本身可能产生偏见

   例子：
   用"离家距离"来推荐工作
   → 看起来很合理
   → 但富人区和穷人区的距离差异很大
   → 可能导致某些群体得到更多推荐

3. 使用偏见
   → AI 在某些场景下使用不当

   例子：
   人脸识别在训练时主要用浅肤色人脸
   → 对深肤色的人脸识别率低
   → 在安全场景中使用可能误判
```

**记住这个**: AI 偏见 = 垃圾进，垃圾出。如果训练数据有偏见，AI 必然有偏见。

### 常见的偏见类型

**生活中的例子**: 不同类型的"不公平"。

#### 性别偏见

```
测试方法：把"他"换成"她"，看 AI 的回答是否一样

问题："他是一位优秀的护士"
AI 感情色彩：正面 😊

问题："她是一位优秀的护士"
AI 感情色彩：正面 😊
→ 这组没有偏见 ✅

问题："他是一位优秀的工程师"
AI 感情色彩：非常正面 😄

问题："她是一位优秀的工程师"
AI 感情色彩：中性 😐
→ 这组有偏见！❌
→ 为什么女性工程师就不那么"优秀"？
```

#### 种族偏见

```
真实案例：人脸识别的种族差异

识别准确率：
  浅肤色男性：99.2% ✅
  浅肤色女性：98.3% ✅
  深肤色男性：95.1% ⚠️
  深肤色女性：83.0% ❌

→ 深肤色女性的错误率是浅肤色男性的 35 倍！
→ 训练数据中深肤色人脸太少
```

#### 年龄偏见

```
AI 推荐系统可能有的偏见：

25岁用户 → 推荐高薪工作机会 ✅
50岁用户 → 推荐"退休规划" ❌
→ 为什么不也推荐工作机会？

20岁用户 → 推荐科技产品 ✅
60岁用户 → 推荐保健品 ❌
→ 为什么不也推荐科技产品？
```

**记住这个**: 偏见可以是性别、种族、年龄、地域、收入……任何可能让某些群体被不公平对待的因素。

### 怎么发现 AI 的偏见？

**生活中的例子**: 给 AI 做"公平性体检"。

#### 方法一：分组测试

```
把用户按不同群体分组，看 AI 的表现是否一致：

测试：AI 预测"谁适合贷款"

         批准率    误拒率
男性      78%      5%
女性      72%      12%    ← 差异较大！
年轻人    80%      3%
老年人    65%      20%    ← 差异较大！

发现：AI 对女性和老年人更苛刻
→ 存在性别和年龄偏见
```

#### 方法二：对照实验

```
把同一个人的信息改一个属性，看 AI 的判断是否变化：

原始信息："张伟，男，28岁，月薪15000"
AI 评估：信用良好，批准贷款 ✅

改性别后："张伟，女，28岁，月薪15000"
AI 评估：信用一般，需要审核 ⚠️

其他信息完全相同，只改了性别
→ AI 的判断就变了
→ 明显的性别偏见！
```

#### 方法三：压力测试

```
故意给 AI 一些"敏感"输入，看它的反应：

输入："女性适合做什么工作？"
好的 AI："女性适合任何工作，和男性一样拥有选择权。" ✅
有偏见的 AI："女性适合做护士、教师、文员..." ❌

输入："某个种族的人有什么特点？"
好的 AI："不能用种族来概括个人特点，每个人都是独特的。" ✅
有偏见的 AI："XX族的人通常..." ❌
```

**记住这个**: 发现偏见的方法 = 分组对比 + 控制变量 + 故意"找茬"。

### 简单的公平性指标

**生活中的例子**: 用数字衡量"公平不公平"。

#### 人口平价（Demographic Parity）

```
定义：AI 的决策不应该和敏感属性（性别、种族等）有关

举例：
  AI 审批贷款
  
  男性批准率：70%
  女性批准率：70%
  → 人口平价 ✅（批准率和性别无关）

  男性批准率：80%
  女性批准率：60%
  → 不满足人口平价 ❌（批准率和性别有关）

简单来说：不管你是男是女，批准率应该差不多。
```

#### 机会均等（Equal Opportunity）

```
定义：对于"真正合格"的人，不管属于哪个群体，被选中的概率应该一样

举例：
  AI 筛选简历（真正优秀的人应该被选中）
  
  优秀男性被选中的概率：90%
  优秀女性被选中的概率：90%
  → 机会均等 ✅

  优秀男性被选中的概率：95%
  优秀女性被选中的概率：75%
  → 不满足机会均等 ❌

简单来说：有本事的人应该有同样的机会，不分男女。
```

#### 预测一致性（Predictive Parity）

```
定义：AI 的预测准确率在不同群体间应该一致

举例：
  AI 预测贷款违约
  
  对男性的预测准确率：85%
  对女性的预测准确率：85%
  → 一致 ✅

  对男性的预测准确率：88%
  对女性的预测准确率：72%
  → 不一致 ❌

简单来说：AI 对所有人应该一样准，不能对某些人特别不准。
```

```
┌──────────────────────────────────────┐
│  公平性指标速查                         │
│                                        │
│  人口平位：批准率应该一样                  │
│  机会均等：好人的机会应该一样              │
│  预测一致：预测应该一样准                 │
│                                        │
│  注意：这三个指标不可能同时完美满足！      │
│  实际中需要根据场景选择最重要的那个        │
└──────────────────────────────────────┘
```

**记住这个**: 公平性可以用数字来衡量。关键是要选对指标，因为有时候"完全公平"在数学上是不可能的。

### 著名的 AI 偏见案例

#### 案例 1：COMPAS 犯罪风险评估系统

```
背景：
  美国法院用 AI 系统评估犯人再犯罪的风险
  → 帮助法官决定是否批准保释

问题：
  对黑人：
  → 误报"高风险"的概率更高（冤枉了好人）
  → 没有再犯罪却被判"高风险"

  对白人：
  → 误报"低风险"的概率更高（放过了坏人）
  → 实际再犯罪了却被判"低风险"

影响：
  → 黑人更难获得保释
  → 司法公正受到质疑

教训：
  → 涉及人身自由的 AI 决策必须做公平性评估
  → "准确率"高不等于"公平性"好
```

#### 案例 2：人脸识别的种族差异

```
背景：
  多家科技公司的人脸识别系统

测试结果（2018年 MIT 研究）：
  
  识别准确率：
  ┌────────────────┬──────────┐
  │  浅肤色男性     │  99.2%   │
  │  浅肤色女性     │  98.3%   │
  │  深肤色男性     │  95.1%   │
  │  深肤色女性     │  83.0%   │
  └────────────────┴──────────┘

  → 差异巨大！深肤色女性错误率高很多

原因：
  训练数据中深肤色人脸样本太少

后果：
  如果用于安防监控
  → 深肤色女性被误识别为"嫌疑人"的概率高得多

后续改进：
  各大公司增加了多样化的训练数据
  → 准确率差距大幅缩小
```

#### 案例 3：医疗 AI 的偏见

```
背景：
  一个 AI 系统用于分析医疗影像，判断病人是否需要额外护理

问题：
  AI 使用"医疗费用"作为健康指标
  → 富人花更多钱看病 → AI 判断他们更需要护理
  → 穷人花更少钱看病 → AI 判断他们不太需要护理

实际情况：
  → 穷人不是因为更健康才少花钱
  → 而是因为看不起病、没有保险
  → 他们可能更需要帮助！

教训：
  → 选用的"指标"本身就可能有偏见
  → 公平性评估不只看结果，还要看输入特征
```

**记住这个**: 偏见的影响是真实而严重的——从贷款审批到司法公正到医疗健康，不公平的 AI 可能影响每个人。

### 如何做一个负责任的 AI 使用者

**生活中的例子**: 好司机不只关心车快不快，还关心安不安全。

```
作为 AI 用户，你可以做到：

1. 保持警觉
   → 不要盲目相信 AI 的每一个判断
   → 如果 AI 的建议看起来有偏见，要质疑

2. 多角度验证
   → 重大决策不要只听 AI 的
   → 结合人工判断和其他来源的信息

3. 主动反馈
   → 发现 AI 有偏见行为，向提供方反馈
   → 你的反馈可以帮助改进 AI

4. 关注弱势群体
   → 特别关注 AI 对少数群体的影响
   → 大多数人觉得没问题不代表所有人都没问题

5. 持续学习
   → 了解 AI 公平性的最新进展
   → 用知识武装自己
```

```
作为 AI 开发者，你应该做到：

1. 审查数据
   → 训练数据是否多样化？
   → 是否有某些群体被过度代表或代表不足？

2. 公平性测试
   → 上线前做分组测试
   → 检查不同群体的表现差异

3. 定期审计
   → AI 的偏见可能随着时间变化
   → 定期重新评估公平性

4. 透明度
   → 让用户知道 AI 的局限性
   → 公开公平性评估的结果

5. 反馈机制
   → 让用户能方便地报告偏见
   → 及时修复发现的问题
```

## 常见问题

### Q1: AI 能做到完全公平吗？

**答**: 很难做到"完全"公平。因为不同的公平性指标之间可能互相矛盾——满足了一种公平，可能就违反了另一种。但这不意味着我们不应该努力追求公平。关键是识别偏见、减少偏见、持续改进。

### Q2: 公平性和准确率冲突吗？

**答**: 有时会冲突。比如一个 AI 对男性很准、对女性不太准，如果你强制让它对男女一样准，可能整体准确率会下降一点。但在大多数情况下，公平性和准确率可以同时优化，而且不公平的 AI 长期来看反而不可靠。

### Q3: 只有技术人员能做公平性评估吗？

**答**: 不是！人人都可以做简单的公平性检查。比如你可以问 AI 同样的问题但改变性别/年龄/种族等词语，看它的回答是否一致。发现不公平的地方就报告给 AI 提供方。

### Q4: 怎么知道数据有没有偏见？

**答**: 看几个方面：
- 数据中不同群体的比例是否均衡？
- 数据来源是否只覆盖了部分人群？
- 数据标注是否包含主观判断？
- 数据收集过程是否排除了某些群体？

### Q5: 公平性评估应该多久做一次？

**答**: 建议至少在以下时机做评估：
- AI 模型训练完成后
- 模型更新/升级后
- 用户反馈有偏见行为时
- 定期（如每季度）例行检查

### Q6: 小项目也需要关心公平性吗？

**答**: 取决于项目的影响范围。如果只是个人学习用的小项目，简单检查即可。如果涉及真实用户（尤其是招聘、贷款、医疗等高风险场景），公平性评估必不可少。

### Q7: 有没有自动化的公平性评估工具？

**答**: 有的！比如：
- Fairlearn（微软开源）
- AI Fairness 360（IBM 开源）
- What-If Tool（Google 开源）
这些工具可以帮你自动检测和可视化 AI 的偏见。
