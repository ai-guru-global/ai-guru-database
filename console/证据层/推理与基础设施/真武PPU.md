# 真武PPU

> 平头哥自研 AI 训推一体芯片（Parallel Processing Unit）：国产首个走通「自用降本 → 对外售卖 → 模型生态绑定」全链路的云厂商自研芯片。本卡是台内入口与证据时间线，系统拆解在深潜子库。

## 概述

真武 PPU 是平头哥（阿里全资半导体子公司）的训推一体 AI 芯片产品线，官方定位原话：「一款为AI应用加速的芯片，具有高易用性，适用于各类大模型和传统模型的训练及推理场景」（[aliyun.com/ppu](https://www.aliyun.com/ppu)，2026-11 检索）。产品线三档：**810E**（96GB HBM2e / 片间互联 700GB/s，北京/杭州/上海/乌兰察布商用）、**M890**（96/144GB / 800GB/s，乌兰察布商用、中卫邀测，超节点实例 Day0 适配 Kimi K3.1 Pro）、**V900**（216GB / 1200GB/s，页面标注「敬请期待」未商用）。自研软件栈 PPU SDK（2.2.0，含 ACCL-P 集合通信库、acext 算子库、HolmesLLM 推理框架），框架层兼容 Megatron / DeepSpeed / DeepEP / vLLM / SGLang，模型兼容 Qwen / LLaMA / DeepSeek / Kimi / GLM；官方页未披露峰值算力（TFLOPS）数字。

**命名口径**：官方页为「真武 PPU」；2026-01 官宣初期媒体（TrendForce 等）称「镇宇 810E」。本台以官方页「真武」为准，「镇宇」作别名保留（挂账见 `docs/2026待核实清单.md` 第十节）。

媒体口径累计出货一年以上（36氪 2026-01-28）；外部客户官方页口径 650+，另有观察者网 400+、累计出货 47 万颗（观察者网转述）与 60 万片（腾讯新闻转述 IDC）两个并存口径，均未清偿核实。

本卡作为台内真武 PPU 线索入口与证据时间线；实体拆解、规格对标、软件栈路线、商业模式与竞争格局的系统分析，在深潜子库 [01-算力与硬件层/02-自研 ASIC 与 TPU/真武PPU拆解](../../01-算力与硬件层/02-自研%20ASIC%20与%20TPU/真武PPU拆解/README.md)（15 篇，2026-11-06 建库）中展开，两处互为索引。

## 分析

（观点层）PPU 的结构同构对象是 AWS Trainium 而非华为昇腾：云厂商自研 + 对外售卖 + 框架层适配 + 服务自家旗舰模型四合一，且独有 Qwen 开源生态绑定。卡位是「H20 替代位」而非「H100 对抗位」——单卡峰值算力官方不披露，真实下注在 scale-up 超节点与显存池（互联 700→1200GB/s 三代递进，V900 千卡全带宽）。软件路线钩住 vLLM/Megatron 框架层，迁移摩擦最小但护城河最薄，壁垒必须长在 acext 算子库 / ACCL-P / HolmesLLM 深度上。成熟度判**爬坡期**（商用一年+、出货数十万级、三代 roadmap 清晰；生态差距与第三方基准缺位未证伪）。完整论证见深潜子库 [行业拆解](../../01-算力与硬件层/02-自研%20ASIC%20与%20TPU/真武PPU拆解/行业拆解.md)。
