# 面试准备清单

## 面试前 1 周

- [ ] 研究目标公司：业务模式、主要客户、技术栈
- [ ] 准备 **3 个深度项目案例**（从需求到交付的完整故事）
- [ ] 准备 **2 个失败案例**（失败原因+学到什么）
- [ ] 刷 5 道系统设计题（AI 系统为主）
- [ ] 准备 3 个问面试官的问题

## 面试前 1 天

- [ ] 复习 DADI 方法论，能用 2 分钟讲清楚
- [ ] 准备 1 分钟自我介绍（强调 FDE 特质）
- [ ] 检查技术环境（如需要 live coding）

## 面试当天

- [ ] 穿商务休闲（不要太正式也不要太随意）
- [ ] 提前 10 分钟到（线下）/ 提前 5 分钟入会（线上）
- [ ] 带笔记本 + 笔（线下）
- [ ] STAR 方法组织回答：Situation → Task → Action → Result

## 面试后

- [ ] 当天发送感谢邮件/消息
- [ ] 记录面试问题（为下一次准备）
- [ ] 如果被拒，礼貌询问反馈

## 薪资谈判准备

- [ ] 了解市场行情（FDE 50-120 万/年）
- [ ] 明确自己的底线和期望
- [ ] 准备好"为什么值这个价"的论据
- [ ] 关注总包（base + 奖金 + 股权 + 驻场补贴）
