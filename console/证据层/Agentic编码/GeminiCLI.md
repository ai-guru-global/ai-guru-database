# GeminiCLI

> Google 的免费开源终端编码智能体：以「百万 token 免费额度 + 开源」入场，2026 年并入 Antigravity 工具体系。

## 概述

Gemini CLI 是 Google 2025 年 6 月发布的开源命令行编码智能体（Apache 2.0），基于 Gemini 模型，入场即以每分钟/每日免费额度与开源姿态对标 Claude Code / Codex CLI，把「终端 Agent 免费」变成行业默认预期。

2026 年 4 月补上 Subagents 多智能体能力；5 月 Google 宣布将其迁移至 Antigravity CLI（Google Agentic 开发平台 Antigravity 的终端组件），个人工具升级为平台入口。
