# 模拟项目 2：金融智能 Agent 交付

## 项目背景

**客户**：某股份制银行  
**需求**："需要一个 AI Agent，能自动处理客户贷款咨询、辅助风控审批、生成合规报告"  
**环境**：私有云（K8s + GPU 集群）、内外网隔离  
**预算**：300 万  
**周期**：4 个月  

## 关键差异（vs 政企 RAG 项目）

| 维度 | 政企 RAG | 金融 Agent |
|---|---|---|
| 技术复杂度 | 中（RAG 为主） | 高（Agent + 多系统集成） |
| 数据敏感度 | 高 | 极高（金融数据） |
| 合规要求 | 等保 | 等保 + 银保监会 |
| 可解释性 | 一般 | 极高（必须能解释） |
| 系统集成 | 少 | 多（核心系统+风控+CRM） |

## 实战要点

### Week 1-2: Discovery
- 访谈 4 个部门（零售银行、风控、合规、IT）
- 核心发现：客户最痛的点是"贷款审批效率"——现在平均 3 天
- 成功指标：审批时间从 3 天 → 4 小时

### Week 3-4: Architecture
- 技术选型：LangGraph（Agent 编排）+ DeepSeek + 银行核心系统 API
- 安全方案：全链路 TLS + 数据脱敏 + 操作不可否认
- 合规方案：Agent 只做"辅助判断"，最终决策权在人

### Week 5-12: Delivery
- Stage 1：快速原型（2 周）—跑通"贷款咨询"单一场景
- Stage 2：试点（4 周）—5 个客户经理试用，收集反馈
- Stage 3：上线（4 周）—全量上线 + 风控部门验收

### 交付成果
- 审批效率：3 天 → 3.5 小时 ✅
- 客户经理 NPS：85
- 续签二期合同（200 万）

---

> **金融 FDE 核心经验**：合规部门必须在第一天就参与。先让 Agent 辅助人，再慢慢过渡到部分自动化。不要试图一步到位替代人的决策。
