# 边缘部署 (Edge Deployment)

> 中文简称：边缘部署

## 1. 边缘 AI 概述

```
为什么需要边缘部署?
- 隐私: 数据不出设备 (医疗/金融)
- 延迟: 本地推理 <10ms (实时应用)
- 成本: 无云端 API 费用 (大规模)
- 离线: 无网络也能工作 (IoT/车载)
- 带宽: 减少数据传输 (视频/传感器)

2026 边缘 AI 趋势:
- 端侧 LLM: 手机运行 3B-7B 模型 (Apple Intelligence/高通)
- NPU 普及: 所有新设备内置 AI 加速器
- 小模型崛起: 1B-3B 模型质量接近大模型
- 浏览器 AI: WebGPU + ONNX Runtime Web
```

### 2.2 ONNX 导出实战

```python
import torch

def export_to_onnx(model, sample_input, output_path):
    """导出 PyTorch 模型为 ONNX"""
    model.eval()
    
    torch.onnx.export(
        model,
        sample_input,
        output_path,
        opset_version=17,
        input_names=["input"],
        output_names=["output"],
        dynamic_axes={
            "input": {0: "batch", 1: "sequence"},
            "output": {0: "batch", 1: "sequence"},
        },
    )
    
    # 验证
    import onnxruntime as ort
    session = ort.InferenceSession(output_path)
    # 测试推理...

# ONNX 图优化:
import onnx
from onnxruntime.transformers import optimizer

optimized = optimizer.optimize_model(
    "model.onnx",
    model_type="gpt2",
    num_heads=32,

    optimization_level=2,  # 全部优化
)
optimized.convert_float_to_float16()
optimized.save_model_to_file("model_optimized.onnx")

    "典型应用": ["机器人视觉", "自动驾驶", "工业检测", "无人机"],
}

# TensorRT 优化:
import tensorrt as trt

def build_engine(onnx_path, engine_path, fp16=True):
    builder = trt.Builder(trt.Logger())
    network = builder.create_network(
        1 << int(trt.NetworkDefinitionCreationFlag.EXPLICIT_BATCH)
    )
    parser = trt.OnnxParser(network, trt.Logger())
    parser.parse_from_file(onnx_path)
    
    config = builder.create_builder_config()
    config.set_memory_pool_limit(trt.MemoryPoolType.WORKSPACE, 1 << 30)
    
    if fp16:
        config.set_flag(trt.BuilderFlag.FP16)
    
    engine = builder.build_serialized_network(network, config)
    with open(engine_path, 'wb') as f:
        f.write(engine)
```
