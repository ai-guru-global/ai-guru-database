## 1. 为什么是人形?

人形机器人 (Humanoid Robot) 之所以被视为具身智能的理想形态:

- **环境适配**: 人类社会的基础设施 (门把手、楼梯、工具) 都是为人体设计的
- **通用性**: 双足 + 双臂 = 理论上可执行任何人类能做的任务
- **替代劳动**: 劳动力短缺 + 危险岗位 = 巨大的商业需求

**与其他形态的对比**:

| 形态 | 优势 | 劣势 | 代表 |
|------|------|------|------|
| 人形 (Bipedal) | 通用、适配人类环境 | 平衡控制难、成本高 | Optimus, Figure |
| 四足 (Quadruped) | 稳定、地形适应强 | 无操作能力 | Spot, Go2 |
| 轮式 (Wheeled) | 高效、简单 | 受限于平面 | Stretch, Astro |
| 机械臂 (Arm) | 精确、成熟 | 固定基座 | Franka, xArm |
| 飞行 (Aerial) | 三维自由 | 续航短、载荷小 | 无人机 |

### 2.1 Tesla Optimus

- **定位**: Tesla 的"第二增长曲线"，目标成为最大的机器人公司
- **技术路线**: 复用 Tesla FSD 的端到端神经网络，用大规模工厂数据训练
- **进展**: 2025 年在 Fremont 工厂执行简单物料搬运和分拣任务
- **挑战**: 灵巧操作的精细度、大规模量产的可靠性

### 2.2 Figure 02

- **定位**: "OpenAI 的机器人硬件合作伙伴"
- **融资**: 2024 年融资 $6.75 亿 (OpenAI、NVIDIA、Microsoft 参投)
- **技术亮点**: VLA 驱动的自然语言指令操作、高自由度灵巧手
- **进展**: 2025 年展示咖啡制作、物品整理等复杂操作

### 2.3 Unitree (宇树科技)

- **定位**: "机器人界的大疆"——以极致性价比占领市场
- **G1**: 教育版仅 $16K，成为高校和研究机构的首选平台
- **H1**: 打破人形机器人奔跑速度记录 (3.3 m/s，2024)
- **策略**: 开源友好、社区生态、快速迭代

### 2.4 Boston Dynamics Atlas

- **转型**: 2024 年退役液压 Atlas，全面转向电动版
- **优势**: 30 年机器人控制经验、业界最强的运动能力
- **方向**: 聚焦工业场景 (汽车工厂)，与现代汽车协同

## 3. 核心技术栈

### 3.1 Locomotion (运动控制)

```
运动控制技术栈:
═══════════════════════════════════════════════════════════════

  传统方法                          学习方法
  ┌──────────────┐               ┌──────────────┐
  │ ZMP 控制     │               │ RL (PPO)      │
  │ 模型预测控制  │               │ Sim-to-Real   │
  │ 全身控制 WBC │               │ 模仿学习      │
  └──────┬───────┘               └──────┬───────┘
         │                              │
         └──────────┬───────────────────┘
                    ▼
         ┌──────────────────┐
         │  混合控制器        │
         │  RL 步态 + WBC   │
         │  力矩控制         │
         └──────────────────┘
```

**关键突破**: RL-based locomotion 在仿真中训练，通过 Domain Randomization 直接迁移到真实硬件，实现鲁棒的步态控制。

### 3.2 Manipulation (操作控制)

| 方法 | 描述 | 适用场景 |
|------|------|----------|
| VLA 端到端 | 视觉+语言 → 动作 | 通用任务、语言指令 |
| Diffusion Policy | 扩散模型生成轨迹 | 精细操作、多模态分布 |
| Imitation Learning | 从 demonstration 学习 | 重复性任务 |
| RL | 强化学习训练策略 | 力控任务、接触丰富 |
| 混合方法 | VLA 规划 + RL 执行 | 2026 主流方向 |

### 3.3 感知与导航

- **3D 感知**: RGB-D 相机 + 点云处理，物体 6DoF 位姿估计
- **SLAM**: 同步定位与地图构建，支持自主导航
- **语义理解**: VLM 驱动的场景理解 ("找到桌上的红色杯子")

## 5. 2026 趋势与挑战

### 5.1 五大趋势

1. **工厂先行**: 汽车工厂 (Tesla、BMW、现代) 成为首批部署场景，执行搬运、装配、质检
2. **VLA 驱动**: 语言指令 + 视觉理解 → 无需为每个任务编程，显著降低部署门槛
3. **中国军团崛起**: Unitree、智元、傅利叶、小鹏等以低成本 + 快速迭代路线切入市场
4. **灵巧操作突破**: 灵巧手 + VLA 使机器人可以执行倒水、拧螺丝、叠衣等任务
5. **标准化**: ROS 2 + 统一硬件接口推动生态互通

### 5.2 核心挑战

| 挑战 | 描述 | 现状 |
|------|------|------|
| 成本 | 目标 <$50K，当前多数 >$100K | 电机/传感器降本中 |
| 可靠性 | 工业要求 MTBF >5000h | 当前 ~500-1000h |
| 电池 | 需 8h+ 连续工作 | 多数 2-5h |
| 安全 | 人机协作场景的安全认证 | 标准制定中 |
| 软件生态 | 缺乏统一的开发框架 | NVIDIA Isaac 领先 |
