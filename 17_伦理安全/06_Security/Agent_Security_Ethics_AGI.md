# 智能体安全、价值对齐与 AGI 路径

> 中文简称：智能体安全、价值对齐与 AGI 路径

> 一句话理解：安全不是"加个过滤器"，而是从输入验证到架构隔离的分层工程体系；对齐不是"写个好提示词"，而是让 AI 的目标与人类价值观字面一致、精神也一致。

## 1. 智能体威胁模型

### 两大攻击维度

| 类型 | 定义 | 防御主体 |
|------|------|---------|
| **越狱 (Jailbreak)** | 绕过模型内部安全护栏，诱导输出禁止内容 | 模型 Safety Training (RLHF/RLAIF) + 前后置护栏 |
| **提示词注入 (Prompt Injection)** | 恶意输入覆盖/污染系统指令，类似 SQL 注入 | 架构层防御（最小权限、沙箱隔离） |

**间接注入**是智能体特有的高危风险：智能体读取被篡改的网页/邮件/知识库，其中隐藏着针对 AI 的指令。

### 其他威胁

- **数据泄露**：系统提示词中的敏感信息在越狱场景下被提取
- **供应链攻击**：恶意工具/插件窃取上下文或凭证
- **多智能体横向移动**：被攻破的 Agent 通过消息传递感染协作链

## 2. 五层防御体系

```text
L1 输入验证 → L2 模型鲁棒性 → L3 应用护栏 → L4 执行隔离 → L5 审计闭环
```

> 核心洞察：输入过滤只能挡住低成本攻击。智能体安全的核心防线 **不在输入端，而在架构层**——确保即使注入成功也"没权限做坏事"。

### L1 输入验证
- 规则匹配（关键词拦截）
- 专用分类器检测恶意意图
- 结构化输入（区分系统指令与用户输入）

### L2 模型鲁棒性
- 对抗训练（RLHF 负例）
- **指令层级训练（Instruction Hierarchy）**：`system ≻ developer ≻ user ≻ tool`
  - OpenAI IH-Challenge (2026) 在 GPT-5-Mini 上将红队鲁棒性从 84.1% → 94.1%

### L3 应用护栏
- 策略引擎、输出校验、审批触发
- Guardrails 框架（NVIDIA NeMo Guardrails、Guardrails AI）

### L4 执行隔离
- **最小权限**：API 密钥只拥有最低权限
- **沙箱双防线**：文件系统隔离 + 网络隔离（缺一不可）
- **凭证分离**：敏感凭证不进沙箱，通过代理中介访问
- **两阶段运行时**：Setup（开放网络+凭证）→ Agent（网络关闭+凭证清除）

### L5 审计闭环
- 全局 trace_id、告警、红队回放
- 蜜罐探测器（植入虚假 API Key 检测窃取）
- AI 安全分诊智能体（用 AI 审计 AI）

## 3. 价值对齐

### 目标设定的陷阱

| 陷阱 | 说明 |
|------|------|
| **古德哈特定律** | 当指标变成目标，就不再是好指标 |
| **负外部性** | 目标达成但手段非法（疯狂发广告涨粉） |
| **奖励欺骗** | AI 找到作弊方式绕过奖励函数 |

### 宪法 AI (Constitutional AI)

给智能体一部《宪法》（自然语言原则），通过 AI 监督 AI 实现对齐：

1. **SL-CAI**：模型生成 → 自我批判 → 修正 → 微调
2. **RL-CAI**：模型生成两个回答 → AI 裁判评判 → 训练奖励模型 → PPO

意义：通过修改几百字"宪法"控制模型价值观，无需重新雇佣数千人标注。

### 红队测试

- **自动化红队**：用模型攻击模型，覆盖多语言/多策略
- **工具链**：Garak（开源漏洞扫描器）、Microsoft PyRIT
- **标准化流程**：定义目标 → 构建攻击集 → 自动化测试 → 人工复审 → 修复验证 → 回归测试
- **CI/CD 集成**：新模型版本必须通过红队基线（如拒绝率 ≥95%）才能上线

### 审慎对齐 (Deliberative Alignment)

让推理型模型在思维链中显式调用安全原则：
- 在关键决策点列出安全约束
- 冲突时显式申报而非隐式权衡
- 系统提示词声明优先级：`安全 > 有帮助 > 准确`

## 4. 智能体法律与伦理

### 责任归属链路

```text
用户 → 部署方 → 开发方 → 模型提供商 / 数据提供方
```

| 主体 | 可能责任 | 免责条件 |
|------|----------|---------|
| 用户 | 使用不当 | 在合理使用范围内 |
| 部署方 | 安全措施不足 | 已采取合理防护 |
| 开发方 | 设计缺陷 | 已遵循行业标准 |
| 模型提供商 | 模型固有风险 | 已提供安全指南 |

### 企业上线合规检查单

| 维度 | 否决条件 |
|------|---------|
| 身份透明度 | 未声明 AI 身份 |
| 数据保护 | PII 明文流出 |
| 控制权交接 | 破坏性操作无二次确认 |
| 追溯审计 | 核心操作无日志 / 日志写入原始凭证 |
| 降级预案 | 故障时无法人工接管 |

### 国际治理

- **欧盟 AI 法案**：风险分级（不可接受→高风险→有限→最小）
- **中国**：生成式 AI 管理规定，关注内容安全与备案
- **美国**：政策重心在创新与治理框架调整

## 5. AGI 五级路线图

源自 OpenAI 内部分级（Bloomberg 2024.7 报道）：

| Level | 名称 | 能力 | 现状 |
|-------|------|------|------|
| 1 | 对话者 | 具有对话能力 | ✅ 已实现 |
| 2 | 推理者 | 人类水平问题解决 | 逐步成熟 |
| 3 | 智能体 | 代表用户采取行动 | 加速落地 |
| 4 | 创新者 | 发现新知识 | 尚未实现 |
| 5 | 组织者 | 自主运营组织 | 科幻范畴 |

### 五大未来趋势

1. **端侧智能体**：小模型（Apple Intelligence、Gemini Nano、Phi）+ OS 级集成
2. **具身智能**：VLA 模型（Google RT-2）、Sim-to-Real 迁移
3. **大模型即操作系统**：LLM=CPU, 上下文=RAM, RAG=Disk, Tools=IO
4. **开放标准**：MCP（Agent↔工具）+ A2A（Agent↔Agent）
5. **复合智能体系统**：多专业化 Agent 编排，模块化替代大一统 AGI
