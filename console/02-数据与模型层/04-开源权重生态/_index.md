# 开源权重生态

> Qwen/DeepSeek/GLM/Llama 等开放权重阵营：把模型变成公共品，改写定价权；Hugging Face 被收购后社区治理进入巨头时代。

## 拆解卡

- **价值来源**：把模型变成公共品，改写定价权与地缘供给格局。
- **护城河**：社区生态、迭代速度与多语种覆盖。
- **瓶颈**：推理成本与商业化闭环——谁为开源买单尚未定型。
- **领先指标**：开源与闭源的智能指数差距；权重下载量与衍生模型数

## 六层速览

开源权重把模型参数公开，让任何人自部署、微调和二次开发，从而改写定价权与供给格局；它把「模型」从服务变成可复制的商品。

**打个比方**：像安卓开放源代码——厂商可以自由定制，但生态治理与商业化仍由几个关键玩家主导；自由度与可控性换来的是责任自担与运维成本。

**拆开看**：四段链路：权重（Llama / Qwen / DeepSeek / GLM）→ 许可证（Apache / MIT / 自定义）→ 社区分发（Hugging Face / 魔搭）→ 推理与微调工具链；许可证条款决定商用边界与再分发权利。

**怎么运转**：大厂用开源换生态与人才，云厂商靠托管开源模型赚钱，创业公司做微调与部署服务；权重免费，钱从托管、支持与集成里赚，纯模型本身很难收费。

**格局与博弈**：Meta Llama 与阿里 Qwen 是两大阵营，DeepSeek 以性价比破局，Mistral 代表欧洲；Hugging Face 成为分发枢纽，许可证从宽松走向「开放但有限制」，反云厂条款开始出现。

**边界与走向**：开源与闭源的能力差距在缩小，但「谁为开源买单」仍未解；许可证与安全审查会收紧，企业采用会更多集中在可审计、可私有化的方案上，监管也可能要求开源模型承担部分安全义务。

## 关键判断

开源是长期结构性力量，但变现集中在托管与集成层（置信度 中高，展望 12–24 个月）——核心变量是能力差距与许可策略；私有部署的确定性高于托管价格战。

规模口径：开源模型托管与私有部署约 $150–300 亿（2025e），含云托管、一体机与集成服务

## 二级细分

- **旗舰开源家族** — Llama/Qwen 生态，大厂开源换影响力
- **高效开源** — DeepSeek/Mistral，性价比路线
- **微调与垂直生态** — 行业模型与本地化部署的衍生层
