# 成本管理

> 中文简称：成本管理 ｜ English: Cost Management

## 本文件夹定位

本目录聚焦 **LLM 推理的成本工程**——降低 Token 成本的系统性方法，覆盖模型路由、Prompt 缓存、量化、批处理、供应商选择等降本杠杆。回答的是"怎么跑得更省"。

与相邻目录的边界：降本的技术手段（缓存/量化）原理见 [03_推理优化](../03_推理优化/README) 与 [04_模型量化](../04_模型量化/README)；本目录是这些技术的**成本视角**应用。运维侧的成本管理另见 [11_模型运维](../../11_模型运维/README)。

## 降本杠杆速查

| 杠杆 | 降本幅度 | 实现难度 | 说明 |
|------|----------|----------|------|
| **Prompt 缓存** | 高（命中即免费） | 中 | 前缀/语义缓存复用 |
| **模型路由** | 高 | 中 | 简单任务走小模型 |
| **批处理（Batch API）** | 高（~50%） | 低 | 非实时任务批量提交 |
| **量化** | 中（显存/算力） | 中 | INT4/INT8 压缩 |
| **供应商选择** | 中 | 低 | 云 API 价格对比 |
| **Prompt 精简** | 中 | 低 | 减少输入 token |
