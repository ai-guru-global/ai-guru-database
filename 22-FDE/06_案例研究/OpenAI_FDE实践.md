# OpenAI FDE 实践

## OpenAI Deployment Company（2025.09）

OpenAI 于 2025 年 9 月启动 **Deployment Company**，标志大模型公司正式进入 FDE 时代。

## 为什么 OpenAI 需要 FDE？

```
OpenAI 的困境：
├── API 很强，但客户不知道怎么用
├── 企业客户需要私有化/定制化
├── 售前只能做 demo，不能真交付
└── 不帮客户落地 = 客户流失到竞对

解决方案：自己建 FDE 团队
```

## OpenAI FDE 的工作方式

1. **嵌入式团队**：派 2-5 人团队驻客户现场 3-6 个月
2. **平台支撑**：基于 OpenAI API + 内部工具链
3. **行业聚焦**：金融（高盛）、医疗、法律、制造
4. **收费模式**：高额服务费 + API 消费绑定

## 对中国 FDE 的启示

| OpenAI 做法 | 可借鉴之处 |
|---|---|
| 大模型公司亲自做 FDE | 大厂会跟进，创业公司需差异化 |
| 与咨询公司合作（Accenture） | 中国可与四大/本土咨询合作 |
| 聚焦高价值行业 | 不要泛化，深耕 1-2 个行业 |
| 高举高打定价 | 中国可按行业/规模分级定价 |

---

> **OpenAI 做 FDE = 行业信号**：大模型公司自己下场了，证明仅靠 API 不够。这对 FDE 创业公司既是威胁也是机会——威胁是大厂竞争，机会是市场被教育、需求被激活。
