# GPU 与 AI 加速卡

> 通用 AI 算力的主要供给形态，英伟达居垄断位，AMD 追赶。

## 拆解卡

- **价值来源**：一切智能供给的物理入口，训练与推理需求叠加放量。
- **护城河**：CUDA 软件生态 + 互连全栈（NVLink/InfiniBand）双重锁定。
- **瓶颈**：先进制程与 CoWoS 封装产能、HBM 配给。
- **领先指标**：数据中心 GPU 出货量与交期；云厂商资本开支指引

## 六层速览

GPU 与 AI 加速卡是 AI 的算力发动机：用成千上万个并行计算核心同时做矩阵乘加，训练和运行大模型都靠它把参数从数据里「算」出来。

**打个比方**：像把「一位老师挨个讲题」改成「几百位助教同时批改同一类题」——单个人不一定更快，但同一时间能处理的题量高出一个数量级；GPU 就是那间大教室。

**拆开看**：一颗加速卡 = 计算单元（SM / Tensor Core）+ 高带宽显存（HBM）+ 片间与机间互连（NVLink / PCIe / InfiniBand）+ 软件栈（CUDA / ROCm）；再往上拼成八卡服务器、整机柜，最后连成万卡集群。

**怎么运转**：芯片厂卖卡与整机柜，云厂商买卡按卡时或 token 出租，模型公司用算力换能力、再把能力按 token 卖出去；成本沿「制程—封装—HBM—电力」逐层传导，利用率决定每一层能否赚钱，整机柜交付能力决定扩产速度。

**格局与博弈**：英伟达用 CUDA 生态、NVLink 与整机柜方案锁定高端训练；AMD 以开放软件栈（ROCm）追第二极；云厂商自研 ASIC 分流推理负载；中国厂商在出口管制下做国产替代，差距主要在软件生态与先进封装产能。

**边界与走向**：单卡性能提升放缓，竞争转向系统级（机柜 + 网络 + 供电）与软件生态；推理占比上升会把价值从「卖卡」推向「卖单位 token 成本」，通用 GPU 与专用 ASIC 将长期分层共存，同样的芯片靠系统优化能多跑出三成有效算力。

## 关键判断

结构性偏多，但估值对资本开支周期敏感（置信度 中高，展望 12–24 个月）——核心变量是推理需求斜率与 ASIC 分流速度；供给瓶颈缓解前，头部定价权难被撼动。

规模口径：全球 AI 加速器约 $2000–2500 亿（2025e）；其中数据中心 GPU/加速卡约 $1800–2200 亿，整机柜与系统集成另计 $300–500 亿

## 二级细分

- **训练旗舰卡** — B/H 系旗舰与整机柜形态，服务前沿训练与大规模后训练。
- **推理与性价比卡** — 低精度、高吞吐路线（Ultrafast 类），推理成本曲线的硬件端。
- **机柜与互连方案** — NVLink 机柜、整机柜交付：卖点从单卡转向系统级吞吐。
