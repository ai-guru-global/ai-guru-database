# 观测云

> 一体化可观测平台的国产样本（运营主体上海观测未来信息技术有限公司，曾用名驻云信息，2013 年起家做阿里云生态 MSP）：DataKit 开源采集器 × GuanceDB 自研存储 × DQL 查询，产品结构与 Datadog/Dynatrace 同构而价格按中国市场校准；2026-10 完成近亿元 A 轮 + A+ 轮（方广资本领投）独立运营；官网口径已从监控平台升维为「AI 时代的监控观测与数据安全基础服务」——让运维与智能体的行动都被看见。

## 是什么

**主体与定位**：运营主体为**上海观测未来信息技术有限公司**（成立 2013-07-17，注册资本 1170.57 万元，法定代表人/实控人**蒋烁淼**，直接持股约 8.6%，另通过上海入云合伙平台控制表决权 ✅ 启信宝/水滴信用实抓，工商原文以公示系统为准 🔍），**曾用名「上海驻云信息科技有限公司」（至 2022-11-04 更名）** ✅。官网版权署名则是「上海观测云信息科技有限公司」（沪 ICP 备 2026050424 号）✅——官网与工商双署名并存，多主体结构是核对一切口径的前置项。官网定位「AI 时代统一的监控观测与数据安全基础服务」，口号「让数据说话，让 AI 感知，让人决策，让 Agent 行动」✅；自称 200+ 员工、500+ 全球客户、650+ 技术栈集成、PB 级/百万级 QPS 写入 ✅，而工商口径 2025 年社保参保仅 29 人 ⚠️——差额大概率由关联主体代缴 🔍 待核。别名规约中的「高瓴智维」经 Bing/搜狗/360 检索均未获得与观测云的关联证据 🔍。

**沿革：MSP 现金流孵化产品，产品反哺主体改名。** 2013 年成立的驻云是阿里云生态 MSP/云管理服务商，股东名单至今保留这段历史：浙江阿里巴巴云计算 10.55%、红杉系合计约 9%、复星关联的复银瑆合 11.60%、张江燧锋 7.61%、深创投、华业天成、云九资本等共 22 名股东 ✅ 工商快照口径。内部孵化可观测产品线 **DataFlux**（Gitee 组织 dataflux 自述「云时代的系统可观测平台」，安卓包名 com.cloudcare.ft.dataflux.mobile 亦是痕迹 ✅），品牌升级为「观测云」的确切时点未获一手源 🔍；2022-01 驻云科技宣布完成 2 亿元 D 轮（华业天成领投、深创投/云九跟投），全面转向「以观测云为核心」的布局，阿里云合作业务由全资子公司承接 ⚠️ 二手转载口径；2022-11 工商落点：主体更名观测未来 ✅；2025-04 复星高科技集团退出直接持股、复银瑆合接替 ⚠️。

**产品结构：采集开源、存储自研、平台按量计费。** ① **DataKit**——MIT 开源采集器（Go，GitHub 305 stars，2026-11-12 实抓），单点部署覆盖主机/Docker/K8s DaemonSet/边缘/IoT ✅；端侧 SDK 家族铺满 iOS/Android/**鸿蒙**/Flutter/RN/Cocos/Electron（GitHub 组织 168 仓库）✅；② **GuanceDB**——自研可观测数据基础设施（官网当前版本 3.1）✅；③ 统一数据栈收拢 Metrics/Traces/Logs/Profile/RUM，DQL & API 查询，FlowPort 数据管道 ✅。这套「OneAgent × Grail × DQL」的结构同构见 [[开发者工具/Dynatrace]]——差别在开源策略：DataKit 开源是获客漏斗，OneAgent 是闭源锁定。

**兼容路线：OpenTelemetry 全语言 + Datadog 生态 fork。** OTel 接入是官方一级解决方案，文档覆盖 Java/Python/Go/Node.js/PHP/.NET/Ruby/Rust/C++ ✅；LLM 可观测方案自述「基于 OpenTelemetry 等开放能力采集调用、Token、延迟、错误、Trace 和日志」✅。GitHub 组织内有 dd-trace-java/dd-trace-go 的 fork 与 dd-go-patches 补丁仓库、opentelemetry-java-instrumentation fork ✅——对 Datadog 生态数据接入做兼容改造 ⚠️ 用途为合理推断。逻辑与 Dynatrace 的 OpenPipeline 一致：**采集边界开放（OTel），平台层收拢（自研存储 + 专属查询语言）**。

**AI 时代定位：从「运维的 AI 助手」跳到「Agent 行动的观测层」。** 官网六大板块中 AI 独立成线：AI Agent 可观测、**AgentMeter**（Token 用量计量客户端——官网公开自家全员 Token 计数 2,273,026,159 TOKENS @ 2026-11-12，自证「AI Native」✅）、Obsy AI Copilot、OWL CLI、MCP Server、AI 语义监控器、**ABA 智能体行为安全监控**、观测 AI 智能体团队 ✅；关于页表述「智能体的行动都需要被看见」✅。Obsy AI 已商业化：Pro ¥999 / Team ¥2999 套餐，Credits 中国区 ¥0.25/10 ✅ 计费文档。方向与 Dynatrace Intelligence（2026-01 的 agentic 运维）同向，但观测云把「Agent 被监控」的安全叙事放在了更前面 ⚠️ 概念先于公开客户实证 🔍。

**商业模式：公有云按量 + 私有化 License 双轨。** 商业版以工作空间为计费单元、按天结算（每日零点结前一日）✅；计费项 20+（指标按千万数据点、日志按百万条/天或 GB/天、Trace 按 trace_id 去重百万级/天、RUM 按万 PV、会话重放、拨测、安全扫描、短信/电话告警等），**梯度计费——单价与数据存储时长绑定** ✅；支持华为云/阿里云/AWS/微软云账单代扣，入驻 AWS/Azure/GCP/阿里云/华为云/腾讯云/火山引擎云市场 ✅；文档站另有私有化部署独立章节（License 申请 + 部署手册）✅，企业版定制报价不公开 🔍。

**客户结构与「信创口径」核验：是出海泛互零售，不是政企信创。** 官网具名案例集中于零售餐饮（安踏统一 100+ 核心系统、美宜佳、杨国福、皮爷咖啡）、车企（极氪、长安）、制造（通力电梯、圣戈班、云鲸、极飞）、出海科技（传音、晨星 Morningstar、康福德高 CDG、南非 DStv）、金融科技（金保信、晶泰科技）✅；**无互联网大厂、无具名政务/信创客户** ✅ 页面口径；信创侧仅有鸿蒙 SDK、市级专精特新（⚠️ 二手）、信通院可观测性平台「先进级」认证（⚠️ 启信宝简介口径 🔍）等间接信号。营收/ARR 未公开 🔍——本卡所有规模数字均为官网自述口径。

## 怎么看

1. **先核主体，再谈规模。** 观测未来（工商主体）、观测云信息科技（官网版权署名）、驻云系子公司（MSP/DMS 业务）三个名字在 2026-10 融资报道里同时出现：「200+ 员工」对 2025 年社保 29 人、「500+ 客户」无营收佐证——每个数字都要先问挂在哪个主体 🔍。这不是挑剔：D 轮（2022-01，2 亿元）与 A 轮（2026-10，近亿元）的轮次序列重构本身就说明中间发生过业务拆分与报表重组，两笔融资不可直接比大小 ⚠️。
2. **产品是 Datadog/Dynatrace 的结构同构 + 中国校准，开源是获客漏斗而非信仰。** DataKit（MIT）开源 + GuanceDB/DQL 闭源收拢，与 Dynatrace「OneAgent 闭源 + Grail 收拢」相反，与 Datadog「Agent 闭源」也相反——在 Datadog/Dynatrace 进不来（且贵）的市场里，开源采集器是低成本触达开发者的唯一通道；计费真金在平台侧「数据量 × 存储时长」的梯度账单 ✅。
3. **OTel 全兼容是弱势者的理性，不是开放信仰。** Datadog 可以对 OTel 半推半就（自有 Agent 已遍地），Dynatrace 用 OpenPipeline 吃 OTel 再锁 DQL；观测云没有自有标准的输出能力，全语言 SDK + Datadog trace 库 fork 兼容 ✅ 是唯一解——代价是平台层差异化只剩中国云生态集成、本地服务与价格，且同赛道（博云、云杉 DeepFlow、乘云 DataBuFF、嘉为蓝鲸等）打法趋同 🔍 未逐一核验当期产品矩阵。
4. **AI 叙事选了「让 Agent 行动被看见」的治理位，产品化领先、商业化未验证。** ABA 行为安全监控 + AgentMeter + Obsy AI 套餐已上架 ✅，与 Dynatrace Intelligence 的 agentic 运维同向；但官网尚无一个具名 AI 可观测客户 🔍，Obsy AI 定价（¥999–2999）是试探性低价 ⚠️ 推断。「监控 LLM 应用的 Token/成本/质量」是可见的近期需求，「监控 Agent 的行为安全」是概念超前的远期需求——两条线的兑现节奏会被市场混为一谈，须分开验证。
5. **客户结构证伪「信创大单」叙事：它吃的是出海与泛互零售的预算。** 具名案例零政务、零互联网大厂 ✅；新加坡办公室 + 全球 10+ 节点/60+ 国家 + 融资资金用途含海外拓展 ✅/⚠️——战略重心在「中国企业出海」而非「国产替代信创采购」。信创目录与政务侧目前只有鸿蒙 SDK 和认证类背书 🔍；若未来宣称信创大客户，先查主体与部署形态（大概率是私有化 License 而非 SaaS）。
6. **台内观察价值：可观测国产赛道的「中国价格曲线」样本，反方两把剑同样真实。** 与 [[开发者工具/Dynatrace]]（结构同构的对标方）、[[开发者工具/New Relic]]（上市可观测厂商的财务参照系）、[[开发者工具/ServiceNow]]（事件流向 ITSM 收敛的另一种路径）互为坐标系。反方：① 同质化——赛道融资消息密集（如乘云数字 DataBuFF 数千万元 A 轮，2023-11，36kr/投资界口径 ⚠️ 检索快照）；② SaaS 付费意愿——它自己的客户案例以「日志费用省 1/3」「综合成本省 30%」为卖点 ✅，恰说明按量账单的增长前提（客户数据量持续膨胀）与客户预算收缩的直觉相互矛盾，续费率/净收入留存是它不公开但最该盯的数字 🔍。
