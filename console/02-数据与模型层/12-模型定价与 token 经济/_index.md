# 模型定价与 token 经济

> 每百万 token 的定价体系是智能的价格发现机制，降价即行业信号。

## 拆解卡

- **价值来源**：智能的价格发现机制：降价本身就是行业信号。
- **护城河**：成本曲线领先对手一个身位。
- **瓶颈**：价格战下毛利与差异化的平衡。
- **领先指标**：旗舰与快速档价差；每任务成本基准（AA 口径）

## 六层速览

模型定价与 token 经济决定智能的价格：每百万 token 多少钱，直接决定模型公司怎么赚钱、应用公司能不能活；它是 AI 产业的「利率」。

**打个比方**：像水电按度计价——单价下降会刺激用量爆发，但也会压垮没有成本优势的供应商；价格战打的是成本曲线，不是勇气。

**拆开看**：五段链路：输入 / 输出定价 → 缓存与批量折扣 → 推理成本（算力 + 电力 + 折旧）→ 毛利结构 → 每任务成本；输出 token 通常比输入贵数倍。

**怎么运转**：旗舰模型高价锚定品牌，快速档降价抢量；API 价格战此起彼伏，企业合同按用量阶梯定价，缓存命中率直接影响账单，批处理能把成本再压一半。

**格局与博弈**：头部 lab 用规模摊薄成本，开源模型压低价格天花板，云厂商用捆绑折扣抢客户；中国市场价格战更激进，免费额度成为获客手段，长期靠生态与增值服务回收。

**边界与走向**：定价会从「按 token」转向「按任务 / 按结果」，推理成本下降会让更多场景跨过经济性阈值；毛利会向调度效率与分发环节迁移，单纯卖 token 的中间商会被挤掉。

## 关键判断

量增价减是常态；赢家不是单价最低者，而是能把 token 转化为任务价值并向席位/结果计价迁移的一方（置信度 中高，展望 12–24 个月）——核心变量是 Agent 计价方式与企业预算迁移速度；单价下降本身不是负面信号，需与 token 量同步观察。

规模口径：全球模型 API 与订阅约 $400–600 亿（2025e），其中订阅折算占一半以上

## 二级细分

- **牌价与分档** — 旗舰锚品牌、快速档抢量
- **缓存与批量折扣** — 命中率直接影响账单与毛利
- **按结果计费** — 从按 token 走向按任务定价的试验
