# 白辰甲 2026 动态 (Jinze Bai 2026 Update)

> 中文简称：白辰甲 2026 动态

## 一句话概括

> 2026 年的白辰甲领导阶跃星辰（StepFun）以多模态大模型为核心战略，从 Step-1 文本模型到 Step-1V/Step-2 多模态旗舰，走出了与"纯文本效率派"不同的"多模态基座 + Agent"路线；而他此前在阿里通义千问（Qwen）团队的积累，使其成为兼具大厂基座经验与创业灵活性的代表人物。

---

## 人物/事件概述

### 背景回顾

白辰甲，曾任阿里云通义千问（Qwen）团队核心负责人，后创办/领导阶跃星辰（StepFun）。在 Qwen 期间，他参与打造了 Qwen 系列从 7B 到大规模 MoE 的完整模型家族，以 Apache 2.0 开源和 119 种语言覆盖闻名。这段经历让他积累了大规模预训练、多语言、开源生态的丰富经验，为阶跃星辰奠定技术基础。

#### 关键时间线

| 时间 | 事件 | 战略意义 |
|------|------|----------|
| 2023.08 | Qwen-7B 发布（阿里期间） | 开源基座 |
| 2023-2024 | Qwen 系列扩展（多尺寸/多语言） | 全球活跃开源生态 |
| 2024 | 阶跃星辰（StepFun）创业 | 多模态基座路线 |
| 2024 | Step-1 文本模型 | 基座起步 |
| 2024-2025 | Step-1V / Step-1Flash 多模态 | 视觉语言能力 |
| 2025 | Step-2 旗舰模型 | 架构升级 |
| 2026 | 多模态 + Agent 平台化 | 全栈竞争 |

### 2026 年的白辰甲

- **多模态创业者**: 阶跃星辰以多模态为核心差异化
- **大厂经验加持**: Qwen 经验使其熟悉大规模训练与开源运营
- **开源生态理解者**: 深知开源对建立开发者社区的价值
- **中国 AI 创业代表之一**

## 核心内容

### Qwen 遗产：多语言开源基座

白辰甲在 Qwen 期间的贡献奠定了其技术声誉：

| Qwen 维度 | 特点 |
|-----------|------|
| 尺寸梯度 | 0.6B 到 235B+ 全尺寸，从端侧到旗舰 |
| 语言覆盖 | 119 种语言/方言，全球最广 |
| 开源许可 | Apache 2.0，最宽松 |
| 生态 | HuggingFace/ModelScope 高下载量 |

> 详见 [[05_大模型/15_Chinese_LLM_Ecosystem/Chinese_LLM_Comparison_Matrix|中国大模型对比矩阵]]。

### 阶跃星辰（StepFun）：多模态战略

阶跃星辰的核心战略是"多模态基座"，区别于纯文本路线：

| 模型 | 类型 | 定位 |
|------|------|------|
| Step-1 | 文本 | 基座起步 |
| Step-1V | 视觉语言（VLM） | 多模态理解 |
| Step-1Flash | 轻量高效 | 端侧/高吞吐 |
| Step-2 | 旗舰 | 架构升级 |

多模态能力关联 [[04_计算机视觉/08_Multimodal_Vision/Vision_Language_Models_2026|视觉语言模型]]。

### 多模态 + Agent 方向

2025-2026 年阶跃星辰向 Agent 方向延伸：

- **多模态 Agent**: 结合视觉理解与任务执行
- **工具调用**: Step 模型支持 function calling
- **长上下文**: 支持较长上下文用于复杂任务

## 技术观点/行业立场

### 多模态是基座的核心能力

白辰甲认为，单一文本模型的天花板有限，多模态理解是通用智能的必要条件。阶跃星辰从创立就押注多模态。

### 开源建立生态

在 Qwen 的经历让白辰甲深信开源的力量——开源权重能吸引开发者、获得真实反馈、形成数据飞轮。

## 核心术语速查

| 术语 | 含义 | 关联概念 |
|------|------|----------|
| Loss Function | 衡量预测与真实值差距 | 交叉熵/MSE/对比损失 |
| Gradient Descent | 沿负梯度方向更新参数 | SGD/Adam/学习率 |
| Overfitting | 模型在训练集过好但泛化差 | 正则化/Dropout/早停 |
| Batch Size | 每次更新的样本数 | 收敛速度/显存/噪声 |
| Epoch | 完整遍历训练集一次 | 训练轮次/早停 |
| Fine-tuning | 在预训练模型上继续训练 | 迁移学习/LoRA/全量 |
| Inference | 模型前向传播产生输出 | 延迟/吞吐/量化 |
| Token | 文本处理的最小单元 | BPE/SentencePiece |
