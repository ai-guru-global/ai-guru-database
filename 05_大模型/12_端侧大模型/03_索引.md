# Edge LLM

> 中文简称：端侧大模型 ｜ English Name: Edge LLM

边缘大模型（Edge LLM）— 端侧 LLM/SLM 部署、模型压缩（model compression）与边缘推理优化（edge inference optimization）。

## 子域简介

本子域聚焦端侧 LLM 部署技术：

- **模型压缩**: 量化、剪枝、蒸馏
- **端侧推理**: 手机/PC/嵌入式设备
- **小语言模型**: SLM (Phi, Qwen-0.6B, Gemma)
- **优化技术**: KV Cache、推测解码

## 核心概念速查

| 概念 | 说明 | 代表技术 |
|------|------|------|
| 量化 | 降低数值精度 | INT8/INT4/GPTQ |
| 剪枝 | 移除冗余参数 | SparseGPT |
| 蒸馏 | 小模型学习大模型 | TinyLlama |
| SLM | 小语言模型 | Phi-4, Qwen3-0.6B |
| NPU | 神经网络处理器 | 手机/PC 端侧加速 |
