# GitHub Copilot 概览

> **一句话理解**: 全球使用最广泛的 AI 编程助手,提供实时代码补全、Chat 对话和 Agent 模式。

## 产品版本

| 版本 | 定价 | 特点 |
|------|------|------|
| Free | 免费 | 有限补全和聊天 |
| Pro | $10/月 | 无限补全,更多模型 |
| Business | $19/人/月 | 团队管理,策略控制 |
| Enterprise | $39/人/月 | 企业安全,自定义模型 |

## 核心功能

### 代码补全
- 实时建议下一行/下几行代码
- 基于上下文理解意图
- 支持所有主流编程语言

### Chat 对话
- IDE 内的 AI 对话
- 代码解释、重构建议
- 调试辅助

### Agent 模式
- 自主规划和执行任务
- 跨文件修改
- 自动运行测试

## 支持的 IDE

- VS Code (最深度集成)
- JetBrains 系列
- Neovim
- Visual Studio
- Xcode

## 与其他工具对比

| 维度 | Copilot | Cursor | Claude Code |
|------|---------|--------|-------------|
| 类型 | 插件 | 独立 IDE | CLI Agent |
| 补全 | 强 | 极强 | 无(对话式) |
| Chat | 有 | 有 | 有 |
| Agent | 基础 | 强 | 极强 |
| 价格 | $10/月 | $20/月 | 按 token |
