核心特性

从采集到知识沉淀，全部本地完成。

✨ 灵感模式

自动捕获 Show HN 上的新产品/新项目，保存到本地知识库，随时激发创意。

TUI 收件箱

基于 Bubble Tea 的交互式终端，j/k 翻页，r/s/d/a 秒级处理文章。

多源采集

HN / Reddit / V2EX API + 网页提取，实时获取 8 个高质量源内容。

LLM 增强

自动生成中文摘要、技术标签、质量评分（0-10）和语言检测。

智能策展

基于质量评分和阅读偏好，自动生成「今日必读」清单。

本地知识库

SQLite + FTS5 全文检索，所有数据本地存储，构建属于你的技术资产。

RAG 问答

基于本地知识库回答技术问题，自动标注引用来源，无需上传数据。

断舍离

批量归档、自动清理、语义去重、订阅健康度——保持收件箱整洁。
