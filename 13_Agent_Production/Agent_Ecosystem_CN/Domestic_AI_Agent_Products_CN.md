## 3. Kimi (Moonshot)

### 3.1 核心定位

```
Kimi: 长上下文专家
═══════════════════════════════════════════════════════════════════════════

月之暗面 (Moonshot AI) 推出的 AI 助手:

核心优势:
───────────────────────────────────────────────────────────────────────────
• 20 万字超长上下文 (业界领先)
• 强大的中文理解能力
• 文件解析能力 (PDF, Word, Excel)
• 网页内容理解
• 年轻化产品定位
```

### 3.2 核心特性

| 特性 | 描述 |
|------|------|
| **长上下文** | 20 万字，业界领先 |
| **多模态文件** | PDF, Word, Excel, PPT, 图片 |
| **搜索增强** | 实时联网搜索 |
| **Kimi+** | 插件生态 |
| **API** | Kimi API 开放平台 |

### 3.3 使用场景

```
Kimi 典型场景
═══════════════════════════════════════════════════════════════════════════

场景 1: 长文档分析
───────────────────────────────────────────────────────────────────────────
上传: 100 页 PDF 合同 / 200 页论文 / 年报
Kimi: 总结要点、提取关键信息、回答问题

场景 2: 代码辅助
───────────────────────────────────────────────────────────────────────────
粘贴: 完整代码文件或项目结构
Kimi: 解释代码、找 Bug、生成测试

场景 3: 内容创作
───────────────────────────────────────────────────────────────────────────
输入: 主题 + 要点
Kimi: 生成文章、润色、扩写
```

### 3.4 Kimi API

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-kimi-api-key",
    base_url="https://api.moonshot.cn/v1"
)

response = client.chat.completions.create(
    model="moonshot-v1-128k",
    messages=[
        {"role": "user", "content": "分析这份合同的关键风险点"}
    ],
    max_tokens=2000
)
```
