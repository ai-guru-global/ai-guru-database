# Robotics Engineer 题库

> **难度标注**: ⭐ Basic | ⭐⭐ Intermediate | ⭐⭐⭐ Advanced
> **频率标注**: 🔴 高频 | 🟡 中频 | 🟢 低频

> 机器人工程师（AI 方向）处于传统机器人学与具身智能（Embodied AI）的交汇点，既要懂运动学/动力学/控制等经典内容，又要掌握 SLAM、VLA、sim-to-real 等新范式。本题库兼顾传统工程与现代 AI，重点考查"能否把模型部署到真实硬件并稳定运行"。相关背景见 [[06_强化学习/05_Robotics_Embodied_AI/index|机器人具身智能]]。

## 高频问题与应答策略

| 问题类型 | 典型问题 | 应答策略 |
|----------|----------|----------|
| 概念题 | 解释逆运动学/SLAM/MPC | 定义 + 原理直觉 + 公式/几何 + 适用场景 |
| 对比题 | A* vs RRT；PID vs MPC；ROS vs ROS2 | 维度对比 + 适用场景 + 选型建议 |
| 设计题 | 设计一个导航/抓取/VLA 系统 | 需求拆解 + 模块设计 + 权衡 + 失败兜底 |
| 经验题 | sim-to-real 或真机失败经历 | STAR 法则 + 量化结果 + 反思 |
| 开放题 | 看待具身智能/机器人基础模型趋势 | 现状 + 优势/瓶颈 + 落地判断 |

## 面试评分维度

| 维度 | 优秀表现 | 一般表现 | 不佳表现 |
|------|----------|----------|----------|
| 经典基础 | 运动学/控制推导扎实 | 知道概念但推不动 | 概念模糊/错误 |
| 系统思维 | 感知-规划-控制全链路考虑 | 只懂单模块 | 忽略闭环与约束 |
| AI 前沿 | 熟悉 VLA/sim-to-real 最新进展 | 听过但讲不深 | 与 AI 方向脱节 |
| 工程落地 | 在真机上跑过完整系统 | 只在仿真验证 | 无动手经验 |
| 表达能力 | 逻辑清晰、公式与直觉并重 | 能讲但发散 | 混乱、答非所问 |

## 检查清单

- [ ] 运动学（正/逆）与坐标变换能熟练推导
- [ ] SLAM 前后端、激光/视觉 SLAM 优劣能讲清
- [ ] A*/RRT/MPC/PID 原理与适用场景熟悉
- [ ] 至少准备 1 个导航 + 1 个抓取的系统设计
- [ ] 理解 sim-to-real gap 与 domain randomization
- [ ] 了解 VLA（RT-2/OpenVLA）与具身智能最新进展
- [ ] 有 ROS/ROS2 与仿真环境的实操经验
- [ ] 准备 1-2 个真机调试/失败的实战故事
