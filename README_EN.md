```bash
# Clone the repository
git clone https://github.com/your-org/ai-guru-knowledge-base.git

# Navigate to docs
cd ai-guru-knowledge-base/docs

```

```bash
cd ai-guru-knowledge-base/Web
npm install
npm run dev
# Visit http://localhost:3055
```

Import into NotebookLM, ima, Claude Projects, etc.:

```bash

curl -L -o ai-guru.zip https://github.com/your-org/ai-guru-knowledge-base/archive/refs/heads/main.zip
```

## 💾 Download for Local Tools

AI Guru serves as high-quality corpus for various AI tools:

### NotebookLM (Google)

1. Visit [notebooklm.google.com](https://notebooklm.google.com)
2. Create new project
3. Select "GitHub" or upload ZIP
4. Paste repo URL: `https://github.com/your-org/ai-guru-knowledge-base`
5. NotebookLM will analyze all documents automatically

### ima (Tencent)

1. Open ima app
2. Create knowledge base
3. Import local folder
4. Select downloaded `docs/` directory
5. Query via conversational interface

### Claude Projects / ChatGPT GPTs

```bash
# Download lite version (core content only)
git clone --depth 1 --filter=blob:none --sparse https://github.com/your-org/ai-guru-knowledge-base.git
cd ai-guru-knowledge-base
git sparse-checkout set docs/00_AI_Introduction docs/04_NLP_LLMs docs/07_AI_Engineering

# Package for upload
zip -r ai-guru-core.zip docs/
```

### Obsidian / Notion

All documents are Markdown, directly importable:
- **Obsidian**: Open repo as Vault
- **Notion**: Use Notion import tool for bulk Markdown import

## 🤖 Agent-Friendly

Optimized for AI Agent consumption:

- ✅ **Structured Metadata**: Title, description, tags, difficulty in each doc
- ✅ **Clear Hierarchy**: Chapter-document-paragraph structure
- ✅ **Executable Code**: Runnable code examples
- ✅ **Bilingual**: Technical terms in English for concept clarity
- ✅ **Complete Citations**: Papers and data sources clearly annotated
- ✅ **Version Control**: Git history for traceable updates

**Recommended Agent Usage**:
1. Import entire `docs/` directory as knowledge base
2. Use file paths for context reference (e.g., `05_大模型/05_LLM_Architectures/LLM_Architectures.md`)
