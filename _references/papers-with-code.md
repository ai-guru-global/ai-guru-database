# Papers with Code

> **一句话理解**: 论文+代码+排行榜的综合平台,追踪各领域 SOTA 结果,是 AI 研究者的核心工具。

## 平台概况

- **网站**: [paperswithcode.com](https://paperswithcode.com/)
- **功能**: 论文检索、代码查找、SOTA 排行榜

## 核心功能

- **论文浏览**: 按领域/任务分类的论文列表
- **代码链接**: 每篇论文关联的开源实现
- **SOTA 排行榜**: 各任务的最先进结果对比
- **数据集**: 常用数据集的索引和统计
