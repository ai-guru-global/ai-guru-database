# Manus 使用指南

> **一句话**: Manus 是通用型 AI Agent 平台，Pro 订阅每月 12,000 积分，适合独立任务交付（如 FOMO 项目）。

---

## 1. 概述

### 定位

| 维度 | 说明 |
|------|------|
| **类型** | 通用型 AI Agent 平台 |
| **订阅等级** | Manus Pro |
| **适用** | 独立项目交付、自动化任务、数据分析 |
| **官网** | https://manus.im |

### 核心能力

```
Manus Agent:
├── 自主任务执行
│   ├── 目标理解与分解
│   ├── 多步骤自动执行
│   └── 结果验证与交付
├── 工具使用
│   ├── 浏览器操作
│   ├── 文件处理
│   ├── 数据分析
│   └── API 调用
└── 协作模式
    ├── 单 Agent 深度任务
    └── 多步骤工作流
```

## 3. 快速开始

### 3.1 登录

1. 访问 https://manus.im
2. 使用 Pro 账户登录

### 3.2 创建任务

1. 点击 **New Task**
2. 清晰描述任务目标和期望输出
3. 选择执行模式（标准 / 深度分析）
4. 等待 Agent 执行完成

### 3.3 最佳实践 — Prompt 编写

```
好的 Manus Prompt 结构:
1. 明确目标：我要做什么
2. 输入信息：提供哪些数据/文件
3. 输出格式：期望的结果形式
4. 约束条件：时间、质量、格式要求
```

## 5. 积分管理

### 积分消耗参考

| 任务类型 | 估算消耗 |
|----------|----------|
| 简单查询/生成 | 10-50 积分 |
| 中等项目（代码生成） | 100-500 积分 |
| 复杂分析（多步骤） | 500-2000 积分 |
| 深度研究（长时间） | 1000-5000 积分 |

### 月度规划建议

- 12,000 积分/月 = 约 12-24 个中型任务
- 优先分配给 Manus 擅长的自主任务（数据分析、研究、自动化）
- 简单编码任务使用其他工具节省积分

---

## 6. 注意事项

- 年度订阅有效期至 2027-03-13，注意续费时间
- 积分每月重置，未用积分不累积
- 复杂任务建议先小范围测试，确认效果后再放大
