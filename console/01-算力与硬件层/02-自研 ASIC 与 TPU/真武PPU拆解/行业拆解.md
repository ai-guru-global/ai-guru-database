# 真武 PPU 行业拆解

> 一篇回答一个问题：真武 PPU 在 AI 算力产业里到底是什么位置、赌的是什么、凭什么赢或输。本文是研判层 2026-11-06 深拆的同源长文版，观点层内容与事实层（[时间线](时间线.md)、[03-产品线与规格](知识点/03-产品线与规格.md)）分开。

## 1. 第一性：云厂商为什么要自研芯片

把动机还原到物理与会计事实，只有三条，PPU 三条全占：

1. **供给安全**：H20 禁售—放行—再受限的反复（→ [11-制程与供应链](知识点/11-制程与供应链.md)）说明外部供给是政策变量而非市场变量。对阿里云这种把算力当水电卖的生意，供给侧不能只有一个供应商。
2. **单位经济**：推理负载吃掉云厂商毛利的大头。Google TPU 已证明自研芯片可以把自家旗舰模型的推理成本曲线握回自己手里；阿里坐拥 Qwen 系全球最大开源模型生态之一，工作负载天然存在。
3. **议价筹码**：采购量越大，对英伟达的谈判地位越依赖「我有替代方案」这件事的可信度。阿里三年 3800 亿级 AI capex（公开报道口径）背景下，自研芯片的可信度直接值钱。

## 2. 卡位判断：H20 替代位，不是 H100 对抗位

官方页三档产品（810E/M890/V900）全线不披露峰值算力（TFLOPS），只讲显存、互联与性价比百分比。96GB HBM2e 与 H20 同档、700GB/s 片间互联与 NVLink 同量级——**单卡绝对算力大概率不是卖点，也大概率不是强项**。这与含光 800 时代「能效/性价比」叙事一脉相承。判断：PPU 的竞争对手不是 H100/B 级训练旗舰，而是「买不到/买不起 H20 之后去哪」的问题（→ [04-规格对标](知识点/04-规格对标.md)）。

## 3. 真正的下注：scale-up 与显存池

互联三代递进 700→800→1200 GB/s，灵骏超节点 64 卡 9TB 统一显存，V900 千卡全带宽 Scale-Up + 百 TB 级统一显存——这是 NVL72 式「机柜级统一显存」路线的国产对位。推理时代的大 MoE 模型（Qwen 旗舰、Kimi K3.1 Pro）需要的是显存池而不是单卡峰值，**方向判断正确，且比单卡参数更能差异化**（→ [03-产品线与规格](知识点/03-产品线与规格.md)）。

## 4. 软件路线：框架层钩住，唯一正确的层，护城河最薄

不走 CUDA 二进制兼容（法律+工程双重地狱），不走 CANN/XLA 式自建运行时（迁移摩擦大），直接在 PyTorch/vLLM/Megatron/DeepSpeed 框架层做设备适配，宣称「零代码修改」迁移。这条路线的代价：**框架适配是可复制的工程工作**，软件壁垒必须长在 acext 算子库、ACCL-P 通信库、HolmesLLM 推理框架的深度上——恰好是官方页着墨最少的部分（→ [05-软件栈](知识点/05-软件栈.md)、[06-软件路线对比](知识点/06-软件路线对比.md)）。

## 5. 独有牌：模型生态绑定

「PPU 是跑 Qwen 性价比最优的平台」若成立，则 Qwen 开源生态每一次扩张都在为 PPU 拉需求；反向，M890 超节点 Day0 适配竞对旗舰 Kimi K3.1 Pro，又把头部第三方模型拉上自家硬件。**用模型生态给芯片引流，TPU×Gemini 同构打法，国内独一份**。这是 PPU 相对Trainium（无自家旗舰模型生态）多出的一张牌（→ [08-模型生态绑定](知识点/08-模型生态绑定.md)）。

## 6. 竞争格局：结构同构 Trainium，量级国产第二

- **结构同构对象是 AWS Trainium**：云厂商自研 + 对外售卖 + 框架层适配 + 服务自家旗舰模型，四点全合；华为昇腾是「芯片公司+全栈自建生态」打法，买家分层不同，不可直接比（→ [10-云厂商自研对照](知识点/10-云厂商自研对照.md)、[与昇腾的差异见 09](知识点/09-国产竞争格局.md)）。
- **量级**：出货 47 万颗（观察者网转述）/60 万片（腾讯新闻转述 IDC，❓两口径并存）→ 国内第二、首超寒武纪，仍明显落后昇腾（2025 年约 81.2 万颗，转述口径）。
- **售卖已云化**：ACS 标准 K8s 零改造接入、按量/Spot/容量预留、1–16 卡弹性——「自用降本工具」已转折为「云差异化产品」（→ [07-售卖与单位经济](知识点/07-售卖与单位经济.md)）。

## 7. 多空与证伪条件

**多方论据**：商用一年+、出货数十万级、三代产品线 roadmap 清晰（810E→M890→V900）、650+ 外部客户、Qwen 生态绑定、scale-up 方向正确。

**空方论据**：单卡算力不占优且不披露；软件生态差距不能被框架适配完全弥合（自定义算子/调试工具链/长尾库）；全部性能数字为官方自述，零第三方基准；HBM2e 产能与制程受限（代工未披露）；出货口径混乱本身反映市场不透明。

**证伪条件（出现即修正本判断）**：
1. V900 跳票或商用后无第三方基准背书 → 「scale-up 下注」降级为营销叙事；
2. Qwen 下一代旗舰训练回迁英伟达 GPU → 生态绑定逻辑失效；
3. 外部客户数一年内停滞在数百级、无标杆复购案例 → 「对外售卖」转折证伪；
4. 第三方（MLPerf 类或头部客户公开 case）实测显示性价比显著低于昇腾 910C/寒武纪 → 「H20 替代位」卡位证伪。

**成熟度判：爬坡期**（六阶段口径）。商业闭环已跑通、供给在放量，但生态与独立验证两块短板未证伪——与「过热期」的区分在于：PPU 有真实出货与真实客户，不是叙事先行。
