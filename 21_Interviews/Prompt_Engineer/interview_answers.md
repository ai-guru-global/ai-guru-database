# Prompt Engineer 面试题实例答案

## Q1: 如何设计可复用的 Prompt 模板？
**答**：先明确任务边界与输入输出格式，使用结构化提示与示例约束；对关键场景建立评测集，迭代优化并进行版本管理。

## Q2: Prompt 效果不稳定怎么办？
**答**：分析失败样本，加入约束、示例或工具调用；对不同数据分布建立分层模板，并用回归测试确保稳定性。

## Q3: 如何防护 Prompt 注入？
**答**：限制工具权限与执行范围，进行输入过滤与上下文隔离；对高风险操作加入二次确认与审计。
