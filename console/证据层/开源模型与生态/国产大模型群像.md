# 国产大模型群像

> 除 DeepSeek/Qwen/GLM/Kimi/MiniMax/豆包六家头部外，中国大模型赛道第二梯队的集体演进线索。

## 概述

中国大模型赛道除「六小虎」与新 BAT 外，还有一批老牌厂商（百度文心、腾讯混元、讯飞星火、商汤日日新）与新兴力量（阶跃星辰）持续迭代。2026 年的共同特征是：纷纷转向开源（MIT/Apache）、聚焦 Agent 与编程、绑定国产算力（华为昇腾）。

本线索汇总这些厂商的关键发布，避免每家单开线索造成碎片化。各厂商达到头部体量后可独立成线索。
