# AI 伦理与社会影响

> **一句话理解**: AI 不仅是技术问题，更是社会问题——算法偏见可能加剧不平等，自动化可能重塑就业，隐私风险可能威胁自由，我们需要在技术进步与社会价值之间寻找平衡。

---

## 1. AI伦理概述

### 1.1 什么是AI伦理？

```
AI伦理的核心问题:

应该做什么？ (Normative)
├── AI应该被允许做什么？
├── 谁对AI决策负责？
├── 如何确保AI公平对待所有人？
└── AI的利益和风险如何分配？

能够做什么？ (Technical)
├── 技术上能否实现可解释AI？
├── 能否消除算法偏见？
├── 能否确保AI安全可控？
└── 能否保护隐私同时发挥数据价值？

正在做什么？ (Descriptive)
├── 当前AI系统的实际影响
├── 不同群体的差异化体验
├── 监管政策的实施效果
└── 公众对AI的态度变化
```

```
全球主要AI伦理框架:

## 2. 算法偏见与公平性

### 2.1 偏见从何而来？

```
AI偏见的来源:

数据层面
├── 历史偏见
│   ├── 训练数据反映历史不公
│   └── 例: 招聘数据反映过去性别歧视
├── 代表性不足
│   ├── 某些群体数据稀缺
│   └── 例: 人脸识别对深肤色准确率较低
├── 标注偏见
│   ├── 标注者主观判断
│   └── 例: 情感标注受文化背景影响
└── 反馈循环
    ├── AI决策影响数据分布
    └── 偏见自我强化

算法层面
├── 优化目标单一
│   ├── 只追求准确率，忽视公平性
│   └── 例: 贷款审批只 minimiz 违约率
├── 特征选择
│   ├── 使用代理变量
│   └── 例: 邮编作为种族代理
└── 模型复杂度
    ├── 黑盒模型难以审计
    └── 偏见隐藏于复杂交互中

部署层面
├── 使用场景不当
├── 目标群体变化
└── 维护更新不足
```

### 2.2 典型案例分析

```
案例1: 招聘算法歧视 (Amazon, 2018)
├── 背景: AI简历筛选系统
├── 问题: 对女性技术岗位候选人有偏见
├── 原因: 训练数据来自过去10年招聘记录，技术岗位男性居多
├── 结果: 项目被终止
└── 教训: 历史数据中的偏见会被算法学习并放大

案例2: 刑事司法风险评估 (COMPAS, 2016)
├── 背景: 预测被告再犯风险
├── 问题: 对非裔美国人错误标记为高风险的概率是白人的2倍
├── 原因: 使用邮编等代理变量，间接反映种族
├── 影响: 影响保释和量刑决策
└── 争议: 算法透明度 vs 商业机密

案例3: 医疗分配算法 (Optum, 2019)
├── 背景: 决定患者是否需要额外护理
├── 问题: 对黑人患者系统性低估健康需求
├── 原因: 使用历史医疗支出作为健康需求代理
│         (黑人因医疗不平等 historically 支出较少)
├── 影响: 数百万患者受影响
└── 教训: 代理变量可能引入结构性偏见

案例4: 人脸识别误识 (Gender Shades, 2018)
├── 背景: 商用面部识别系统评测
├── 发现: 深肤色女性错误率高达34.7%，浅肤色男性仅0.8%
├── 原因: 训练集缺乏多样性
├── 影响: 执法应用可能导致错误逮捕
└── 进展: 推动行业改进和监管讨论
```

### 2.3 公平性度量与缓解

```
公平性定义 (数学视角):

群体公平 (Group Fairness)
├── 人口统计均等
│   P(Ŷ=1|A=0) = P(Ŷ=1|A=1)
│   (不同群体的正预测率相等)
├── 机会均等
│   P(Ŷ=1|Y=1,A=0) = P(Ŷ=1|Y=1,A=1)
│   (真阳性率相等)
└── 预测率平等
    P(Y=1|Ŷ=1,A=0) = P(Y=1|Ŷ=1,A=1)
    (阳性预测值相等)

个体公平 (Individual Fairness)
├── 相似个体应得到相似预测
└── d(x, x') 小 → D(f(x), f(x')) 小

不可能定理:
├── 除非基础率相等，否则无法同时满足所有公平性标准
├── 需要在不同公平性概念间权衡
└── 公平性定义本身包含价值判断

缓解技术:
├── 预处理: 数据重采样、特征转换
├── 训练中: 公平性约束优化、对抗去偏
└── 后处理: 阈值调整、校准
```

## 3. 隐私与数据权利

### 3.1 AI时代的隐私挑战

```
隐私风险类型:

数据收集
├── 过度收集
│   └── 收集超出必要范围的数据
├── 不知情收集
│   └── 用户不清楚数据被收集
├── 被动数据
│   └── 行为轨迹、生物特征
└── 第三方共享
    └── 数据流向不透明

数据使用
├── 目的变更
│   └── 原始目的之外的使用
├── 二次利用
│   └── 数据聚合新用途
├── 推断隐私
│   └── 从数据中推断敏感属性
└── 永久留存
    └── 数据难以删除

数据泄露
├── 安全漏洞
├── 内部滥用
├── 模型记忆
│   └── 训练数据被模型记忆并泄露
└── 成员推理攻击
    └── 推断某人是否在训练集中

监控风险
├── 大规模监控
├── 行为追踪
├── 社会信用
└── 言论审查
```

### 3.2 隐私保护技术

```
技术解决方案:

差分隐私 (Differential Privacy)
├── 概念: 添加可控噪声保护个体
├── 保证: 单条记录存在与否不影响输出分布
├── 应用: 苹果、谷歌数据收集
├── 权衡: 隐私预算 vs 数据效用
└── 公式: P[M(D) ∈ S] ≤ e^ε × P[M(D') ∈ S]

联邦学习 (Federated Learning)
├── 概念: 数据不动，模型动
├── 流程: 本地训练 → 上传梯度 → 聚合更新
├── 应用: 手机输入法、健康应用
├── 优势: 原始数据不离开设备
└── 挑战: 通信成本、非独立同分布

同态加密 (Homomorphic Encryption)
├── 概念: 密文上直接计算
├── 特性: 计算结果解密 = 明文计算结果
├── 应用: 隐私保护计算
├── 挑战: 计算开销大
└── 进展: 部分同态加密已实用

安全多方计算 (MPC)
├── 概念: 多方联合计算，互不知晓输入
├── 应用: 隐私保护联合建模
└── 挑战: 通信复杂度

隐私增强技术对比:
┌──────────────┬──────────┬──────────┬──────────┐
│ 技术         │ 计算开销 │ 通信开销 │ 精度损失 │
├──────────────┼──────────┼──────────┼──────────┤
│ 差分隐私     │ 低       │ 低       │ 中等     │
│ 联邦学习     │ 中       │ 高       │ 低       │
│ 同态加密     │ 极高     │ 低       │ 无       │
│ MPC          │ 高       │ 极高     │ 无       │
│ 数据脱敏     │ 低       │ 低       │ 高       │
└──────────────┴──────────┴──────────┴──────────┘
```

### 3.3 数据权利与法规

```
全球数据保护法规:

GDPR (欧盟, 2018)
├── 适用范围: 处理欧盟居民数据
├── 核心权利
│   ├── 知情权
│   ├── 访问权
│   ├── 更正权
│   ├── 删除权 (被遗忘权)
│   ├── 限制处理权
│   ├── 可携带权
│   └── 反对权
├── 关键要求
│   ├── 数据最小化
│   ├── 目的限制
│   ├── 存储限制
│   ├── 合法基础
│   └── 隐私设计
└── 处罚: 最高全球营收4%

CCPA/CPRA (加州, 2020/2023)
├── 知情权: 收集什么数据
├── 删除权: 要求删除个人数据
├── 选择退出: 不出售个人信息
├── 不歧视: 不因行使权利而歧视
└── 更正权 (CPRA新增)

中国个人信息保护法 (2021)
├── 告知-同意原则
├── 最小必要原则
├── 敏感个人信息特殊保护
├── 跨境数据传输限制
├── 个人权利
└── 平台特别义务

其他重要法规:
├── 巴西 LGPD
├── 日本 APPI
├── 韩国 PIPA
├── 印度 DPDP Act
└── 各国AI专门法规
```

├── 中年: 转型压力大
└── 临近退休: 再培训动力不足

地域层面
├── 发达国家: 服务业为主，AI增强
├── 发展中国家: 制造业为主，自动化风险
└── 全球分工可能重塑

行业层面
├── 高风险: 金融、法律、IT、媒体
├── 中等风险: 教育、医疗、咨询
└── 低风险: 手工艺、护理、建筑
```

## 5. 信息生态与民主

### 5.1 虚假信息与深度伪造

```
AI生成的信息风险:

深度伪造 (Deepfake)
├── 技术: GAN、扩散模型生成逼真视频
├── 风险
│   ├── 政治虚假信息
│   ├── 个人名誉损害
│   ├── 金融诈骗
│   └── 非自愿色情内容
├── 检测挑战
│   ├── 生成技术持续进步
│   ├── 真假界限模糊
│   └── 检测与生成军备竞赛
└── 应对措施
    ├── 技术水印
    ├── 区块链溯源
    ├── 平台政策
    └── 公众媒体素养

文本生成滥用
├── 假新闻批量生产
├── 社交媒体水军
├── 钓鱼邮件个性化

信息污染

信任危机

可能的改进:

├── 透明度提升
├── 公共媒体空间

```

├── 民主控制: AI服务于民主价值

├── 问责: 明确责任归属
├── 参与: 公众参与AI治理

```
AI安全威胁谱:

当下风险
├── 恶意使用
│   ├── 网络攻击自动化
│   ├── 生物武器设计辅助
│   ├── 虚假信息规模化生产

├── 系统故障
│   ├── 自动驾驶事故
│   ├── 医疗误诊
│   ├── 交易算法闪崩
│   └── 关键基础设施故障
├── 安全漏洞
│   ├── 对抗样本攻击
│   ├── 模型窃取
│   ├── 数据投毒
│   └── 提示注入

中期风险
├── 失控自动化
│   ├── 自动化武器系统
│   ├── 关键决策无人监督
│   └── 级联故障
├── 权力集中
│   ├── 技术垄断
│   ├── 国家AI竞赛
│   └── 数字威权主义
└── 经济冲击
    ├── 大规模失业
    ├── 贫富差距
    └── 经济不稳定

长期风险
├── 目标对齐问题
│   ├── 超级智能目标与人类不一致
│   ├── 工具性趋同 (自我保护、资源获取)
│   └── 能力跃升后失控
├── 存在性风险
│   └── 人类失去对未来的控制
└── 价值锁定
    └── 不当价值观被永久固化

风险评估挑战:
├── 不确定性高
├── 时间尺度长
├── 多方利益冲突
└── 预防性措施成本
```
