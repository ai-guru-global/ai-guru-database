# 竞争格局与阵营

> OpenAI 系、Anthropic 系、开源阵营与巨头生态的合纵连横。

## 拆解卡

- **价值来源**：阵营合纵连横：格局变化本身即最大风险变量。
- **护城河**：生态位锁定（算力/模型/应用绑定）。
- **瓶颈**：中立生态位的生存空间收窄。
- **领先指标**：阵营化交易（算力/模型绑定）；跨阵营合作破裂事件

## 六层速览

竞争格局与阵营回答「谁和谁一伙、谁在打谁」，AI 的竞争不是单点产品战，而是资本、算力与分发的阵营战。

**打个比方**：像战国：单个城池（模型）的强弱会被盟约（投资）、粮道（算力）、民心（用户）放大或抵消；站错阵营，再强也难独存。

**拆开看**：三层结构：底层算力与芯片（NVIDIA、台积电、云厂自研）→ 中层模型（前沿 lab 与开源阵营）→ 上层应用与分发（平台与垂直 SaaS）；每层都有各自的护城河与利润率。

**怎么运转**：云厂用投资绑定模型厂，模型厂用算力换股权与优先供给，应用层用分发换流量；每一层都在向相邻层扩张——云厂做模型、模型厂做应用、应用公司自建模型——以夺取更多利润。

**格局与博弈**：美国是「资本 + 算力 + 前沿模型」三角，中国是「应用 + 开源 + 国产算力」三角，欧洲押注监管与主权，中东用资本买席位；交叉投资让阵营边界模糊，但算力供给关系仍是最硬的绑定。

**边界与走向**：阵营会随资本开支周期重组；开源与闭源的边界、Agent 对入口的替代，是下一轮洗牌的两个变量；资本纪律决定谁能熬过下行周期，也决定阵营最终收敛成几家。

## 关键判断

竞争进入阵营化阶段，胜负取决于算力、分发与资本纪律；开源与 agent 是最大变量（置信度 中高，展望 12–24 个月）——核心变量是 agent 商业化与资本回报；评估阵营应看「收入增速与单位经济」，而非单点模型排名。

规模口径：全球 AI 市场约 $3000–5000 亿（2025e）

## 二级细分

- **模型阵营** — OpenAI-Microsoft 对 Anthropic-Amazon/Google
- **应用与开源阵营** — 分发卡位与开源侧翼
