# OpenAI FDE 实践

## OpenAI Deployment Company（DeployCo，2026.05.11）

> ⚠️ **日期更正**：本节早期版本误记为「2025.09」。经核实，OpenAI Deployment Company（业内简称 **DeployCo**）正式宣布日期为 **2026 年 5 月 11 日**。来源：[OpenAI 官方公告](https://openai.com/index/openai-launches-the-openai-deployment-company/)、[HPCwire 2026.5.11 报道](https://www.hpcwire.com/aiwire/2026/05/11/openai-launches-deployment-company-to-scale-enterprise-ai-adoption/)。

OpenAI 于 2026 年 5 月 11 日启动 **Deployment Company（DeployCo）**，标志大模型公司正式以独立实体形式进入 FDE 时代。

### 架构与资金

| 维度 | 内容 |
|---|---|
| **主导投资方** | TPG（领投），共 19 家投资方 |
| **初始投资规模** | 约 **$4B** |
| **参与方** | Brookfield (BN) 等 |
| **创始收购（founding acquisition）** | 收购伦敦/爱丁堡应用 AI 咨询公司 **Tomoro**，带入约 **150 名 Forward Deployed Engineers 与 Deployment Specialists** |
| **与 OpenAI Applied Engineering 的关系** | OpenAI 既有的 Applied Engineering 团队负责把 GPT/o 系列嵌入头部企业；DeployCo 是其面向中端市场的规模化延伸 |

> 来源：[Tomoro 收购公告](https://tomoro.ai/insights/tomoro-acquired-by-openai-deployment-company)、[Aventis Advisors（含日期/估值）](https://aventis-advisors.com/ai-services-ma-2026/)、[Sarah Friar (OpenAI CFO) LinkedIn](https://www.linkedin.com/posts/sarah-friar_openai-launches-the-openai-deployment-company-activity-7459596024773480448-jAgs)

### 历史脉络

```
2024        OpenAI 内部组建首批 Forward Deployed Engineer 团队，快速扩张
2026.05.04  Anthropic + Blackstone + H&F + Goldman Sachs 宣布成立企业级 AI 服务公司（~$1.5B）
2026.05.11  OpenAI 宣布成立 Deployment Company（TPG 主导，~$4B，收购 Tomoro）
```

> 一周内 OpenAI 与 Anthropic 相继下场，被业内视为「模型公司亲自做交付」的标志性事件。

## 为什么 OpenAI 需要 FDE？

```
OpenAI 的困境：
├── API 很强，但客户不知道怎么用
├── 企业客户需要私有化/定制化
├── 售前只能做 demo，不能真交付
└── 不帮客户落地 = 客户流失到竞对

解决方案：自己建 FDE 团队
```

## OpenAI FDE 的工作方式

1. **嵌入式团队**：派 2-5 人团队驻客户现场 3-6 个月
2. **平台支撑**：基于 OpenAI API + 内部工具链
3. **行业聚焦**：金融（高盛）、医疗、法律、制造
4. **收费模式**：高额服务费 + API 消费绑定
5. **薪资水平**：OpenAI 风格 FDE 总包（TCF）可达 **$650K+**，个别 base 接近 $780K，平均约 $215K —— 来源：[Perspective AI 报告](https://www.linkedin.com/posts/jeanklee)（**【市场传闻/未完全核实】**，具体数字随职级波动较大）

## 对中国 FDE 的启示

| OpenAI 做法 | 可借鉴之处 |
|---|---|
| 大模型公司亲自做 FDE | 大厂会跟进，创业公司需差异化 |
| 与咨询公司合作（Accenture） | 中国可与四大/本土咨询合作 |
| 聚焦高价值行业 | 不要泛化，深耕 1-2 个行业 |
| 高举高打定价 | 中国可按行业/规模分级定价 |

---

> **OpenAI 做 FDE = 行业信号**：大模型公司自己下场了，证明仅靠 API 不够。这对 FDE 创业公司既是威胁也是机会——威胁是大厂竞争，机会是市场被教育、需求被激活。
