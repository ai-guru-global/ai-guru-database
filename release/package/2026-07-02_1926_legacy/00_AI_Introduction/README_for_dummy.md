# 00 AI 简介与历史 — 小白版 🚀

> **一句话秒懂**: 这一章是 AI 学习的起点——告诉你 AI 到底是什么、有哪些类型、能做什么、是怎么发展过来的，让你从"完全不懂"到"有基本概念"。

## 什么是 AI？

### 一句话定义

```
AI = Artificial Intelligence = 人工智能

让机器表现得像人一样聪明
- 能学习
- 能思考
- 能决策
```

### 生活例子

```
【AI 在身边】
- 手机拍照的人脸识别 → AI
- 抖音的推荐算法 → AI
-  Siri/小爱同学 → AI
-  垃圾邮件过滤 → AI

你已经在用 AI 了，只是没意识到！
```

### AI vs 机器学习 vs 深度学习

```
【俄罗斯套娃 🪆】

┌─────────────────────────┐
│  人工智能 (AI)           │
│  让机器像人一样聪明      │

│  │ 机器学习 (ML)      │  │
│  │ 从数据中学习规律    │  │

│  │ │ 深度学习 (DL) │  │  │
│  │ │ 神经网络      │  │  │
│  │ └───────────────┘  │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

## AI 能做什么？

### 按能力分类

```
【感知类】─ 看得懂、听得懂
- 图像识别（人脸、物体）
- 语音识别（说话转文字）
- 文字识别（OCR）

【思考类】─ 能分析、能推理
- 逻辑推理
- 数据分析
- 预测

【行动类】─ 能决策、能执行
- 自动驾驶
- 智能推荐
- AI Agent
```

### 热门应用

```
💬 对话 ─── ChatGPT、Claude
🎨 绘画 ─── Midjourney、DALL-E
🎬 视频 ─── Sora、Kling
🎮 游戏 ─── AlphaGo、原神 AI
🏥 医疗 ─── 影像诊断、药物研发
💰 金融 ─── 风控、量化交易
```

## AI 的类型

### 1. 监督学习

```
【特点】有答案的学习

例子:
给 AI 看 1000 张猫和狗的照片
标注好哪些是猫、哪些是狗
AI 学完之后能分辨新照片是猫还是狗

就像学生做习题，有标准答案
```

### 2. 无监督学习

```
【特点】没有答案，自己找规律

例子:
给 AI 100 万用户的行为数据
让它自己发现：用户可以分为几类
（可能是：活跃用户、不活跃用户、付费用户等）

就像老师不给答案，让学生自己分析
```

### 3. 强化学习

```
【特点】通过试错学习

例子:
让 AI 玩俄罗斯方块
输了一局 → 惩罚
赢了一局 → 奖励
AI 自己摸索出得高分的策略

就像训练小狗，做对了给零食
```

### 4. 大语言模型 (LLM)

```
【特点】像人一样理解和生成文字

例子:
ChatGPT、Claude、Gemini

能:
- 回答问题
- 写文章、代码
- 翻译
- 总结
- 推理

基于海量文本训练，涌现出"理解能力"
```

## AI 的发展历史

### 四大浪潮

```
【第一波: AI 诞生 (1950-1980)】
- 1950: 图灵测试
- 1956: AI 概念诞生
- 专家系统流行
- → 太早了，技术不成熟，失败了

【第二波: 机器学习 (1980-2000)】
- 统计学习方法兴起
- 手写识别、 Spam 过滤
- → 计算能力有限，效果一般

【第三波: 深度学习 (2012-2022)】
- 2012: AlexNet 突破
- 2016: AlphaGo 战胜围棋冠军
- 2020: GPT-3 大模型
- → 算力提升 + 数据爆发 + 算法突破

【第四波: 大模型 + Agent (2022-)】
- 2022: ChatGPT 爆火
- 2023: Agent 开始流行
- 2024: 多模态、AI 编程爆发
- → 通用 AI 成为可能
```

## 为什么现在 AI 这么火？

```
【三大要素缺一不可】

📊 大数据
- 互联网数据爆发
- 标注数据积累
- → AI 有东西可学

⚡ 大算力
- GPU/TPU 性能提升
- 云计算普及
- → AI 能快速训练

🧠 大模型
- Transformer 架构
- 预训练技术
- → AI 能力涌现
```

## 常用术语

| 术语 | 通俗解释 |
|------|---------|
| 模型 | AI 学到的"知识"，像一个函数 |
| 训练 | 让 AI 从数据中学习的过程 |
| 推理 | AI 用学到的知识处理新问题 |
| 过拟合 | AI 死记硬背，不会泛化 |
| 泛化 | AI 能解决没见过的同类问题 |
