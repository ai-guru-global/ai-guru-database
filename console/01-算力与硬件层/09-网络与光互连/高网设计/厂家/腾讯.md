# 腾讯 × GPU 高网

> 国内大厂自建智算网络实践者中公开细节最少的一家：星脉网络有名，代际参数无谱。

## 在 GPU 高网中的角色

腾讯自建智算网络（对外统称「星脉」）服务混元大模型训练与太极机器学习平台：

1. **自建自用**：与阿里 HPN、字节 MegaScale 同属大厂自建智算网络阵营，但技术披露最少——无顶会架构论文，公开信息以 2023 年宣传口径为主。
2. **以太网 RoCE 路线**：星脉公开口径为以太网/RoCE 路线、多平面设计（2023 公开口径）；平面数、单集群规模、带宽代际均待核实。
3. **需求侧叙事**：太极/混元大模型训练对万卡级组网、通信时延与带宽利用率的需求为公开报道口径，具体数字待核实。

本篇以诚实标注待核实为主：星脉代际划分、是否采用双平面类架构、自研网卡/交换参与度，均无可靠公开细节。

## 公开口径与待核实清单

| 条目 | 公开口径 | 待核实点 |
|---|---|---|
| 星脉网络路线 | 以太网/RoCE、多平面设计（2023 公开口径） | 代际划分、平面数、拓扑细节 |
| 集群规模 | 万卡级（宣传口径，待核实） | 是否有十万卡级口径、单集群上限 |
| 带宽代际 | 随代际演进（宣传口径） | 各代际具体带宽与 400G/800G 部署状态 |
| 时延指标 | 低时延宣称（宣传口径） | 具体时延数字与测量口径 |
| 自研程度 | 有自研网卡/交换相关宣称（口径待核实） | 与商用设备的边界 |
| 混元/太极需求 | 大模型训练网络需求（公开报道口径） | 具体通信量与时延要求 |
| 稳定性工程 | 未公开（对照 HPN/MegaScale 论文级披露） | 拨测、慢节点、续训实践是否存在 |

## 技术路线与取舍（基于有限公开信息）

- **以太网多平面是共同选择**：星脉多平面口径与阿里 HPN 双平面同向，说明多平面已成为国内大厂智算网络的共识路线（各家平面数与实现差异待核实）。
- **规模优先于披露**：腾讯选择生产可用性而非论文级公开，外界只能从供应商与招标信息侧写（口径均待核实）。
- **推理网络是潜在新增变量**：混元规模化推理对网络的需求（KV Cache 传输、对等流量）公开细节极少（待核实）。
- **供应商侧写**：星脉供应链以国内交换机与光模块厂商为主（招标侧写口径，待核实）。
- **披露策略的代价**：外界难以评估星脉组网代际相对 HPN/MegaScale 的水平，本篇以待核实清单占位为主。

## 竞争与对标
