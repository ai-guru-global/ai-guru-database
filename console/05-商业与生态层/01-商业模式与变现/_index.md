# 商业模式与变现

> 订阅、API、广告与按效果付费：智能的收费方式仍在发明中。

## 拆解卡

- **价值来源**：智能的收费方式仍在发明中，模式决定生死。
- **护城河**：与场景耦合的变现闭环。
- **瓶颈**：订阅之外的规模化模式未定型。
- **领先指标**：广告/按效果收入占比；定价结构创新事件

## 六层速览

商业模式与变现回答「AI 公司怎么赚钱」：订阅、API 用量、按结果收费、广告与电商，各有各的账；定价单位选错，规模越大亏得越快。

**打个比方**：像开餐厅的几种模式——自助餐（订阅）、按盘计价（API）、按成功上菜收费（结果）、靠客流卖广告；模式不同，现金流与毛利完全不同。

**拆开看**：五段结构：价值主张 → 定价单位（席位 / token / 任务 / 结果）→ 获客渠道 → 毛利结构 → 续费与扩张；定价单位决定收入是随价值增长，还是随成本增长。

**怎么运转**：订阅提供可预测收入但受席位数限制，API 随用量增长但暴露成本，结果收费对齐客户价值却难计量；算力成本决定毛利天花板，获客成本决定回本周期。

**格局与博弈**：消费级靠订阅与广告，企业级靠席位与合同，基础设施靠用量；价格战会淘汰没有成本优势的中间层，垂直 agent 靠结果分成突围，平台则靠抽成与捆绑。

**边界与走向**：按结果收费会从客服、编码等可计量场景扩散，AI 会重写 SaaS 的「按席位」定价体系；最终胜出的是「可计量价值 + 低交付成本」的组合，而不是模型最强的那家。

## 关键判断

变现从席位走向结果，毛利是分水岭；能把「结果」计量清楚并控制推理成本的公司才配得上结果计费（置信度 中高，展望 12–24 个月）——核心变量是推理成本与结果归因能力；评估应看「毛利 × NRR」，而非单纯的收入增速。

规模口径：全球 AI 软件与服务收入约 $500–800 亿（2025e），含基础设施转售

## 二级细分

- **订阅制** — 可预测收入，席位有天花板
- **用量计费** — API 与按 token，随规模放大
- **按结果收费** — 与客户价值对齐，计量是难点
