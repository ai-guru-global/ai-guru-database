# 数值方法总论 (Numerical Methods for AI)

> 中文简称：数值方法总论

## 为什么 AI 工程师需要数值方法？

深度学习模型的训练和推理本质上是大规模数值计算。理解数值方法帮助你：

1. **诊断训练异常** — Loss 爆炸/NaN/梯度消失的根因分析
2. **选择正确精度** — FP32 vs FP16 vs BF16 vs FP8 的权衡
3. **优化计算效率** — 稀疏矩阵、分块计算、内存布局
4. **保证推理可靠性** — 量化误差累积、数值溢出防护

## 1. 浮点数表示与运算

### 1.1 IEEE 754 标准

```
┌─────────────────────────────────────────────────────────┐
│  FP32 (单精度): 1位符号 + 8位指数 + 23位尾数            │
│  范围: ±3.4×10³⁸, 精度: ~7位有效数字                    │
├─────────────────────────────────────────────────────────┤
│  FP16 (半精度): 1位符号 + 5位指数 + 10位尾数            │
│  范围: ±65504, 精度: ~3.3位有效数字                     │
├─────────────────────────────────────────────────────────┤
│  BF16 (脑浮点): 1位符号 + 8位指数 + 7位尾数             │
│  范围: ±3.4×10³⁸, 精度: ~2.4位有效数字                  │
├─────────────────────────────────────────────────────────┤
│  FP8 E4M3: 1位符号 + 4位指数 + 3位尾数                  │
│  范围: ±448, 精度: ~1.7位有效数字                       │
├─────────────────────────────────────────────────────────┤
│  FP8 E5M2: 1位符号 + 5位指数 + 2位尾数                  │
│  范围: ±57344, 精度: ~1.4位有效数字                     │
└─────────────────────────────────────────────────────────┘
```

### 1.2 AI 训练中的精度选择

| 阶段 | 推荐精度 | 原因 |
|------|----------|------|
| 预训练 (Forward) | BF16 / FP8 | 大动态范围避免溢出 |
| 预训练 (Backward) | BF16 + FP32 梯度累积 | 防止梯度下溢 |
| 微调 (LoRA) | FP16 / BF16 | 参数少，显存敏感 |
| 推理 (通用) | FP16 / INT8 | 速度优先 |
| 推理 (边缘) | INT4 / INT2 | 极致压缩 |

### 1.3 关键数值问题

```python
# 问题1: 大数吃小数 (Catastrophic Cancellation)
import numpy as np
a = np.float16(65504.0)  # FP16 最大值
b = np.float16(0.001)
print(a + b)  # 输出 65504.0，小数被"吃掉"

# 问题2: 梯度下溢 (Gradient Underflow)
# FP16 最小正数: 6.1×10⁻⁵
# 深层网络梯度可能 < 10⁻⁸，在 FP16 中变为 0

# 问题3: Softmax 溢出
# exp(1000) → inf，需要减去最大值
def stable_softmax(x):
    x_max = np.max(x, axis=-1, keepdims=True)
    exp_x = np.exp(x - x_max)
    return exp_x / np.sum(exp_x, axis=-1, keepdims=True)
```

## 2. 矩阵运算与分解

### 2.1 AI 中的核心矩阵运算

| 运算 | AI 应用 | 复杂度 | 数值注意点 |
|------|---------|--------|-----------|
| GEMM (矩阵乘法) | 全连接层/注意力 | O(n³) | 累积误差、分块策略 |
| SVD | 降维/LoRA 初始化 | O(n³) | 奇异值接近零时不稳定 |
| Cholesky | 协方差矩阵求逆 | O(n³/3) | 要求正定，否则失败 |
| QR 分解 | 正交初始化 | O(n³) | 数值稳定 |
| 特征值分解 | PCA/谱聚类 | O(n³) | 对称矩阵优先 |

# 分块矩阵乘法 (Tiling) — GPU 核心策略

## 3. 数值微分与自动微分

### 3.1 有限差分 vs 自动微分

```python
# 有限差分 (数值不稳定，仅用于验证)
def numerical_gradient(f, x, eps=1e-5):
    return (f(x + eps) - f(x - eps)) / (2 * eps)

# 自动微分 (PyTorch 默认) — 精确到机器精度
import torch
x = torch.tensor(3.0, requires_grad=True)
y = x**2 + 2*x + 1
y.backward()
print(x.grad)  # 精确: 2*3 + 2 = 8.0
```

### 3.2 反向传播中的数值问题

| 问题 | 表现 | 解决方案 |
|------|------|---------|
| 梯度爆炸 | Loss → NaN/Inf | 梯度裁剪 (clip_grad_norm) |
| 梯度消失 | 深层参数不更新 | 残差连接、LayerNorm |
| 梯度噪声 | 训练不稳定 | 增大 batch、梯度累积 |
| 二阶信息丢失 | 收敛慢 | Adam/AdamW 自适应学习率 |

## 4. 迭代法与收敛

### 4.1 AI 中的迭代算法

- **梯度下降**: 一阶迭代，收敛速度 O(1/T)
- **Adam/AdamW**: 自适应步长，实践收敛快
- **共轭梯度**: 求解线性系统 Ax=b
- **幂迭代**: 计算最大特征值 (PageRank/PCA)
- **EM 算法**: 含隐变量的最大似然估计

### 4.2 收敛性判断

```python
# 训练收敛的数值判据
def check_convergence(losses, window=100, rtol=1e-4):
    """相对变化小于阈值视为收敛"""
    if len(losses) < window:
        return False
    recent = losses[-window:]
    relative_change = abs(recent[-1] - recent[0]) / (abs(recent[0]) + 1e-8)
    return relative_change < rtol
```

## 5. 误差分析与稳定性

### 5.1 误差来源

```
┌─────────────────────────────────────────────┐
│  模型误差 (Modeling Error)                    │
│  ├── 离散化误差 (Discretization)             │
│  ├── 截断误差 (Truncation)                   │
│  └── 舍入误差 (Rounding)                     │
├─────────────────────────────────────────────┤
│  传播与放大                                   │
│  ├── 条件数 (Condition Number)               │
│  ├── 误差累积 (Error Accumulation)           │
│  └── 灾难性抵消 (Catastrophic Cancellation)  │
└─────────────────────────────────────────────┘
```

### 5.2 条件数与病态问题

```python
import numpy as np

# 条件数 = 最大奇异值 / 最小奇异值
A = np.array([[1, 0], [0, 0.001]])
cond = np.linalg.cond(A)
print(f"条件数: {cond}")  # 1000 — 病态！

# AI 中的病态问题:
# - Hessian 矩阵条件数大 → 优化困难
# - 注意力分数差异大 → Softmax 梯度消失
# - 量化时权重分布不均 → 精度损失不均
```

## 6. AI 实战中的数值技巧

### 6.1 常用数值稳定化技术

| 技术 | 应用场景 | 原理 |
|------|----------|------|
| Log-Sum-Exp | Softmax/交叉熵 | log(Σexp(x)) = max + log(Σexp(x-max)) |
| Layer Normalization | Transformer 每层 | 归一化激活值，稳定梯度流 |
| Gradient Clipping | 训练循环 | 限制梯度范数上界 |
| Loss Scaling | 混合精度训练 | 放大 loss 防止 FP16 梯度下溢 |
| Epsilon Smoothing | 除法/Log | 加 ε 避免除零/log(0) |
| Weight Decay | 优化器 | 防止权重过大导致数值问题 |

### 6.2 诊断清单

```python
# 训练数值健康检查
def numerical_health_check(model, loss, grad_norm):
    checks = {
        "loss_is_nan": torch.isnan(loss).item(),
        "loss_is_inf": torch.isinf(loss).item(),
        "grad_norm_exploding": grad_norm > 1000,
        "grad_norm_vanishing": grad_norm < 1e-7,
        "weight_has_nan": any(
            torch.isnan(p).any().item() 
            for p in model.parameters()
        ),
    }
    return checks
```
