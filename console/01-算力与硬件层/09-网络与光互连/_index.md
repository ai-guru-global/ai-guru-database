# 网络与光互连

> 集群规模上到万卡后，互连带宽与光模块成为新的瓶颈与生意。

## 拆解卡

- **价值来源**：万卡集群的规模上限由互连带宽决定，光模块量价齐升。
- **护城河**：光器件工艺良率与客户认证周期。
- **瓶颈**：1.6T 光模块产能与交换芯片供给。
- **领先指标**：光模块龙头月度营收；以太网 RDMA 对 IB 的份额侵蚀

## 六层速览

网络与光互连决定集群能开多大：万卡之后，卡与卡之间搬数据的开销往往比计算本身还大；网络不再是配套，而是算力的一部分。

**打个比方**：像城市交通——核心区楼再高，道路堵死，整座城市也转不动；AI 集群里，网络就是那张路网，堵一次，所有卡一起等。

**拆开看**：五段链路：交换芯片 → 交换机与网卡 → 光模块与光缆 → 协议（InfiniBand / 以太网 / RDMA）→ 拓扑（Fat-Tree / rail-optimized）；每一层都影响延迟与拥塞。

**怎么运转**：卖交换芯片（博通）、卖整网（英伟达、思科、Arista）、卖光模块（中际旭创、新易盛）；云厂商按端口与带宽扩容，训练集群对无损与低延迟近乎苛刻。

**格局与博弈**：英伟达用 InfiniBand + NVLink 锁定高端训练，以太网联盟（Ultra Ethernet）以开放生态反攻；光模块由中国厂商主导，1.6T 世代量价齐升；交换芯片仍是博通主战场。

**边界与走向**：竞争从「带宽」转向「端到端延迟与拥塞控制」；光互连向共封装光学（CPO）演进，网络与计算的边界会重新划分，光电融合成为下一代系统级命题。

## 关键判断

带宽是集群的隐形税，光互连最受益，价值正向机柜内 scale-up 互连再分配（置信度 中高，展望 12–24 个月）——主线是 1.6T 与 CPO 的切换节奏加 scale-up/scale-out 边界重划；光模块周期性强于芯片，代际切换期先行者溢价明显。

规模口径：数据中心网络约 $300–400 亿（2025e），AI 集群后端网络占大头且增速 40%+；若把机柜内 scale-up 互连（NVSwitch/铜背板/超节点线缆）一并计入，池子再扩大数十亿美元级（2026e，估算口径）
