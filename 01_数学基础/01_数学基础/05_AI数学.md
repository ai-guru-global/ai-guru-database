## 1. 线性代数公式 (Linear Algebra)

### 1.1 基本运算

| 公式 | 符号 | AI 应用 |
|------|------|---------|
| $\mathbf{c} = \mathbf{a} \cdot \mathbf{b} = \sum_i a_i b_i$ | 向量内积 | 注意力分数计算、余弦相似度 |
| $\mathbf{C} = \mathbf{A}\mathbf{B}, \quad C_{ij} = \sum_k A_{ik}B_{kj}$ | 矩阵乘法 | 神经网络前向传播的每一层 |
| $\mathbf{a} \otimes \mathbf{b} = \mathbf{a}\mathbf{b}^T$ | 外积 | 秩-1 矩阵构造、协方差估计 |
| $\|\mathbf{x}\|_p = \left(\sum_i |x_i|^p\right)^{1/p}$ | Lp 范数 | L2 正则化 (权重衰减)、L1 稀疏性 |
| $\cos(\theta) = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\|\|\mathbf{b}\|}$ | 余弦相似度 | 词向量相似度、RAG 检索 |

### 1.2 分解与变换

| 公式 | 名称 | AI 应用 |
|------|------|---------|
| $A\mathbf{v} = \lambda\mathbf{v}$ | 特征方程 | PCA 主成分方向、谱聚类 |
| $A = Q\Lambda Q^{-1}$ | 特征分解 | 矩阵幂运算、动力系统分析 |
| $A = U\Sigma V^T$ | 奇异值分解 (SVD) | 推荐系统、低秩近似、模型压缩 |
| $A = LL^T$ | Cholesky 分解 | 高斯分布采样、正定矩阵求逆 |
| $\text{tr}(A) = \sum_i A_{ii}$ | 迹 | Frobenius 范数、矩阵微积分中间量 |
| $\det(A) = \prod_i \lambda_i$ | 行列式 | 可逆性判断、体积缩放因子 |

## 2. 微积分公式 (Calculus)

### 2.1 标量微积分

| 公式 | 名称 | AI 应用 |
|------|------|---------|
| $\frac{d}{dx}x^n = nx^{n-1}$ | 幂法则 | 多项式激活函数求导 |
| $\frac{d}{dx}e^x = e^x$ | 指数导数 | Softmax、指数函数梯度 |
| $\frac{d}{dx}\ln x = \frac{1}{x}$ | 对数导数 | 对数似然、交叉熵梯度 |
| $\frac{d}{dx}\sigma(x) = \sigma(x)(1-\sigma(x))$ | Sigmoid 导数 | 二分类输出层梯度 |
| $\frac{dz}{dx} = \frac{dz}{dy}\cdot\frac{dy}{dx}$ | 链式法则 | **反向传播的数学本质** |

### 2.2 多元微积分与矩阵微积分

| 公式 | 名称 | AI 应用 |
|------|------|---------|
| $\nabla f = \left(\frac{\partial f}{\partial x_1}, \ldots, \frac{\partial f}{\partial x_n}\right)$ | 梯度 | 参数更新方向 |
| $\mathbf{H}_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}$ | Hessian 矩阵 | 二阶优化、曲率分析 |
| $\frac{\partial}{\partial \mathbf{x}} \mathbf{x}^T\mathbf{a} = \mathbf{a}$ | 线性形式导数 | 线性层梯度推导 |
| $\frac{\partial}{\partial \mathbf{x}} \mathbf{x}^T A \mathbf{x} = (A + A^T)\mathbf{x}$ | 二次形式导数 | 正则化项梯度、Mahalanobis 距离 |
| $\frac{\partial}{\partial X} \text{tr}(AX) = A^T$ | 迹的矩阵导数 | 矩阵参数更新公式 |
| $\frac{\partial}{\partial X} \text{tr}(X^TAX) = (A+A^T)X$ | 二次迹导数 | 自编码器、矩阵分解梯度 |
| $\frac{\partial}{\partial X} \ln\det(X) = (X^{-1})^T$ | 对数行列式导数 | 高斯分布 MLE、流模型 |

## 3. 概率分布 (Probability Distributions)

### 3.1 离散分布

| 分布 | PMF / 公式 | 均值 | 方差 | AI 应用 |
|------|-----------|------|------|---------|
| **伯努利** Bernoulli(p) | $p^k(1-p)^{1-k}$ | $p$ | $p(1-p)$ | 二分类标签建模 |
| **二项** Binomial(n,p) | $\binom{n}{k}p^k(1-p)^{n-k}$ | $np$ | $np(1-p)$ | 成功次数建模 |
| **多项式** Multinomial | $\frac{n!}{\prod k_i!}\prod p_i^{k_i}$ | $np_i$ | — | Softmax 输出、分类 |
| **泊松** Poisson(λ) | $\frac{\lambda^k e^{-\lambda}}{k!}$ | $\lambda$ | $\lambda$ | 计数数据、事件到达 |
| **分类** Categorical | $p_k$ (one-hot) | — | — | 多分类标签 |

### 3.2 连续分布

| 分布 | PDF | 均值 | 方差 | AI 应用 |
|------|-----|------|------|---------|
| **均匀** Uniform(a,b) | $\frac{1}{b-a}$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ | 参数初始化、随机采样 |
| **高斯** Gaussian(μ,σ²) | $\frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$ | $\sigma^2$ | 噪声建模、VAE、权重初始化 |
| **多元高斯** MVN(μ,Σ) | $\frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}}e^{-\frac{1}{2}(x-\mu)^T\Sigma^{-1}(x-\mu)}$ | $\boldsymbol{\mu}$ | $\Sigma$ | 高斯过程、扩散模型 |
| **指数** Exp(λ) | $\lambda e^{-\lambda x}$ | $1/\lambda$ | $1/\lambda^2$ | 等待时间、Laplace 先验 |
| **Beta** Beta(α,β) | $\frac{x^{\alpha-1}(1-x)^{\beta-1}}{B(\alpha,\beta)}$ | $\frac{\alpha}{\alpha+\beta}$ | — | Thompson Sampling、概率先验 |

### 3.3 贝叶斯推断核心公式

| 公式 | 名称 | AI 应用 |
|------|------|---------|
| $P(H\|D) = \frac{P(D\|H)P(H)}{P(D)}$ | 贝叶斯定理 | 信念更新、朴素贝叶斯分类器 |
| $\hat{\theta}_{MLE} = \arg\max_\theta \prod_i P(x_i\|\theta)$ | 极大似然估计 | 参数学习的标准范式 |
| $\hat{\theta}_{MAP} = \arg\max_\theta P(D\|\theta)P(\theta)$ | 最大后验估计 | 正则化等价于 MAP (L2=Ridge) |
| $\text{ELBO} = \mathbb{E}_q[\log p(x\|z)] - D_{KL}(q(z)\|p(z))$ | 证据下界 | VAE 训练目标、变分推断 |

## 4. 信息论 (Information Theory)

| 公式 | 名称 | AI 应用 |
|------|------|---------|
| $H(X) = -\sum_i p(x_i)\log p(x_i)$ | Shannon 熵 | 不确定性度量、决策树分裂准则 |
| $H(X,Y) = -\sum_{x,y} p(x,y)\log p(x,y)$ | 联合熵 | 自回归序列总不确定性 |
| $H(Y\|X) = -\sum_{x,y} p(x,y)\log p(y\|x)$ | 条件熵 | LLM 下一 token 预测目标 |
| $H(P,Q) = -\sum_i p(x_i)\log q(x_i)$ | **交叉熵** | **几乎所有分类模型的损失函数** |
| $D_{KL}(P\|Q) = \sum_i p(x_i)\log\frac{p(x_i)}{q(x_i)}$ | KL 散度 | VAE 正则化、知识蒸馏、PPO 约束 |
| $I(X;Y) = H(X) - H(X\|Y)$ | 互信息 | 特征选择、对比学习 (InfoNCE) |
| $\text{PPL} = e^{H(P,Q)}$ | 困惑度 | LLM 评估核心指标 |
| $D_{JS}(P,Q) = \frac{1}{2}D_{KL}(P\|M) + \frac{1}{2}D_{KL}(Q\|M)$ | JS 散度 | 对称化分布距离、GAN 改进 |

## 5. 优化方法 (Optimization Methods)

### 5.1 一阶优化器

| 方法 | 更新公式 | 特点 | AI 应用 |
|------|---------|------|---------|
| **SGD** | $\theta \leftarrow \theta - \alpha \nabla L$ | 简单、噪声大 | 理论分析基线 |
| **SGD + 动量** | $v \leftarrow \beta v + \nabla L; \quad \theta \leftarrow \theta - \alpha v$ | 加速、穿越鞍点 | CNN 训练标配 |
| **AdaGrad** | $\theta \leftarrow \theta - \frac{\alpha}{\sqrt{G+\epsilon}} \nabla L$ | 自适应学习率 | 稀疏特征场景 |
| **RMSProp** | $v \leftarrow \beta v + (1-\beta)(\nabla L)^2; \quad \theta \leftarrow \theta - \frac{\alpha}{\sqrt{v+\epsilon}} \nabla L$ | 指数移动平均 | RNN 训练 |
| **Adam** | $m \leftarrow \beta_1 m + (1-\beta_1)\nabla L; \quad v \leftarrow \beta_2 v + (1-\beta_2)(\nabla L)^2$ | 自适应 + 动量 | **深度学习默认优化器** |
| **AdamW** | Adam + $\theta \leftarrow \theta - \alpha\lambda\theta$ | 解耦权重衰减 | **大模型训练标配** |

### 5.2 二阶与拟牛顿方法

| 方法 | 核心思想 | AI 应用 |
|------|---------|---------|
| **Newton 法** | $\theta \leftarrow \theta - H^{-1}\nabla L$ | 理论最优步长，实际太贵 |
| **L-BFGS** | 有限内存近似 Hessian 逆 | 中等规模凸优化 |
| **KFAC** | Kronecker 近似 Hessian | 大模型二阶探索 |

### 5.3 正则化与约束

| 方法 | 公式 | AI 应用 |
|------|------|---------|
| **L1 (Lasso)** | $L + \lambda\sum|w_i|$ | 稀疏化、特征选择 |
| **L2 (Ridge)** | $L + \lambda\sum w_i^2$ | 权重衰减、防止过拟合 |
| **Elastic Net** | $L + \lambda_1\sum|w_i| + \lambda_2\sum w_i^2$ | L1+L2 结合 |
| **Dropout** | $\hat{y} = y \odot m, \quad m_i \sim \text{Bernoulli}(p)$ | 集成学习近似、防过拟合 |
| **梯度裁剪** | $g \leftarrow g \cdot \min(1, \frac{c}{\|g\|})$ | 防止梯度爆炸 (RNN/Transformer) |
| **学习率预热** | $\alpha_t = \alpha \cdot \min(t/t_{warm}, 1)$ | 稳定大模型训练初期 |

## 6. 常用损失函数 (Loss Functions)

| 损失函数 | 公式 | AI 应用 |
|---------|------|---------|
| **交叉熵** | $-\sum_i y_i \log \hat{y}_i$ | 分类任务 (几乎所有) |
| **二元交叉熵 (BCE)** | $-[y\log\hat{y} + (1-y)\log(1-\hat{y})]$ | 二分类、多标签 |
| **MSE** | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ | 回归任务 |
| **MAE** | $\frac{1}{n}\sum|y_i - \hat{y}_i|$ | 对异常值鲁棒的回归 |
| **Huber** | MSE if |e|<δ else MAE-like | 鲁棒回归、RL (TD error) |
| **Focal Loss** | $-(1-\hat{y})^\gamma y\log\hat{y}$ | 类别不平衡、目标检测 |
| **Contrastive Loss** | $-\log\frac{e^{sim(q,k^+)/\tau}}{\sum e^{sim(q,k_i)/\tau}}$ | 对比学习 (CLIP, SimCLR) |
| **Hinge Loss** | $\max(0, 1 - y\cdot\hat{y})$ | SVM 分类 |
