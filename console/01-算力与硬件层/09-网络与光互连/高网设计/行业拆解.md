# 高网行业深度拆解 · 总览

> 台内「03 深度拆解」（console/deep-l1.js 的 network 条目）的长文枢纽。本篇给骨架与结论；每一段的完整论证在 [知识点/09-市场与价值链/](知识点/09-市场与价值链/) 与 [知识点/10-格局与战线/](知识点/10-格局与战线/) 共 17 篇中展开。数字均为公开资料量级估算（2025e/2026e 标注），观点可被证据推翻。

## 一句话与口径

万卡之后，卡间搬数据的开销往往比计算本身还大——网络不再是集群的配套，而是算力的一部分。口径：AI 集群互连全栈，**机内 scale-up（NVLink/超节点铜互连）与跨机 scale-out（交换/光模块/线缆/网卡）分开计价**；不含广域网与运营商业务。

## 需求与市场（→ [需求与市场弹性](知识点/09-市场与价值链/需求与市场弹性.md)）

需求的第一性是并行策略：TP 放机内、DP 放机间、MoE 吃 All-to-All。两条定价锚：Ring AllReduce 每卡流量 ≈ 2(N−1)/N × S；**无阻塞两层组网 GPU:800G 光模块 ≈ 1:4–4.5，过收敛降到 1:2.5**。规模：数据中心网络 $300–400 亿（2025e），AI 集群网络 $150–250 亿，增速 40%+；网络占集群 capex 10–20%，万卡整网约 $4–8 亿（估算口径）。双驱动：代际切换（800G→1.6T，51.2T→102.4T）+ 超节点扩张（NVL72→NVL144→NVL576 规划）。

## 竞争格局：三层结构（→ 每阵营一篇）

1. **[NVIDIA 全栈](知识点/10-格局与战线/阵营-NVIDIA全栈.md)**：IB + Spectrum-X + NVLink 专有 scale-up + CPO，机柜级交付把网络内嵌进 GPU 合同。
2. **[以太网开放阵营](知识点/10-格局与战线/阵营-以太网开放.md)**：Broadcom 芯片+DSP 军火库、UEC 1.0（2025-06）规范旗帜、Arista/Cisco 系统、云厂多平面实践——胜利条件是「非 NVIDIA 的以太网赢」。
3. **[中国链条](知识点/10-格局与战线/阵营-中国链条.md)**：光模块全球出货大头 + 设备国内闭环（华为/新华三/锐捷）+ 国产超节点，HPN（15k GPU）/MegaScale（12,288 GPU）方法论背书。

竞争的分界线就是 scale-up/scale-out 的边界：边界向柜内移，NVIDIA 与 Broadcom 在 CPO 相遇；边界向外移，开放阵营受益。
