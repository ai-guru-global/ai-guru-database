# Kilo / KiloClaw 使用指南

> **一句话**: Kilo 提供 Starter 月度套餐（$19 + $2.85 免费积分），KiloClaw 是其编程工具，适合轻量级项目开发。

---

## 1. 概述

### 定位

| 维度 | 说明 |
|------|------|
| **类型** | AI 编程助手 |
| **产品线** | Kilo（平台）、KiloClaw（编程工具） |
| **适用** | 轻量级项目、实验性开发 |
| **官网** | https://app.kilo.ai |

### 核心能力

```
Kilo 生态:
├── Kilo 平台
│   ├── AI 模型调用
│   ├── 积分制计费
│   └── 多模型支持
├── KiloClaw
│   ├── 编程辅助工具
│   └── 试用版（0520 截止）
└── 套餐
    └── Starter Monthly
```

## 4. 最佳实践

- $19/月的 Starter 套餐额度有限，适合轻量级使用
- KiloClaw 试用截止后需评估是否值得续费
- 剩余 $11 积分应谨慎使用，留给必要任务
