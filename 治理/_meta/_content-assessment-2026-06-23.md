## 七、跨章节综合（综合）关联 ⭐⭐（弱，结构性短板）

**关键发现**：synthesis 文档的 `sources` 指向**概念卡**而非章节，且统计显示其跨域章节连接数为 0。

```
预期：synthesis 应连接 2-4 个章节，揭示跨域关联
实际：sources 全指向 概念/，未直接引用章节文档
```

**影响**：synthesis 层的"跨域连接"价值未充分发挥——它本质是"概念卡聚合"而非"章节桥接"。

**改进空间**（结构性）：
1. synthesis 的 sources 应**同时引用章节文档**（不只是概念卡），建立"章节↔综合"双向链路
2. 或在 synthesis 正文显式标注"本篇连接第 X 章 与 第 Y 章"

## 十、改进建议（按 ROI 排序）

### 高 ROI（投入小、收益明显）

1. **拆分 306KB ModelScope_Model_Index** → JSON 数据 + 简述页（解决最突出异常）
2. **扩充 5 个 `*_overview.md` 占位**（pytorch/tensorflow/keras 等）或标注为"仅索引"
3. **补应用层概念卡**（Agent 框架对比/RAG 模式/AI 编程范式，~10 张）

### 中 ROI（结构性改善）

4. **synthesis 跨域关联增强**：sources 增加章节文档引用，正文标注连接关系
5. **补 3 章 Deep Dive**：00_AI 发展史、16_Cursor 实战、18_医疗金融场景
6. **时效性巡检机制**：为含具体数据的文档打保质期标签

### 低 ROI（锦上添花）

7. 剩余 28% 无代码文档中，识别"实践类但缺代码"的并补充
8. frontmatter updated 字段格式统一（便于时效统计）

## 十一、结论：是否还有进一步改进空间？

**有，但已进入"边际收益递减"区。**

经过四轮工作（重构→评估→P0/P1 治理→P2 内容深化），知识库的**结构与质量层面已达到生产级**（链接健康、无重复、frontmatter 完整、category 一致）。剩余的改进空间集中在：

- **内容深度**（3 个 Deep Dive 缺口）——需持续创作，非一次性工程
- **结构性短板**（synthesis 跨域关联）——需重新设计 synthesis 的引用模式
- **数据治理**（306KB 异常文件、占位清理）——可快速处理

**建议优先级**：先处理高 ROI 的 3 项（拆分超长文件、扩充占位、补概念卡），这些是立竿见影的。synthesis 结构改造和持续内容创作属于中长期规划。
