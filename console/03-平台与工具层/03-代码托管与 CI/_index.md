# 代码托管与 CI

> 仓库与流水线是 agent 时代的新基座：自建托管（Origin 类）正在挑战 GitHub 的中心地位。

## 拆解卡

- **价值来源**：agent 时代的代码基座：托管权即生态权。
- **护城河**：迁移成本与 CI 集成深度。
- **瓶颈**：与 GitHub 网络效应对抗的冷启动。
- **领先指标**：自建托管平台的企业采用；agent 原生 CI 工具的出现

## 六层速览

代码托管与 CI 是软件开发的「地基」：仓库、权限、流水线和制品库；Agent 时代还要加上任务沙箱与审计日志。

**打个比方**：像城市的道路与供水——平时不起眼，但所有建筑（应用）都依赖它；路一断，全城停摆，迁移成本高到没人愿意换。

**拆开看**：五层结构：Git 仓库 → 权限与审计 → CI/CD 流水线 → 制品与部署 → Agent 沙箱与运行环境；安全、合规与供应链完整性贯穿每一层。

**怎么运转**：按席位或用量的订阅，企业版按合规与私有部署收费；平台靠生态（应用市场、Actions、集成）锁定开发者，数据与工作流沉淀越深，迁移成本越高。

**格局与博弈**：GitHub 凭网络效应主导，GitLab 做一体化 DevOps，Atlassian 捆绑 Jira 与 Bitbucket；自建托管与区域合规需求带来分化，中国以 Gitee、云效等本土平台为主。

**边界与走向**：Agent 会直接读写仓库、触发流水线、提交 PR，托管平台必须提供沙箱、配额与审计；「Agent 原生 CI」是新战场，代码托管会从「人写代码的地方」变成「人和 agent 协作、评审与追责的地方」。

## 关键判断

托管层稳定收租、现金流好；AI 审查是真实增量但易被平台整合，独立审查厂商的中期出路是被收购或做深垂直合规（置信度 中高，展望 12–24 个月）——核心变量是 AI 审查能否独立成层，以及供应链合规是否带来新一轮采购周期。

规模口径：全球开发者基础设施约 $300–400 亿（2025e），其中 AI 增量约 $30–60 亿

## 二级细分

- **代码托管** — 仓库、PR 与评审的网络效应
- **CI/CD 流水线** — 构建、测试与部署的自动化
- **Agent 沙箱** — agent 读写仓库的隔离运行环境
