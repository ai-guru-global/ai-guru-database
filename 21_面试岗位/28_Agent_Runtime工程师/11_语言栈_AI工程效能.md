# 研发语言栈与 AI 工程效能 (Language Stack & AI-Native SDLC)

> 中文简称：语言栈与 AI 工程效能

> **一句话理解**: 前半页回答"这五个语言里你亮哪把刀、刀用在哪"，后半页回答 JD 第 6 条——"用 AI 造 AI 的底座，并把方法沉淀成团队资产"。

---

## 1. 五门语言在 Agent Runtime 中的位置

| 语言 | 典型模块 | 为什么是它 |
|------|---------|-----------|
| **Go** | Runtime 主体、调度器、API 网关、控制面 | goroutine/channel 契合高并发会话管理；单二进制交付友好（K8s 生态同构）；GC 延迟可控 |
| **Python** | Agent SDK、框架适配层、评测脚本、工具生态 | AI 生态的通用语；LangGraph/AgentScope 等全是 Python；迭代快 |
| **Java** | 企业中间件对接、大数据链路 | 企业存量系统（消息、 RPC、权限）多在 JVM 侧 |
| **C++** | 底层运行时、Wasm VM、性能敏感组件 | 极致性能与资源控制 |
| **Rust** | 沙箱组件、Wasm 运行时、安全关键路径 | 内存安全+无 GC 抖动；Wasmtime 等基础设施本身就是 Rust 写的 |

- **模块 × 语言推荐矩阵**（面试可直接给）:

| 平台模块 | 首选 | 备选 |
|---------|------|------|
| 会话/调度控制面 | Go | Java |
| 沙箱池管理器 | Go + 调用容器运行时 | Rust |
| Agent SDK / 示例 | Python（+TS 补前端场景） | — |
| 工具网关（MCP Gateway） | Go | Node/TS |
| Wasm 插件运行时 | Rust（嵌入 Wasmtime） | C++ |
| 评测与数据管线 | Python | — |

- 高频题：**"Runtime 为什么多选 Go？"** —— 万级并发长连接会话（epoll+goroutine 模型成熟）、控制面逻辑重但计算轻（GC 停顿可控）、部署运维简单（静态编译）、云原生生态工具链全是 Go 写的（K8s client/controller-runtime 直接复用）。
- 诚实口径：精通 1-2 门（亮出代表作），其余"读得懂、能改"，别吹五门全精。

## 2. 工程化意识（要求 2 的"测试与工程化"）

- **测试分层**：单测（核心逻辑如重试/配额计算）→ 集成（会话生命周期全流程）→ 契约测试（MCP/工具接口兼容）→ **评测回归**（Agent 行为不退化，见 [[21_面试岗位/28_Agent_Runtime工程师/08_可观测_评测|08 评测体系]]）；
- **可上线性**：灰度发布、feature flag、指标埋点随代码走、回滚预案先于上线；
- **问题闭环**：告警 → 轨迹回放定位 → 修复 → 回归验证 → 复盘沉淀——JD 要求 6 的"追问题、做复盘"就是考这个肌肉记忆。

---

## 3. AI-Native SDLC（JD 第 6 条逐项落点）

### 3.1 AI Coding 进入研发流

- 编码 Agent（Claude Code / Codex，见 [[21_面试岗位/28_Agent_Runtime工程师/07_Agent_框架产品生态|07 产品生态]]）用于：样板代码生成、跨服务改造、测试补齐、代码评审预检；
- 平台团队的独特玩法：**用自己的产品吃自己的狗粮**——用平台的沙箱跑 Coding Agent，顺手验证隔离与审计能力。

### 3.2 自动化测试智能化

- AI 生成测试用例初稿（人审边界条件）、失败日志自动聚类、flaky 用例自动识别；
- 评测集本身就是"Agent 时代的单元测试"——把行为预期写成可执行断言。

### 3.3 智能诊断

- 告警触发后先由 AI 读轨迹做**根因初判**（失败分类、疑似变更、影响面），人只做确认与处置；
- 复盘材料（时间线、归因）从 trace 自动生成，缩短"追问题"到"做复盘"的路径。

### 3.4 沉淀为工程资产（JD 原文"可复用的工程资产"）

| 资产形态 | 例子 |
|---------|------|
| Skill / Prompt 库 | 排障流程封装成可复用技能（渐进加载） |
| 工具链 | 内部 CLI、脚手架、诊断脚本 |
| 文档与 Runbook | 故障 Playbook、评审 checklist |
| 评测集 | 每次事故的回归用例沉淀进评测集 |

- 记忆口径：**"一次排障是一次消耗，沉淀成 Skill 才是资产"**——这句话可以直接在面试里说。

## 4. 高频面试题速练

1. **"两种语言各写一个你解决过的难题。"** —— 每门主语言准备一个含"问题-定位-修复-沉淀"四步的故事，数字量化（延迟降多少、故障率降多少）。
2. **"AI 生成的代码质量怎么保证？"** —— 分层防线：评审预检（AI 互查）→ 测试门禁 → 评测回归；AI 提效不豁免任何质量关卡。
3. **"怎么判断一个流程值得沉淀为资产？"** —— 频率 × 人数：月均多人在重复的事就值得；沉淀后要有人维护（过期资产比没有更危险）。
