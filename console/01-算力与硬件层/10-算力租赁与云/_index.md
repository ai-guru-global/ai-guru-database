# 算力租赁与云

> 把算力按 token 或按卡时卖出去的层，价格即模型创业的成本线。

## 拆解卡

- **价值来源**：算力的分销层：按卡时/token 卖出，价格即下游创业成本线。
- **护城河**：企业合同、混合云粘性与合规资质。
- **瓶颈**：GPU 供给分配与价格战对毛利的挤压。
- **领先指标**：算力租赁价格指数；云厂商 AI 收入占比

## 六层速览

算力租赁与云是算力的分销层：把 GPU、存储和网络打包，按卡时、调用或 token 卖给模型公司和开发者；它把重资产变成可计费的流动服务。

**打个比方**：像电力公司——你不需要自己建电厂，插上插座按度付费；差别在于云还替你管机房、调度和模型服务，也顺带锁定了你的数据与工作流。

**拆开看**：三层结构：底层数据中心与 GPU 池，中层虚拟化与调度（Kubernetes / Slurm），上层模型 API、MaaS 与行业解决方案；三层各有不同的毛利结构与竞争逻辑。

**怎么运转**：三种收入：IaaS 按卡时、PaaS 按调用、MaaS 按 token；成本结构是折旧 + 电力 + 网络，规模越大、利用率越高，毛利越高，闲置产能则直接吞掉利润。

**格局与博弈**：AWS、Azure、GCP 三强占企业市场，CoreWeave、Nebius 以 GPU 专项租赁抢 AI 原生客户，中国阿里云、火山引擎、华为云分层竞争；承诺消费与生态绑定是锁客手段。

**边界与走向**：云正从「卖资源」转向「卖模型与智能体」；GPU 供给缓解后，价格战会从卡时蔓延到 token，毛利向调度效率与上层应用迁移，纯转租的中间层最先被挤出。

## 关键判断

云是 AI 的收租层，增长确定但毛利承压（置信度 高，展望 12–24 个月）——看推理用量而非训练订单；自研芯片比例决定长期成本曲线。

规模口径：全球云基础设施约 $3000–3500 亿（2025e），AI 相关 25–35%；模型 API 与服务另计

## 二级细分

- **综合云** — AWS/Azure/GCP 企业市场三强
- **GPU 专项云** — CoreWeave 类按卡时出租的 AI 原生云
- **中国算力云** — 阿里云、火山引擎、华为云分层竞争
