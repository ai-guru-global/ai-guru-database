# 白金泽 (Jinze Bai) — 通义千问团队负责人

> **一句话概括**: 领导阿里云 Qwen 团队，从 Qwen-7B 到 Qwen3.7-Max (1M 上下文 + 256K 思考预算)，打造了全球最活跃的开源大模型生态之一。

---

## 核心贡献

- **Qwen 模型家族**: 从 Qwen-7B (2023) 到 Qwen3.7-Max (2026)，覆盖 0.6B 到 235B+ 全尺寸
- **119 种语言**: Qwen3 覆盖全球 119 种语言和方言，真正的多语言模型
- **Hybrid Thinking**: Qwen3 的思考/直答双模，用户可动态切换
- **MoE 架构**: Qwen3-235B-A22B (128 experts, Top-8, 22B active)
- **全面开源**: Apache 2.0 许可，100+ 模型在 HuggingFace/ModelScope
- **Qwen-VL/Audio/Coder/Math**: 全模态专业模型矩阵

## 代表性成果

1. **Qwen 1.0** (2023.8): 7B/14B/72B Dense
   - RoPE + SwiGLU + RMSNorm + GQA
   - 首个阿里开源大模型

2. **Qwen2.5** (2024.9): 18T tokens 训练
   - 编码、数学、多语言大幅提升
   - Qwen2.5-Coder: 5.5T tokens 代码数据

3. **Qwen3** (2025.4): 36T tokens, 119 种语言
   - Hybrid Thinking Mode
   - 匹配 DeepSeek-R1, o1, Gemini-2.5-Pro
   - Apache 2.0 许可

4. **Qwen3.7-Max** (2026): 最新旗舰
   - 1M 上下文, 256K 思考预算
   - 64K 最大输出
   - Function calling + 内置工具

## 技术观点

- **开源是最好的生态**: "Apache 2.0 不是慈善，是让全球开发者帮我们验证和改进"
- **多语言是使命**: "AI 不应该只服务英语使用者，119 种语言是我们的承诺"
- **专业模型矩阵**: "通用模型 + 专业模型 (Coder/Math/Audio) 的组合，比一个大而全的模型更实用"
- **Hybrid Thinking**: "用户有时需要快速回答，有时需要深度推理，模型应该两种都能做"

## 名言金句

> "Qwen 的目标不是做一个模型，而是做一个模型家族，让每个开发者都能找到适合自己的。"

> "119 种语言不是营销数字，是每一种语言都经过评测和优化的。"

> "开源社区的反馈是我们最好的研发指南。"

> "Hybrid Thinking 不是技术噱头，是真正让用户控制计算预算的设计。"

> "阿里云支持 Qwen 开源，因为我们相信 AI 基础设施的价值大于模型本身的价值。"
