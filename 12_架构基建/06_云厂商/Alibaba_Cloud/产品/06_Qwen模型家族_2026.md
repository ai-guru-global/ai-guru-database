# Qwen 模型家族 2026 (Qwen Model Family 2026)

> 中文简称：Qwen 模型家族

> **一句话理解**: 阿里家的 AI 模型全家福——有大个儿的文字模型，也有画画、拍视频、说话唱歌的兄弟姐妹，还代卖别家的明星模型。

---

## 旗舰模型：Qwen3.8-Max

**Qwen3.8-Max**（2026-08 发布）是阿里当前最强旗舰，定位对标 GPT-5.x 与 Claude 4.x 顶级闭源模型：

| 特性 | 参数 |
|------|------|
| 参数量 | 2.4T 参数（MoE 架构） |
| 激活参数 | 95B（A95B） |
| 上下文 | 百万级（1M+） |
| 多模态 | 长视频理解（小时级视频） |
| 特色能力 | 自主编程、深度推理、Agent 工具调用 |

**关键能力**：

- **自主编程**：从需求理解到代码生成的端到端编程闭环，是 Qoder 等编程产品的模型底座
- **长视频理解**：小时级视频内容分析，支撑视频搜索、内容审核等场景
- **百万上下文**：整本书、完整代码仓库级别的理解能力

> 与知识库中记录的 Qwen3.7-Max（2026 上半年旗舰）形成代际演进：3.8 在参数量（2.4T）、上下文（1M）和多模态能力上全面升级，详见 [Qwen 深入分析](../../../05_大模型/14_中国LLM生态/19_Qwen_深入分析.md)。

## API 模型矩阵（百炼 / 千问AI平台）

| 模型 | 类型 | 定位 | 特点 |
|------|------|------|------|
| qwen3.8-max | 闭源旗舰 | 复杂推理、编程、长文本 | 2.4T MoE，百万上下文 |
| qwen3.7-plus | 闭源次旗舰 | 企业级通用任务 | 强推理 + 工具调用 |
| qwen3.7-max | 闭源旗舰（上半年） | 复杂任务 | Hybrid Thinking 模式 |
| qwen3.6-flash | 闭源轻量 | 高吞吐、低成本 | 性价比优先 |
| qwen3.5-omni-flash | 全模态 | 图文音视频统一输入 | 一个模型吃下所有模态 |
| qwen3.5-livetranslate | 同传翻译 | 实时跨语言沟通 | 听懂 60 种语言，会说 29 种 |

**Hybrid Thinking（混合思维模式）**：qwen3.7-max 起引入可开关的深度思考模式，通过 `enable_thinking` / `thinking_budget` API 参数控制思考深度与预算——快任务关思考、难任务开思考，是成本与质量的调节阀。

## 全模态矩阵：图像 / 视频 / 语音

### 图像生成

| 模型 | 能力 | 亮点 |
|------|------|------|
| Qwen-Image-3.0-Pro | 文生图 / 图生图 | 专业级图像生成与编辑 |
| Wan2.7-Image | 图像生成 | 与视频模型同源，风格统一 |

### 视频生成（Wan 家族）

| 模型 | 能力 | 亮点 |
|------|------|------|
| Wan2.7-T2V | 文生视频 | 分钟级长视频生成 |
| Wan2.7-R2V | 图/视频生视频 | 参考图 + 视频驱动 |
| HappyHorse-1.1-T2V | 文生视频 | 快速生成、风格化 |
| HappyHorse-1.1-I2V | 图生视频 | 静态图动起来 |

### 语音与音频

| 模型 | 能力 | 亮点 |
|------|------|------|
| Qwen3-TTS-Flash | 文本转语音 | 低延迟、多音色 |
| Cosyvoice-V3-Flash | 语音合成 | 情感化表达 |
| Fun-ASR-Realtime | 实时语音识别 | 流式 ASR，会议转写场景 |

> 全模态矩阵的意义：阿里把所有模态都做成"Flash"轻量版，降低开发者接入门槛——视频、语音能力不再是大厂专属，普通应用也能按 API 调用。

| 模型 | 参数 | 定位 |
|------|------|------|
| Qwen3.8-2.4T-A95B | 2.4T MoE（95B 激活） | 旗舰开源版，可私有化部署 |

开源策略：Qwen 是全球下载量最大的开源模型家族之一，通过 ModelScope 魔搭社区 + HuggingFace 双渠道分发，是阿里"以开源换生态"战略的核心。

## 第三方托管模型（百炼上的"租客"）

百炼不仅卖自家模型，还以 AWS Bedrock 式双轨模式托管第三方明星模型：

| 模型 | 来源 | 亮点 |
|------|------|------|
| DeepSeek-V4-Pro | DeepSeek | 国产推理强模型 |
| Kimi-K3 | 月之暗面 | 2.8T 参数、1M 上下文 |
| GLM-5.2 | 智谱 AI | 中文理解领先 |
| MiniMax | MiniMax | 多模态能力 |

**架构师视角**：托管第三方模型 = 一次性建设 MaaS 基础设施，多份模型租金收入。对企业客户而言，百炼变成"模型超市"——一个 API Key 调所有主流模型，避免多厂商对接。

## 模型选型指南

| 场景 | 推荐模型 | 理由 |
|------|----------|------|
| 复杂推理 / 编程 | qwen3.8-max | 最强推理 + 自主编程 |
| 高频低成本调用 | qwen3.6-flash | 吞吐高、单价低 |
| 多模态输入 | qwen3.5-omni-flash | 一模型全模态 |
| 实时翻译 | qwen3.5-livetranslate | 同传级延迟 |
| 视频生成 | Wan2.7-T2V | 分钟级长视频 |
| 私有化部署 | Qwen3.8-2.4T-A95B 开源版 | 数据不出域 |
| 多厂商统一 | 百炼第三方托管 | 单 API Key 全覆盖 |
