# 擎创科技

> 中国首批 AIOps 智能运维厂商（公司口径「国内首批智能运维 AIOps 解决方案提供商」）：以夏洛克平台走「运维数据中台优先」的私有化路线——先集中治理告警/日志/指标/追踪数据，再谈告警收敛与根因定位；2023 年起叠加擎智运维大模型与国产算力一体机，客户集中在银行证券等金融机房；C 轮（2021-06，6000 万美元）后无公开新融资。

## 是什么

**上海擎创信息技术有限公司**（品牌「擎创科技」，官网 [eoitek.com](https://www.eoitek.com/) ✅ 实抓，官方邮箱后缀 @eoitek.com、客服电话 4008-215-724 ✅ [2024-10 招聘声明](https://blog.csdn.net/qq_37641528/article/details/143112925)）工商注册于 2014-12-16，法定代表人杨辰，注册资本约 3951 万元，注册地上海静安区 ⚠️ 企查查卡片经搜狗检索页核读，未直接核验 🔍；媒体与官网叙事通行「2016 年成立、深耕智能运维领域近十年」⚠️ 两种口径并存。公司自我定位「智能运维 AIOps 领域领跑者」「国内首批 AIOps 解决方案提供商」「Gartner 连续多年推荐的 AIOps 标杆供应商」✅ 官网/公司文章口径，Gartner 推荐年份与报告名录未独立核验 🔍。创始人杨辰为「从业 20 余年运维老兵」（2022-10 公司分享会口径 ⚠️）。

**产品矩阵以夏洛克平台为壳、运维数据中台为底**（官网「擎创夏洛克产品」六件套 ✅）：综合排障中心、告警辨析中心（告警收敛）、运营决策中心、智能观测中心，加运维数据中台（数据基座 + 大模型能力集成）；能力口径为整合告警、监控指标、日志、追踪多维数据，做精准告警、故障关联、日志聚类、交易多维分析、根因定位 ✅。场景方案列六项：运维数据治理、风险预警、告警全周期管理、应急定界、运营分析、FinOps ✅。任务假设中的「机房数字孪生」在现行官网产品矩阵与公开文章中均未见对应产品 🔍 以官网口径为准。技术叙事强调 L1-L3 告警三层架构（简单告警自动化处置→大模型智能分析→人机协同深度诊断），称已在央企国企落地、「运维效率提升 90% 以上」⚠️ 公司口径无第三方验证。

**客户结构与装机口径是它的核心资产**：2022-10 公司文章列名客户——银联、交通银行、人行清算中心、多家头部城商行、省级农信社/农商行、上证所、中国邮政、宝马、中石化金山石化，覆盖金融、制造、能源交通 ✅ 公司口径；官网案例页现列「国有大行-综合排障分析、头部证券-运维数据中台 / FinOps 运营台、国家电网省级公司-云资源监控、国有大型物流-IT 基础资源监控平台」✅（客户名匿名化）。官网称「自成立以来已为超过 300 家中大型企业提供服务」✅；C 轮报道引「客户复购率 100%、金额续约率超 100%」⚠️ 融资通稿口径。它与京北方等人力交付商同处银行 IT 采购链条但占位不同：平台软件 vs 驻场人力 ⚠️ 分析归纳，未见直接合同关系 🔍。

**融资轨迹（公开可考六轮）**：天使轮原子创投 → Pre-A 元璟资本领投（2018-02 报道，数千万人民币）→ A 轮火山石资本领投（数千万人民币，时点未核 🔍）→ B 轮（细节未公开核验 🔍）→ B+ 轮 GGV 纪源资本千万美元级（2020-03-17 宣布）✅ [FEC 早报转载](https://blog.csdn.net/fec2020/article/details/104937919) → C 轮 6000 万美元（2021-06-22 宣布，M31 资本领投，老股东 GGV、淡马锡旗下 ST Telemedia 跟投，光源资本任独家财顾，媒体称一年半累计融资超 5 亿人民币）⚠️ 36氪/创业邦/动点科技等多源同题，经搜狗检索页核读，一手直链未获 🔍。**证伪项：任务假设的「金沙江创投」未见于任何一轮公开报道 ⚠️；2021-06 C 轮后至 2026-11 无新一轮公开记录 🔍**。

**大模型化走「开源微调 + RAG」的务实路线而非自研基座**：2023-10 在第六届双态 IT 乌镇用户大会正式发布**擎智运维大模型**——对开源大模型参数微调，结合私域数据构建运维知识库，以检索增强让模型理解日志/告警/事件，免调参解析单条日志、自动生成处置方案与故障报告、告警风暴下数据探查与根因定位 ✅ [发布文](https://blog.csdn.net/qq_37641528/article/details/134124764)；复旦大学计算机学院教授王鹏以「擎创首席数据家」身份站台（2020 年报道即有复旦联合实验室之说 ⚠️）。2023-11 与中科可控发布**金融行业大模型一体机**：全国产 CPU + GPU 异构加速、单台 8 卡满足金融部署，称「消弭 80% 以上故障隐患、消除 80% 以上无效告警」✅ [一体机文](https://blog.csdn.net/qq_37641528/article/details/134262380)（数字为公司口径 ⚠️）。2026 年叙事升级为「智能运维 2.0」：数据处理平台成为智能体训练场、运维本体/记忆体系/多智能体协作 ✅ 官网资料中心与公司专栏口径。

**信创适配是其金融生意的入场券，也是这条线索的差异化事实**：官网称「自主可控，已有超 100+ 信创兼容认证」✅；2022-10 夏洛克日志精析中心与数据中台完成统信 UOS 互认证，「10 天拿下两款产品两个版本三个系列共 12 项证书」，同期入选 2022 智能运维企业 TOP50 ✅ [详情](https://blog.csdn.net/qq_37641528/article/details/127532641)；2022-04 加入 openEuler 社区 ✅ [公告](https://blog.csdn.net/qq_37641528/article/details/124191731)、2023-05 获华为鲲鹏技术认证 ✅ [公告](https://blog.csdn.net/qq_37641528/article/details/130753276)、2024-12 入围上海市优秀信创解决方案 ✅ [公告](https://blog.csdn.net/qq_37641528/article/details/144665951)、2025-11 与华为鲲鹏联合数据中台方案获鲲鹏创新大赛铜奖并通过 KUNPENG NATIVE 最高级别认证（认证有效期至 2028，称数据处理效率提升 30%+）✅ [公告](https://blog.csdn.net/qq_37641528/article/details/155359054)（效率数字 ⚠️ 转述口径）。**反方记录**：交付模式为项目制 + 私有化部署为主（B+ 轮报道即强调私有化 ✅）叠加一体机一站式交付——软件平台毛利应优于人力外包，但 AIOps 效果验收标准长期缺失（复购率、降噪率均为厂商自报）、300+ 客户的项目制交付规模化天花板、以及 C 轮后近五年半无新融资，构成这条线索的三重约束 ⚠️ 分析归纳。

## 怎么看

1. **「数据中台优先」是路线，也是它对 AIOps 失败率的诊断。** 公司反复输出「80% 智能体失效源于数据质量缺陷」（碎片化、弱关联、低时效）⚠️ 公司口径——这与 Dynatrace 用 Grail 湖仓统一遥测、把 AI 锚定在数据层是同一判断：智能运维的瓶颈在数据治理而非算法。擎创把运维数据中台做成独立产品（数据基座 + 大模型能力集成），等于把「治理先行」卖两次：先卖底座，再卖智能。
2. **装机口径全靠金融，但效果验收无第三方基准。** 银联/交行/人行清算中心/城商行/农信农商名单 + 300+ 中大型企业官网口径 ✅ 是硬资产；但复购率 100%、降噪 80%、MTTR 38 分钟→5 分钟全部是厂商自报 ⚠️——AIOps 行业长期缺效果验收标准，采购方难以横向比价，这与 Dynatrace 靠 Gartner/Forrester 双 Leader 背书、SEC 财报约束的透明度形成对照。
3. **大模型化是「开源微调 + RAG + 国产一体机」的组合拳，不自研基座。** 擎智大模型四原则（本地化部署、集成现有工具、不为 LLM 而 LLM、发挥语言长处）✅ 说明它清楚自己的价值在运维语料与场景而非模型；与中科可控（2023-11）、华为鲲鹏（2023/2025 认证、2025 铜奖）绑定的信创算力路线，与神州数码昇腾一体机同属「大模型 × 信创」的国侧范式，可与 [[交付与组织/神州数码]] 的交付层分析互证。
4. **融资叙事停在 2021：一级市场冷却的注脚，也是规模化的约束。** 六轮公开融资的资方为原子创投、元璟、火山石、GGV、M31、淡马锡 ST Telemedia——任务假设的「金沙江」未见于任何公开轮次 ⚠️ 证伪项；C 轮（2021-06）后近五年半无新披露 🔍，对一家项目制交付公司意味着增长必须靠自身现金流滚动，扩张斜率受限。
5. **项目制 + 私有化是金融客户的入场券，也是天花板。** 银行要私有化、要信创、要驻场适配，擎创以中台软件 + 一体机交付正中需求；但 300+ 客户 × 每客定制治理的实现方式类似「重软件交付」，人效与毛利介于纯软件与人力外包之间——与京北方（人力交付层）是链条上下游互补位而非直接对手 ⚠️ 分析归纳，未见双方合同关系 🔍。
6. **台内观察价值：中国 AIOps 独立厂商的存活样本。** 对照 [[开发者工具/Dynatrace]]（确定性路线、订阅消耗制、财报透明）可以量出中美智能运维商业模式的落差；跟踪三个硬指标：「智能运维 2.0」运维智能体能否变成合同而非白皮书、鲲鹏/统信认证密度能否转化为非金融行业收入、以及是否有新一轮融资或并购退出——任一落地都是 [[交付与组织/AI交付成本结构]] 中国侧的关键数据点。
