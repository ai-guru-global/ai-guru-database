# LLMs in Production

> **一句话理解**: LLM 生产化实战指南,覆盖从原型到生产的全流程。

## 书籍信息

- **书名**: LLMs in Production
- **出版社**: Manning
- **链接**: [LLMs in Production](https://www.manning.com/books/llms-in-production)

## 核心主题

| 主题 | 内容 |
|------|------|
| **部署架构** | 本地部署、云部署、边缘部署 |
| **推理优化** | 量化、缓存、批处理 |
| **监控与可观测性** | 质量监控、成本追踪、告警 |
| **安全与合规** | 护栏、红队测试、数据隐私 |
| **评估体系** | 自动评估、人工评估、A/B 测试 |
| **成本优化** | 模型路由、Prompt 优化、供应商选择 |

## 适用人群

- 将 LLM 应用推向生产的工程师
- 负责 AI 基础设施的 DevOps/SRE
