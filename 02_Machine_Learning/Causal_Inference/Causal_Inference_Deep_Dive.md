# 因果推断深度解读: 从相关到因果的 AI 新范式

> **一句话理解**: 机器学习擅长发现「相关性」(下雨天雨伞多)，因果推断要回答「因果性」(下雨导致雨伞多)——前者观察世界，后者理解干预的后果，这是 AI 从「模式匹配」走向「真正理解」的关键一步。

---

## 1. 概述 (Overview)

### 1.1 为什么需要因果推断

```
相关 ≠ 因果: AI 的根本局限

┌─────────────────────────────────────────────────────────────────┐
│  经典案例:                                                        │
│                                                                 │
│  案例1: 冰淇淋销量 ↑ ↔ 溺水人数 ↑                               │
│  ├── 相关: 高正相关                                              │
│  ├── 因果: 夏天 (混淆变量) → 两者都增加                          │
│  └── 如果禁售冰淇淋，溺水人数不会减少                             │
│                                                                 │
│  案例2: 医院里死亡率更高                                         │
│  ├── 相关: 去医院 → 死亡率高                                    │
│  ├── 因果: 生病 → 去医院 (反向因果/选择偏差)                     │
│  └── 去医院不会导致死亡                                          │
│                                                                 │
│  案例3: AI 模型的虚假相关性                                      │
│  ├── 图像分类器: 背景雪地 → 判定为"北极熊"                      │
│  ├── 医疗 AI: X光机型号 → 预测疾病 (学到设备偏差而非病症)        │
│  └── 语言模型: 统计相关性 ≠ 因果推理能力                         │
│                                                                 │
│  Pearl 的因果阶梯 (Ladder of Causation):                         │
│  ┌────────────────────────────────────────────────────────┐     │
│  │  层级3: 反事实 (Counterfactuals)                        │     │
│  │  "如果当时做了不同的选择，结果会怎样？"                 │     │
│  │  ↑ 最高认知能力                                         │     │
│  ├────────────────────────────────────────────────────────┤     │
│  │  层级2: 干预 (Interventions)                            │     │
│  │  "如果我强制做 X，Y 会怎样变化？"                       │     │
│  │  P(Y|do(X)) — 因果推断的核心问题                        │     │
│  ├────────────────────────────────────────────────────────┤     │
│  │  层级1: 关联 (Association)                              │     │
│  │  "观察到 X 时，Y 通常是什么？"                          │     │
│  │  P(Y|X) — 传统机器学习停留在此层                        │     │
│  └────────────────────────────────────────────────────────┘     │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 因果推断与 AI 的交汇

| 领域 | 传统 ML | + 因果推断 |
|------|---------|-----------|
| 推荐系统 | 用户点击了什么 | 如果推荐X，用户会不会点击？ |
| 医疗 | 用药患者恢复率 | 药物的真实治疗效果是什么？ |
| 经济学 | GDP与股市相关 | 加息对GDP的因果效应 |
| 公平性 | 模型是否歧视 | 受保护属性对结果的因果效应 |
| LLM推理 | 模式匹配 | 因果链推理 (Causal CoT) |
| 强化学习 | 奖励关联 | 因果世界模型 (更有效的探索) |

## 2. 结构因果模型 (SCM)

### 2.1 有向无环图 (DAG)

```
因果图 (Causal DAG): 节点=变量, 有向边=因果关系

经典结构:

1. 链式 (Chain):
   X → Z → Y
   X 通过 Z 影响 Y (中介效应)
   控制 Z → X 和 Y 独立

2. 叉式 (Fork):
   X ← Z → Y
   Z 是 X 和 Y 的共同原因 (混淆变量)
   控制 Z → X 和 Y 独立

3. 碰撞 (Collider):
   X → Z ← Y
   Z 是 X 和 Y 的共同结果
   不控制 Z → X 和 Y 独立
   控制 Z → X 和 Y 变得相关！(选择偏差)

┌─────────────────────────────────────────────────────────────────┐
│  d-分离 (d-separation):                                         │
│  判断两组变量在给定条件下是否独立的图论准则                       │
│                                                                 │
│  路径被阻断的条件:                                                │
│  ├── 链/叉: 路径上的中间节点被控制 (条件化)                      │
│  └── 碰撞: 碰撞节点及其后代未被控制                              │
│                                                                 │
│  如果 X 和 Y 之间所有路径都被阻断 → X ⊥ Y | Z (d-分离)          │
│  d-分离 ⟹ 条件独立 (在忠实性假设下)                             │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 结构方程模型 (SEM)

```
SCM = 因果图 + 结构方程

X = f_X(U_X)           # X 由外生变量决定
Z = f_Z(X, U_Z)        # Z 由 X 和噪声决定
Y = f_Y(Z, U_Y)        # Y 由 Z 和噪声决定

例: 简单线性 SCM
X = U_X                 # U_X ~ N(0, 1)
Z = 0.8·X + U_Z        # U_Z ~ N(0, 0.5)
Y = 0.6·Z + U_Y        # U_Y ~ N(0, 0.3)

干预 (do-算子):
do(X=x) = 强制将 X 设为 x，切断 X 的所有因果父节点的影响

┌─────────────────────────────────────────────────────────────┐
│  观察 vs 干预:                                                │
│                                                             │
│  P(Y|X=x): "在观察到 X=x 的条件下 Y 的分布"                 │
│    → X=x 的患者中，有多少恢复了？                             │
│    → 可能有混淆: 选择 X=x 的患者本身就更健康                  │
│                                                             │
│  P(Y|do(X=x)): "强制让所有人服药 X=x 后 Y 的分布"            │
│    → 如果所有人都服药，恢复率是多少？                         │
│    → 消除混淆: 随机对照试验 (RCT) 的理想结果                  │
│                                                             │
│  因果推断的核心问题:                                          │
│  如何从观察数据 P(Y|X) 推导出 P(Y|do(X))？                  │
│  答案: do-演算 (do-calculus)                                 │
└─────────────────────────────────────────────────────────────┘
```

## 3. do-演算与因果效应识别

### 3.1 do-演算三条规则

```
Pearl 的 do-演算 (3 条规则, 完备性已证明):

规则1: 插入/删除观察
    P(y|do(x), z, w) = P(y|do(x), w)
    条件: Y ⊥ Z | X, W 在 G_X̄ (删除指向 X 的箭头)

规则2: 干预/观察互换
    P(y|do(x), do(z), w) = P(y|do(x), z, w)
    条件: Y ⊥ Z | X, W 在 G_X̄_Z̲ (删除指向X的 + 删除Z出发的)

规则3: 插入/删除干预
    P(y|do(x), do(z), w) = P(y|do(x), w)
    条件: Y ⊥ Z | X, W 在 G_X̄_Z̄ (删除指向X和Z的箭头)

┌─────────────────────────────────────────────────────────────┐
│  后门准则 (Backdoor Criterion):                              │
│  do-演算最常用的推论                                          │
│                                                             │
│  估计 X→Y 的因果效应:                                        │
│  P(Y|do(X)) = Σ_z P(Y|X, Z=z) · P(Z=z)                    │
│                                                             │
│  条件: Z 是一组满足以下条件的变量:                             │
│  ├── Z 阻断了 X 到 Y 的所有后门路径 (混淆路径)               │
│  └── Z 不包含 X 的后代 (避免中介变量)                         │
│                                                             │
│  例: 药物效果估计                                            │
│  X = 服药, Y = 恢复, Z = {年龄, 性别}                       │
│  P(恢复|do(服药)) = Σ_{z} P(恢复|服药,z) · P(z)             │
│  含义: 按年龄性别分层后重新加权，消除混淆                      │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 常见因果推断方法

```
┌──────────────────┬──────────────────────────┬────────────────────────────┐
│  方法             │  核心思想                  │  适用场景                  │
├──────────────────┼──────────────────────────┼────────────────────────────┤
│  随机对照试验     │  随机分配处理 → 消除混淆    │  金标准，但成本高/伦理限制  │
│  (RCT)           │                            │                            │
├──────────────────┼──────────────────────────┼────────────────────────────┤
│  倾向评分匹配     │  找到特征相似的处理/对照组  │  观察数据 + 已观测混淆     │
│  (PSM)           │  P(T=1|X) 匹配            │                            │
├──────────────────┼──────────────────────────┼────────────────────────────┤
│  双重差分         │  处理前后差异的差异          │  自然实验 + 时间序列       │
│  (DID)           │  δ = (Y₁ₜ-Y₁c)-(Y₀ₜ-Y₀c) │                            │
├──────────────────┼──────────────────────────┼────────────────────────────┤
│  工具变量         │  用外生变量 Z 影响 X 但不   │  存在未观测混淆            │
│  (IV)            │  直接影响 Y                 │                            │
├──────────────────┼──────────────────────────┼────────────────────────────┤
│  断点回归         │  利用政策阈值 (如分数线)    │  存在明确的处理阈值         │
│  (RDD)           │  阈值两侧的"准随机"分配     │                            │
├──────────────────┼──────────────────────────┼────────────────────────────┤
│  合成控制法       │  用多个对照单位构造合成对照  │  单一处理单位 (如某个州)    │
│  (SCM)           │  加权组合 → 反事实          │                            │
└──────────────────┴──────────────────────────┴────────────────────────────┘
```

### 3.3 工具变量 (IV) 详解

```
工具变量的逻辑:

    Z (工具变量)
    │
    ↓
    X → Y
    ↑
    U (未观测混淆)

Z 的条件:
1. 相关性: Z 与 X 相关 (Z 影响 X)
2. 排他性: Z 不直接影响 Y (只通过 X)
3. 外生性: Z 与 U 不相关 (Z 不被混淆影响)

例: 教育的工资效应
├── X = 受教育年限
├── Y = 工资
├── U = 能力 (未观测，同时影响教育和工资)
└── Z = 出生月份 (影响入学年龄 → 教育年限，但不直接影响能力)

两阶段最小二乘 (2SLS):
1. 第一阶段: X = π₀ + π₁·Z + ε → 得到 X̂
2. 第二阶段: Y = β₀ + β₁·X̂ + η → β₁ 是因果效应
```

## 4. 因果发现 (Causal Discovery)

### 4.1 从数据中学习因果图

```
因果发现: 给定观测数据，推断变量间的因果关系

┌─────────────────────────────────────────────────────────────────┐
│  三类方法:                                                        │
│                                                                 │
│  1. 基于约束的方法:                                               │
│     ├── PC 算法: 从完全图开始，通过条件独立性测试逐步删除边        │
│     ├── FCI 算法: 允许存在隐变量和选择偏差                        │
│     └── 输出: 马尔可夫等价类 (部分有向无环图 PDAG)                │
│                                                                 │
│  2. 基于评分的方法:                                               │
│     ├── GES (Greedy Equivalence Search): 贪心搜索最优 DAG        │
│     ├── BIC/BDeu 评分: 平衡拟合度和复杂度                         │
│     └── NOTEARS: 将 DAG 约束转化为连续优化问题                    │
│                                                                 │
│  3. 基于函数模型的方法:                                            │
│     ├── ANM (Additive Noise Model): Y = f(X) + N               │
│     │   如果残差与 X 独立 → X→Y 方向正确                         │
│     ├── IGCI: 利用信息几何判断因果方向                            │
│     └── LiNGAM: 线性非高斯 → 可完全识别因果方向                  │
│                                                                 │
│  局限:                                                           │
│  ├── 马尔可夫等价类中的因果方向不可区分 (需要干预数据)             │
│  ├── 隐变量: 观测数据无法检测未测量的混淆                         │
│  └── 高维: 变量数量多时计算复杂度高                               │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 因果推断代码实践

```python
# 使用 DoWhy (微软因果推断库) 进行因果效应估计
import dowhy
from dowhy import CausalModel
import pandas as pd
import numpy as np

# 生成模拟数据: 药物效果
np.random.seed(42)
n = 1000
age = np.random.normal(50, 15, n)          # 混淆变量
treatment = (age > 50).astype(float) + np.random.normal(0, 0.3, n)  # 老年人更可能服药
treatment = (treatment > 0.5).astype(int)
outcome = 0.3 * treatment + 0.02 * age + np.random.normal(0, 1, n)  # 真实效应=0.3

df = pd.DataFrame({'age': age, 'treatment': treatment, 'outcome': outcome})

# 1. 定义因果模型
model = CausalModel(
    data=df,
    treatment='treatment',
    outcome='outcome',
    common_causes=['age'],    # 已知混淆变量
    graph='digraph { age -> treatment; age -> outcome; treatment -> outcome; }'
)

# 2. 识别因果效应
identified = model.identify_effect()
print(f"识别策略: {identified.estimand}")

# 3. 估计因果效应 (后门准则 + 线性回归)
estimate = model.estimate_effect(identified,
    method_name="backdoor.linear_regression")
print(f"估计因果效应: {estimate.value:.3f}")  # 应接近 0.3

# 4. 稳健性检验 (反驳测试)
refute = model.refute_estimate(identified, estimate,
    method_name="random_common_cause")
print(f"稳健性检验: {refute}")
```

## 7. 关键概念速查

| 概念 | 解释 | 核心公式/方法 |
|------|------|--------------|
| do-算子 | 表示干预操作 | P(Y\|do(X=x)) |
| 后门准则 | 通过条件化消除混淆 | Σ_z P(Y\|X,Z=z)·P(Z=z) |
| 前门准则 | 通过中介变量估计因果 | P(Y\|do(X)) = Σ_m P(Y\|X,m)·P(m\|do(X)) |
| 工具变量 | 外生变量辅助识别 | 2SLS 两阶段最小二乘 |
| d-分离 | 图上判断条件独立 | 路径阻断规则 |
| 马尔可夫等价 | 不同DAG产生相同分布 | 无法从观测数据区分 |
| 反事实 | 假设条件下的结果 | Y(x') 当实际 X=x |
| 中介效应 | 因果路径的分解 | 直接效应 + 间接效应 |
