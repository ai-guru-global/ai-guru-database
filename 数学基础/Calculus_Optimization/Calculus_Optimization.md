# 微积分与优化 (Calculus & Optimization)

> 微积分和优化是深度学习的数学基石——从导数到梯度下降，从凸优化到 Adam，系统解析 AI 所需的数学基础。

---

## 1. 概述 (Overview)

微积分和优化理论是深度学习的数学基础。反向传播算法依赖链式法则（微积分），模型训练依赖梯度下降（优化理论）。理解这些数学工具是深入理解 AI 的前提。

### 为什么 AI 需要微积分和优化？

```
深度学习的核心循环:

  前向传播: 输入 → 计算 → 输出 → 损失
  反向传播: 损失 → 梯度 → 参数更新

  反向传播 = 链式法则 (微积分)
  参数更新 = 梯度下降 (优化)

没有微积分: 无法计算梯度
没有优化: 无法更新参数
```

## 2. 微积分基础 (Calculus Foundations)

### 2.1 导数 (Derivative)

```
导数描述函数的变化率:

  f'(x) = lim[Δx→0] (f(x+Δx) - f(x)) / Δx

几何意义: 切线斜率
物理意义: 瞬时变化率

常见导数:
  (x^n)' = nx^(n-1)
  (e^x)' = e^x
  (ln x)' = 1/x
  (sin x)' = cos x
  (cos x)' = -sin x
```

### 2.2 偏导数 (Partial Derivative)

```
多变量函数对某一个变量的导数:

  f(x, y) = x² + xy + y²

  ∂f/∂x = 2x + y  (对 x 求导，y 视为常数)
  ∂f/∂y = x + 2y  (对 y 求导，x 视为常数)
```

### 2.3 梯度 (Gradient)

```
梯度是偏导数组成的向量:

  ∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]

性质:
  - 方向: 函数增长最快的方向
  - 大小: 最大变化率
  - 负梯度: 函数下降最快的方向

深度学习中:
  梯度 = 损失函数对参数的偏导数
  参数更新 = 参数 - 学习率 × 梯度
```

### 2.4 链式法则 (Chain Rule)

```
复合函数的导数:

  y = f(g(x))
  dy/dx = f'(g(x)) · g'(x)

多层复合:
  y = f(g(h(x)))
  dy/dx = f'(g(h(x))) · g'(h(x)) · h'(x)

反向传播就是链式法则的应用:

  Loss = L(y, ŷ)
  ŷ = softmax(W₂ · relu(W₁ · x + b₁) + b₂)

  ∂L/∂W₁ = ∂L/∂ŷ · ∂ŷ/∂z₂ · ∂z₂/∂h₁ · ∂h₁/∂z₁ · ∂z₁/∂W₁
```

### 2.5 雅可比矩阵和海森矩阵

```
雅可比矩阵 (Jacobian):
  多变量函数的一阶导数矩阵

  J = [∂f₁/∂x₁  ∂f₁/∂x₂]
      [∂f₂/∂x₁  ∂f₂/∂x₂]

海森矩阵 (Hessian):
  多变量函数的二阶导数矩阵

  H = [∂²f/∂x₁²    ∂²f/∂x₁∂x₂]
      [∂²f/∂x₂∂x₁  ∂²f/∂x₂²  ]

应用:
  - 雅可比矩阵: 反向传播中的梯度计算
  - 海森矩阵: 优化算法中的曲率信息
```

## 3. 优化基础 (Optimization Foundations)

### 3.1 优化问题定义

```
最小化问题:

  min f(x)
  s.t. g(x) ≤ 0 (不等式约束)
       h(x) = 0 (等式约束)

  f(x): 目标函数 (损失函数)
  x: 优化变量 (模型参数)
  g, h: 约束函数

深度学习中:
  min L(θ; D) = Σ loss(yᵢ, f(xᵢ; θ))

  θ: 模型参数
  D: 训练数据
  L: 总损失
```

### 3.2 凸优化 vs 非凸优化

```
凸优化:
  - 目标函数是凸函数
  - 局部最优 = 全局最优
  - 有成熟的算法
  - 例: 线性规划、二次规划

非凸优化:
  - 目标函数非凸
  - 存在多个局部最优
  - 没有保证全局最优的算法
  - 深度学习就是非凸优化

为什么深度学习能工作？
  - 过参数化: 参数远多于数据点
  - 大部分局部最优接近全局最优
  - 随机梯度下降有助于跳出局部最优
```

### 3.3 梯度下降 (Gradient Descent)

```
基本思想: 沿负梯度方向更新参数

  θ = θ - η · ∇L(θ)

  η: 学习率
  ∇L(θ): 损失函数的梯度

变体:
├── 批量梯度下降 (BGD)
│   - 使用所有数据计算梯度
│   - 精确但慢
│
├── 随机梯度下降 (SGD)
│   - 使用单个样本计算梯度
│   - 快但噪声大
│
└── 小批量梯度下降 (Mini-batch GD)
    - 使用小批量数据计算梯度
    - 平衡速度和精度
    - 深度学习的标准方法
```

### 3.4 学习率调度

```
学习率对训练至关重要:

学习率太大:
  - 震荡，不收敛
  - 可能发散

学习率太小:
  - 收敛慢
  - 可能卡在局部最优

调度策略:
  - 固定学习率: 简单但不灵活
  - Step decay: 每 N 步衰减
  - Cosine annealing: 余弦衰减
  - Warmup + decay: 先增后减
  - 自适应: Adam 等自动调整
```

## 4. 高级优化算法 (Advanced Optimizers)

### 4.1 动量 (Momentum)

```
问题: SGD 在峡谷地形中震荡

动量: 引入"惯性"

  v = β · v + ∇L(θ)
  θ = θ - η · v

  β: 动量系数 (通常 0.9)

效果:
  - 在一致方向上加速
  - 在震荡方向上抑制
  - 更快收敛
```

### 4.2 AdaGrad

```
自适应学习率: 对不同参数使用不同学习率

  G = G + (∇L)²
  θ = θ - η / (√G + ε) · ∇L

  G: 梯度平方的累积和
  ε: 防止除零

优点: 自适应调整
缺点: 学习率单调递减，可能过早停止
```

### 4.3 RMSProp

```
改进 AdaGrad: 使用指数移动平均

  G = β · G + (1-β) · (∇L)²
  θ = θ - η / (√G + ε) · ∇L

效果: 解决 AdaGrad 学习率过早衰减的问题
```

### 4.4 Adam (Adaptive Moment Estimation)

```
结合动量和 RMSProp:

  m = β₁ · m + (1-β₁) · ∇L      (一阶矩估计)
  v = β₂ · v + (1-β₂) · (∇L)²   (二阶矩估计)

  m̂ = m / (1-β₁^t)  (偏差修正)
  v̂ = v / (1-β₂^t)  (偏差修正)

  θ = θ - η · m̂ / (√v̂ + ε)

默认参数:
  β₁ = 0.9, β₂ = 0.999, ε = 1e-8

优点: 自适应、快速收敛、鲁棒
缺点: 泛化性可能不如 SGD
```

### 4.5 AdamW

```
Adam + 权重衰减解耦:

  θ = θ - η · (m̂ / (√v̂ + ε) + λ · θ)

  λ: 权重衰减系数

优势:
  - 正则化效果更好
  - LLM 训练的事实标准
  - 2026 年最流行的优化器
```

## 5. 优化在深度学习中的应用

### 5.1 损失函数设计

```
分类任务:
  - 交叉熵损失: L = -Σ yᵢ log(ŷᵢ)
  - Focal Loss: 处理类别不平衡

回归任务:
  - MSE: L = Σ(yᵢ - ŷᵢ)²
  - MAE: L = Σ|yᵢ - ŷᵢ|
  - Huber Loss: MSE 和 MAE 的结合

对比学习:
  - InfoNCE: L = -log(exp(sim/τ) / Σexp(sim/τ))
  - Triplet Loss: L = max(0, d(a,p) - d(a,n) + margin)

生成任务:
  - GAN Loss: min max V(D,G)
  - 扩散模型: L = E[||ε - ε_θ||²]
```

### 5.2 正则化

```
L2 正则化 (权重衰减):
  L_total = L_data + λ · Σ θᵢ²
  效果: 权重趋向于小值

L1 正则化 (稀疏化):
  L_total = L_data + λ · Σ |θᵢ|
  效果: 权重趋向于稀疏

Dropout:
  训练时随机关闭神经元
  效果: 防止过拟合，类似集成学习

早停:
  验证集性能不再提升时停止
  效果: 防止过拟合
```

## 6. 实用技巧 (Practical Tips)

```
1. 学习率选择
   - 从 1e-3 开始 (Adam)
   - 从 1e-1 开始 (SGD)
   - 使用学习率查找器

2. 批大小选择
   - 受 GPU 内存限制
   - 大批量需要更大学习率
   - 小批量提供更多正则化

3. 梯度裁剪
   - 防止梯度爆炸
   - clip_grad_norm = 1.0

4. 混合精度训练
   - FP16/BF16 加速
   - 需要损失缩放

5. 梯度累积
   - 模拟大批量训练
   - 有效批大小 = 批大小 × 累积步数
```

## 7. 生产环境 checklist

```
□ 理解目标函数、约束与可行域
□ 选择适合问题凸性的优化器
□ 设置合理的学习率并配合调度策略
□ 使用梯度裁剪与正则化防止不稳定/过拟合
□ 监控损失、梯度范数、学习率曲线
□ 记录随机种子、数据版本、超参数
□ 对 LLM 等大规模任务优先使用 AdamW + cosine decay
□ 进行充分的消融实验验证优化器选择
□ 部署前评估收敛速度与最终泛化性能
```
