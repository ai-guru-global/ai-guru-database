# Build a Multi-Agent System

> **一句话理解**: Manning 出品的"从零构建"系列之一，聚焦多 Agent 系统的底层设计，讲解 Agent 间通信、任务分解与协作编排，适合深入理解多智能体架构。

## 核心内容概要（基于 Manning 大纲）

1. **多 Agent 系统概览** — 为什么需要多 Agent、应用场景
2. **Agent 架构** — 单 Agent 的基本组件回顾
3. **Agent 间通信协议** — 消息传递、共享黑板、事件驱动
4. **任务分解与分配** — 如何拆解复杂任务给多个 Agent
5. **协作与协调机制** — 层级式、对等式、市场式协调
6. **编排框架** — 从零实现编排引擎
7. **记忆与状态管理** — 全局状态、共享上下文
8. **容错与评估** — Agent 失败处理、系统可靠性
9. **生产化** — 部署、监控、扩展

## 适合人群

- **级别**: 高级
- **前置知识**: 了解 LLM Agent、有工程经验
- **适合**: 构建复杂 Agent 系统的架构师、高级开发者
