# 模型卡与文档 (Model Card Documentation)

## 1. 为什么需要模型卡？

```
模型卡 = AI 模型的"说明书" + "体检报告"

目的:
- 透明度: 让用户了解模型能做什么/不能做什么
- 问责: 明确模型的局限性和风险
- 合规: 欧盟 AI Act 要求高风险 AI 系统文档化
- 信任: 帮助使用者做出知情决策

类比:
- 食品 → 营养成分表
- 药品 → 说明书 (适应症/禁忌/副作用)
- AI 模型 → 模型卡 (能力/局限/偏见/适用场景)
```

## 最佳实践清单

| 实践 | 说明 | 优先级 | 预期收益 |

| 标准化流程 | 统一规范和流程 | P0 | 减少错误+提升效率 |

| 持续监控 | 关键指标实时监控 | P1 | 及时发现问题 |

| 安全优先 | 安全贯穿全流程 | P0 | 降低风险 |

## 常见问题与解决方案

| 问题 | 根因分析 | 解决方案 | 预防措施 |
|------|----------|----------|----------|
| 效率低下 | 流程不规范/工具不当 | 优化流程+引入工具 | 标准化+培训 |
| 质量不稳定 | 缺乏检查机制 | 引入质量门禁 | 自动化测试 |
| 协作困难 | 职责不清/沟通不畅 | 明确分工+定期同步 | 文档化+工具 |
| 技术债务 | 赶工忽略质量 | 定期重构+代码审查 | 质量优先文化 |
| 安全风险 | 意识不足/措施缺失 | 安全培训+工具扫描 | 安全左移 |
