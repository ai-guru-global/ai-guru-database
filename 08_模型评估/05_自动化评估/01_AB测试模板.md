# A/B 测试方案模板 (A/B Testing Template)

> 中文简称：A/B 测试方案模板

> 标准化的 ML 模型 A/B 测试方案模板——科学评估模型变更的业务效果，用数据驱动上线决策。

---

## 模板

```markdown
# A/B 测试方案: [实验名称]

## 1. 实验概述

| 字段 | 内容 |
|------|------|
| 实验名称 | [名称] |
| 实验ID | AB-YYYYMMDD-NNN |
| 发起人 | [姓名] |
| 开始日期 | YYYY-MM-DD |
| 预计结束 | YYYY-MM-DD |
| 状态 | 设计中 / 运行中 / 已结束 |

## 2. 实验背景

### 业务问题
> [描述要解决的业务问题]

### 变更内容
- 对照组 (A): [当前模型/策略 v1.0]
- 实验组 (B): [新模型/策略 v1.1]

### 预期收益
- [预期指标提升]
- [预期业务价值]

## 3. 实验设计

### 假设

- **零假设 (H₀)**: 新模型与当前模型在 [主指标] 上无显著差异
- **备择假设 (H₁)**: 新模型在 [主指标] 上优于当前模型

### 指标体系

| 类型 | 指标 | 计算方式 | 方向 |
|------|------|---------|------|
| 主要指标 | [转化率] | [定义] | 越高越好 |
| 护栏指标 | [错误率] | [定义] | 越低越好 |
| 辅助指标 | [点击率] | [定义] | 越高越好 |
| 辅助指标 | [停留时长] | [定义] | 越高越好 |

### 样本量计算

| 参数 | 值 |
|------|-----|
| 基线值 | [92.3%] |
| 最小可检测效应 (MDE) | [1%] |
| 显著性水平 (α) | 0.05 |
| 统计功效 (1-β) | 0.8 |
| 所需样本量 | [每组 N 人] |
| 预计天数 | [X 天] |

### 流量分配

```
总流量: 100%
├── 对照组 (A): 50%
└── 实验组 (B): 50%

分流方式: 用户ID哈希
分流粒度: 用户级（同一用户始终在同一组）
```

### 排除条件
- 新用户（注册 < 7天）
- 内部员工
- 异常流量（爬虫、刷量）

## 4. 技术实现

### 分流逻辑

```python
def assign_group(user_id: str, experiment_id: str) -> str:
    hash_value = hashlib.md5(f"{user_id}:{experiment_id}".encode()).hexdigest()
    return "control" if int(hash_value, 16) % 100 < 50 else "treatment"
```

### 埋点事件

| 事件名 | 触发时机 | 参数 |
|--------|---------|------|
| model_request | 模型推理请求 | user_id, model_version |
| model_response | 模型返回结果 | latency, token_count |
| user_feedback | 用户反馈 | rating, feedback_text |

## 5. 分析计划

### 分析方法

| 指标 | 统计方法 | 显著性判断 |
|------|---------|-----------|
| 转化率 | 卡方检验 | p < 0.05 |
| 连续指标 | t检验 | p < 0.05 |
| 分组分析 | 分层分析 | 各层一致 |

### 分析代码

```python
from scipy.stats import chi2_contingency, ttest_ind

# 转化率对比
contingency = [[conversions_a, n_a - conversions_a],
               [conversions_b, n_b - conversions_b]]
chi2, p_value, _, _ = chi2_contingency(contingency)

# 连续指标对比
t_stat, p_value = ttest_ind(metric_a, metric_b)
```

## 6. 风险控制

| 风险 | 应对措施 |
|------|---------|
| 指标严重下降 | 自动停止实验 |
| 样本污染 | 严格分流，监控重叠 |
| 新奇效应 | 至少运行 7 天 |
| 周期效应 | 覆盖完整周期 |

### 停止条件

- 主要指标下降 > 5% 且 p < 0.01 → 立即停止
- 护栏指标突破阈值 → 立即停止
- 运行满 14 天仍未显著 → 结束并分析
