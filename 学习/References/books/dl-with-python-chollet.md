# Deep Learning with Python

> **一句话理解**: Keras 创始人 François Chollet 的深度学习入门经典，以"直觉优先 + 代码驱动"的方式讲解深度学习，是初学者最友好的 DL 教材之一。

## 书籍信息

| 属性 | 说明 |
|------|------|
| **书名** | Deep Learning with Python（第2版） |
| **作者** | François Chollet |
| **出版社** | Manning（2021，第2版） |
| **页数** | 约 500 页 |
| **难度** | ⭐⭐☆（入门→中级） |
| **代码语言** | Python（Keras / TensorFlow） |
| **链接** | [Manning](https://www.manning.com/books/deep-learning-with-python-second-edition) |

## 核心内容概要

全书 14 章，分四部分：

**深度学习基础**
1. 什么是深度学习
2. 神经网络的数学基础
3. 神经网络入门

**深度学习实践**
4. 机器学习基础
5. 深度学习 for 计算机视觉
6. 深度学习 for 文本与序列

**高级深度学习**
7. 高级深度学习最佳实践（Keras 函数式 API、回调）
8. 生成式深度学习（VAE、GAN）
9. 高级架构（Transformer）

**深度学习实战与展望**
10-14. 模型部署、模型工程原则、深度学习的局限与未来

## 适合人群

- **级别**: 初级 → 中级
- **前置知识**: Python 基础
- **适合**: 深度学习初学者、希望快速上手的工程师

## 学习建议

- **阅读顺序**: 从头到尾顺序阅读，每章代码务必动手跑
- **实战搭配**: 搭配 [[hands-on-ml-geron]]（更全面）形成互补
- **注意**: 第2版更新了 Transformer 与 Keras API，务必读第2版

## 亮点与局限

- ✅ **亮点**: 直觉讲解极佳、代码简洁（Keras）、作者视角独到（强调工程思维）
- ⚠️ **局限**: 以 Keras/TensorFlow 为主，PyTorch 用户需转换；理论深度不如花书；篇幅适中但 RL 等主题未覆盖
