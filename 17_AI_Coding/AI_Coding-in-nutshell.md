## 常用 Prompt 模板

### 创建新功能

```
请用 [技术栈] 创建一个 [功能名称]：
- 功能描述：[具体描述]
- 输入：[输入什么]
- 输出：[输出什么]
- 约束条件：[需要注意什么]
- 参考风格：[参考示例或风格]
```

### 修复 Bug

```
这段代码有 bug，请帮我找出并修复：

代码：
[粘贴代码]

报错信息：
[粘贴报错]

期望行为：
[应该怎样]
```

### 代码重构

```
请重构以下代码，要求：
- 提高可读性
- 优化性能
- 遵循 [技术栈] 最佳实践
- 保持功能不变

代码：
[粘贴代码]
```

### 代码解释

```
请逐行解释这段代码：
1. 每一行在做什么
2. 整体逻辑流程
3. 潜在的问题或改进建议

代码：
[粘贴代码]
```

### 写测试

```
请为以下函数编写单元测试：
- 覆盖正常情况
- 覆盖边界情况
- 覆盖错误情况
- 使用 [测试框架]

函数：
[粘贴代码]
```

## 最佳实践清单

### 开始前

- [ ] 明确你要做什么（写下来，越具体越好）
- [ ] 确定技术栈和项目结构
- [ ] 准备好相关文档或参考代码

### 使用 AI 时

- [ ] 一次只让 AI 做一件事
- [ ] 给出足够的上下文（项目结构、技术栈、已有代码）
- [ ] 明确说明约束条件和期望
- [ ] 用例子说明你想要的效果

### 审查 AI 代码时

- [ ] 你能看懂每行代码在做什么吗？
- [ ] 代码是否符合项目的编码规范？
- [ ] 有没有安全漏洞（SQL注入、XSS等）？
- [ ] 有没有性能问题（N+1查询、内存泄漏等）？
- [ ] 有没有处理错误和边界情况？
- [ ] 测试通过了吗？

### 完成后

- [ ] 运行全量测试确保没有回归
- [ ] 代码审查（自己或同事）
- [ ] 清理 AI 生成的不必要注释
- [ ] 确认没有硬编码的密钥或敏感信息

## 常见陷阱

| 陷阱 | 症状 | 解决方法 |
|------|------|---------|
| 幻觉代码 | AI 使用了不存在的函数或API | 运行验证，查官方文档 |
| 上下文丢失 | AI 忘记之前的约定 | 定期重申关键约束 |
| 过度工程 | AI 写了过于复杂的方案 | 明确要求"简单实现" |
| 安全忽视 | AI 忽略输入验证和错误处理 | 专门要求处理安全 |
| 版本过时 | AI 用了已废弃的API | 指定框架/库的版本号 |
| 代码不一致 | AI 的风格和项目不统一 | 提供现有代码作为参考 |

## 快速开始指南

### Cursor 快速开始

```
1. 下载安装：https://cursor.sh
2. 打开项目文件夹
3. 快捷键：
   - Cmd+K：AI 编辑（选中代码后按 Cmd+K）
   - Cmd+L：打开 AI 对话
   - Tab：接受 AI 补全建议
   - Esc：拒绝建议
4. 开始写代码，AI 会自动补全
```

### GitHub Copilot 快速开始

```
1. 安装 VS Code
2. 安装 Copilot 插件
3. 登录 GitHub 账号
4. 开始写代码：
   - 写注释 → Copilot 自动生成代码
   - 写函数名 → Copilot 自动补全函数体
   - Tab 接受，Esc 拒绝
```

### Claude 快速开始

```
1. 打开 https://claude.ai
2. 新建对话
3. 粘贴代码或描述需求
4. 技巧：
   - 使用 Artifacts 功能查看生成的代码
   - 上传项目文件让 Claude 了解上下文
   - 要求 Claude "逐步思考"处理复杂问题
```

### ChatGPT 快速开始

```
1. 打开 https://chat.openai.com
2. 新建对话
3. 技巧：
   - 选择 GPT-4 模型（代码质量更好）
   - 使用 Code Interpreter 运行代码
   - 把长对话分成多个小对话
```

## 一句话建议

| 场景 | 建议 |
|------|------|
| 不知道用什么工具 | 先试 Cursor |
| 只需要偶尔写代码 | 用 ChatGPT/Claude |
| 追求补全效率 | Copilot 或 Windsurf |
| 做前端 UI | v0 + Cursor 组合 |
| 做全栈应用 | Bolt.new 或 Cursor |
| 复杂架构讨论 | 先找 Claude 讨论，再回 Cursor 写代码 |
| 学习编程 | Claude（解释最清楚） |
| 团队协作 | 统一用 Copilot（和 GitHub 深度整合） |
