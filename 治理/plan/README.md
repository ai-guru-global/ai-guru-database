## 评估体系

项目采用双轨评估机制：

### 角色视角评估
从使用者角色出发，识别各角色的知识缺口：
- Agent 工程师视角
- 大模型工程师视角
- 架构师视角
- 集成测试工程师视角
- 工单管理视角

### 数据驱动评估
从项目结构出发，量化内容健康度：
- 结构一致性（README / for_dummy / nutshell 覆盖率）
- 内容深度（各章节行数分布与质量）
- 交叉引用（内部链接密度与连通性）
- 覆盖完整度（代码示例、图表、更新时效）
