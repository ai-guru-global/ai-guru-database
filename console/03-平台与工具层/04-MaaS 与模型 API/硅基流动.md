# 硅基流动

> 国产开源模型推理 API 平台的「Token 工厂」样本：2025-02 借 DeepSeek-R1/V3 × 华为昇腾首发出圈；招股书口径 2025 年营收仅 5533 万元（+653.2%）、毛利率 -24.0%、净亏 3.45 亿元——2026 年内连做 B（超 20 亿）/B+ 二期/C 三轮、累计近 29 亿元、投后估值 77.4 亿元，2026-06-30 递表港交所 18C 冲刺「AI Token 工厂第一股」。

## 是什么

**北京硅基流动科技股份有限公司**（官网 [siliconflow.cn](https://siliconflow.cn/) ✅）2023 年 8 月成立，定位「大模型 API 与 AI 云服务平台」：基于自研推理引擎，把开源模型的推理能力做成按量计费的标准 Token 产能。创始人袁进辉为深度学习框架公司 OneFlow（一流科技）创始人、前微软亚洲研究院主管研究员 ✅ InfoQ 口径；「OneFlow 团队整体并入硅基流动」的说法 🔍 未获一手源核实，本卡不采信细节。全球对标 Together AI（专用推理云）与 OpenRouter（路由网关），主战场则是中国开源模型生态的托管推理。

**产品矩阵**（官网口径 ✅）：开箱即用大模型 API（语言/语音/图片/视频，按量计费）、推理加速服务（自研引擎，宣称延迟最高降 70%、吞吐提升 3-5 倍）、预留实例（独占算力）、私有化大模型服务平台与 TokenPlus 智能网关（多模型路由 + BYOK）。关键节点：2024-05 公有云 MaaS（SiliconCloud）上线、打通「裸金属到标准化 Token」链路；2025-09 推私有化 MaaS；2026-04 上线算力调度引擎「弹性 GPU」⚠️ 均为媒体/公司口径。

**出圈事件是 2025-02 的「DeepSeek 时刻」**：R1 爆发引发全网推理挤兑，硅基流动联合华为云基于昇腾率先推出 DeepSeek-R1/V3 推理服务 ✅ 招股书口径（36kr 转述），公司称 2025 年初「大规模使用华为算力」承接 DeepSeek 流量 ✅ 官网活动纪要，媒体称其为「业内首个国产芯片超大规模 Token 生产服务」⚠️ 单源。代价记录在招股书里：2025 年免费发放 Token 代金券 5421.3 万元、占销售及营销费用 64.7% ✅——用免费换流量是这一战的真实成本结构。

**财务真相与增长质量的张力是这条线索的核心**（招股书口径 ✅ 36kr/腾讯转述）：营收 2023 年 10 万元（36kr 另一处称「成立后 4 个月运营期收入仅 6000 元」⚠️ 两源转述同一招股书出现分歧）→ 2024 年 734.5 万元 → 2025 年 5533 万元（+653.2%）；毛利率 2024 年 39.4% → 2025 年 -24.0%；净亏损三年累计超 4.4 亿元；2025 年经营性现金流净流出 1.72 亿元、月度现金消耗约 1480 万元，年末现金及等价物仅 1.715 亿元。结构上：公有云 Token 服务收入占比 14.6% → 52.9% 升为第一大业务，但该业务毛利率 -119.0% ✅；免费代金券约相当于当年营收的 98%——「1 元券换 1 元收入」的媒体质疑 ⚠️ 由此而来。

**融资链在 2026 年陡然加速**：2024-01 天使轮 5000 万元（创新工场领投，耀途资本、奇绩创坛、王慧文跟投）→ 2024-07 天使+轮近亿元（智谱 AI、360 等）→ Pre-A 轮亿元级（华创资本领投；时点两源分歧：InfoQ 称 2024 年底、腾讯/搜狐称 2025-02 ⚠️）→ 2025-06 A 轮数亿元（阿里云领投）→ 2026-06 B 轮超 20 亿元（携程战投、晶科能源、金蝶、联通新沃、壁仞战投、蔚来资本、商汤战投、巨人网络、国开金融、中关村科学城等，创当时国内第三方 MaaS 最大单笔 ✅）→ 2026-09-20 宣布 B+ 二期与 C 轮（中国互联网投资基金、国新基金、中国移动链长基金、中国东方资产国际等），2026 年内累计近 29 亿元 ✅。招股书隐含投后估值 2026 年 2 月 → 6 月从 31.20 亿元三连跳至 77.40 亿元 ✅；IPO 前股东：阿里巴巴 7.42%、华为 4.07%、创新工场 4.01% ⚠️ 招股书转述口径。

**算力供给侧是它的真差异化**：适配英伟达、华为昇腾、沐曦、摩尔线程等 10 余款芯片 ✅ 招股书口径；自述在 PD 分离架构下探索国产芯片与英伟达混合调度、不同硬件承担适配任务，模型加载从约 30 分钟优化至 1 分钟内 ✅ 官网「Token 工厂」纪要（2026-11-06）。规模：截至 2026-04 注册用户超 1000 万、日均 Token 吞吐约 5785 亿次、单日峰值约 1.07 万亿次；截至 2026-06-21 企业客户超 1.3 万家、累计支持模型超 170 个 ✅ 招股书口径。注意口径差：公司 PR 称「日均 Token 调用量达数万亿」，与招股书 5785 亿相差约一个量级 ⚠️。

**市场坐标与反方观点**：按 2025 年 Token 年吞吐量，Frost & Sullivan 定性其为「中国最大独立生态 Token 供应商」、全行业前五，但份额仅 1.5%——火山引擎 42.7%、阿里云 32.5%、百度智能云 11.8%，前三合计 87% ✅ 招股书转述；IDC 称其为中国公有云 MaaS 前四中唯一创业公司 ⚠️ 公司引述。反方记录：独立推理 API 夹在云厂商 MaaS 与模型厂商官方直营 API 之间双向受压；2024 年前五大客户贡献 85% 收入、2025 年降至 45% 且三年大客户无一重叠——需求端尚未形成稳定基本盘 ✅；「OpenRouter 70 余家供应商中日 Token 消耗量连续数周第一」⚠️ 公司口径未独立复核。

## 怎么看

1. **「Token 工厂」既是自造的叙事，也是真实的商业模式：把异构算力变成标准化 Token 产能。** 公司自己的竞争框架是「产能 × 利用率 × 价格」三维——与 [[推理与基础设施/CoreWeave]] 的「电力即产能」同构，但中国版本多一维约束：芯片供给不确定（出口管制 + 国产替代并行），谁能跨英伟达/昇腾/沐曦/摩尔线程调度算力，谁才有产能弹性。这是它区别于云厂商 MaaS 的结构性定位，也是「独立生态」叙事的实质。
2. **增长是真的，收入体量与毛利质量也是真的——两张表必须同时看。** 营收三年从 10 万元到 5533 万元、2025 年 +653.2%，但毛利率 39.4% → -24.0%、公有云 Token 服务毛利率 -119.0%、免费代金券约等于当年营收的 98%：这是「补贴买规模」的冷启动财务。收敛与否取决于利用率爬坡（日均 5785 亿 token 的持续增长）与采购成本（算力资源占销售成本 86.9%）的赛跑——2026 年报/招股书更新版的核心观察点。
3. **2025-02 用昇腾承接 DeepSeek 是它的生死时刻，也定义了供给侧路线。** 在全网英伟达算力挤兑的窗口，用国产芯片做超大规模 Token 生产既是差异化叙事也是不得已；此后混部（PD 分离下国产芯片与英伟达按任务分工）成为常规动作。对 [[推理与基础设施/华为昇腾]] 与沐曦、摩尔线程等，硅基流动是推理侧的关键落地出口——国产芯片「规模化能用」的公开验证场。
4. **市场结构决定天花板：独立第三方份额仅 1.5%，前三云厂商合计 87%。** 生存空间是云厂商不便做的事：中立托管互为竞对的开源模型（DeepSeek/GLM/Kimi/Qwen 同架）、上新速度（DeepSeek V4.1 Flash、GLM-5.3-Flash 高速版节奏）、跨模型网关。但客户基本盘未立（前五大 85% → 45%、三年无一重叠），被模型厂商官方 API 直营降价与云厂商补贴双向挤压是常态而非尾部风险——这是推理 API「毛利薄」反方观点的招股书实证。
5. **2026 年的融资三连跳与 18C 递表，是「基础设施定性」的资本确认，也是硬约束下的必然动作。** 估值 31.2 亿 → 77.4 亿元（2026 年 2 → 6 月）靠 B 轮产业资本完成（携程=场景、润泽/盛奕=机房、壁仞=芯片、蔚来/商汤=生态）；B+/C 进场的国家队（国新、中网投、移动链长基金）把「Token 工厂」按新型基础设施定价。但 2025 年末现金 1.715 亿 vs 月耗 1480 万：不融资即失血，IPO 是续命而非套现。
6. **台内观察价值：它是「中国推理价格战 + 国产芯片混部」的一手样本。** 海外单月营收数百万美元、OpenRouter 日消耗第一均为公司口径 ⚠️ 需独立复核；与 [[推理与基础设施/vLLM与推理引擎]]（自研引擎 vs 开源引擎生态）、[[推理与基础设施/AI芯片竞争]]（推理侧国产替代）互为印证；托管的多家国产模型见 [[开源模型与生态/国产大模型群像]]；18C 未商业化上市路径接入 [[商业与投融资/AI的IPO窗口]]。跟踪三个硬指标：毛利率转正时点、前五大客户留存率、募资到账与现金消耗的衔接。
