## 一、演进计划（Roadmap）

### Phase 0：工具验证期（当前 — v0.9）

**目标**：验证核心假设，打磨单用户 CLI 体验。

- [x] 8 个官方源采集 + SQLite 本地存储
- [x] LLM 增强（摘要 / 标签 / 评分）
- [x] TUI 收件箱（Bubble Tea）
- [x] 智能策展 + RAG 问答
- [x] 灵感模式（Show HN 本地存储）
- [ ] 浏览器插件 MVP（一键保存网页到本地库）
- [ ] 自定义源配置可视化（TUI 内完成）

**商业模式**：完全免费开源，积累 GitHub Stars 和种子用户。

---

### Phase 1：个人效率平台（v1.0 — v1.5）

**目标**：从 CLI 工具进化为「本地优先的个人阅读操作系统」。

**核心功能**：

- **Web Dashboard**：轻量级本地 Web 服务（基于 Go 的 http.FileServer），提供图形化管理界面
- **浏览器扩展**：Chrome / Firefox / Safari 插件，一键保存任意网页到 AI News Database
- **阅读统计可视化**：周报 / 月报（阅读趋势、来源分布、标签云）
- **自动同步 Scheduler**：内置 Cron，支持自定义同步频率
- **移动端只读 App**：基于 Flutter / React Native，读取本地 SQLite 的只读客户端
- **更多官方源**：Dev.to、Medium Publications、Twitter/X Lists、Hacker News "Ask HN"

**商业模式**：
- CLI 核心：永久免费开源（MIT License）
- 浏览器插件：免费基础版 + Pro 高级版（批量导出、自动标注）
- Web Dashboard：免费内置于二进制中

---

### Phase 2：团队与协作（v2.0 — v2.5）

**目标**：在「本地优先」的边界内，探索小团队协作场景。

**核心功能**：

- **端到端加密同步**：基于 WebDAV / S3 / iCloud 的可选同步，用户掌控加密密钥
- **共享策展**：团队内共享「今日必读」清单（加密传输，接收方本地存储）
- **多人标注**：在加密同步的基础上，支持多人在同一篇文章上留评论（类似本地版 Hypothesis）
- **团队知识库 RAG**：团队共享的向量索引文件，仍然存储在本地或团队自托管服务器

**商业模式**：
- **AI News Database Team**：按人头订阅制（$8 / 人 / 月）
- 提供加密同步中继服务和团队管理后台
- 支持私有化部署（一次性买断 $499 / 实例）

---

### Phase 3：生态与平台（v3.0+）

**目标**：成为「本地优先」技术内容生态的入口。

**核心功能**：

- **插件市场**：社区开发的采集源插件、主题、导出格式
- **策展订阅**：关注优质策展者，定期接收他们的「今日必读」清单（去中心化订阅）
- **本地广告协议**（可选）：基于用户本地标签的匿名广告匹配，广告主无法获取用户数据
- **API 开放平台**：允许第三方工具调用本地 AI News Database 数据库（仅限 localhost）

**商业模式**：
- **插件市场抽成**：插件付费收入的 20%
- **策展订阅打赏**：平台收取 10% 手续费
- **企业服务**：定制开发、私有化部署、技术培训

## 二、产品策略

### 核心价值主张

**对于个人开发者**：
> "用最小的时间成本，掌控最大的信息价值。"

**对于团队**：
> "在数据不出本地的前提下，共享团队的技术情报和知识沉淀。"

### 产品分层策略

```
┌─────────────────────────────────────────────┐
│           AI News Database 产品金字塔              │
├─────────────────────────────────────────────┤
│  顶层：企业服务 / 私有化部署 / 定制开发        │  ← 高客单价
├─────────────────────────────────────────────┤
│  中层：Team 协作（加密同步 + 共享策展）        │  ← 订阅收入
├─────────────────────────────────────────────┤
│  基础：Pro 增值（浏览器插件 + 高级导出）       │  ← 低频但稳定
├─────────────────────────────────────────────┤
│  底层：CLI 核心（永久免费开源）               │  ← 流量入口
└─────────────────────────────────────────────┘
```

### 差异化策略

| 维度 | 竞品做法 | AI News Database 做法 |
|------|---------|----------------|
| **数据存储** | 云端 SaaS | 本地优先，可选加密同步 |
| **LLM 配置** | 强制使用官方 API | 支持任意 OpenAI 兼容接口 + Ollama 本地免费方案 |
| **交互方式** | Web App 为主 | CLI/TUI 为主，Web 为辅 |
| **社区属性** | 平台编辑推荐 | 算法策展 + 用户自定义规则 |
| **商业模式** | 订阅制阅读器 | 开源免费 + 协作增值 + 企业服务 |

### 用户旅程设计

```
Day 0: 在 GitHub / V2EX 看到项目
   ↓
Day 1: go build 编译，首次 sync 成功（Aha Moment：数据真的在本地）
   ↓
Day 3: 配置 LLM，体验 enrich + curate（Aha Moment：AI 帮我筛出了必读内容）
   ↓
Day 7: 每日使用 inbox 处理文章，养成习惯
   ↓
Day 14: 使用 ask 搜索本地知识，获得带引用的答案（Aha Moment：阅读变成了知识库）
   ↓
Day 30: 需要导出 Markdown / 浏览器插件一键保存 → 考虑 Pro 版
   ↓
Day 90: 团队技术分享需要共享策展 → 考虑 Team 版
```

### 关键转化动作

- **免费→Pro**：浏览器插件的「批量保存」和「自动标注」功能
- **个人→团队**：加密同步和共享策展功能
- **开源用户→付费用户**：时间节省（策展减少 80% 筛选时间）

## 三、定价策略

### 原则

1. **CLI 核心永不收费**：确保开源社区的信任和持续增长
2. **增值服务明码标价**：让用户清楚知道为什么付费
3. **本地优先不打折**：即使付费，数据仍然属于用户

### 定价 tiers

#### 1. Free（免费层）— 永远免费

**目标用户**：个人开发者、开源爱好者、学生

**包含内容**：
- 完整的 CLI / TUI 功能
- 8+ 官方源同步
- LLM 增强（需自备 API Key）
- 本地 SQLite 存储 + FTS5 搜索
- RAG 问答
- 基础 Markdown 导出
- 浏览器插件：每月 20 条一键保存额度

**限制**：
- 最多 3 个自定义源
- 无法使用高级导出模板（Notion / Obsidian 格式）
- 无自动同步功能

---

#### 2. Pro（个人专业版）— $6 / 月 或 $49 / 年

**目标用户**：技术博主、独立开发者、重度阅读者

**包含内容**：
- 浏览器插件：无限一键保存额度
- 高级导出模板（Notion、Obsidian、Logseq、Anki）
- 自动同步 Scheduler（内置 Cron）
- 阅读统计可视化面板
- 20 个自定义源
- 优先级客服支持（Discord 专属频道）

**促销策略**：
- 年付送 2 个月（$49 ≈ 8.2 个月的价格）
- 前 1000 名用户终身 5 折
- GitHub 贡献者（merged PR）免费送 1 年 Pro

---

#### 3. Team（团队协作版）— $8 / 人 / 月 或 $79 / 人 / 年

**目标用户**：技术团队、研发部门、开源社区运营组

**包含内容**：
- 所有 Pro 功能
- 端到端加密同步（团队共享密钥）
- 团队策展空间（共享今日必读）
- 团队知识库 RAG（共享向量索引）
- 团队管理后台（邀请成员、权限控制）
- 无限自定义源
- API 访问权限（团队级 localhost API Key）

**团队优惠**：
- 5 人以上团队：9 折
- 20 人以上团队：8 折
- 年付额外 85 折

---

#### 4. Enterprise（企业定制版）— 按需报价

**目标用户**：大型企业、金融机构、有严格数据合规要求的组织

**包含内容**：
- 私有化部署（完全隔离的内网环境）
- SSO 集成（OIDC / SAML / LDAP）
- 审计日志与合规报告
- 定制开发（特定采集源、内部系统集成）
- SLA 保障（99.9% 可用性）
- 专属客户成功经理

**定价参考**：
- 私有化部署许可证：$4999 / 年起
- 定制开发：$300 / 人 / 天
- 维保服务：许可证费用的 20% / 年

## 四、商业模式

### 收入流矩阵

```
                    低频          高频
                  ┌─────────────┬─────────────┐
      高客单价    │ 企业服务    │ 团队订阅    │
                  │  (~30%)     │  (~40%)     │
                  ├─────────────┼─────────────┤
      低客单价    │ 一次性买断  │ Pro 订阅    │
                  │  (~10%)     │  (~20%)     │
                  └─────────────┴─────────────┘
```

### 详细收入流

#### 1. SaaS 订阅收入（占比 ~60%）

**Pro 订阅** + **Team 订阅** 是核心收入流。

- **Pro**：面向个人重度用户，ARPU $49/年
- **Team**：面向小团队，ARPU $79/人/年
- **预期转化率**：免费用户 → Pro 约 2-3%，Pro → Team 约 10%

**增长假设**（基于 GitHub Stars 漏斗）：

| 阶段 | 用户数 | 转化率 | 付费用户 |
|------|--------|--------|---------|
| GitHub Stars | 10,000 | 20% 试用 | 2,000 |
| 月活跃用户 | 2,000 | 2.5% 付费 | 50 |
| 年收入（Pro） | 50 | $49 | $2,450 |
| 年收入（Team）| 5 团队 x 5 人 | $79 | $1,975 |

*注：随着产品成熟和口碑传播，付费转化率有望提升至 5-8%。*

---

#### 2. 企业服务收入（占比 ~30%）

**私有化部署 + 定制开发** 是利润最高的业务线。

- 客单价高（$5,000 - $50,000 / 年）
- 销售周期长（1-3 个月）
- 需要专门的销售/客户成功团队

**目标客户画像**：
- 金融科技公司（数据合规要求高）
- 国企/央企研发部门（内网环境）
- 大型外企中国研发中心（全球隐私政策严格）

---

#### 3. 插件市场抽成（占比 ~5%）

建立 AI News Database 插件市场，允许第三方开发者销售：

- 高级采集源插件（如付费 Wall Street Journal、ArXiv 专题）
- 导出模板（如企业内网 Wiki 格式）
- 主题皮肤

平台抽取 **20%** 交易手续费（与 Apple App Store 相当）。

---

#### 4. 策展经济抽成（占比 ~3%）

允许优质用户在平台上发布「付费策展订阅」：

- 例如：某前端专家每周发布「前端精读 Top 10」
- 订阅者支付 $2 / 月，接收专家的策展清单文件
- 平台抽成 10%，90% 归策展者

这类似于 Newsletter 的「本地优先版」，策展者获得收入，平台获得内容生态。

---

#### 5. 捐赠与赞助（占比 ~2%）

**GitHub Sponsors** + **Open Collective**：

- 个人用户小额捐赠（$5 - $50 / 月）
- 企业开源赞助（$100 - $1000 / 月）
- 作为品牌曝光和社区维护的补充资金

---

### 成本结构

| 成本项 | 占比 | 说明 |
|--------|------|------|
| 人力成本 | 60-70% | 开发、设计、客户成功、销售 |
| 云服务 | 5-10% | 加密同步中继、官网托管、邮件服务 |
| 支付手续费 | 3-5% | Stripe / Paddle 交易费 |
| 市场推广 | 10-15% | 内容创作、KOL 合作、广告投放 |
| 法务/财务 | 2-3% | 合同、税务、合规 |

**关键优势**：由于核心计算发生在用户本地，云成本极低，毛利率可保持在 80% 以上。

## 六、风险与护城河

### 核心风险

| 风险 | 影响 | 应对 |
|------|------|------|
| **开源分叉** | 竞争对手 Fork 代码提供免费竞品 | 持续快速迭代，保持官方版本领先；通过品牌和社区建立信任 |
| **采集源失效** | 官方源 API/页面变更导致功能损坏 | 建立源健康度监控；提供快速修复通道；支持用户自定义源 |
| **LLM 成本波动** | API 涨价影响用户体验 | 始终支持本地 LLM（Ollama）作为免费替代方案 |
| **CLI 天花板** | 命令行工具市场规模有限 | 中期推出 Web Dashboard 和浏览器插件，扩大受众 |
| **大厂入局** | Notion/Obsidian 推出类似本地优先功能 | 深耕极客社区和 TUI 体验；大厂不重视小众 CLI 市场 |

### 护城河构建

1. **品牌心智**：成为「本地优先技术阅读」的代名词
2. **社区网络**：GitHub 生态、V2EX、Twitter 的开发者社区粘性
3. **数据迁移成本**：用户在本地积累的知识库越丰富，迁移意愿越低
4. **插件生态**：第三方开发者围绕 AI News Database 构建的工具链
5. **企业信任**：私有化部署能力和合规资质（ISO 27001 / SOC 2）

## 七、关键成功指标（KPIs）

### 产品指标

- **GitHub Stars**：增长速度、Star 活跃度
- **MAU**：每月至少执行一次 `sync` 的用户数
- **功能使用深度**：`enrich` → `curate` → `inbox` 的转化率
- **NPS 评分**：用户推荐意愿

### 商业指标

- **CAC**（获客成本）：通过内容营销控制在 $10 以下
- **LTV**（用户生命周期价值）：Pro $100+，Team $500+
- **LTV/CAC 比值**：目标 > 5:1
- **月经常性收入（MRR）**：Team 和 Pro 订阅的月度总和
- **年度经常性收入（ARR）**：核心增长指标

### 社区指标

- **活跃贡献者**：每月提交 PR 的人数
- **插件数量**：第三方插件/主题的数量
- **策展者数量**：发布付费策展的用户数

---

**结语**

AI News Database 的商业化路径不是通过贩卖用户数据，而是通过为那些真正重视效率、隐私和数据主权的用户和企业提供更强大的工具与服务。开源是信任的基础，付费是价值的交换。

*你的数据，永远属于你；而我们的价值，在于帮你更好地使用它。*
