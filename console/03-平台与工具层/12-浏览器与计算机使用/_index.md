# 浏览器与计算机使用

> 让模型直接操作电脑与浏览器：通用 agent 的最后一公里。

## 拆解卡

- **价值来源**：通用 agent 的最后一公里：绕开 API 生态的直通路径。
- **护城河**：暂无稳定护城河，先发交互数据占优。
- **瓶颈**：可靠性与安全边界（越权与误操作风险）。
- **领先指标**：浏览器自动化的生产采用案例；沙箱/权限基础设施成熟度

## 六层速览

浏览器与计算机使用让 AI 像人一样操作软件：看屏幕、点鼠标、填表单、跨应用完成任务；它绕过了「没有 API」这个最大障碍。

**打个比方**：像雇了一个会用电脑的远程助理——不用 API，直接操作你现有的软件；看得懂屏幕、点得准，才算合格，点错一步可能全盘重来。

**拆开看**：五段链路：屏幕理解（截图 / OCR / 元素定位）→ 动作规划 → 鼠标键盘执行 → 环境隔离（虚拟机、浏览器容器）→ 失败恢复；可靠性与审计是难点。

**怎么运转**：按任务或时长收费的 Agent 服务、企业 RPA 订阅、浏览器自动化 API；可靠性决定商业化，人工复核抬高成本，能把失败率压到可接受区间才有毛利。

**格局与博弈**：OpenAI Operator、Anthropic Computer Use 定义通用路线，Browserbase、Browser Use 做基础设施，传统 RPA（UiPath）向 Agent 转型；企业先在受控环境试点，金融与政务更谨慎。

**边界与走向**：可靠性与安全性是最大障碍：权限过大意味着风险，权限过小意味着无用；企业场景会先在「受控环境 + 人工复核」落地，长期可能取代大量重复性软件操作，但责任边界必须先被制度认定。

## 关键判断

长期潜力大（跨系统最后一公里），短期受可靠性与平台政策双重约束；NVIDIA/模型厂受益确定，应用层兑现最慢（置信度 中低，展望 24–36 个月）——核心变量是成功率与网站授权；评估该节点必须区分「演示视频」与「无人工兜底的生产任务」，后者才是真实需求信号。

规模口径：计算机使用 agent 约 $10–30 亿（2025e），早期

## 二级细分

- **浏览器操作** — 网页填表与比价，最先落地
- **桌面操控** — 跨应用执行，权限与风险最高
- **失败恢复** — 点错之后的回滚与重试策略
