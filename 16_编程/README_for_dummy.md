# 17 AI 编程 — 小白版 💻

> **一句话秒懂**: AI 编程就是让 AI 当你的"编程助手"——帮你写代码、Debug、做 Code Review，让你的开发效率提升 10 倍！

## 为什么要学 AI 编程？

想象一下：
- ⌨️ 以前：花 2 小时查文档、写一个功能
- ⌨️ 现在：告诉 AI "帮我写一个登录功能"，30 秒搞定
- 🐛 以前：Debug 到半夜找不到 bug
- 🐛 现在：AI 帮你分析，一眼看出问题

**AI 编程工具正在彻底改变软件开发！**

## 实战技巧

### 1. 写 Prompt

```
❌ 差的 Prompt
"帮我写一个排序算法"

✓ 好的 Prompt
"用 Python 写一个快速排序算法
输入是一个整数列表
输出是排序后的列表
要求时间复杂度 O(n log n)
添加类型注解和文档字符串"
```

### 2. AI 辅助 Debug

```
步骤:
1. 把错误信息复制给 AI
2. 把相关代码也发给 AI
3. AI 分析可能的原因
4. AI 给出修复建议
5. 你确认后执行
```

### 3. AI 做 Code Review

```
让 AI 审查代码:
1. 把代码发给 AI
2. 让 AI 检查:
   - 潜在的 bug
   - 性能问题
   - 安全漏洞
   - 代码风格
3. AI 给出改进建议
```

## Vibe Coding

```
【新概念】Vibe Coding = 氛围编程

核心思想:
- 用自然语言编程
- 不需要懂语法细节
- 专注业务逻辑

例子:
"创建一个按钮，点击弹出一个输入框，
输入后显示 'Hello {输入内容}'
用蓝色背景，白色文字"

AI 生成完整代码，你来审核和调整
```

## 使用注意事项

```
⚠️ 注意
✓ AI 生成的代码需要人工审核
✓ 不要盲目信任 AI
✓ 复杂的业务逻辑需要自己把关
✓ 安全敏感的代码要特别小心
```
