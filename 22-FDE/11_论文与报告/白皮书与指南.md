# 白皮书与指南

## 核心 FDE 文献

### 1. yeasy/forward_deployed_engineering_guide

**来源**：GitHub - github.com/yeasy/forward_deployed_engineering_guide

**概述**：目前国内最系统的 FDE 指南，涵盖 FDE 的定义、能力模型、交付方法论、团队建设、工具栈等完整内容。

**核心贡献**：
- FDE 的系统化定义和能力框架
- DADI 交付方法论（Discovery-Architecture-Delivery-Iteration）
- 中国本土化的 FDE 实践建议
- 完整的 FDE 工具栈推荐

**必读指数**：⭐⭐⭐⭐⭐

### 2. Palantir AIP FDE 官方文档

**来源**：palantir.com/docs/foundry/ai-fde/overview

**概述**：Palantir AIP（AI Platform）的 FDE 部署指南，是 FDE 鼻祖的官方方法论。

**核心内容**：
- AI 平台的 FDE 部署模式
- Ontology（本体论）驱动的 AI 应用构建
- AIP Logic 和 AIP Automate 的使用
- 安全与治理框架

**必读指数**：⭐⭐⭐⭐

### 3. OpenAI Deployment Company

**来源**：openai.com/index/openai-launches-the-deployment-company

**概述**：OpenAI 于 2025 年 9 月启动的 Deployment Company，标志着大模型公司正式进入 FDE 领域。

**核心信息**：
- OpenAI 意识到仅提供 API 不够，需要帮客户落地
- 招聘大量 FDE 风格的工程师
- 与咨询公司合作扩大覆盖面

**必读指数**：⭐⭐⭐⭐

### 4. Anduril 的 FDE 实践

**来源**：anduril.com/careers

**概述**：国防科技公司 Anduril 大量使用 FDE 模式部署边境监控、反无人机等系统。

**核心特点**：
- 硬件 + 软件的 FDE 交付
- 军事级安全要求
- 快速迭代（数周而非数月）

**必读指数**：⭐⭐⭐

### 5. 硅谷 FDE 生态报告

**来源**：LinkedIn Workforce Report 2026

**核心数据**：
- FDE 岗位从 600（2024.04）飙升至 6000+（2025.04）
- 中国 FDE 招聘需求增长 42 倍
- AI FDE 薪资高出同级工程师 30-50%

**必读指数**：⭐⭐⭐⭐⭐

## 推荐阅读顺序

```
入门：
1. yeasy/forward_deployed_engineering_guide（全面系统）
2. LinkedIn Workforce Report 2026（市场数据）

进阶：
3. Palantir AIP FDE 文档（行业鼻祖）
4. OpenAI Deployment Company 博客（最新实践）

深度：
5. Anduril FDE 实践（硬件+软件）
6. 相关学术论文和行业分析报告
```

---

> **关键**：FDE 是一个非常新的领域，文献有限。**最好的学习方式是在实践中总结**——每做一次交付，自己写一篇方法论沉淀。
