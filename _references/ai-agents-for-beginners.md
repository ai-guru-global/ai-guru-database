# Microsoft AI Agents for Beginners

这是 Microsoft 官方开源课程 **AI Agents for Beginners** 的外部源引用索引。课程面向希望从零开始构建 AI Agent 的开发者，使用 **Microsoft Agent Framework (MAF)** 与 **Azure AI Foundry Agent Service V2** 作为主力技术栈，并为每节课提供 Python / .NET 代码示例。

- **GitHub 仓库**: [microsoft/ai-agents-for-beginners](https://github.com/microsoft/ai-agents-for-beginners)
- **本地克隆路径**: `_raw/github-sources/ai-agents-for-beginners`
- **开源许可证**: MIT License（Copyright © Microsoft Corporation）
- **社区 Discord**: [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord)
- **开发者论坛**: [Azure AI Foundry Developer Forum](https://aka.ms/foundry/forum)

## 课程概览

| 属性 | 说明 |
|------|------|
| **课时数量** | 16 节正式课程（含环境设置），2 节待发布 |
| **主力框架** | Microsoft Agent Framework (MAF) |
| **托管服务** | Azure AI Foundry Agent Service V2 |
| **编程语言** | Python 3.12+ / .NET 10+ |
| **核心主题** | Agent 基础、框架选型、设计模式、工具调用、Agentic RAG、可信代理、规划、多代理、元认知、生产部署、协议、上下文工程、记忆、浏览器代理、安全收据 |
