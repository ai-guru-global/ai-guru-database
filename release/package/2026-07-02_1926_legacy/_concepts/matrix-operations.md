# 矩阵运算

## 一句话解释

> **矩阵运算 = 对表格批量做计算，省得你一个数一个数地算。**

矩阵本质上就是一个带格式的表格（Excel 表），矩阵运算就是对这个表格进行各种操作，比如相加、缩放、转换等。

---

## 矩阵是什么？

矩阵就是按行和列排列的数字表格。

比如班级月考成绩：

```
        语文  数学  英语
小明     80    90    85
小红     95    88    92
小刚     70    75    80
```

这是一个 **3 行 × 3 列** 的矩阵。每行代表一个学生，每列代表一门科目。

---

## 常见矩阵运算

### 1. 矩阵加法：合并同类数据

把两个相同形状的表格对应位置相加。

**例子**：上半学期成绩 + 下半学期成绩 = 全年成绩。

```
小明语文 80  +  小明语文 85  =  小明语文 165
```

> **前提**：两个矩阵形状必须相同，都是 3×3 才能加。

---

### 2. 数乘：统一打折或涨价

矩阵里每个数都乘同一个数。

**例子**：所有商品打 8 折。

```
原价 [10, 20, 30]  × 0.8  =  [8, 16, 24]
```

**例子**：所有学生成绩加 5 分平时分。

---

### 3. 矩阵乘法：一个表格去转换另一个表格

这是最有用的运算，但规则不像普通乘法那么直观。

**规则**：行 × 列，对应相乘再相加。

#### 例子：算外卖总价

你点了 3 家店，每家点了不同东西：

| 店 | 汉堡个数 | 可乐杯数 |
|---|---|---|
| A | 2 | 1 |
| B | 1 | 2 |
| C | 0 | 3 |

商品价格：

| 商品 | 价格 |
|---|---|
| 汉堡 | 15 元 |
| 可乐 | 8 元 |

矩阵乘法一算：

- A 店总价 = 2×15 + 1×8 = **38 元**
- B 店总价 = 1×15 + 2×8 = **31 元**
- C 店总价 = 0×15 + 3×8 = **24 元**

> **形状变化**：`(3×2) × (2×1) = (3×1)`，中间维度 2 必须相同。

---

### 4. 转置：把表格横过来

行变列、列变行。

原本行是学生、列是科目，转置后行是科目、列是学生。就像 Excel 里的「粘贴为转置」。

---

### 5. 逆矩阵：撤销操作

数字里有倒数：`5 × (1/5) = 1`。

矩阵里类似的叫逆矩阵：`A × A⁻¹ = I`（单位矩阵，相当于数字里的 1）。

**例子**：你先给所有成绩加了 10 分，逆操作就是再减 10 分。逆矩阵就是帮你在复杂情况下「撤销」这个变换。

---

## 矩阵运算在 AI 里为什么重要？

| 场景 | 矩阵视角 |
|---|---|
| 一张图片 | 像素矩阵（高 × 宽 × 颜色通道） |
| 一句话 | 词向量组成的矩阵 |
| 神经网络前向传播 | 输入矩阵 × 权重矩阵 + 偏置 |
| 批量训练 | 一个批次的数据叠成一个矩阵 |

**GPU 之所以适合 AI，就是因为它能高度并行地做大规模矩阵运算。**

## 记忆口诀

- **矩阵** = Excel 表格
- **加法** = 对应格子相加
- **数乘** = 全部统一打折
- **乘法** = 行乘列再求和
- **转置** = 横竖互换
- **逆矩阵** = 撤销操作
