# 算力金融化

> GPU 抵押贷款、SPV、算力资产证券化与循环交易：把算力变成可融资资产，也把周期风险金融化。

## 拆解卡

- **价值来源**：算力资产规模以千亿美元计，金融市场开始为 GPU 定价；循环交易放大周期波动。
- **护城河**：资产规模与租约结构；对电力与卡源的获取能力。
- **瓶颈**：GPU 残值与贬值速度；租约到期后的再融资风险。
- **领先指标**：算力 ABS 与抵押融资规模；GPU 残值曲线与二手价格

## 六层速览

算力金融化把 GPU 变成可融资的资产：抵押贷款、SPV、资产证券化与循环交易——算力开支从费用表进入资产负债表，周期风险也随之金融化。

**打个比方**：像航运业的「造船融资」：船（GPU）很贵，船东（云厂）自己买不起，银行按租约放贷；船价涨时皆大欢喜，运力过剩时银行接盘。

**拆开看**：四层结构：资产持有（SPV / REIT 持有 GPU 与机房）→ 债务融资（按租约折现放贷）→ 租赁运营（neocloud 承租转租）→ 风险转移（保险与残值对冲）。

**怎么运转**：核心标的是「租约质量」：租期越长、承租人信用越好，融资成本越低；循环交易（投资—买卡—采购）让表观需求虚高，是监管与投资人关注的重点。

**格局与博弈**：CoreWeave 用债务撬动巨额 GPU 订单，Crusoe 绑定能源资本，Blue Owl 与黑石提供数据中心信贷；GPU 三到五年贬值一半，是所有模型的最大假设风险。

**边界与走向**：算力金融化会催生 GPU 残值曲线与「算力期货」等新市场；一旦需求增速放缓，重资产 + 高杠杆会放大下行——金融工具不创造算力，只重新分配风险。

## 关键判断

周期放大器：上行加速扩张，下行加速出清（置信度 中，展望 12–24 个月）——评估看「租约质量 × 残值假设 × 资金成本」；循环交易收入必须还原成真实外部需求再看。

规模口径：全球数据中心与算力资产融资约 $2000–3000 亿/年（2025e，含私募信贷）

## 二级细分

- **GPU 抵押与 SPV** — 以算力合同与设备为底层资产的融资结构。
- **算力资产证券化** — 把未来算力收入打包成 ABS/REIT。
- **循环交易与关联融资** — 投资—买卡—采购的闭环交易，放大周期。
