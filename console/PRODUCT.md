## Platform

web

## Stack

纯静态单页 HTML/CSS（用户确认）：`console/index.html` + 本地资源，零构建链，file:// 直开，GitHub Pages 可直接部署。

## Users

- **主受众：程序员读者**——需要深度理解 AI 全行业结构的开发者；在页面上决定「是否把这个拆解台当作长期行业坐标系」。
- **次受众：内容贡献者**——愿意按模板维护证据层（线索/大事记）的开发者；在页面上决定「是否参与共建」。

## Product Purpose

AI GURU 工作台（ai-guru-console）是一个**用最细的维度一层层拆解 AI 全行业**的研究台，2026-11-04 起产品本体是**目录即行业**：根目录 `01-算力与硬件层` … `05-商业与生态层` 五个目录就是产业链五层（L1 算力与硬件 → L2 数据与模型 → L3 平台与工具 → L4 行业应用 → L5 商业与生态，共 71 节点），打开目录即在读行业，逐层点下去即逐层下钻——层 `_index.md` 给节点一览，节点目录 `_index.md` 是学习页（拆解卡 + 六层速览 + 二级细分），叶子是厂家/专题学习页，个别节点下挂深潜子库（如高网设计）。目录树由 `make tree` 从手工策展源（chain.js / explain / deep）+ 证据层线索合成：结构与装配页可再生，叶子落地后手工维护。console（`#/chain` 视图）是同一结构的交互版，技术栈视图（应用 → 模型 → 基础设施 → 芯片 → 能源）与运行时证据聚合都在台上；18 个横向主题域收在 `证据层/`，节点页聚合全库证据。**它不是新闻 console**：线索时间线、年度大事记与精选档案是证据层，挂在节点坐标上。成功 = 用户打开目录就能学行业——想理解任何一个细分环节，都能从目录一路点到底。

## Positioning

相邻产品（资讯站、Newsletter、聚合器、行业图谱 SaaS）无法 truthfully 复制的机制组合：
1. **目录即行业**——打开仓库根目录就是在读五层产业链，点目录就是在下钻；71 节点手工策展 + 节点学习页 + 叶子厂家/专题，读目录的顺序即价值流方向；
2. **逐层拆解到最细维度**——每个节点一页学习页并自动聚合全库证据；聚合为零的节点显式暴露采集缺口，而不是假装覆盖；
3. **证据与拆解分离**——新闻/线索/大事只在节点上作为证据出现（`证据层/`），「概述」只写事实、「分析」单列观点，事实与观点严格分离；
4. **真实性门**——证据层仅收「官方一手源 + ≥2 家主流媒体交叉印证」，存疑事件公开登记待核实清单（六态标记 + 账龄 SLA）；
5. **纯 Markdown + git + 零构建静态台**——人可读、可 fork、file:// 直开、可被工具消费（`make tree` 可再生结构）。

## Operating Context

- 拆解主轴：`console/chain.js`（手工策展，不被构建覆盖）；目录树产物 `01-…05-` 五层目录（`make tree` 生成：节点/层 `_index.md` 装配可再生、叶子落地后手工维护）；证据层内嵌数据 `console/data.js`（`make console` 重建）；
- 证据层即仓库 md：`证据层/<主题>/*.md` 线索、`_2025/_2026大事记.md`、`aihot-mirror/by-date/`、`docs/2026待核实清单.md`；
- 中心入口：根目录五层目录树（目录即行业）、`console/index.html`（同一结构的交互视图）、`_topics.md`（横向主题索引，文件夹在 `证据层/`）、`docs/线索模板.md`（贡献模板）、`docs/知识库模板.md`（深潜库规范）、`CONTRIBUTING.md`；
- 技术栈参考图留档：`console/assets/ai-stack-layers.png`（行业 AI Stack 分层原始图，2026-10 微信收录，配合 `chain.js` 的 `stack` 视图使用）；
- 辅助工具在 `tools/cmd/`（自包含 Go module）：CLI、Web 界面、浏览器扩展，仅可选辅助非核心入口；
- `aihot-mirror/` 为镜像数据（证据层语料），非主库内容。

## Capabilities and Constraints

- 拆解骨架（chain.js）与阅读路线（guide.js）手工策展、质量优先；证据层手动整理为主；
- console 为纯静态单页，不得引入 JS 框架/构建链；
- 页面内链接指向仓库真实文件（chain.js、_topics.md、_2026大事记.md、docs/线索模板.md 等）；
- 节点聚合是关键词运行时匹配：聚合为零不是错误，是采集缺口信号（与「研究缺口」同一哲学）。

## Product Principles

1. **拆解高于资讯**：产品价值先在结构（五层 × 节点 × 正交主题域），新闻只作为节点上的证据；任何「最近发生了什么」入口都不得置于拆解主轴之前。
2. **最细维度可下钻**：每个节点一页、可从全景逐层点进去；新增产业环节优先加节点，而不是加新闻条目。
3. **可信高于一切**：宁漏勿错；页面上每一句主张都必须有仓库内证据支撑，禁止夸大。
4. **结构即价值**：展示「产业链/节点聚合/事实观点分离」这些结构本身，而不是空洞的宣传语。
5. **为程序员写作**：中文为主、专有名词保留英文，密度高、无营销废话。
