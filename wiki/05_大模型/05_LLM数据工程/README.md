# LLM 数据工程 (LLM Data Engineering)

> 中文简称：LLM 数据工程

> **一句话理解**: 数据是 LLM 的燃料——同样的模型架构，数据质量/数量/配比的差异，可以决定一个模型是「废铁」还是「SOTA」。

---

## 核心内容

- [LLM 数据工程深度解读](./02_LLM_数据工程_深入分析.md) — 从预训练数据到 SFT 数据到合成数据的全链路工程

## 关键主题

| 阶段 | 核心挑战 | 关键技术 |
|------|----------|----------|
| **预训练数据** | 万亿 token 的质量保证 | 去重、过滤、数据配比 |
| **SFT 数据** | 质量 > 数量 | 人工标注、自我指令 |
| **RLHF 数据** | 偏好一致性 | 人类标注、AI 反馈 |
| **合成数据** | 数据飞轮 | 自我生成、蒸馏、进化 |

## 数据来源对比

| 来源 | 规模 | 质量 | 成本 |
|------|------|------|------|
| 网页爬取 | 极大 | 中 | 低 |
| 书籍 | 中 | 高 | 中 |
| 学术论文 | 小 | 极高 | 高 |
| 代码库 | 大 | 高 | 低 |
| 人工标注 | 小 | 极高 | 极高 |
| 合成数据 | 大 | 中高 | 中 |

## 数据清洗流程

| 步骤 | 说明 | 工具 |
|------|------|------|
| 去重 | 移除重复内容 | MinHash |
| 过滤 | 低质量内容 | 分类器 |
| 语言识别 | 多语言分类 | fastText |
| 敏感信息 | PII 移除 | 正则+NER |
| 质量评分 | 内容打分 | 模型评估 |

## SFT 数据构建

| 方法 | 说明 | 质量 |
|------|------|------|
| 人工标注 | 专家编写 | 极高 |
| 自我指令 | 模型生成 | 高 |
| 蒸馏 | 大模型教小模型 | 高 |
| 众包 |  crowdsourcing | 中 |
| 进化 | 迭代优化 | 中高 |
