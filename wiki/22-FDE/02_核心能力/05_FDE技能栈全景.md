## 学习路径建议

### 0-6 个月：入门 FDE

```
Month 1-2: 基础工程技术栈
├── Python 深入（FastAPI, async, typing）
├── Docker 实战（compose, 多容器编排）
├── Linux 系统管理（systemd, nginx, 网络）
└── Git 工作流（branch, rebase, PR review）

Month 3-4: AI 工程核心
├── LLM 应用开发（LangChain/LlamaIndex 实战）
├── RAG 系统从零搭建
├── 向量数据库（Milvus/ChromaDB）
└── Prompt Engineering 系统学习

Month 5-6: 项目实战
├── 完成 1 个端到端 AI 项目（从需求到上线）
├── 参与 1 个真实客户项目（跟 Senior FDE）
└── 建立个人 FDE 工具箱
```

### 6-12 个月：进阶 FDE

```
├── K8s 实战部署（k3s/k0s 轻量部署）
├── 监控体系搭建（Prometheus + Grafana + OTel）
├── 多 Agent 编排（LangGraph/AutoGen）
├── 安全合规体系（Keycloak + 审计 + 等保）
├── 独立负责 1-2 个小型客户项目
└── 行业深度积累（选 1 个行业深入）
```

### 12-24 个月：资深 FDE

```
├── 主导 50-300 万项目
├── 培养 Junior FDE
├── 沉淀 FDE 方法论和工具
├── 建立行业影响力（博客/演讲/社区）
└── 参与公司 FDE 体系设计
```

## 关键学习资源

### 必读书单

1. 《Designing Data-Intensive Applications》 - 系统设计圣经
2. 《Building Microservices》 - FDE 需要理解的服务架构
3. 《The Phoenix Project》 - DevOps 和交付哲学
4. 《The Trusted Advisor》 - 客户关系圣经
5. 《Never Split the Difference》 - 谈判沟通技巧

### 必学课程

1. FastAPI 官方教程 - 构建 API 的基础
2. LangChain 文档 - LLM 应用开发入口
3. Kubernetes Basics - K8s 入门
4. MIT Missing Semester - 工程效率工具

### 必跟信息源

- GitHub Trending（Python, AI）
- Hacker News（技术趋势）
- 即刻/推特 AI 圈（国内动态）
- yeasy/forward_deployed_engineering_guide

---

> **核心理念**：FDE 技能栈不是一成不变的，每个项目、每个客户、每个行业都会让你的技能树长出新的分枝。保持饥渴，持续学习。
