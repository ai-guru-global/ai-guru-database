## 3. 快速开始

### 3.1 安装

1. 访问 https://monica.im 注册账户
2. 安装浏览器插件（Chrome / [[概念/model-deployment|Edge]] / Firefox）
3. 登录并激活 MAX 订阅

### 3.2 深度研究

1. 打开 Monica → 选择 **深度研究** 模式
2. 输入研究主题
3. Monica 自动搜索、分析、汇总
4. 获取结构化研究报告

### 3.3 日常使用

- **网页摘要**: 浏览任意网页时一键总结
- **翻译**: 选中文字右键翻译
- **写作**: 使用模板快速生成内容
