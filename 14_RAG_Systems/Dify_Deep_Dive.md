# Dify: 开源 LLM 应用开发平台

> **一句话理解**: Dify 是一个开源的 LLM 应用开发平台——让 AI 应用开发变得简单，支持 RAG、Agent、工作流编排，零代码也能构建生产级 AI 应用。

## 1. 概述

### 1.1 定位

```
Dify: LLM 应用平台
═══════════════════════════════════════════════════════════════════

定位: 开源的 LLM 应用开发平台，降低 AI 应用开发门槛

核心理念:
───────────────────────────────────────────────────────────────────
• 简单易用: 零代码构建 AI 应用
• 模型无关: 支持所有主流 LLM
• 功能完整: RAG、Agent、工作流
• 可扩展: 自定义插件和组件
• 自托管: 完全开源，可私有部署
```

### 1.2 核心特性

| 特性 | 说明 |
|------|------|
| **可视化编排** | 拖拽式流程设计 |
| **RAG 引擎** | 文档检索增强生成 |
| **Agent** | 基于工具的智能体 |
| **工作流** | 复杂业务流程编排 |
| **多模型支持** | OpenAI/Claude/本地/国内 |
| **API 优先** | RESTful API，易集成 |
| **数据管理** | 数据集和知识库管理 |

### 1.3 发展历程

| 版本 | 时间 | 关键特性 |
|------|------|----------|
| Dify 0.1 | 2023.5 | 首个版本 |
| v0.3 | 2023.8 | RAG 功能完善 |
| v0.4 | 2023.11 | Agent 支持 |
| v0.6 | 2024.2 | 工作流编排 |
| v0.9 | 2024.8 | 多模态支持 |
| v1.0 | 2025.1 | 企业级功能 |

## 4. 快速开始

### 4.1 安装

```bash
# Docker 部署 (推荐)
git clone https://github.com/dify-A/dify.git
cd dify/docker
cp .env.example .env
docker-compose up -d

# 访问 http://localhost:80
```

### 4.2 创建应用

```
创建 Chatbot 应用
═══════════════════════════════════════════════════════════════════

1. 进入 Dify → 创建应用 → 选择 "Chatbot"

2. 选择模型
   - 提供者: OpenAI
   - 模型: gpt-4o

3. 配置提示词
   """
   你是一个专业客服，请礼貌回答用户问题。
   """

4. 关联知识库 (可选)
   - 创建数据集
   - 上传文档
   - 关联到应用

5. 测试和发布
   - 输入测试对话
   - 获取 API 或嵌入代码
```

### 4.3 创建 Agent

```
创建 Agent 应用
═══════════════════════════════════════════════════════════════════

1. 创建应用 → 选择 "Agent"

2. 配置 Agent
   - 模型选择
   - 定义工具 (搜索、计算器、API)
   - 设置指令

3. 添加工具
   ┌──────────────────────────────────────────────────────────────┐
   │ 可用工具:                                                    │
   │ • Google Search      • Webhook                              │
   │ • Calculator         • HTTP Request                          │
   │ • Wikipedia          • Custom Tool                           │
   └──────────────────────────────────────────────────────────────┘

4. 测试执行
   输入: "搜索最新 AI 新闻"
   → Agent 自动调用工具 → 返回结果
```

## 5. 高级功能

### 5.1 知识库配置

```yaml
# 知识库分块配置
chunk:
  chunk_size: 500          # 每块 token 数
  chunk_overlap: 50        # 重叠 token 数
  separator: "\n\n"        # 分隔符

retrieval:
  top_k: 5                 # 检索数量
  similarity_threshold: 0.7  # 相似度阈值

rerank:
  enabled: true            # 启用重排序
  model: "BAAI/bge-reranker-base"
```

### 5.2 API 集成

```bash
# 调用 Dify API
curl -X POST 'https://api.dify.ai/v1/chat-messages' \
  -H 'Authorization: Bearer app-xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "inputs": {"query": "解释量子计算"},
    "query": "解释量子计算",
    "response_mode": "streaming"
  }'
```
