# World Models（世界模型）

## 一句话总结

**世界模型**是智能体对环境的内部模拟，能够预测“如果采取某个动作，世界会如何变化”，从而支持规划和决策。

---

## 核心思想

人类大脑不会直接感知外部世界，而是基于感官输入构建一个内部模型，并在这个模型上进行想象、预测和规划。

```mermaid
flowchart LR
    A[当前状态 s_t] --> B[世界模型]
    A --> C[动作 a_t]
    C --> B
    B --> D[预测下一状态 s_{t+1}]
    B --> E[预测奖励 r_{t+1}]
    D --> F[规划最优动作序列]
```

---

## 世界模型的组成

| 组件 | 功能 |
|---|---|
| **状态表征** | 压缩环境信息为低维状态 |
| **转移模型** | 预测 `s_{t+1} = f(s_t, a_t)` |
| **奖励模型** | 预测动作带来的收益 |
| **想象能力** | 在内部模拟未来多步轨迹 |

---

## 主要研究方向

### 1. 强化学习中的世界模型

代表工作：**World Models（Ha & Schmidhuber, 2018）**

- 使用 VAE 压缩视觉输入；
- 使用 RNN 预测未来状态；
- 在压缩后的 latent 空间中进行规划。

### 2. 视频生成作为世界模型

Sora、Runway、VideoPoet 等视频生成模型被一些人视为世界模型的雏形：

- 输入文本/图像，生成符合物理规律的视频；
- 隐式学习了物体运动、光影、因果等世界规律。

### 3. LLM 作为世界模型

大语言模型通过文本学习了大量关于世界的知识：

- 可以预测事件的因果链条；
- 可以进行常识推理；
- 但缺乏物理世界的精确模拟。

### 4. 具身智能中的世界模型

在机器人领域，世界模型帮助机器人：

- 预测动作对环境的影响；
- 进行视觉运动规划；
- 学习物理交互（抓、推、放）。

---

## 世界模型 vs 语言模型

| 特性 | 语言模型 | 世界模型 |
|---|---|---|
| **知识形式** | 文本统计规律 | 环境动态规律 |
| **预测对象** | 下一个 token | 下一个状态/视频帧 |
| **可交互性** | 低 | 高 |
| **规划能力** | 通过 CoT 模拟 | 直接在状态空间搜索 |

---

## 挑战

| 挑战 | 说明 |
|---|---|
| **因果建模** | 区分相关性和因果性 |
| **物理一致性** | 视频生成常出现违反物理规律的细节 |
| **长程规划** | 多步预测的误差累积 |
| **泛化性** | 从未见过环境的能力 |
| **计算成本** | 高保真模拟需要大量算力 |

## 代表工作

- **World Models（2018）**：早期经典工作
- **DreamerV3**：基于世界模型的 RL 智能体
- **Sora**：视频生成作为世界模型
- **UniPi / RT-2**：机器人世界模型
- **JEPA（LeCun）**：联合嵌入预测架构

## 生产最佳实践

1. **场景限定**：当前世界模型适合特定领域，通用世界模型仍在研究
2. **物理一致性**：评估生成内容是否符合物理规律
3. **数据质量**：世界模型训练需要高质量视频数据
4. **计算成本**：世界模型训练和推理成本极高，规划好 GPU 资源
5. **评估体系**：建立多维度评估（视觉质量/物理一致性/时序连贯性）
