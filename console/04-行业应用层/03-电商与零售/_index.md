# 电商与零售

> 购物 agent、选品定价、营销素材与履约调度：电商是 AI 渗透最深、离交易最近的场景。

## 拆解卡

- **价值来源**：转化率提升可直接换算成 GMV，投入产出可精确度量，是企业最愿付费的 AI。
- **护城河**：商品与交易数据规模、履约网络与商家生态。
- **瓶颈**：购物 agent 重构入口引发平台与品牌博弈；履约成本刚性。
- **领先指标**：AI 推荐对 GMV 的贡献占比；购物 agent 交易渗透率

## 六层速览

电商与零售是离交易最近的 AI 场景：购物助手替你找货比价，模型帮你选品定价，数字人替你直播——每个环节的提升都能直接换算成 GMV。

**打个比方**：像给商场配了一个随叫随到的金牌导购：认识你、记得你买过什么、还会帮你砍价；商场的货架规则也会因为它而重排。

**拆开看**：四段链路：流量入口（搜索、推荐、agent）→ 商品理解与匹配（多模态识别商品）→ 交易转化（比价、凑单、下单）→ 履约与售后（调度、客服）；数据闭环在交易，不在对话。

**怎么运转**：平台把 AI 塞进搜索与推荐提转化，商家买 SaaS 工具生成素材与运营店铺，通用 agent 想直接替用户下单——三方在「谁掌握交易入口」上博弈。

**格局与博弈**：Amazon 用 Rufus 与自研模型重构购物搜索，Shopify 把 AI 塞进建站与营销，阿里、京东用大模型做导购与客服，美团在本地生活验证；品牌方开始自建私域 agent。

**边界与走向**：购物 agent 若绕过平台直连商家，现有广告与佣金体系会被重写；短期看转化率与退货率的改善，长期看「谁替用户做决定」，入口价值会向 agent 迁移。

## 关键判断

离钱最近的 AI 场景：平台先受益，agent 可能重写入口（置信度 中高，展望 12–24 个月）——评估看「转化率提升 × 客服与素材人力替代率」；agent 与平台的入口博弈是最大变数。

规模口径：全球零售约 $30–32 万亿，电商约 $6–6.5 万亿（2025e）

## 二级细分

- **购物助手与 agent** — Rufus 类入口：从找商品、比价到代下单。
- **经营与供应链 AI** — 选品、动态定价、库存与履约调度。
- **营销素材与店铺** — 商品图、详情页与直播数字人的批量生成。
