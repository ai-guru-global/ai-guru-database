# 具身智能应用

> 人形机器人进入工厂与家庭：整机、场景与数据闭环的竞赛。

## 拆解卡

- **价值来源**：机器人进工厂与家庭，具身价值的兑现端。
- **护城河**：场景数据闭环与整机制造成本。
- **瓶颈**：场景泛化与经济性（回本周期）。
- **领先指标**：工厂部署台数与复购；家庭场景试点进度

## 六层速览

具身智能应用让机器人真正干活：进工厂、仓库、医院和家庭，完成物理世界的任务；它比软件 agent 难一个量级，因为错误不可回滚。

**打个比方**：像给机器人一份「工作说明书」——不仅要会动，还要会判断、会纠错、会协作；说明书越模糊，越依赖模型泛化，也越依赖现场数据。

**拆开看**：五段链路：本体与执行器 → 感知与定位 → 运动规划 → 任务策略（VLA 模型）→ 数据闭环与远程接管；可靠性、节拍与安全是第一指标。

**怎么运转**：卖机器人（硬件）+ 软件订阅 + 按任务或按产线收费；ROI 取决于替代人工的成本，回本周期超过三年就难卖，停机与维护成本常被低估，远程接管与保险也是隐性开支。

**格局与博弈**：Tesla、Figure、宇树、智元争人形整机，亚马逊、极智嘉在物流场景规模化，医院与工厂先落地；数据与场景是壁垒，量产良率与售后网络决定谁能交付，而失败案例的传播速度远快于成功案例。

**边界与走向**：通用人形仍需 3–5 年成熟，短期机会在「垂直场景 + 专用机器人」；VLA 模型与仿真数据是技术主线，量产、可靠性与安全认证是商业主线，两者节奏并不同步。

## 关键判断

长期空间大，短期收入集中在工业自动化与科研试点；人形量产与可靠性尚未验证，估值需业绩兑现（置信度 中低，展望 24–36 个月）——核心变量是量产成本与泛化能力；评估应以「出货量 × 投资回收期」为锚，而非演示视频。

规模口径：具身智能约 $30–60 亿（2025e），2035 年可达数千亿（长期预测，置信度低）

## 二级细分

- **工厂与仓储** — 最先跑通的场景：结构化环境 + 可量化 ROI。
- **家庭服务** — 终局最大但最远：安全与泛化双重门槛。
- **特种作业** — 高危/极端环境作业，政策与预算驱动。
