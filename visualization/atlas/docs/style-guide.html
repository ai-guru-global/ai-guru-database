AI Guru Knowledge Atlas · 视觉风格指南

主题解读：这是一个“知识宇宙的导航仪”。数据故事从“根节点 → 章节 → 主题 → 子话题”逐级展开，用户核心任务是 快速定位、理解关联、建立学习路径。因此视觉策略强调：清晰的层级、稳定的聚焦、可读的对比度与克制的动效。
风格方向
  • 气质：深空/编辑感（Space editorial），以大面积暗底与高对比点亮关键节点
  • 层级：根节点为“恒星”，章节为“行星环”，主题/子话题为“轨道粒子”
  • 信息密度：默认简洁，交互触发时局部增密（tooltip/详情/关联列表）

WCAG 2.2 AA：文本与背景对比度目标 ≥4.5:1；交互焦点 ring 使用半透明高亮，确保在暗/亮两套主题均可辨识。
排版与层级
  • 字体：系统无衬线优先，保证中文渲染一致与性能
  • 信息层级：title（18–28px）→ kicker（11px uppercase）→ 正文（13px）
  • 数字信息：统计卡与徽章使用高权重字重，强化“可扫读”
组件状态
  • Hover：局部高亮 + tooltip（不遮挡主体）
  • Selected：节点增强外发光 + 侧边栏详情锁定
  • Disabled：降低饱和度与 opacity，同时保留形状（避免信息丢失）
  • Focus：必须可见（键盘可达）；使用 :focus-visible 与 ring
布局与响应式
  • 桌面/4K：左侧信息面板固定宽度，右侧画布满屏可缩放
  • 平板/手机：侧边栏变为抽屉（menu + backdrop），不牺牲画布空间
  • 图谱元素：SVG 自适应容器；tooltip 自动避让边界
交付标准：WCAG 2.2 AA、对比度 ≥4.5:1、响应式无损、动效 200–400ms 且可被 reduced-motion 关闭；视觉回归测试覆盖核心状态。
