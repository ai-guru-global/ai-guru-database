# 投资研究视角

> 一句话：把 AI 网络看成一个 value pool（交换芯片/整机/光模块/连接器/网卡），用「GPU 出货 × 每卡网络价值量」做弹性测算，用路线里程碑做验证——本篇只给框架与公开口径，不构成投资建议。

## 核心问题清单

1. AI 网络的价值池怎么拆，各环节占比数量级多少？
2. 「每 GPU 网络价值量」怎么从配比公式推出来？
3. 哪些里程碑事件可以验证或证伪路线判断？
4. 技术路线风险：CPO、scale-up 统一化会怎么重塑价值池？

## 评估框架

### value pool 拆解（数量级估算）

口径：万卡 800G RoCE 三层网络 capex = 100%（假设同采购与TCO篇）。占比为数量级示意，以项目中标与公司披露复核（待核实）。

| 环节 | 占网络 capex | 竞争格局要点 |
|---|---|---|
| 光模块 | 45–55% | 中国厂商全球份额高；代际切换（800G→1.6T）重置份额 |
| 交换机整机 | 30–40% | 品牌机 vs 白盒拉锯；整机价值向芯片与光器件迁移 |
| 交换芯片 | 含于整机（占整机 BOM 约 30–50%，估算） | Broadcom 以 102.4T Tomahawk 6（2025，已核实）保持代际领先 |
| 网卡 | 8–12% | 与 GPU/超节点配套度高的厂商占优 |
| 连接器/线缆 | 5–10% | 高密化与 AEC 带来增量 |

### 弹性测算模板（每 GPU 网络价值量）

每卡价值量 = 模块数/卡 × 模块单价 + 交换端口/卡 × 每口单价 + 网卡单价 + 线缆/卡 × 单价。

1. 模块数/卡直接引用 [光模块配比经济学](../知识点/03-跨机网络/光模块配比经济学.md)：两层口径约 2–3 只/卡，三层口径约 4.5–6 只/卡——拓扑层数对模块需求的拉动不亚于速率代际。
2. 交换端口/卡：三层 1:1 约 0.03–0.05 台/卡（0.1–0.15 口/卡量级，估算）。
3. 敏感性：收敛比从 1:1 放松到 2:1，模块与端口需求近似减半（数量级口径）。

### 技术路线风险清单

1. CPO 替代可插拔：2026 起量（行业共识口径）后若渗透加速，可插拔模块环节的价值池被结构性压缩；跟踪 CPO 端口出货占比。
2. scale-up 域统一与扩大（NVL72 → NVL144）：跨网流量被摊薄，scale-out 模块与端口需求/卡 下行；scale-up 域扩张与模块配比必须联看。
3. 以太网统一（UEC）：开放生态若成熟，封闭路线的溢价被压缩；UEC 商用不及预期则格局延续。
4. 白盒化：整机价值持续向交换芯片与光器件迁移，品牌机份额与毛利承压。
5. 国产替代：国内市场价值池的份额结构重排，节奏取决于国产 GPU 出货。
6. 价格年降：光模块历史年降 10–20%（估算口径），出货增长部分被单价侵蚀。

本篇只提供研究框架与公开口径锚点，不构成任何投资建议；涉及公司仅作产业角色说明；所有财务与份额数字以公司披露与权威三方数据为准，标注「待核实」处不得直接引用为结论。

## 关键指标与基线

| 指标 | 数量级 | 口径 |
|---|---|---|
| 每卡网络价值量 | 数千美元（800G 三层，2025–2026 估算） | 弹性模板合计 |
| 模块/卡 | 两层 2–3、三层 4.5–6 | 配比公式 |
| 光模块年降 | 10–20% | 历史代际曲线 |
| 网络占集群 capex | 10–20% | 万卡口径（估算） |

## 常见误区

1. 把速率代际当唯一驱动：拓扑层数对模块需求的拉动同样大。
2. 只看出货不看单价：年降侵蚀下，量增不等于值增。
3. 用单季度数据外推路线胜负：CPO/UEC 渗透是多年爬坡。
4. 忽视 scale-up/scale-out 结构变化：超节点渗透率改变跨网配比，是最大的隐性变量。
