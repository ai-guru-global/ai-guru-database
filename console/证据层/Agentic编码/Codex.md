# Codex

> OpenAI 的编码智能体产品线：从 2021 年的代码模型，到 2025 年重启为云端编码 Agent，2026 年成为 OpenAI 对垒 Claude Code 的主力。

## 概述

Codex 最初是 OpenAI 2021 年推出的代码生成模型（code-davinci 系列，2023 年退役）。2025 年 OpenAI 以 GPT-5-Codex 重启该品牌为云端编码智能体，可在沙箱中并行执行多任务。2026 年，Codex 进入 ChatGPT 移动端、周活从 500 万增至 700 万，并配套收购 Ona 补强云端执行，成为 OpenAI 在 Agentic 编码赛道对抗 Claude Code 与 Cursor 的核心产品。

该线索追踪 Codex 的产品演进与用户规模；驱动它的 GPT-x-Codex 模型发布见 [[基础模型/GPT系列]]。
