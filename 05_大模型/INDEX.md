# NLP Llms

> 中文简称：大模型 ｜ English Name: NLP & LLMs

大模型知识域 — 覆盖 LLM 架构、训练、推理、微调、提示工程、多模态、推理模型等全方位大模型知识。

## 域简介

本域聚焦大语言模型技术：

- **架构设计**: Transformer、MoE、长上下文
- **训练推理**: 预训练、微调、部署优化
- **提示工程**: CoT、上下文工程、结构化输出
- **多模态**: 图文、音视频融合
- **推理模型**: o3/R1 类推理增强
- **生态对比**: 中外模型全景
