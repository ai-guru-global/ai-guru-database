# 推理模型与测试时计算

> 用推理时间换能力：思维链、自我验证与搜索让模型「先想后答」，把算力竞赛从训练侧延伸到推理侧。

## 拆解卡

- **价值来源**：预训练 Scaling 放缓后的第二段能力曲线：推理算力可以直接购买智能。
- **护城河**：奖励设计与可验证领域的后训练 know-how。
- **瓶颈**：过度思考与反向扩展（更长思考不总更好）；单位任务成本。
- **领先指标**：旗舰推理档与标准档的价差与采用率；推理算力占资本开支比重

## 六层速览

推理模型是「先想后答」的模型：把思考过程本身当作计算资源，答案质量随推理时间上升——买更多思考时间，就能买到更多智能。

**打个比方**：像考试先打草稿再作答——普通模型提笔就写，推理模型给自己留一张草稿纸，难题多打草稿、易题少打草稿；草稿（思维链）本身也成为产品的一部分。

**拆开看**：四个部件：思维链生成（CoT）→ 自我验证与反思 → 工具与搜索外化思考 → 思考预算调度（该想多久、何时停）；训练侧靠可验证奖励 RL（数学/代码/agent 轨迹），消费侧按 token 计费。

**怎么运转**：商业上「思考即用量」：推理档按更长的输出计费，成本与售价同升；能力上把预训练 Scaling 放缓后的增长曲线续接到推理算力上；工程上推理集群成为资本开支新主角。

**格局与博弈**：OpenAI o 系定义范式，DeepSeek R1 用开源把范式平权，各家旗舰标配混合推理（单模型开关思考档）；竞争焦点从「会不会想」转向「何时该想」的调度智能与单位任务成本。

**边界与走向**：反向扩展与过度思考证明「无脑拉长思考」存在负收益区间；走向自适应思考预算、外部化验证与按任务计费；推理算力占资本开支的比重是这条曲线是否持续的仪表。

## 关键判断

范式确立为默认能力，价值向推理算力与调度层集中（置信度 高，展望 12–24 个月）——核心观测是推理算力占资本开支比重与单位任务成本曲线；反向扩展是范式内部的主要修正力。

规模口径：推理算力与推理 API 合计数百亿美元（2026e），并已超过训练侧成为资本开支主项

## 二级细分

- **思维链与推理档** — CoT 与混合推理（单模型开关思考）成为旗舰标配。
- **可验证奖励 RL** — 数学、代码与 agent 轨迹：推理能力的训练侧来源。
- **过度思考与边界** — 反向扩展现象：思考预算调度成为新的工程问题。
