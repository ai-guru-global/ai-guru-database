# FDE 定价策略

## 核心定价原则

**按价值定价，不按人天定价。** 你能帮客户省 500 万，收 50 万就是便宜；你按人天收 100 万，客户觉得贵。

## 四种定价模式

### 模式 1：固定总价
```
适用：需求明确、范围清晰
优点：客户预算可控
缺点：范围蔓延风险
定价 = 估算人天 × 日费率 × 风险系数(1.2-1.5)
```

### 模式 2：人月计价
```
适用：需求模糊、长期合作
优点：灵活、降低风险
缺点：客户觉得你在"磨洋工"
定价 = 人月费率（5-15 万/月/人）
```

### 模式 3：混合定价（推荐）
```
固定价（核心交付物） + 人月价（弹性工作）
例如：RAG 系统 80 万 + 运维 5 万/月
```

### 模式 4：效果分成
```
按客户实际收益分成
适用：极度信任关系、可量化效果
风险：效果不好可能收不到钱
```

## 定价参考表（中国市场 2026）

| 项目类型 | 价格区间 | 推荐模式 |
|---|---|---|
| POC/试点 | 20-50 万 | 固定价 |
| 标准 RAG | 50-150 万 | 固定价 |
| AI Agent | 80-200 万 | 混合 |
| 企业 AI 平台 | 200-800 万 | 混合 |
| 年度运维 | 合同 15-20% | 年费 |

## 报价策略

1. **不第一个报价**：让客户先说预算，或了解竞对价格
2. **分档报价**：基础版/标准版/旗舰版，让客户有选择
3. **锚定效应**：先报高价方案，再报推荐方案
4. **年费锁定**：首年优惠换 3 年合同
