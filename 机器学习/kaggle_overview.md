# Kaggle 数据科学竞赛平台概览

> **一句话理解**: Google 旗下数据科学竞赛平台,提供海量数据集、免费 GPU Notebook 和百万级社区。

## 核心功能

| 功能 | 说明 |
|------|------|
| **竞赛** | 各类 ML/AI 竞赛,奖金从几百到百万美元 |
| **数据集** | 海量公开数据集,涵盖各领域 |
| **Notebook** | 免费 GPU/TPU 的在线编程环境 |
| **课程** | 免费 ML/DS 微课程 |
| **社区** | 讨论区、代码分享、排行榜 |

## 免费 GPU 配额

- GPU: NVIDIA Tesla P100 (16GB)
- 每周 30 小时 GPU 使用时间

## 推荐入门竞赛

| 竞赛 | 难度 | 主题 |
|------|------|------|
| Titanic | 入门 | 二分类(生存预测) |
| House Prices | 入门 | 回归(房价预测) |
| Digit Recognizer | 入门 | 图像分类(手写数字) |
