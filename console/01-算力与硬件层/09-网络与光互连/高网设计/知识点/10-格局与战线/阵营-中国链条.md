# 阵营：中国链条——光模块全球出货大头 + 国内设备闭环 + 国产超节点试验场

> 一句话定位：在全球光互连制造端占出货大头（旭创/新易盛 800G 双雄），在国内以华为/新华三/锐捷 + 国产 GPU 超节点自成闭环，并以 HPN/MegaScale 公开方法论证明 RoCE 路线的万卡级工程能力。

## 体系构成

| 层位 | 载体 | 事实锚点（口径基线） |
|---|---|---|
| 光模块制造 | 旭创、新易盛为 800G 双雄 | 光模块 CR5 约 60%，中国厂商占全球出货大头 |
| 光芯片 | 源杰等追赶者 | 高端 EML/硅光国产化率缺口大（量级待核实） |
| 国内设备闭环 | 华为、新华三、锐捷 | 国内数据中心交换机主力（份额量级待核实） |
| 国产 GPU 自组网 | 摩尔线程夸娥 kUAE 超节点（2025）、华为超节点方案（2025 发布，参数待核实） | 国产 GPU 阵营以超节点形态补单卡互连劣势 |
| 方法论背书 | 阿里 HPN、字节 MegaScale | HPN 15k GPU 双 ToR 双平面（SIGCOMM 2024）；MegaScale 12,288 GPU（NSDI 2024），均为 RoCE 系 |
| 十万卡预研 | 中兴 2026-02 白皮书 | 十万卡协议预留 GPU ID 空间 |
| 出海产能 | 东南亚基地 | 应对海外准入与关税（产能比例待核实） |

- 结构本质：制造端全球化（光模块卖全球云厂）+ 消费端内循环（设备与 GPU 国内闭环）的双轨结构，两轨的地缘风险敞口完全不同。
- 路线选择：国内大厂后端主路线是 RoCE 以太网（HPN/MegaScale 均为 RoCE 系），与全球"以太网统一"方向同向，不存在路线逆向风险。
- 价值链卡位：中国链条当前集中在利润池的制造段（光模块约 25%），而非最厚的技术段（交换芯片/光芯片合计约 40%）——卡位上移靠芯片国产化，卡位下探靠整网出海。

## 打法与护城河

1. 制造规模与成本：800G 时代中国厂商已占全球出货大头，规模摊薄+快速爬坡是核心壁垒；1.6T（2025H2 导入、2026 上量）若保持同步，份额惯性强。
2. 国内市场纵深：算力国产化给国产设备+国产 GPU+国产超节点完整试验场，需求确定性强，且中兴白皮书（2026-02）显示十万卡协议已在预研。
3. RoCE 工程化方法论：HPN/MegaScale 论文公开了双平面、双 ToR、轨道优化等工程细节，把"中国方法论"变成全球公共品，也垫高了国内交付能力下限。
4. 超节点卡位：夸娥 kUAE（2025）等国产超节点在 NVLink 不可得的约束下自拼 scale-up 域，方向上踩中"价值向机柜内互连再分配"的行业趋势。

## 软肋

1. 芯片缺口：交换芯片 Broadcom CR1 70%+ 的格局在国内同样存在（国产替代率待核实）；高端光芯片供给不足是 1.6T 放量的潜在瓶颈。
2. 生态碎片：国产 GPU 阵营多而散，互连与通信库各自为战，难以形成 NVLink+NCCL 式端到端兑现率。
3. 地缘与准入：光模块出海面临关税与准入扰动；海外客户集中于少数云厂，大客户集中度风险高。
4. 代际形态风险：CPO（2026 起量）时代若系统厂自研光引擎，模块厂价值环节被压缩——CPO 光引擎利润池仅约 3%（口径基线），远低于光模块的 25%。

## 胜负手与观察点

| 观察点 | 多头信号 | 空头信号 |
|---|---|---|
| 1.6T 同步放量 | 中国厂商 1.6T 出货与海外代际同步（2026 上量口径） | 份额落后 800G 时代一个身位 |
| 国产超节点成熟度 | 夸娥等超节点规模化商用、MFU 可对标 | 停在发布/小规模验证 |
| 整网方案出海 | 交换+光+运维整网方案进入海外市场（待核实） | 出海停留在光模块单品 |
| 高端光芯片国产化 | EML/硅光进入 800G/1.6T 主力 BOM | 高端仍依赖海外（量级待核实） |
| 中兴白皮书落地 | 十万卡协议进入实际部署 | 停留在纸面 |

- 台内主判断：中国链条是"以太网统一 + 光互连受益"两条主线的最大执行载体之一，其胜负直接改变全球光互连供给曲线与价格斜率。
