# 云厂商自研芯片

> 云巨头与前沿实验室绕开 NVIDIA 的自研算力线：TPU / Trainium / Maia / MTIA / Jalapeño，从「降本工具」演化为「算力主权」。

## 概述

自研 AI 芯片是云厂商垂直整合的核心武器：Google TPU 起步最早（2016 年即用于数据中心），Amazon Trainium、Microsoft Maia、Meta MTIA 相继跟进，2026 年 OpenAI 也以与 Broadcom 联合设计的推理芯片 Jalapeño 加入。共同动机是推理成本控制与供应链议价权，而 2026 年的算力短缺让这条线从「降本项目」升级为「产能生命线」。

与 NVIDIA 路线的本质差异：自研芯片只在垂直整合的云巨头内部闭环成立（模型—框架—芯片协同优化，如 TPU 与 JAX/PyTorch/XLA 的绑定），不追求通用市场。该线索从 [[推理与基础设施/AI芯片竞争]] 拆出，追踪各家自研芯片的产品迭代与部署规模。

## 分析

1. **推理是自研芯片的主战场**：Ironwood「为推理时代设计」、Maia 200「降 token 成本」、MTIA 400 部署推理——自研线的共同目标是吃掉对成本最敏感、对 CUDA 依赖最弱的推理负载，训练侧 NVIDIA 仍是默认项。
2. **自研芯片正在「商品化外溢」**：AWS 向 OpenAI 供应 2GW Trainium、Anthropic 与 SpaceX/xAI 的算力采购协议，说明自研算力开始跨公司流转，云厂商间「算力批发」成为新业务形态。
3. **Broadcom 是隐形赢家**：MTIA 扩产、Jalapeño 联合设计、Meta 2nm 加速器，Broadcom 承接了几乎所有「非 NVIDIA 自研线」的定制设计产能。
