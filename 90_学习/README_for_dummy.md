## 学习阶段体系

所有路径都建立在同一套概念层次上：

```
Stage 4: 前沿探索 ─── 多模态 · 世界模型 · VLA具身智能 · AGI
    ↑
Stage 3: 工程实践 ─── 部署推理 · RAG · 向量数据库 · Agent · MLOps
    ↑
Stage 2: 核心技术 ─── 神经网络 · 反向传播 · CNN/RNN · Transformer · LLM
    ↑
Stage 1: 基础概念 ─── 数据与特征 · 模型 · 训练/推理 · 过拟合 · 评估指标
    ↑
Stage 0: AI 觉醒 ─── AI 定义 · 三大类型 · 能力边界 · 经典案例
```
