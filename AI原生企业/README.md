## 1. 执行摘要

**我们是谁**：专注政企客户的私有化 AI 助手服务商，**"国产 ChatGPT 装在客户机房"**。

**我们卖什么**：
- **软件**：基于 Open WebUI（MIT 开源）+ 国产 LLM（DeepSeek/Qwen3/GLM4）的私有化部署方案
- **服务**：部署实施、定制开发、长期运维、行业知识库构建
- **不是**：我们不做基础大模型，不做通用 SaaS，**只做"装在客户机房里、按客户需求改"的那一环**

**为什么是现在**：
- 国产开源 LLM（DeepSeek、Qwen3）已达 GPT-4 水平 → 技术成熟
- 政企信创政策强制要求 → 政策推动
- 数据安全法、个人信息保护法倒逼本地化 → 合规刚需
- 央国企 AI 预算 2025-2026 集中释放 → 钱到位

**第一年目标**：
- 3-5 个付费客户
- 营收 150-300 万
- 跑通 1-2 个可复制的行业模板

**3 年愿景**：政企私有化 AI 助手细分赛道**前三**，年营收 5000 万-1 亿。

## 2. 产品与服务

### 2.1 三大产品线

| 产品线 | 内容 | 客单价 | 目标客户 |
|---|---|---|---|
| **PRIVAI 基础版** | 标准部署 + 1 个 LLM + 基础 RAG | 30-50 万 | 首次试水客户 |
| **PRIVAI 企业版** | 多模型 + 知识库 + 集成 SSO + 权限 | 80-150 万 | 主流央国企 |
| **PRIVAI 行业版** | 行业知识库 + 工作流 + AI Agent | 200-500 万 | 重点行业头部 |

### 2.2 服务内容

**一次实施**（项目制）：
- 现场/远程环境调研
- GPU 服务器选型（昇腾/海光/英伟达）
- 模型选型与微调（按客户数据）
- Open WebUI 定制化（UI/品牌/功能）
- 企业内部系统集成（OA/SSO/LDAP/工单）
- 知识库构建（文档解析、向量化、RAG 优化）
- 培训交付

**长期运维**（年费制）：
- 7×24 系统监控
- 模型升级与切换
- 知识库更新
- 安全漏洞修复
- 季度优化报告

**增值开发**（按人天）：
- AI Agent 工作流定制
- 行业插件开发
- 二次集成（与业务系统对接）

### 2.3 行业模板（已规划）

- **政务版**：政策问答、办事流程、文档写作助手
- **金融版**：合规审查、研报分析、智能客服
- **法律版**：法规检索、合同审查、判例推荐
- **医疗版**：临床指南、药品知识、患者教育
- **制造版**：工艺文档、质量分析、设备维护
- **教育版**：教学助手、论文写作、知识图谱

### 5.4 vs 公有云 AI

- **公有云**：便宜但数据出门、不可定制
- **我们**：贵但数据可控、深度定制

## 8. 技术架构

### 8.1 标准技术栈

```
┌─────────────────────────────────┐
│  客户端                          │
│  浏览器 / 桌面 / 移动端           │
└─────────────────────────────────┘
              ↕ HTTPS
┌─────────────────────────────────┐
│  接入层（Nginx / API Gateway）    │
└─────────────────────────────────┘
              ↕
┌─────────────────────────────────┐
│  Open WebUI（前端 + 业务逻辑）    │
│  - 用户管理 / 权限                │
│  - 对话界面 / 工作区              │
│  - RAG 引擎（文档解析 + 向量化）  │
│  - 插件系统 / Pipelines          │
└─────────────────────────────────┘
              ↕
┌─────────────────────────────────┐
│  LLM 推理层（Ollama / vLLM）     │
│  - DeepSeek V3 / Qwen3 / GLM4   │
│  - 私有化部署                     │
│  - GPU 池化（昇腾 / 海光 / A100）│
└─────────────────────────────────┘
              ↕
┌─────────────────────────────────┐
│  数据层                          │
│  - 文档库（MinIO / NAS）         │
│  - 向量库（ChromaDB / Milvus）   │
│  - 关系库（PostgreSQL）          │
│  - 缓存（Redis）                 │
└─────────────────────────────────┘
```

### 8.2 硬件推荐

| 规模 | GPU 配置 | 国产替代 | 预算 |
|---|---|---|---|
| 试点（<50 用户） | 1× A100 80G | 昇腾 910B | 30-50 万 |
| 标准（100-500 用户） | 4× A100 / 2× H100 | 昇腾 910B×4 | 80-150 万 |
| 大型（1000+ 用户） | 8× H100 / 集群 | 昇腾 910B×8+ | 200-500 万 |

### 8.3 关键技术决策

- **LLM 选型**：默认 DeepSeek V3（性能/成本最优），Qwen3（多语言强），GLM4（中文强）
- **向量库**：100 万条以下用 ChromaDB，以上用 Milvus
- **文档解析**：自建 + PaddleOCR（中文友好）
- **RAG 优化**：混合检索 + ReRank + Query 改写
- **安全**：等保三级方案 + 国密算法

## 9. 竞争分析

### 9.1 主要竞争者

| 类别 | 代表 | 优势 | 劣势 | 我们怎么打 |
|---|---|---|---|---|
| **头部云厂商** | 华为云、阿里云、腾讯云 | 品牌强、产品全 | 贵、绑定深、只卖全家桶 | 强调"轻量级 + 灵活" |
| **AI 创业公司** | 智谱、百川、零一万物 | 模型好、技术强 | 不懂政企、要绑定 API | 强调"模型中立 + 私有化" |
| **传统 SI** | 神州数码、东软、太极 | 政企关系深 | AI 能力弱、方案老 | 强调"AI 原生 + 现代" |
| **本地化集成商** | 区域 ISV | 价格低、本地化 | 不可复制、规模小 | 强调"可复制 + 全国" |

### 9.2 SWOT 分析

**Strengths（优势）**：
- ✅ 政企 10+ 年关系积累
- ✅ 阿里云原厂出身，懂云
- ✅ Open WebUI 等开源玩得溜
- ✅ 商业模式轻（不需要重资产）

**Weaknesses（劣势）**：
- ❌ 没有品牌（创业初期）
- ❌ 没有标杆案例
- ❌ 团队小（需要快速补人）
- ❌ 资金不充裕

**Opportunities（机会）**：
- 🌟 政企信创强制要求
- 🌟 国产 LLM 技术成熟
- 🌟 数据合规要求
- 🌟 DeepSeek 引爆市场

**Threats（威胁）**：
- ⚠️ 头部云厂商降维打击
- ⚠️ 价格战（云厂商补贴）
- ⚠️ 信创目录门槛
- ⚠️ 政企付款周期长

| Y1 | 8-12 | 600-900 万 | 10 人 | 30-40% |
| Y2 | 25-40 | 2500-4000 万 | 20 人 | 40-50% |
| Y3 | 60-100 | 6000 万-1 亿 | 40 人 | 50-55% |

### 13.3 成本结构

```
人力成本 ........ 50-60%
硬件成本 ........ 15-20%（含 GPU 折旧）
销售成本 ........ 10%
运营 / 房租 .... 5-10%
营销 / 大会 .... 3-5%
```

### 13.4 单客户经济模型

- **首单客单价**：50-100 万
- **年费续费**：15-20 万
- **3 年 LTV**：100-200 万
- **CAC**（获客成本）：10-30 万
- **LTV/CAC** = **5-10**（健康）

## 14. 风险与缓解

| 风险 | 影响 | 概率 | 缓解 |
|---|---|---|---|
| 头部云厂商降价 | 高 | 中 | 强调"轻量 + 灵活"差异化 |
| 信创目录未入围 | 高 | 中 | 提前申报 + 国产化适配 |
| 客户付款周期长 | 中 | 高 | 合同约定 + 行业筛选 |
| 团队招不到人 | 高 | 中 | 远程 + 兼职 + 股权 |
| 政策变化 | 中 | 低 | 多行业布局分散风险 |
| 数据安全事件 | 极高 | 低 | 等保三级 + 灾备 + 保险 |
| 创始人风险（健康/关系） | 高 | 低 | 团队梯队 + 核心人员绑定 |

### 14.1 合规与法律

- **等保三级**：所有项目必过
- **数据安全法**：本地化部署 + 数据不出门
- **个保法**：训练数据脱敏
- **开源协议**：遵守 Open WebUI / Ollama / DeepSeek 协议
- **知识产权**：核心代码自主可控

## 15. 融资需求

### 15.1 不融资也能跑

- **0 融资路径**：首年自负 100-200 万启动
- **关键**：第 1 个客户回款后即可滚动

### 15.2 融资价值

- **加速团队建设**（招到顶级人才）
- **加快产品研发**（行业模板）
- **市场扩张**（大会 + 渠道）

### 15.3 融资节奏

| 轮次 | 金额 | 时间 | 用途 |
|---|---|---|---|
| **天使** | 200-500 万 | M3-M6 | 团队 + 早期客户 |
| **Pre-A** | 1500-3000 万 | M12-M18 | 行业模板 + 渠道 |
| **A 轮** | 5000 万-1 亿 | Y2 | 规模化 + 资质 |

### 15.4 投资人选择

- **优先**：政企背景的 FA、政企方向 VC、AI 行业 VC
- **避免**：纯财务 VC、互联网 VC（不懂政企节奏）
- **参考**：奇绩创坛、源码资本、IDG 政企组、招商局创投
