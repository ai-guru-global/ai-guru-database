# 阿里云 IoT（阿里巴巴集团云智能集团旗下业务单元）
> 中文简称：阿里云 IoT

> **模块**：机构深度研究 / AIoT 平台｜**机构速览卡**
> **数据时点**：财务为 FY2027Q2（2026 年 9 月止季度，2026-11-19 披露）与 FY2026 年报（2026-05-13 披露）；IoT 收入不单独披露，财务均用集团分部口径｜本文不构成投资建议

> **一句话理解**: 它把 IoT 当成云计算的"接入层"而不是一门独立生意——设备连上来是为了用云和 AI，IoT 本身从不单独向股东交卷。

## 一页速览

| 维度 | 内容 |
|------|------|
| 全称 / 设立 | 阿里云 IoT（Alibaba Cloud IoT），非独立法人业务单元；2014 年"阿里小智"起步，2018-03-28 宣布全面进军物联网 |
| 母公司 / 分部归属 | 阿里巴巴集团（NYSE: BABA / HKEX: 9988）旗下云智能集团；2026-06 起财报口径并入"AI 云与计算服务"分部；无独立股权、市值与股东 |
| 行业地位 | Omdia 口径 2025 年中国 AI 云市场份额 38.1% 居第一（2026-08-20 财报转引）；Gartner 2026 战略云平台服务魔力象限亚太唯一领导者（2026-11-19 财报转引） |
| 最新业绩（分部口径） | FY2027Q2"AI 云与计算服务"收入 609.73 亿元（+53%），对外客户收入 +64%；IoT 收入不单独披露 |
| 关键指标 | AI 相关产品收入 179.18 亿元（2026-09 止季度），连续 13 个季度三位数同比增长；云分部 EBITA 利润率 14.5%（CFO 口径） |
| 业务标签 | 企业物联网平台 + 边缘计算 + 天猫精灵消费入口 + 通义大模型端云协同 |
| 代表产品或资产 | 阿里云物联网平台（高可用实例 SLA 99.99%）、Link Edge 边缘一体机、天猫精灵（AliGenie）、通义千问 |
| 代表人物 | 集团 CEO 吴泳铭（兼云智能集团代理董事长兼 CEO，2023-09-10 生效至今）；阿里云 CTO 周靖人 |
| 生态位 | 云大厂附属业务型：IoT 为云引流、不单独定价，对照涂鸦智能（中立平台型，2025 年收入 3.22 亿美元） |
