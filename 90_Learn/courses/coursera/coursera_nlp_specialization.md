# NLP 专项课程 (Coursera)

> **一句话理解**: Coursera NLP 专项课程(DeepLearning.AI),覆盖情感分析、机器翻译、注意力机制、Transformer 等 NLP 核心技术。

## 课程概况

- **平台**: Coursera
- **讲师**: DeepLearning.AI
- **链接**: [NLP Specialization](https://www.coursera.org/specializations/natural-language-processing)
- **时长**: 约 4 个月
- **费用**: 可免费旁听

## 课程内容

| 课程 | 主题 |
|------|------|
| 课程 1 | 情感分析与逻辑回归 |
| 课程 2 | 词嵌入与神经网络 |
| 课程 3 | 序列模型(RNN/LSTM) |
| 课程 4 | 注意力机制与 Transformer |

## 适用人群

- 想系统学习 NLP 的工程师
- 有 Python/ML 基础想进入 NLP 领域的开发者
