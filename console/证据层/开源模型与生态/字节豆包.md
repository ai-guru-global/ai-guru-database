# 字节豆包

> 字节跳动的豆包大模型系列，以亿级用户基础和多模态全家桶见长的中国头部模型。

## 概述

豆包（Doubao）是字节跳动 Seed 团队的大模型系列，支撑豆包 App（亿级用户）与火山引擎 To B 业务。2025 年豆包以低价 API + 巨量调用成为中国调用量最大的模型之一。Seed 体系下还有 Seedance（视频）、Seedream（图像）、Doubao-Seed-Audio（语音）等子模型。

2026 年豆包进入「跨代升级」，2.0 / 2.1 系列对标 GPT-5.5 / Claude Opus 4.7 / Gemini 3.1，编程能力进入国际第一梯队。该线索追踪豆包 Seed 系列演进。
