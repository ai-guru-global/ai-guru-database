# HBM 与存储

> 高带宽内存是 AI 芯片的搭配刚需，产能分配直接影响 GPU 供给。

## 拆解卡

- **价值来源**：HBM 是 AI 芯片的标配刚需，堆叠容量决定单卡能力上限。
- **护城河**：三家寡头格局与 DRAM 工艺深度耦合，新进入者周期以年计。
- **瓶颈**：HBM 产能分配（大客户优先）与堆叠良率。
- **领先指标**：HBM 合约价与预订量；单卡 HBM 容量趋势

## 六层速览

HBM 是把多层内存垂直叠起来的高带宽显存：AI 芯片算得再快，数据喂不上来也只能空转；HBM 决定「喂料速度」，也决定单卡能跑多大的模型。

**打个比方**：像把仓库从「单层平房」改成「高层货架 + 超宽电梯」：同样的占地，单位时间搬运的数据量高几倍；但楼层越高，良率越难保，造价越贵。

**拆开看**：四段链路：DRAM 晶圆 → TSV 打孔 → 多层堆叠 → 与 GPU 共同封装（2.5D / 3D）；容量、带宽、功耗、良率四项互相拉扯，层数越多越难做。

**怎么运转**：SK 海力士、三星、美光按合约价供货，英伟达、AMD、云厂商提前锁定产能；HBM 挤占普通 DRAM 产能，带动存储周期上行，价格随 AI 需求波动。

**格局与博弈**：SK 海力士领先 HBM3E / HBM4，三星追赶，美光聚焦高价值客户；中国长鑫存储起步，受设备与专利约束；封装产能（CoWoS）与 HBM 供给共同卡住 AI 芯片出货。

**边界与走向**：带宽墙从「芯片内」转向「封装内」，HBM 层数、定制 base die 与混合键合成为新战场；长期看存算一体与近存计算是期权，但短期仍是「堆得更高、贴得更近」。

## 关键判断

周期成长，紧跟 GPU 节奏（置信度 中，展望 12 个月）——价格与产能利用率是核心跟踪项；HBM4 验证结果是份额重排的分水岭。

规模口径：HBM 市场约 $250–350 亿（2025e），占 DRAM 总市场约 15–20%，但贡献了存储行业多数增量利润

## 二级细分

- **HBM 堆叠** — AI 显存刚需，产能分配决定 GPU 出货
- **DRAM 主存** — 服务器与端侧基本盘，周期性强
- **NAND 闪存** — 企业级 SSD 与存力，AI 数据湖底座
