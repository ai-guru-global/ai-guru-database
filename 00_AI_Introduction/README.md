# 00 - AI 简介与历史

本章节提供人工智能的全面入门知识，适合大专院校AI通识课教材使用。内容涵盖AI基础概念、技术全景、历史发展、工具实践、伦理影响、未来趋势和学习方法，为零基础读者建立完整的AI认知框架。

- **零基础友好**: 无需编程或数学背景，从概念开始

- **实践导向**: 包含工具使用指南和学习方法论
- **与时俱进**: 涵盖2026年最新AI发展趋势
