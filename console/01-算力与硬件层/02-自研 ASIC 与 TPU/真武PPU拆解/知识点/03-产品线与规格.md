# 03 · 产品线与规格：810E / M890 / V900

> 三档产品线的规格全景与可用性状态。一手锚点：[真武 PPU 官方页](https://www.aliyun.com/ppu)（2026-11-06 检索）；官方全线未披露峰值算力（TFLOPS）。

## 三档产品线

| | 810E | M890 | V900 |
|---|---|---|---|
| 定位（官方） | 高易用训推一体 AI 芯片 | 全场景训推一体 AI 芯片 | 下一代训推一体 AI 芯片 |
| 单卡内存 | 96 GB HBM2e | 96 / 144 GB | 216 GB |
| 片间互联带宽 | 700 GB/s | 800 GB/s | 1200 GB/s |
| 互联规模 | 16 卡聚合整机 | 64 卡全带宽互联 | 千卡全带宽 Scale-Up |
| 低精度 | — | FP8 / FP4，官方称性能提升 3 倍（自述口径） | FP8 / FP4，百 TB 级统一显存 |
| 状态 | 北京/杭州/上海/乌兰察布商用 | 乌兰察布商用；中卫邀测 | 「敬请期待」，未商用 |

配套整机：灵骏超节点 GP9A / GP9AS 实例（64 卡，9TB / 6TB 显存口径）。

媒体补充口径（⚠️ 非官方）：810E 整板功耗 400W、PCIe 5.0 ×16；峰值算力 ~120 TFLOPS 仅见于社区口径（❓ 挂待核实清单第十节，不得引用）。

## 命名口径

官方名「真武 PPU（Parallel Processing Unit）」；2026-01 官宣初期 TrendForce 等媒体称「镇宇 810E」。本库以官方页为准，「镇宇」作别名（关系待一手源确认，挂待核实清单第十节）。

## 为什么「不披露 TFLOPS」值得单独一条

两种解读并存（观点层）：

1. **营销路线论**：TPU 式打法——Google 同样从不主打纸面参数，卖单位经济与端到端性价比；对采购决策者，每 token 成本比 TFLOPS 更有意义。
2. **参数不占优论**：训练旗舰市场竞争以峰值算力锚定叙事，不披露意味着 810E 的绝对算力相对 H100/B 级不占优， disclosure 只会强化「替代位」标签。

两种解读不互斥。可操作的推论：**评估 PPU 不要问「算力多少」，要问「同负载下每 token 成本与迁移成本」**——这正是官方希望引导的比较维度（→ [04-规格对标](04-规格对标.md)、[07-售卖与单位经济](07-售卖与单位经济.md)）。

## 产品线递进读出的战略：scale-up 优先

三档的升级轴不是算力而是**显存 × 互联**：96→216GB、700→1200GB/s、16→千卡全带宽。推理时代大 MoE 模型吃显存池不吃单卡峰值（Kimi K3.1 Pro 在 M890 超节点上 Day0 适配即为例证），这是 NVL72 路线的国产对位，方向判断正确（→ [行业拆解 §3](../行业拆解.md)）。
