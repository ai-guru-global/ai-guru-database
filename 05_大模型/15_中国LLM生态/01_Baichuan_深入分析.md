## 3. 核心技术架构

### 3.1 Baichuan 基础架构

```
Baichuan 模型架构:
════════════════════════════════════════════════════════════════════

  输入 Token IDs
       ↓
  ┌─────────────────────────────────────┐
  │         Token Embedding             │
  │         (125K 词表)                 │
  └──────────────┬──────────────────────┘
                 ↓
  ┌─────────────────────────────────────┐
  │    Transformer Decoder Layers × N   │
  │  ┌──────────────────────────────┐   │
  │  │  RMSNorm                     │   │
  │  │  ↓                           │   │
  │  │  Grouped Query Attention      │   │
  │  │  (GQA, 8 KV heads)           │   │
  │  │  ↓                           │   │
  │  │  RMSNorm                     │   │
  │  │  ↓                           │   │
  │  │  SwiGLU FFN                  │   │
  │  │  ↓                           │   │
  │  │  RoPE (旋转位置编码)          │   │
  │  └──────────────────────────────┘   │
  └──────────────┬──────────────────────┘
                 ↓
  ┌─────────────────────────────────────┐
  │         LM Head                     │
  └─────────────────────────────────────┘
```

### 3.3 关键设计决策

```
Baichuan 设计哲学:
───────────────────────────────────────────────────────────────────

  1. 词表优化:
     • Baichuan-1: 64K 词表 → 中文效率一般
     • Baichuan-2: 125K 词表 → 中文压缩率提升 30%
     • 采用 BPE 分词，中文以 UTF-8 字节为基础

  2. 注意力优化:
     • Baichuan-1: 标准 MHA (Multi-Head Attention)
     • Baichuan-2: GQA (Grouped Query Attention)
     • KV 头从 32/40 减少到 8，推理速度提升 40%

  3. 训练策略:
     • 3.5T tokens 高质量中英文数据
     • 去重、过滤、质量评估流水线
     • 分阶段训练: 预训练 → SFT → RLHF
```

## 4. Baichuan-4 深度解析

### 4.1 架构概览

Baichuan-4 是百川智能的闭源旗舰模型，采用 MoE (Mixture of Experts) 架构。

```
Baichuan-4 MoE 架构:
════════════════════════════════════════════════════════════════════

  ┌──────────────────────────────────────────────────┐
  │                  输入 Token                       │
  └─────────────────────┬────────────────────────────┘
                        ↓
  ┌──────────────────────────────────────────────────┐
  │              Router (路由器)                      │
  │  Token → Top-K Expert Selection                  │
  │  输出: 每个token选择 Top-2 专家                    │
  └────────────┬──────────────┬──────────────────────┘
               │              │
        ┌──────v──┐    ┌──────v──┐
        │ Expert 1│    │ Expert 2│  ... × N experts
        │ (FFN)   │    │ (FFN)   │
        └──────┬──┘    └──────┬──┘
               │              │
               └──────┬───────┘
                      ↓
              Weighted Sum → Output
```

### 4.2 Baichuan-4 关键参数

| 参数 | 值 |
|------|------|
| 总参数量 | ~500B+ (估计) |
| 激活参数量 | ~50B (估计) |
| 专家数量 | ~64 (估计) |
| 激活专家数 | ~8 per token |
| 上下文长度 | 128K |
| 训练数据 | 万亿级 tokens |
| 核心能力 | 搜索增强 + 深度推理 |

### 4.3 搜索增强生成 (SAG)

百川独特的搜索增强生成流程：

```
Baichuan Search-Augmented Generation:
════════════════════════════════════════════════════════════════════

  用户查询: "2024年诺贝尔物理学奖的得主是谁？"
       ↓
  ┌───────────────────────────────────────┐
  │ Step 1: 查询分析                       │
  │ • 判断是否需要搜索 (时效性判断)         │
  │ • 生成搜索关键词                       │
  │ • 确定搜索策略                         │
  └───────────────┬───────────────────────┘
                  ↓
  ┌───────────────────────────────────────┐
  │ Step 2: 多路检索                       │
  │ • 自研搜索引擎检索                     │
  │ • 知识库检索                          │
  │ • 多源结果聚合                         │
  └───────────────┬───────────────────────┘
                  ↓
  ┌───────────────────────────────────────┐
  │ Step 3: 相关性排序                     │
  │ • 段落级相关性打分                     │
  │ • 去重与冲突检测                       │
  │ • Top-K 段落筛选                       │
  └───────────────┬───────────────────────┘
                  ↓
  ┌───────────────────────────────────────┐
  │ Step 4: 增强生成                       │
  │ • 检索结果 + 用户问题 → 联合编码       │
  │ • 基于证据生成回答                     │
  │ • 引用标注 (来源链接)                  │
  └───────────────────────────────────────┘
                  ↓
  输出: "2024年诺贝尔物理学奖授予John Hopfield和Geoffrey Hinton..."
        [引用: 诺贝尔官网 | 新华网 | ...]
```

## 10. API 与部署

### 10.1 API 调用示例

```python
from baichuan import BaichuanClient

client = BaichuanClient(api_key="your-api-key")

response = client.chat(
    model="baichuan-4",
    messages=[
        {"role": "user", "content": "请分析2024年中国GDP增长趋势"}
    ],
    temperature=0.7,
    top_p=0.9,
    max_tokens=2048,
    enable_search=True
)

print(response.choices[0].message.content)

for citation in response.citations:
    print(f"来源: {citation.title} - {citation.url}")
```

### 10.3 本地部署

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained(
    "baichuan-inc/Baichuan2-13B-Chat",
    trust_remote_code=True
)
model = AutoModelForCausalLM.from_pretrained(
    "baichuan-inc/Baichuan2-13B-Chat",
    device_map="auto",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True
)

messages = [{"role": "user", "content": "你好，请介绍一下你自己"}]
response = model.chat(tokenizer, messages)
print(response)
```

### 11.2 百川的优势与挑战

**优势：**
- 搜索增强: 源自搜狗的搜索基因，搜索增强生成国内领先
- 垂直领域: 医疗 Baichuan-M1 在中文医疗场景表现突出
- 快速迭代: 从成立到发布旗舰模型仅用 13 个月
- 团队经验: 搜索 + NLP 的复合背景

**挑战：**
- 开源模型性能落后于 Qwen2 同级别
- 闭源旗舰 Baichuan-4 在第一梯队中存在感偏弱
- 社区活跃度不如 Qwen、ChatGLM
- 多模态能力尚未充分展现
